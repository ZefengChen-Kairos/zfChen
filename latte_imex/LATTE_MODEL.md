这份文档是**要实现的完整模型**的唯一依据：从奶罐给出的落点量开始，到杯面上看到的白度场为止。

- 屈服应力那一项的推导细节见 `YIELD_FILM_DERIVATION.md`，这里只给结论。

**状态**

## 0. 审查与修正记录（v1 → v2）

审查 v1 时发现两处硬伤：

**修正 1：新加入表面的物质没有动量。**
v1 代码里，双层模型的动量源 s_mom 为零：浮上来的奶泡、上涌的褐色表面都以**静止状态**加入膜，相当于一个拉向静止的假阻力。落点附近 s ≈ S·K ≈ 40 /s、卷吸胞内 D_s ≈ 10 /s，都远大于拖曳 β ≈ 2 /s，正好作用在形成褐缝的区域。v1 文档里 v* = (s_f U_s + Λ v_jet)/(s_f + Λ) 的写法把"新物质带着咖啡速度"和"射流牵引"混在了一起。
v2：新物质以表面速度 U_s 加入（动量源 s·U_s）；射流牵引的目标速度就是 v_jet。

**修正 2：厚度单位 "1" 同时当作咖啡深度和膜厚。**
v1 的势流按"深度 = 1"计算速度，而由 k_Q = 1.33 反推，这个 1 ≈ D_L/k_Q ≈ 6 cm，是咖啡深度；同一个 1 又被当作表面膜的参考厚度，于是 c = m/ℓ 实际上是"奶泡占整个液柱的比例"，不是表面覆盖度；c_p、φ_foam、SSA 薄膜近似的物理含义都依赖这个尺度，拟合值靠互相补偿凑出来（比如 φ_foam 拟合到 0.9，换算后相当于只有 1/20 的奶泡进入膜）。
v2：
- 势流用咖啡深度 H，膜用漂浮层参考厚度 H_f，k_Q 被两个可测的厚度替代；
- 膜 = **漂在咖啡上的东西**（crema + 奶泡），ℓ = 漂浮层厚度 / H_f，m = 奶泡厚度 / H_f；
- 咖啡上涌、下沉不再需要源项：上涌处表面散开，漂浮层被拉薄，奶泡变薄就透出褐色；射流处表面汇聚，漂浮物有浮力下不去，就在那里堆积。v1 的"上涌生成褐色表面、只卷下褐色液"两个源项删除；
- 可见白度改为奶泡层的不透明度 W = 1 − exp(−m/m_o)；
- 膜内压力来自漂浮层的浮力，c_p² = g′ H_f / D_L，不再是自由参数，和奶泡存活、上浮时间用同一个 g′；
- 拖曳改为膜底的剪切应力，与膜厚无关，所以对动量方程是 −β₀(u − U_s)，即 v1 的 β 变成 β₀/ℓ（v1 审查的第 5 点；单位一致后 ℓ 的变化范围从 1 附近扩大到 0–6，这一项必须改）。

修正后所有拟合参数作废，要重新拟合（参数的物理含义变了）。

## 1. 输入：奶罐模型给出的落点量

奶罐模型每帧（1/120 s）给出**本帧落到咖啡上**的那份奶（已含飞行时延）：

| 量 | 符号 | 单位（SI） | 来源 |
|---|---|---|---|
| 到达流量 | Q | m³/s | 堰流律 → 壶嘴通道 → 飞行中的奶团按到达时间窗口分配 |
| 落点 | x_hit | m | 抛体运动落到 z = 0 |
| 法向冲击速度 | U⊥ | m/s | 落点处的竖直速度 |
| 水平速度 | u_h | m/s | 出口速度的水平分量 + 壶的速度 |
| 足迹椭圆 | r₁, r₂, φ | m, rad | 唇沿通量矩给出出口液片，表面张力在毛细时间内把它收圆 |

### 1.1 换成杯面单位（纯量纲换算，没有拟合常数）
- 落点 x = x_hit / D_L；U⊥ ← U⊥/D_L，u_in ← u_h/D_L，水平速度限幅 |u_in| ≤ U⊥ tan 60°（射流倾角上限，建模选择）；
- 足迹 r₁, r₂ ← r₁/D_L, r₂/D_L；射流直径 d = 2√(r₁ r₂)；
- **体积强度（给咖啡）**：S_v = Q / (H D_L²)  [1/s]（倒入的全部体积，奶液和奶泡都算，都要先把咖啡推开）
- **体积强度（给漂浮层）**：S_f = Q / (H_f D_L²) = S_v · H/H_f  [1/s]

### 1.2 足迹核
紧支撑椭圆核，在杯内归一化：

  K(x) ∝ max(0, 1 − a² − b²)²，a = ((x − x_hit)·e₁)/r₁，b = ((x − x_hit)·e₂)/r₂，∫_cup K dA = 1

半轴下限 1.5h，网格内自适应子格求积（3×3 起，薄足迹时更密，上限 12×12）。

## 2. 物理模型

### 2.1 杯面上的三样东西
1. **漂浮层（膜）**：漂在咖啡上的 crema 和奶泡。状态量：漂浮层厚度 ℓ = h/H_f、动量 q = ℓu、奶泡厚度 m = h_foam/H_f（0 ≤ m ≤ ℓ）。初始 ℓ = 1、m = 0（整杯一层 crema）。
2. **水下奶泡**：被射流带进咖啡里、还没浮上来的奶泡 f（同样以 H_f 为单位的体积/面积），以及上浮时间常数的矩 g = f·τ_f。
3. **咖啡**：漂浮层下面的液体，深度 H。它的水平流动由两个准稳态势流给出（第 2.3 节），不单独求动量。

### 2.2 落点闭合（每帧由输入算出，帧内冻结）

| 量 | 表达式 | 物理意义 |
|---|---|---|
| 密度 Froude 数 | Fr² = U⊥² / (g′ d) | g′ = g(1 − ρ_f/ρ) 是奶泡的约化重力 |
| 奶泡存活率 | χ = 1 / (1 + (Fr²/Fr_c²)^p) | 冲得越猛，奶泡破得越多（经验形式） |
| 水下奶泡源 | F = χ · φ_foam · S_f · K | φ_foam：倒出的奶里奶泡的体积分数（打发后体积比可测） |
| 上浮时间 | τ_new = max(2U⊥/g′, 10⁻³ s) | 浮力喷泉的上升时间（弹道估计） |
| 卷吸体积通量 | E = ent · Fr · Q | Ricou–Spalding 0.32 z/d × Turner 喷泉深度 2.32 Fr d → ent ≈ 0.74 |
| 卷吸胞半径 | R_c = min(cell_frac · 2.32 Fr d, 0.45) | 胞的尺度和喷泉深度成正比 |
| 射流牵引强度 | Λ = κ_c · S_f · K | 射流把它打到的漂浮层往自己的水平方向拖 |
| 牵引目标速度 | v_jet = κ_t · u_in | |

### 2.3 咖啡：两个准稳态势流（每帧解一次）
**体积铺展**（深度平均，表面和深层相同）：
  ∇·U_v = S_v (K − ⟨K⟩)

**射流卷吸胞**：射流把咖啡拖下去，在半径 R_c 内涌上来；竖直环流深度平均为零。设环流的上、下两支各占一半深度（h_s = H/2），表面支的体积通量 E 给出

  ∇·U_c = S_E (K_c − K)，S_E = E / (h_s D_L²) = 2 · ent · Fr · S_v

（K_c：以落点为圆心、半径 R_c（至少 2h）的圆盘上的均匀分布。）

- 表面速度 U_s = U_v + U_c：拖着漂浮层走；
- 深层速度 U_d = U_v − U_c：带着水下奶泡走（下支与上支等厚，所以回流速度与表面支大小相同、方向相反）。

### 2.4 水下奶泡
  ∂f/∂t + ∇·(U_d f) = F − f/τ_f
  ∂g/∂t + ∇·(U_d g) = F τ_new − g/τ_f，τ_f = g/f

上浮是无记忆的指数过程：f 和 g 以同一比例减少，τ_f 只因新奶泡混入而改变。浮出速率 s_f = f/τ_f。

### 2.5 漂浮层
**质量**：
  ∂ℓ/∂t + ∇·q = s_f + s_skin

- s_f：浮上来的奶泡；
- s_skin = ℓ_skin · max(∇·U_s, 0)：新露出的咖啡表面带一层很薄的表面皮（表面活性物质）。这是为了让 ℓ 不降到零（干湿边界）的正则化，ℓ_skin ≈ 0.02–0.05，结果应对它不敏感。

上涌处表面散开，漂浮层随 U_s 被拉薄；射流处表面汇聚，漂浮层堆积。不再有"生成褐色表面""卷下褐色液"的源项。

**奶泡**：
  ∂m/∂t + ∇·(c q) = s_f + ∇·(ℓ D_m ∇c)，c = m/ℓ（奶泡在漂浮层中的比例）

**动量**：
  ∂q/∂t + ∇·(q⊗u) = −c_p² ℓ∇ℓ − β₀ (u − U_s) + Λ (v_jet − u) + (s_f + s_skin) U_s + ∇·(ℓ T/ρ)

- −c_p² ℓ∇ℓ：漂浮层的浮力压力，c_p² = g′ H_f / D_L（模型单位：g′ 用 D_L/s²，H_f/D_L 无量纲）；
- −β₀(u − U_s)：膜底的剪切应力，与厚度无关（所以对速度的作用是 β₀/ℓ，薄的地方紧跟咖啡，厚的奶泡块跟得慢）；
- Λ(v_jet − u)：射流牵引；
- (s_f + s_skin) U_s：新加入的物质带着表面流的速度（修正 1）；
- ∇·(ℓT/ρ)：面内应力（第 2.6 节）。

### 2.6 面内应力：浮在液体上的 Bingham 薄膜
漂浮层很薄（h ≪ 图案尺度），上表面无应力，下表面在咖啡上滑动（滑动阻力就是 β₀ 项）。对厚度积分得到 shallow-shelf（SSA）形式：

  T/ρ = 2 ν_eff (D + (tr D) I)
  T_xx/ρ = 2ν_eff (2u_x + v_y)，T_yy/ρ = 2ν_eff (u_x + 2v_y)，T_xy/ρ = ν_eff (u_y + v_x)

奶泡是粘塑性的（Bingham）：

  ν_eff = min( ν + τ̂(c) / (2|D|_e + ε), ν_max )，|D|_e² = u_x² + v_y² + u_x v_y + ¼(u_y + v_x)²
  τ̂(c) = c τ̂_foam + (1 − c) τ̂_crema，先取 τ̂_crema = 0

ℓ·τ̂(c) = m τ̂_foam + (ℓ − m) τ̂_crema：屈服力和奶泡厚度成正比。
适用范围：SSA 要求厚度远小于水平尺度。拉花后期白区的奶泡可以厚到 1–2 cm，和图案尺度只差几倍，这时 SSA 只是近似。

### 2.7 可见白度
奶泡层越厚越不透明：

  W = 1 − exp(−m / m_o)

m_o 是让奶泡层透光率降到 1/e 的厚度（以 H_f 为单位，预计 0.1–0.3，即 0.3–1 mm）。crema 本身是褐色的，不计入白度。和目标图比较时直接用 W。

## 3. 边界条件与初始状态

**杯域**：半径 0.49 杯径的圆盘，用网格掩码表示；杯外单元保持 ℓ = 1、q = 0、m = 0、f = g = 0。

| 量 | 杯壁条件 | 离散 |
|---|---|---|
| ℓ、m | 零通量 | 关闭面的通量为零 |
| q | 无穿透；面内应力为零（自由滑移） | 关闭面不计入 Rusanov 通量和粘性泛函 |
| f、g | 零通量 | 关闭面的迎风通量为零 |
| φ_v、φ_c | Neumann（∂φ/∂n = 0） | 关闭面不计入拉普拉斯算子；ε_φ = 10⁻⁶ 固定常数 |

可解性：S_v(K − ⟨K⟩) 和 S_E(K_c − K) 在杯内积分都为零（第二项是两个归一化分布之差，数值上再减一次平均）。
杯壁自由滑移是简化：真实的弯月面会把奶泡粘住一些。

**初始状态**：ℓ = 1、q = 0、m = 0、f = g = 0；咖啡静止；W = 0（全褐）。

## 4. 守恒与能量

**漂浮层体积**：∫ℓ dA(t) = ∫ℓ dA(0) + ∫∫ s_f + ∫∫ s_skin（s_skin 单独记账，应远小于 s_f）。
**奶泡**：∫m dA(t) + ∫f dA(t) = ∫∫ F（奶泡只在水下和漂浮层之间转移）。
**有界性**：m 和 ℓ 用同一个面通量输运 → 均匀 c 保持均匀，0 ≤ m ≤ ℓ；W ∈ [0, 1)。
**动量**：不守恒（拖曳、牵引、源项本来就不守恒）；面内应力是离散散度形式，壁面无应力，本身不改变总动量。
**能量**（E_k = ½∫ℓ|u|²，E_p = ½∫c_p² ℓ²）：
- 压力：动能 ↔ 势能交换（隐式 Euler 额外耗散一点声波能量）；
- 拖曳 −β₀(u − U_s)·u = −β₀|u − U_s|² − β₀(u − U_s)·U_s：相对咖啡速度耗散，咖啡做功是输入；
- 牵引 Λ(v_jet − u)·u：射流做功；
- 质量源：以 U_s 加入。由 ∂(½ℓ|u|²)/∂t 中的源项 u·(sU_s) − ½s|u|² = ½s|U_s|² − ½s|u − U_s|²：带入动能 ½s|U_s|²，同时有 ½s|u − U_s|² 的混合耗散；膜已随咖啡运动（u = U_s）时速度不变，没有虚假的加速或减速；
- 面内应力：耗散率 2ν_eff ℓ [u_x² + v_y² + ½(u_y + v_x)² + (u_x + v_y)²] ≥ 0。

## 5. IMEX 离散

### 5.1 网格与变量
N×N 均匀网格覆盖 [−½, ½]²，h = 1/N；所有变量在单元中心（共位网格）；面通量只定义在两侧都在杯内的"开放面"上。

### 5.2 每个控制帧（Δt_frame = 1/120 s；扫描快时缩短到 0.5·min(h, r₁, r₂)/v_scan）
1. 由输入算出第 2.2 节的量和核 K，帧内冻结；
2. 解两个势流。系数矩阵（ε_φ + 开放面拉普拉斯）整个运行中不变，只分解一次（Python 稀疏 LU，JS 带状 Cholesky），每帧两次三角回代；同时算出 ∇·U_s（给 s_skin）；
3. 子步数 n_sub = ⌈Δt_frame / (CFL·h/(2u_max))⌉，CFL = 0.5，u_max = max(膜速度, 牵引处 |v_jet|, |U_s|, |U_d|)；
4. 做 n_sub 个子步；出现非有限值或杯内 ℓ ≤ 10⁻³ 时整帧回滚（含 f、g、账本），子步数加倍重试。

### 5.3 一个子步（Δt）

**步骤 0：水下奶泡与源项**（显式）
- f* = fⁿ − Δt ∇_h·(U_d f)_迎风 + Δt F，g* = gⁿ − Δt ∇_h·(U_d g)_迎风 + Δt F τ_new，截到 ≥ 0；
- τ_f = g*/f*（下限 10⁻³ s），σ = f*(1 − e^{−Δt/τ_f})，fⁿ⁺¹ = f* − σ，gⁿ⁺¹ = τ_f fⁿ⁺¹；
- s_f = σ/Δt，s_skin = ℓ_skin max(∇·U_s, 0)，s_ℓ = s_f + s_skin，s_m = s_f。

**步骤 A：动量对流**（显式 Rusanov，ℓ 冻结）
- 面通量 F_f = ½(q_L u_n,L + q_R u_n,R) − ½ α_f (q_R − q_L)，α_f = 2 max(|u_n,L|, |u_n,R|)；
- q* = qⁿ − Δt ∇_h·F。

**步骤 B：质量 + 压力 + 拖曳 + 牵引 + 源项动量**（隐式部分：压力、质量通量、−β₀u、−Λu）
- θ = 1 + Δt (β₀ + Λ)/ℓⁿ；
- q̂ = q* + Δt [ β₀ U_s + Λ v_jet + s_ℓ U_s ]（拖向咖啡速度的部分、牵引目标、源项动量都是已知量，显式）；
- qⁿ⁺¹ = q̂/θ − Δt (c_p² ℓⁿ/θ) ∇ℓⁿ⁺¹；代入质量方程：
  ℓⁿ⁺¹ − Δt² ∇·((c_p² ℓⁿ/θ) ∇ℓⁿ⁺¹) = ℓⁿ + Δt s_ℓ − Δt ∇·(q̂/θ)
  对称正定，Jacobi PCG（相对残差 10⁻¹⁰）；显式部分面通量带 Rusanov 型耗散 ½ w_f(ℓ_R − ℓ_L)；
- 用最终面通量 G_f 重算 ℓⁿ⁺¹ = ℓⁿ + Δt s_ℓ − Δt ∇_h·G（体积守恒精确到舍入）；qⁿ⁺¹ 由单元梯度回代。

**步骤 C：奶泡量**（同一面通量）
- mⁿ⁺¹ = mⁿ + Δt s_m − Δt ∇_h·(G c_f)，c_f 为 van Leer 限制的迎风重构，夹在两侧 c 之间。

**步骤 D：面内应力**（隐式，ℓ 冻结在 ℓⁿ⁺¹）
- 离散耗散泛函：I = u_x² + v_y² + (u_x + v_y)² + ½(u_y + v_x)²，u_x² 放 x 面、v_y² 放 y 面（紧凑差分），散度项放单元中心，剪切项放单元角点（2×2 紧凑差分）；Φ = ½Σ h² w (Gz)²，w = 2ν_eff ℓ（角点项乘 ½）；
- 算子 K = Gᵀ diag(w) G：对称半正定，刚体运动不受力，零空间只有刚体运动，纯剪切精确退化为一维紧凑格式（第一版"每个面算完整不变量"在强拖曳边界旁有一阶滑移误差，已弃用，见 `YIELD_FILM_DERIVATION.md` 第 4.1 节）；
- ν_eff = min(ν + τ̂(c)/(2|D|_e + ε), ν_max) 在单元中心用 D 步之前的速度计算（滞后一步），再平均到面和角点；
- 实现上 D 步在每个控制帧结束时做一次（隐式、无条件稳定，Lie 分裂放到帧的尺度；与每个子步做一次相比，push_heart 96² 的白度平均差 0.023），PCG 容差 10⁻⁴；
- 解 (M + Δt K) u⁺ = M u⁻，M = diag(ℓⁿ⁺¹)，2N² 维对称正定，Jacobi PCG；
- 动能不增，对任意 Δt、ν_eff ≥ 0 无条件稳定；ℓ、m 不变。

**步骤 D′：混合** ℓ(c⁺ − c⁻)/Δt = ∇·(ℓ D_m ∇c⁺)（D_m = 10⁻⁷，显式，可忽略）。

**接受检查**：所有量有限、杯内 ℓ > 10⁻³，然后提交 ℓ、q、m、f、g 和账本。

### 5.4 性质汇总

| 性质 | 由谁保证 |

| 时间步与 c_p 无关 | 压力和质量通量在 B 步隐式，Rusanov 速度不含 c_p |

| 面内应力无条件稳定 | D 步算子对称半正定，动能不增 |
| 势流每帧便宜 | 常系数矩阵一次分解 |

## 7. 推导核对（v2）

### 7.1 量纲
| 项 | 表达式 | 单位 | 核对 |
|---|---|---|---|
| S_v | Q/(H D_L²) | (m³/s)/(m·m²) = 1/s | ✓ |
| ∇·U_v = S_v K | 物理：∇_phys·(H U_phys) = Q k_phys，k_phys = K/D_L²（K 在模型面积上归一），U_phys = D_L U，∇_phys = ∇/D_L | (1/D_L)·H·D_L ∇·U = Q K/D_L² → ∇·U = Q K/(H D_L²) = S_v K，两边都是 1/s | ✓ |
| S_E | E/(h_s D_L²) | 1/s | ✓ |
| S_f | Q/(H_f D_L²) | 1/s（单位时间加到漂浮层的厚度，以 H_f 计） | ✓ |
| c_p² ℓ∇ℓ | 物理：∂(h u_phys)/∂t = −g′ h ∇_phys h；h = H_f ℓ，u_phys = D_L u，∇_phys = ∇/D_L | H_f D_L ∂q/∂t = −g′ H_f² ℓ∇ℓ / D_L → ∂q/∂t = −(g′ H_f/D_L²) ℓ∇ℓ，c_p² = g′H_f/D_L² = g′_model·(H_f/D_L)，g′_model = g′/D_L | ✓ |
| β₀(u − U_s) | 物理：τ_b/(ρ_f H_f)，τ_b = ρ_f k (u − U_s) | β₀ = k/H_f [1/s] | ✓ |
| Λ(v_jet − u) | 射流水平动量通量 ρQ u_in 按核分布，κ_c 是传递效率 | Λ = κ_c Q K/(H_f D_L²) = κ_c S_f K [1/s] | ✓ |
| W | m/m_o 无量纲 | | ✓ |

数值：Q = 15 mL/s、H = 5 cm、H_f = 3 mm 时 S_v = 0.047 /s、S_f = 0.78 /s。v1 的 S = k_Q Q/D_L³ = 0.039 /s，对应的参考厚度 D_L/k_Q = 6 cm，确认 v1 的 "1" 是咖啡深度。c_p：g′ = 6 m/s²、H_f = 3 mm → √(g′H_f) = 0.134 m/s = 1.7 D/s（v1 拟合 0.97）。

### 7.2 奶泡量是否合理
φ_foam = 0.5、χ = 0.8、15 mL/s 倒 4 s：进入漂浮层的奶泡 24 mL；铺在半径 2 cm 的白盘上，厚 1.9 cm ≈ 6 H_f。拉花后奶泡层厚 1–2 cm，与经验一致。W = 1 − e^{−6/0.2} ≈ 1（白）。

### 7.3 褐缝怎么出来（不再靠源项）
漂浮层基本随表面流走（β₀/ℓ 大的薄处更是如此）：∂ℓ/∂t ≈ −ℓ ∇·U_s，所以上涌处 ℓ、m 都按 exp(−∇·U_s · t) 衰减。卷吸胞内 ∇·U_s ≈ S_E K_c ≈ 2·0.74·3·0.047/(π·0.05²) ≈ 27 /s（R_c = 4 mm 时），0.1 s 内奶泡厚度减到 e⁻³ ≈ 5%；只要 m 降到 m_o 以下，W 就变褐。射流处 ∇·U_s < 0，漂浮物堆积，由浮力压力 c_p²ℓ∇ℓ 和屈服应力决定它往外摊多快。这和 v1 的源项给出同样的定性结构，但现在是运动学的直接结果。

### 7.4 修正 1 的效果
若漂浮层已随咖啡运动（u = U_s），加入质量 s 后 q + Δt s U_s = (ℓ + Δt s) U_s，速度不变 ✓；v1 里速度会变成 ℓU_s/(ℓ + Δt s)，等价于一个 s/ℓ 量级的假阻力。

### 7.5 B 步仍然对称正定
θ = 1 + Δt(β₀ + Λ)/ℓⁿ ≥ 1，系数 c_p²ℓⁿ/θ > 0（ℓⁿ > 0 由 s_skin 和接受检查保证）→ 质量方程左端算子对称正定 ✓。β₀/ℓ 在薄处很大，但只出现在 θ 里（隐式），不限制时间步 ✓。

### 7.6 一个可检验的预测
射流足迹内 ∇·U_s = ∇·U_v + ∇·U_c ≈ K(S_v − S_E) = K S_v (1 − 2·ent·Fr)。Fr ≈ 3、ent = 0.74 时 1 − 2·ent·Fr ≈ −3.4，所以**射流处表面总是汇聚的**（只有 Fr < 1/(2 ent) ≈ 0.7 的极低冲击才会向外散开）。因此低位倒奶时白盘向外扩张，靠的是奶泡层的浮力压力 c_p²ℓ∇ℓ（加上屈服应力的阻碍），而不是表面流把它带出去。白盘扩张速度可以直接从俯视过程视频量出来，用来检验 g′、H_f、τ̂_foam 这一组参数。

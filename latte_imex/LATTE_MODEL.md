# 拉花杯面模型：完整物理模型与 IMEX 离散（双层 + 卷吸胞 + Bingham 奶泡膜）

这份文档是**要实现的完整模型**的唯一依据：从奶罐给出的落点量开始，到杯面上看到的白度场为止。
- 奶罐本身（液面、堰流、射流、账本、咖啡师控制）见 `PITCHER_MODEL.md`，这里只用它的输出。
- 屈服应力那一项的推导细节见 `YIELD_FILM_DERIVATION.md`，这里只给结论。
- 已实现：第 1–4 节除屈服应力以外的全部内容（`solver.py` 的 `closure="twolayer"`，`web/latte2d.js` 与之对拍，最大差 3×10⁻⁸）。
- 待实现：Bingham 奶泡膜（第 2.6 节、第 5 节 D 步），代码要等它的数值验证通过之后再写。

单位：长度以杯径 D_L = 8 cm 为单位，时间以秒为单位；膜厚以参考表层厚度为 1（无量纲）。

## 1. 输入：奶罐模型给出的落点量

奶罐模型每帧（1/120 s）给出**本帧落到咖啡上**的那份奶（已含飞行时延）：

| 量 | 符号 | 单位（SI） | 来源 |
|---|---|---|---|
| 到达流量 | Q | m³/s | 堰流律 → 壶嘴通道 → 飞行中的奶团按到达时间窗口分配 |
| 落点 | x_hit | m | 抛体运动落到 z = 0 |
| 法向冲击速度 | U⊥ | m/s | 落点处的竖直速度 |
| 水平速度 | u_h | m/s | 出口速度的水平分量 + 壶的速度 |
| 足迹椭圆 | r₁, r₂, φ | m, rad | 唇沿通量矩给出出口液片，表面张力在毛细时间内把它收圆 |

### 1.1 换成杯面单位（纯量纲换算）
- 落点 x = x_hit / D_L
- 落点强度 S = k_Q · Q / D_L³（单位 1/s：单位时间注入的层量，按杯径² 归一）
- U⊥ ← U⊥ / D_L，u_in ← u_h / D_L；水平速度限幅 |u_in| ≤ U⊥ · tan 60°
- 足迹 r₁, r₂ ← r₁/D_L, r₂/D_L；射流直径 d = 2√(r₁ r₂)

唯一的标定常数是 k_Q（奶的体积变成了多少表层量）。

### 1.2 足迹核
紧支撑椭圆核，在杯内归一化：

  K(x) ∝ max(0, 1 − a² − b²)²，a = ((x − x_hit)·e₁)/r₁，b = ((x − x_hit)·e₂)/r₂，∫_cup K dA = 1

半轴下限 1.5h（h 是网格间距），网格内用自适应子格求积（至少 3×3，薄足迹时更密，上限 12×12）。

## 2. 物理模型

### 2.1 杯面上的三样东西
1. **表面膜**：漂在最上面、看得到的一层，由褐色表面液（crema、翻上来的咖啡）和白色奶泡组成。状态量：膜厚 ℓ、膜动量 q = ℓu、奶泡量 m。可见白度 **c = m/ℓ ∈ [0, 1]**。
2. **水下奶泡**：被射流带进咖啡里、还没浮上来的奶泡量 f，以及上浮时间常数的矩 g = f·τ_f（让不同时刻、不同高度倒进去的奶泡各自带着自己的上浮时间一起输运；混在一起时按奶泡量加权平均）。
3. **咖啡**：膜下面的液体。它的流动不单独求动量，而是由两个准稳态势流给出（第 2.3 节）。

### 2.2 落点闭合（每帧由输入算出，帧内冻结）

| 量 | 表达式 | 物理意义 |
|---|---|---|
| 密度 Froude 数 | Fr² = U⊥² / (g′ d) | g′ 是奶泡的约化重力 g(1 − ρ_f/ρ) |
| 奶泡存活率 | χ = 1 / (1 + (Fr²/Fr_c²)^p) | 冲得越猛，奶泡破得越多 |
| 水下奶泡源 | F = χ · φ_foam · S · K | 只有存活下来的奶泡才会变白 |
| 上浮时间 | τ_new = max(2U⊥/g′, 10⁻³ s) | 浮力喷泉的上升时间 |
| 卷吸通量 | S_E = ent · Fr · S | Ricou–Spalding 射流卷吸 0.32 z/d × Turner 喷泉深度 2.32 Fr d，给出 ent ≈ 0.74 |
| 卷吸胞半径 | R_c = min(cell_frac · 2.32 · Fr · d, 0.45) | 胞的尺度和喷泉深度成正比 |
| 射流牵引强度 | Λ = κ_c · S · K | 射流把它打到的膜往自己的水平方向拖 |
| 牵引目标速度 | v_jet = κ_t · u_in | 射流水平速度传给膜的那部分 |

没有落点（Q = 0）时，F、Λ、S、S_E 都为零。

### 2.3 咖啡：两个准稳态势流（每帧解一次）
**体积铺展**：倒进来的体积要把周围的咖啡推开，在深度上是均匀的：

  ∇·U_v = S K − ⟨S K⟩，U_v = ∇φ_v

**射流卷吸胞**：射流把周围的咖啡拖下去，咖啡在半径 R_c 内又涌上来。这是一个竖直环流，深度平均为零，所以它表现为一个**表面流**（流向射流），以及深层里方向相反的回流：

  ∇·U_c = D_s，D_s = S_E (K_c − K) − ⟨·⟩，U_c = ∇φ_c

其中 K_c 是以落点为圆心、半径 R_c（至少 2h）的圆盘上的均匀分布（∫K_c = 1）。

- 表面速度 **U_s = U_v + U_c**：拖着膜走；
- 深层速度 **U_d = U_v − U_c**：带着水下奶泡走；
- 表面散度 **D_s**：D_s > 0 的地方咖啡上涌，D_s < 0（射流处）表面液被卷下去。

### 2.4 水下奶泡

  ∂f/∂t + ∇·(U_d f) = F − f/τ_f
  ∂g/∂t + ∇·(U_d g) = F · τ_new − g/τ_f
  τ_f = g / f

上浮是无记忆的指数过程：每一份奶泡在单位时间内以概率 1/τ_f 浮出，所以 f 和 g 按同一比例减少，τ_f 本身不随时间倒数（只因新奶泡混入而改变）。浮出速率 **s_f = f / τ_f**（离散时取 f(1 − e^{−Δt/τ_f})/Δt），是膜里白色奶泡的唯一来源。

### 2.5 表面膜

**质量（膜厚）**：
  ∂ℓ/∂t + ∇·q = s_f + D_s⁺ − D_s⁻,brown

- s_f：浮上来的奶泡；
- D_s⁺ = max(D_s, 0)：上涌处**生成褐色表面**；
- D_s⁻,brown = min(max(−D_s, 0), 可用的褐色液)：射流处**只卷下褐色液体** ℓ − m，奶泡有浮力，留在表面堆积。

**奶泡**：
  ∂m/∂t + ∇·(c q) = s_f + ∇·(ℓ D_m ∇c)

只有浮上来的奶泡算白；D_m 是物理混合系数（奶泡和咖啡几乎不相溶，取 10⁻⁷，基本为零）。

**动量**：
  ∂q/∂t + ∇·(q⊗u) = −c_p² ℓ∇ℓ − β(q − ℓ U_s) + Λ(v* − u) + ∇·(ℓ T/ρ)

- −c_p² ℓ∇ℓ：膜内的重力压力（p = ½ c_p² ℓ²），把厚的地方往外摊；
- −β(q − ℓU_s)：膜被表面的咖啡流拖着走；
- Λ(v* − u)：射流牵引，目标速度 v* = (s_f U_s + Λ v_jet) / (s_f + Λ)（浮上来的奶泡带着咖啡的速度，被射流打到的地方被拖向射流方向）；
- ∇·(ℓT/ρ)：膜的面内应力（第 2.6 节）。

### 2.6 膜的面内应力：浮在液体上的 Bingham 薄膜（待实现）
膜很薄，上表面无应力，下表面在咖啡上滑动（滑动阻力就是上面的 β 项）。对厚度积分得到 shallow-shelf（SSA）形式的面内应力：

  T/ρ = 2 ν_eff (D + (tr D) I)，D = ½(∇u + ∇uᵀ)
  T_xx/ρ = 2ν_eff (2u_x + v_y)，T_yy/ρ = 2ν_eff (u_x + 2v_y)，T_xy/ρ = ν_eff (u_y + v_x)

奶泡是粘塑性的（Bingham），屈服应力只属于奶泡：

  ν_eff = min( ν + τ̂(c) / (2|D|_e + ε), ν_max )
  |D|_e² = ½ D:D = u_x² + v_y² + u_x v_y + ¼(u_y + v_x)²（含 D_zz = −(D_xx + D_yy)）
  τ̂(c) = c · τ̂_foam + (1 − c) · τ̂_crema，先取 τ̂_crema = 0

效果：应力低于屈服应力的奶泡块整块平移、转动，边缘保持锐利；褐色区域照常流动，推开的褐缝不会被摊开的奶泡填回去。τ̂ = 0 时退化为牛顿膜。

现有代码里的粘性项是逐分量的 Laplace 形式 ∇·(νℓ∇u)。ν 是很小的常数时没问题，但 ν_eff 随空间变化时它不客观（刚体转动会受到假力），所以实现屈服应力时整个粘性项要换成上面的对称形式。

### 2.7 可见白度
  c = m / ℓ；和目标图比较时用 s = clip(c / 0.6, 0, 1)

## 3. 边界条件与初始状态

**杯域**：半径 0.49 杯径的圆盘，用网格掩码表示；杯外单元保持 ℓ = 1、q = 0、m = 0。

| 量 | 杯壁上的条件 | 离散 |
|---|---|---|
| 膜厚 ℓ、奶泡量 m | 零通量 | 关闭面的通量为零 |
| 膜动量 q | 无穿透；面内应力为零（自由滑移） | 关闭面不计入 Rusanov 通量和粘性泛函 |
| 水下奶泡 f、g | 零通量 | 关闭面的迎风通量为零 |
| 咖啡势流 φ_v、φ_c | Neumann（∂φ/∂n = 0） | 关闭面不计入拉普拉斯算子；加 ε = 10⁻⁶ 的正则项固定常数 |

源项在杯内积分为零的部分：⟨S K⟩ 和 ⟨D_s⟩ 都先减去杯内平均，保证 Neumann 问题有解。

**初始状态**：ℓ = 1、q = 0、m = 0、f = g = 0；咖啡静止；杯面全褐。

## 4. 守恒与能量

**膜体积账本**：
  ∫ℓ dA (t) = ∫ℓ dA (0) + ∫∫ s_f + ∫∫ (D_s⁺ − D_s⁻,brown)

即"初始膜 + 浮上来的奶泡 + 净生成的褐色表面"。实现里单独记录后两项（`deposited`、`brown_net`），每步核对，误差在机器精度（−4×10⁻¹⁵）。

**奶泡账本**：
  ∫m dA (t) = ∫∫ s_f；水下奶泡 ∫f dA 与已浮出的量之和 = ∫∫ F（奶泡只能在水下和膜之间转移）。

**有界性**：m 和 ℓ 用同一个面通量输运，均匀的 c 保持均匀；卷下褐色液时最多卷走 0.9(ℓ − m)，所以始终 0 ≤ m ≤ ℓ、0 ≤ c ≤ 1。

**动量**：不守恒（拖曳、牵引、源项本来就不守恒）。面内应力项写成离散散度形式，内部面的贡献两两抵消，壁面无应力，所以它本身不改变总动量。

**能量**（膜的动能 E_k = ½∫ℓ|u|² 加压力势能 E_p = ½∫c_p² ℓ²）：
- 压力：只在动能和势能之间交换（隐式 Euler 会额外耗散一点声波能量）；
- 拖曳 −β(q − ℓU_s)：相对于咖啡速度是耗散的，咖啡对膜做的功 βℓU_s·u 是输入；
- 射流牵引 Λ(v* − u)：输入（射流做功）；
- 面内应力：耗散率 2ν_eff ℓ [u_x² + v_y² + ½(u_y + v_x)² + (u_x + v_y)²] ≥ 0，只耗散不输入；
- 质量源：新加入的膜（奶泡、褐色表面）带着咖啡的速度加入，会改变动能，但不是虚假的能量来源。

## 5. IMEX 离散

### 5.1 网格与变量
N×N 均匀网格覆盖 [−½, ½]²，h = 1/N；所有变量放在单元中心（共位网格）。面通量定义在两个都在杯内的相邻单元之间的面上（"开放面"）。

### 5.2 每个控制帧（Δt_frame = 1/120 s；摆动扫描快时缩短到 0.5·min(h, r₁, r₂)/v_scan）
1. 由输入算出第 2.2 节的落点量和核 K，帧内冻结；
2. 解两个势流（第 2.3 节）。系数矩阵（ε 加上开放面拉普拉斯）在整个运行中不变，**只分解一次**（Python 用稀疏 LU，JS 用带状 Cholesky），之后每帧只做两次三角回代；
3. 子步数 n_sub = ⌈Δt_frame / (CFL · h / (2 u_max))⌉，CFL = 0.5，u_max 取膜速度、有牵引处的 |v_jet|、|U_s|、|U_d| 中的最大值；
4. 做 n_sub 个子步（第 5.3 节）；任何一步出现非有限值或 ℓ ≤ 10⁻³，整帧回滚（包括 f、g、账本），子步数加倍重试。

### 5.3 一个子步（Δt）

**步骤 0：水下奶泡与膜的源项**（显式）
- f* = fⁿ − Δt ∇_h·(U_d f)_迎风 + Δt F，g* = gⁿ − Δt ∇_h·(U_d g)_迎风 + Δt F τ_new，截到 ≥ 0；
- τ_f = g*/f*（下限 10⁻³ s），浮出量 σ = f*(1 − e^{−Δt/τ_f})；
- fⁿ⁺¹ = f* − σ，gⁿ⁺¹ = τ_f fⁿ⁺¹（剩下的奶泡保留同样的时间常数，相当于 g 按 σ/f* 的同一比例减少）；
- s_f = σ/Δt；s_up = max(D_s, 0)；s_dn = min(max(−D_s, 0), 0.9(ℓⁿ − mⁿ)/Δt)；
- 膜厚源 s_ℓ = s_f + s_up − s_dn；奶泡源 s_m = s_f；
- 牵引目标 v* = (s_f U_s + Λ v_jet)/(s_f + Λ)（s_f + Λ = 0 处取 0）。

**步骤 A：动量对流**（显式 Rusanov，ℓ 冻结）
- 面通量 F_f = ½(q_L u_n,L + q_R u_n,R) − ½ α_f (q_R − q_L)，α_f = 2 max(|u_n,L|, |u_n,R|)（不含 c_p，所以时间步与 c_p 无关）；
- q* = qⁿ − Δt ∇_h·F + Δt β ℓⁿ U_s（拖曳里"拖向咖啡速度"的显式部分）。

**步骤 B：质量 + 压力 + 拖曳 + 牵引**（隐式）
- θ = 1 + Δt(β + Λ/ℓⁿ)，q̂ = q* + Δt Λ v*；
- 动量隐式 Euler 给出 qⁿ⁺¹ = q̂/θ − Δt (c_p² ℓⁿ/θ) ∇ℓⁿ⁺¹；
- 代入质量方程得到只含 ℓⁿ⁺¹ 的椭圆方程：
  ℓⁿ⁺¹ − Δt² ∇·((c_p² ℓⁿ/θ) ∇ℓⁿ⁺¹) = ℓⁿ + Δt s_ℓ − Δt ∇·(q̂/θ)
  左边对称正定，Jacobi 预条件 PCG（相对残差 10⁻¹⁰）。显式部分的面通量带 Rusanov 型耗散 ½ w_f (ℓ_R − ℓ_L)，w_f = max(|q̂/(θℓ)|)，保证 ℓ 单调；
- 解出后用最终面通量 G_f 重算 ℓⁿ⁺¹ = ℓⁿ + Δt s_ℓ − Δt ∇_h·G，所以膜体积守恒精确到舍入，与 PCG 精度无关；qⁿ⁺¹ 由单元梯度回代。

**步骤 C：奶泡量**（同一个面通量）
- mⁿ⁺¹ = mⁿ + Δt s_m − Δt ∇_h·(G c_f)，c_f 是迎风侧经 van Leer 限制的线性重构，再夹在两侧 c 之间；
- 因为和 ℓ 用同一个 G，均匀 c 保持均匀，0 ≤ c ≤ 1；越界量单独记账（应为 0）。

**步骤 D：面内应力**（隐式，ℓ 冻结在 ℓⁿ⁺¹）——**待实现**
- 离散耗散泛函 Φ = ¼Σ_{x 面} h² w_f I_f + ¼Σ_{y 面} h² w_f I_f，w_f = 2ν_eff,f ℓ_f，I_f = sᵀQs，s = (u_x, v_y, u_y, v_x)：每个面上法向导数用紧凑差分、切向导数用两侧单元中心差分的平均；
- 粘性力 = −∂Φ/∂u / h²，算子 K = ½ Gᵀ(W⊗Q)G：对称半正定，刚体运动不受力，零空间只有刚体运动；
- ν_eff,f = min(ν + τ̂(c_f)/(√(2I_f) + ε), ν_max)，用 D 步之前的速度计算（滞后一步）；
- 解 (M + Δt K) u⁺ = M u⁻，M = diag(ℓⁿ⁺¹)，两个速度分量耦合成 2N² 维对称正定系统，Jacobi 预条件 PCG；
- 能量不等式 ½Σℓ|u⁺|² ≤ ½Σℓ|u⁻|² 对任意 Δt、任意 ν_eff ≥ 0 成立（无条件稳定）；ℓ、m 不变，所以守恒和有界性不受影响。
- （现有代码的 D 步是逐分量 Laplace 形式 ∇·(νℓ∇u)，ν 小时显式、否则隐式；实现屈服应力时整体替换。）

**步骤 D′：混合**
- ℓ(c⁺ − c⁻)/Δt = ∇·(ℓ D_m ∇c⁺)；D_m Δt/h² < 0.05 时用显式更新（D_m = 10⁻⁷ 时总是显式，实际上可以忽略）。

**接受检查**：所有量有限、杯内 ℓ > 10⁻³；然后提交 ℓ、q、m、f、g 和账本。

### 5.4 性质汇总

| 性质 | 由谁保证 |
|---|---|
| 时间步与 c_p 无关 | 压力和质量通量在 B 步隐式，A 步的 Rusanov 速度不含 c_p |
| 膜体积精确守恒 | B 步用最终面通量重算 ℓ |
| 0 ≤ c ≤ 1 | C 步用同一面通量 + 限制重构；卷下量不超过褐色液 |
| 刚性拖曳、牵引稳定 | 都在 θ 里隐式处理 |
| 面内应力无条件稳定 | D 步算子对称半正定，动能不增 |
| 势流每帧便宜 | 常系数矩阵一次分解 |
| 一阶时间精度 | Lie 分裂 + 帧内冻结的落点量 + 滞后的 ν_eff |

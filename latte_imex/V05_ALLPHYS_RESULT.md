# V0.5 全物理入口：最终结论（含两位裁判意见后的更正与补跑）

> 用户的问题："动作先靠猜吧，我就是想知道那些不物理的量如果物理了，还能不能出这样的图"。
> 模型：学长的 V0.5（单层 IMEX 求解器 `latte_imex/solver.py`，闭合 'chi'，回流律 v05）。比较对象：V0.5 自己在 256² 上的六张图（`runs/v05_256`）。
> 动作：Codex 的路径、时序、摆动不动（`latte_imex/v05_controls/*.json`），可以重猜的只有每一笔的壶嘴高度和 5 Hz 流量峰在摆动周期里的位置；每一个入口量都必须在物理包络内。
> 单位：D = 8 cm 杯径，D³ = 512 mL，s；速度 m/s，长度 mm/cm。全部 256²。没有改 `latte_imex`、`v05audit`、`v05allphys` 里任何已有文件；本轮的代码、运行、图都在 `v05allphys/final/`。
> 本文取代 `results.md` 的结论部分；`results.md` 的数字仍可查，但其 §0 的框架、P4bf 树叶的判定、大白心和"p_dep 是真正杠杆"的说法按本文更正。

## 1. 一句话回答

**能出，六个都能。** 把每一个入口量都放进真实奶壶的包络——接收流量 1.0–21.8 mL/s、壶嘴高 0.30–2.50 cm（细切 1.20–1.84 cm）、冲击速度 U⊥ = √(0.35² + 2gz) = 0.43–0.78 m/s、足迹按连续性 r = 0.64–3.2 mm、出口水平速度 ≥ 0.10 m/s 且横摆严格等于手速、5 Hz 脉动 ≤ 0.41（慢壶嘴 τ = 0.08 s 也倒得出）、流量经 τ = 0.08 s 的壶嘴滞后（桥里有漏流、笔与笔之间流量和高度都连续变化）——再把 c_p 换成奶泡筏的物理名义值 1.36 D/s，β、ν 用 V0.5 原值（不看图调），六个图案的决定性结构在 256² 上全部出来（最终组 FS，6/6）。**没有哪一张图出不来；差在"轻柔全沉积"那几笔**：大白心底座 #1/#2、郁金香 #6、树叶 #4 两笔补白、天鹅颈/头 #8/#9。V0.5 让这几笔以 0.011–0.036 m/s 的水平速度落到液面，而真实奶柱的出口水平速度至少 0.10 m/s（贴面倒也至少约 0.07 m/s）。于是大白心多出一条 34 mm 长的褐缝（V0.5 只有 4 mm 凹口），郁金香和树叶的白心底座裂成两颗白滴，天鹅的直喙变成回卷的钩。诊断运行里只把这几笔的水平速度放回 V0.5 的值，这三处差别就全部消失（§6.1）。此外，千层心要求 5 Hz 流量峰与 2.5 Hz 横摆 2:1 锁相，峰要落在回摆途中，成形窗口至少 25 ms、不到 75 ms（周期 200 ms）。人手能不能做到这一点，还没有验证（§6.2）。郁金香、树叶、天鹅完全不脉动也成形。

## 4. 选出的物理动作（最终组 FS）

### 4.1 共享闭合与入口规则

- 闭合（六图共用一组）：B_dep = 1550 D/s²，p_dep = 8（先验范围上界；p = 2、4 也能成图，见 §3.3），κ_r = 0.0373，κ_Q = 2.0 /D；c_p = 1.36 D/s（物理名义值），β = 3 /s，ν = 1e-3 D²/s（V0.5 原值，在物理范围内，没有按图调）；κ_t = 0.7、κ_c = 1.0 与 V0.5 相同。B_dep、p_dep、κ_r 和每笔高度只来自"逐笔流量加权 χ 配 V0.5"的反设计（与 P2 相同，裁判 1 已逐位复核）。
- 入口（`final/drvf.py`，`--exp P2 --pulse 0.41 --lat exitmin --lag 0.08 --ztr`）：
  - 流量：Codex 的流量（锥度、5 Hz 脉动夹到 0.41、桥 ≥ 0.3 s、0.1 s 起停指令斜坡）先过一阶壶嘴滞后 τ = 0.08 s（只作用于逐笔包络；脉动在滞后之后按 0.41 叠加，0.41 是 τ = 0.08 s 时 `verify_d1/pulse_tau.py` 给出的可达上限）；Q = F/κ_Q 夹到 1–32 mL/s，S_eff = κ_Q Q；桥里的漏流低于 1 mL/s 即断流。
  - 高度：每笔一个 z（反设计）；不经桥的相邻两笔之间以 ≤ 0.11 m/s 线性过渡（窗口 ≥ 0.05 s，以交界为中心），桥里线性过渡；U⊥ = √(0.35² + 2 g z)。
  - 水平速度：杯面系 u_h = v_手 + 出口部分。出口部分沿 Codex 射流方向 ê，大小 = clip(\|b\| − v_手·ê, 0.10, 0.27) m/s（b 为 Codex 的杯面射流）；\|u_h\| ≤ min(0.40, U⊥)。所以摆动笔的横摆严格等于手速，且 Codex 的杯面速度只在出口部分不足 0.10 时才被改。
  - 足迹：连续性椭圆 r = √(Q/(πU⊥))，长宽比 \|v\|/U⊥，d = 2√(Q/(\|v\|π))。
  - 5 Hz 流量峰的位置：郁金香、树叶、天鹅取过中线（相位 0）；千层心取回摆途中 \|x\| ≈ 0.71 振幅处（π/2）；大白心、推推乐本来不脉动。

## 5. c_p 物理化的结果

- 同一套动作（P1 → P4，c_p 0.3 → 1.36 D/s，Codex 相位 π）：千层心、郁金香、树叶从"是"掉到"部分"，IoU 降 0.11–0.16（0.79 → 0.67、0.69 → 0.53、0.73 → 0.62）。原因是摆到两端的流量峰：在物理入口里流量越大越沉积，峰放在两端时中轴被反复扫开（上半轴线 c：千层心 0.34 → 0.19，树叶 0.31 → 0.09）。大白心、推推乐、天鹅仍成形（天鹅 IoU 0.79 → 0.67，圆顶中央的褐色空洞变大）。
- c_p 取物理下端 0.68（裁判 2 的 altcp068，相位 π）救不回来：千层心上半照样张开（轴线 c 0.18），IoU 0.70。c_p = 1.0（P3）在 256² 上没有跑，它介于 0.68 与 1.36 之间，两端结论相同。
- 换一个流量峰位置就都回来了：郁金香、树叶、天鹅取相位 0，或者干脆不脉动（FSnp），都成形；千层心取 π/2 或 π/4 成形。所以 **c_p 物理化本身不毁图**。它的作用是让"5 Hz 流量峰放在摆动周期的哪里"变得承重：在 c_p = 0.3 下，Codex 的 π 是无害的；在 c_p = 1.36 下，π 让千层心、郁金香、树叶只部分成形（天鹅仍成形）。
- β、ν 不必动。P4b/P4bf 用过 β 4.8、ν 3.7e-3，那是看图挑的，并且会压紧推推乐的臂、减弱树叶的叶脉（P4bf 3/6）。最终组用 V0.5 的 β 3、ν 1e-3。

### 6.1 "轻柔全沉积"笔的水平动量（模型问题，不是动作问题）

- 现象：大白心中轴褐缝 34 mm（V0.5 4 mm），两瓣底部各一团褐涡；郁金香、树叶的白心底座裂成两颗白滴（郁金香底座中心 c 0.00，V0.5 0.70）；天鹅喙从约 6 mm 的直喙变成回卷的钩（喙尖 x −0.199 对 −0.252 D）。
- 来源：这几笔在 V0.5 里的杯面水平速度只有 0.011–0.036 m/s（大白心底座 0.036/0.030，郁金香 #6 0.020，树叶 #4 0.028，天鹅颈/头 0.024/0.011），而真实奶柱的出口水平速度下限是 0.10 m/s（自由射流）或约 0.07 m/s（贴面倒，u₀ cosβ，CAD 壶嘴 β ≤ 67°）。在 V0.5 的闭合里，即使 χ ≈ 1（全部留在表面），射流也把 κ_t u_h = 0.7 × 0.10 = 0.07 m/s 的水平目标速度加在足迹上。大白心底座就是在冲击点后方拖出两团褐涡（`snaps_FS_heart.png`，t = 2 s 已经出现），然后 #2 往前移时把它们拖成缝。
- 证据：只把这几笔的 \|u_h\| 放回 V0.5 的值（其余全物理，χ 实际 0.978/0.982 不变），缝从 34 mm 缩到 0.6 mm，IoU 0.70 → 0.94，r_hp −0.05 → 0.79；郁金香、树叶底座重新合成一个白心，天鹅喙伸直到 −0.258 D。反过来，κ_r × 0.27（把径向回流降到 V0.5 的量级）一点用没有（缝仍 34 mm）。把底座改从 0.3 cm 倒能缩短到 22 mm，但消不掉。
- 动作上补不回来：要把杯面速度降到 0.03 m/s，手得以约 0.07 m/s 逆着出口方向走；大白心底座要倒 5.6 s，那就要走约 39 cm，杯子才 8 cm。
- 需要改的模型机制：一股全沉积（χ → 1）的奶柱向表面传递的水平动量。按诊断，κ_t \|u_h\| 要从 0.07 降到约 0.025 m/s 以下，也就是这类笔的有效 κ_t ≤ 约 0.25（现在 0.7）。可以把 κ_t 像牵引项 Λ 那样乘上 (1 − χ)，或者按铺开的奶泡层稀释动量。这是唯一一处"物理入口 + 当前闭合"给不出 V0.5 图样的机制。至于它是不是缺陷，要拿真实视频判断：真实的大白心是实心白，所以更像是模型的问题。

### 6.2 千层心的 2:1 锁相（动作还没有被证明）

- 千层心在全物理下要求 5 Hz 流量峰落在回摆途中 \|x\| = 0.38–0.71 振幅处（相位 π/4–π/2）；落在 0、3π/4、π 或不脉动，都只"部分"成形。成形窗口至少 25 ms、不到 75 ms（5 Hz 周期 200 ms），也就是相位误差要压在约 ±12–37 ms 以内，并且要在 6.4 s 的底座里一直保持 2:1 锁相。
- 纯横摆本身在 2f 只产生 0.01–0.04 的流量脉动（envelope §6.2），所以 0.41 的脉动要靠另加 5 Hz 的前后抖或绕壶嘴尖倾转，并与 2.5 Hz 横摆保持锁相。包络只限制了脉动深度，人手能不能稳定做出指定相位，没有测过。若用绕腕倾转产生脉动，±1° 就让壶嘴上下 ±2.6 mm，在 p_dep = 8 下超出部分沉积笔 ±1.7 mm 的高度容差；p_dep = 2 时容差放宽到 ±3–5 mm，p_dep = 2 下千层心也成形（§3.3）。
- 郁金香、树叶、天鹅不受此限：不脉动也成形。

### 6.3 已经不缺的（撤回 `results.md` 的说法）

- "p_dep 是真正的杠杆，要 p ≥ 5"——撤回。逐笔高度在包络内自由选时，p_dep = 2、4、8 都六图成形，p_dep 只决定逐笔 χ 配得多准（J 0.49 / 0.052 / 0），也就是图偏白多少。审计时 X01/P0 的失败来自"按类固定高度"（天鹅颈在 1.0 cm 时 χ 只有 0.23–0.27；改在 0.3 cm 倒，p = 2 下 χ 也有 0.84），不是来自指数。
- "一个 κ_r 配不上逐笔径向回流"——数字仍然对（轻柔笔的径向目标是 V0.5 的 3.2–4.2 倍），但诊断表明它对图不承重。

## 7. 局限

- 动作是猜的。高度是按"逐笔流量加权 χ 配 V0.5"反设计出来的，没有看图；流量峰相位（郁金香/树叶/天鹅 0、千层心 π/2）是看了 P1/P4 的图之后再猜的（裁判 1 #8）。相位扫描只做了千层心的 0、π/4、π/2、3π/4、π 五点。
- 比较对象是 V0.5 自己的图，不是视频。"成形"指的是 V0.5 那张图的决定性结构，不代表与真实拉花一致。
- p_dep = 8 是先验范围的上界。它要求部分沉积笔的高度保持在 ±1.6–1.8 mm 内，而底座那 6.4 s 里液面上升约 1.25 cm（相对液面的高度要边摆边抬约 2 mm/s），这一点没有模拟。p_dep = 2 也能成图，但白区大 1.15–1.33 倍、沉积量多 1.18–1.35 倍。
- 包络里有两处取的是边界值：脉动 0.41 取 τ = 0.08 s 那一支的上限；高度五笔在 2.50 cm、两笔在 0.30 cm。0.30–0.65 cm 的低位低于视频里见过的 1 cm。若把 0.35 m/s 当作出口总速度，同一 U⊥ 还要再高 0.5–1.3 mm。
- 壶嘴滞后用的是一阶模型（τ = 0.08 s，只作用于逐笔包络）。漏流按 1 mL/s 断流，这一读法本身没有实测。细切尾巴是"抬到 1 mL/s"还是"断流"，两种读法都试过（FSstop），结论相同。
- 只用了一个网格（256²）和一个确定性求解器，没有噪声、没有重复；目判由我一人做，结构量的定义沿用裁判 2 的 `structm.py`。
- 天鹅颈在 FS 里有一段 c 只有 0.47–0.60（strictB3 是 0.75）。它仍然连续，但这是全组里离"断"最近的结构。
- 贴面倒（P5）不在最终组里；若要用，β ≈ 70° 略超 CAD 壶嘴的 67°。

# 表面层模型 V2：表面水流、浮筏式垂直交换、泡沫前方浮出

> 本文记录在 V0.5/V1 薄膜模型（`V05_MODEL_SPEC.md`）基础上做的三处基础层改动、它们的证据、实现与验证，以及用真实倒奶视频做全视频监督标定的结果。三处改动都是可选开关，参数取 0 时严格退回 V0.5（numpy 与 Warp 两个求解器逐位一致，见 §4）。

---

## 1 为什么要改：数据里看到的三件事

### 1.1 白色在落点**前方**长出来

把 E0 测得的射流落点（`rig/stream_foot.py`，三台 RealSense 的射流中心线外推到液面）叠到俯视校正图上，可以看到：

- tulip、heart、leaf 都是如此：新沉积的白色在落点的前方（远离壶的一侧）长出；
- 落点本身是棕色的；
- heart 在 3–4 s 时，落点和心形上缘之间隔着一道棕色缝。

V0.5 的沉积核以落点为中心，所以有一半白色落在落点后方（靠壶一侧），而实测那里是棕色。

物理解释：斜射流下潜时，泡沫被射流的水平速度带着在液面下前行，浮力使它在约 τ_s 时间后浮出。浮出点在落点前方 τ_s·u_in 处（u_in 为射流水平到达速度，约 0.9 D/s）。泡沫在水下也会失去一部分射流动量（份额 μ_s）。

### 1.2 旧层是被压扁的宽弧

真实 tulip 中，旧层被新心形推开后，成为沿推送方向压扁、向两侧拉宽的薄弧，位置在杯子中部，还没有到远端杯壁。V0.5 中旧层是以落点下方某点为圆心的同心圆弧，宽高相当。N=96 与 N=48 结果一致，所以这不是分辨率问题。

对实测光流做时间平均、加权平滑后求散度，可以看到：面积在落点附近产生，在杯子中部的一条横带上汇聚。汇聚处棕色液体下沉，有浮力的微泡沫留在表面，被挤成宽薄的弧。

### 1.3 光流显示整体前移

实测的平均表面速度约为 0.04 D/s（同一像素掩膜下，模拟只有其 1/5）。需要注意：光流跟踪的是纹理边缘，泡沫在前方浮出时白色前缘的推进也会被当成流动。因此这个数值是"物质输运 + 图案生长"之和，**不能**直接用来标定水流强度（§5 的结果支持这一点）。

## 2 模型

### 2.1 射流动量驱动的表面流（`circulation.py: SurfaceCurrent`，开关 `circ`）

二维表面流 U，单向耦合（薄膜对水的反作用约为 ρ_f h_f /(ρ δ) ≈ 0.1，忽略）：

$$\partial_t U = \kappa_M F - r U + \nu(\nabla^2 U + \nabla\nabla\cdot U),\quad \nu = r L_C^2,\quad U\cdot n = 0\ \text{（杯壁，罚函数）},$$

$$F = Q Z\, u_{\rm in}\, K_F(x - x_{\rm hit})$$

其中 F 是射流带入的水平动量通量，K_F 是半径为 R_F 的光滑核，积分为 1。

- U 对 F 是线性的，用稳态响应按自旋衰减率 r 松弛：$U \leftarrow e U + (1-e) U_{ss}(F)$，$e = e^{-r\,\Delta t}$。每个 Δt 只需一次稀疏 LU 回代。
- 散度 σ = ∇·U 用面平均通量计算，杯壁面封闭，全杯积分为 0（舍入误差内）。
- 上涌 σ⁺ = max(σ, 0)，下沉 σ⁻ = max(−σ, 0)。
- 形状常数：r = 1 /s（实测平均表面流约 1 s 内消失），L_C = 0.4，R_F = 0.06。

### 2.2 浮筏式垂直交换（`wsolver.k_exchange`，`solver.substep` 末尾）

每个子步之后进行垂直交换，只作用于棕色部分 b = ℓ − m。微泡沫（ρ_f/ρ ≈ 0.4）是浮在上面的筏子，水从它旁边上涌和下沉：

$$\frac{db}{dt} = -W b + \kappa_M \sigma^+ (1 - c),\qquad \frac{dm}{dt} = -\varepsilon_f W m,\qquad W = \kappa_M \sigma^- + \kappa_w \kappa_Q W_n$$

- W_n 是接收流量对应的面积（ā 为松弛后的接收流量），在水流下沉处离开：$W_n = \bar a\,\sigma^-/\!\int\sigma^-$。没有水流时改为沿杯壁离开。κ_w = 1 时，入口加入的面积全部离开。
- 交换的物质随薄膜运动（u 不变）。
- 拖曳参考速度 κ_M U：$-\beta(q - \ell\kappa_M U)$。
- ε_f 为泡沫随水下沉的份额，物理值约为 0。

### 2.3 泡沫前方浮出（`wsolver.k_kernel_raw(dep=1)`，`Solver.inlet_fields`）

- 新奶源用沉积核 K_d，中心位于 $x_{\rm hit} + \tau_s u_{\rm in}$，形状与落点核相同；若 K_d 完全落在杯外，则退回落点核。
- 牵引 Λ、下潜部分（upwell）和杯内接收比例 Z 仍按落点核计算。
- 新奶中份额 μ_s 以薄膜速度到达（射流动量在水下失去），其余以 v* 到达：

$$a = \big(q^* + \Delta t\,((1-\mu_s)s_m + \Lambda)v^* + \Delta t\,(s - (1-\mu_s)s_m)\,u + \Delta t\,\beta\ell\kappa_M U\big)/\theta$$

### 2.4 参数与开关

| 参数 | 含义 | 拟合范围 | V0.5 |
|---|---|---|---|
| κ_M | 表面流强度（拖曳参考、上涌、下沉） | 0–8 | 0 |
| ε_f | 泡沫下沉份额 | 0–1 | – |
| κ_w | 接收面积的下沉 | 0–2 | 0 |
| τ_s [s] | 泡沫浮出前在水下前行的时间 | 0–0.2 | 0 |
| μ_s | 浮出泡沫失去的射流动量份额 | 0–1 | 0 |

- 拟合入口：`diff/fit.py --circ`（κ_M, ε_f, κ_w）、`--dep`（τ_s, μ_s）、`--upwell`（整个接收体积到达液面）。
- 闭合 json 中的 `circ`、`upwell`、`e0` 是模型开关的唯一来源，渲染（`rig/real_program.py`）按 json 读回。
- AutoDL：`FIT_ARGS="--circ --dep" bash scripts/autodl_diff.sh`。

## 3 实现

- `circulation.py`：SurfaceCurrent（宿主端，scipy 稀疏 LU）。
- `diff/run.py: circ_fields`：每帧预计算 U、σ⁺、σ⁻、W_n。落点修正时重算，这部分不进伴随，因此 foot_a/foot_b 的梯度是部分梯度，仅作诊断。
- `diff/wsolver.py`：
  - PARAMS 增至 15 个（κ_M, ε_f, κ_w, τ_s, μ_s）；
  - 新增 k_exchange；
  - k_kernel_raw 增加 dep 偏移；
  - k_fields 使用两套核；
  - k_stepA_B 中加入 μ_s。
- `solver.py`：numpy 参考实现，与以上逐项对应。

## 5 标定与留出检验（N=48，E0，多尺度损失）

标定集 = tulip + leaf（V1 计划 A+B），留出集 = heart、push_heart、swan。

**拟合方式**：每个模型都用 CMA-ES（无导数）从 S1 出发，在单位盒内拟合 8 个 V0.5 闭合参数加上该模型的新参数。种群 10，σ0 = 0.12，目标为两个标定图案的逐帧 IoU（视频 IoU）的平均值。到平台期后停止（约 5–9 代）。

## 6 结构：tulip 为什么还没"打开"

N=96 下五个图案的对比见 `v2_surface/compare_n96.png`，各行依次为视频、V0.5 拟合、τ_s+μ_s 拟合。

- **heart**：τ_s+μ_s 去掉了 V0.5 中本不该有的同心环，成为实心心形。
  - 这些环不是由 χ 抖动造成的：heart 在 0–4.6 s 内 χ 一直约为 1。
  - 真正的原因是沉积泡沫带着射流动量前冲，落点处空出来的位置被周围的棕色薄膜填入。
- **tulip**：τ_s+μ_s 把层合并成了实心白团。IoU 更高，但视觉上离"打开"更远。
  - 层间那些细棕线面积很小，在 IoU 里几乎不计分。
  - 缝隙结构指标（对白色掩膜做闭运算后多出的细棕缝，实测与模拟的 IoU）对所有模型都不超过 0.05。
- **实测 tulip 的关键时刻**：3.6 s 时第二个心形还很小，第一块白色已经变成又宽又扁的弧带。所以这块白色是在第一次停顿（1.8–2.8 s，抬壶、射流下潜，χ≈0）期间被摊平的。
  - 物理图景：下潜的来奶在落点处以棕色重新浮出（upwell），形成一个从落点向外的径向面积源。位于落点前方的白块被从后方中心推开，包着棕色圆盘变成新月形的宽薄弧。
  - 下一次沉积落在棕色圆盘里，就形成"心形嵌在弧里、两者之间隔一道棕线"的结构。
  - 在 τ_s+μ_s 闭合上直接叠加 upwell 和 κ_w（不重新拟合）后，tulip 宽度达到 0.62（实测 0.62），下方出现宽弧带；但 heart 和 swan 的 IoU 下降。需要联合重新拟合（`cmafit2 uwdm`：upwell + κ_w + τ_s + μ_s，κ_M 固定为 0）。
- **已撤掉的尝试**：深潜牵引截止 κ_p，即 Λ 乘以 1/(1+(κ_p z_c)^p)，用来描述高处下潜的射流少拖表面。它对拟合闭合的影响只有 ±0.004，已从代码中删除。
- **后半段**：tulip 在 7 s 以后、heart 在 5 s 以后，测得的落差升到 40–56 mm（拉线收尾），χ≈0 是正确的。

## 7 结论与下一步

1. **推荐的基础改动：泡沫前方浮出 + 动量损失（τ_s, μ_s）**。
   - 在所有候选中，只有它在留出集上稳定胜出：视频 IoU 从 0.411（V0.5 拟合）提到 0.441。
   - heart 0.472 → 0.550，swan 0.368 → 0.380，push_heart 持平。
   - N=96 复核结论相同（0.402 → 0.436）。
   - 参考闭合：`data/closures/dep_AB_cmaes_N48.json`。
2. **表面水流（κ_M > 0）**：在三次独立的组合中都提高了标定分数，但降低了留出分数，swan 最明显（实测漂移只有 4 mm）。
   - 光流测到的"整体前移"主要是图案生长（泡沫在前方浮出使白色前缘推进），不是物质输运。
   - 保留为可选开关，不推荐使用。
3. **upwell + 接收面积下沉（κ_M = 0）**：让 tulip 重新出现分层弧（`v2_surface/tulip_n96.png`），宽度 0.58（实测 0.62），push_heart 有提升。但留出平均为 0.423，低于 τ_s+μ_s。
   - 参考闭合：`data/closures/dep_upwell_AB_cmaes_N48.json`。
4. **tulip 的"打开"还没有解决**，有两个原因：
   - 逐像素的损失与 IoU 偏爱白团，不奖励层间细棕线。
   - 结构位置取决于落点和时间，而输入有毫米级误差。
   - 下一步需要对位置有容忍度、能看出层次的结构评分（已试过的缝隙 IoU 和内部边缘密度都不可用，见 §6），并在此评分下重新标定 upwell 新月弧机制。
5. **AutoDL（GPU，N=128）**：`FITS="AB:tulip,leaf" FIT_ARGS="--dep" INIT=latte_imex/data/closures/dep_AB_cmaes_N48.json bash scripts/autodl_diff.sh`，即从 CMA-ES 的结果出发做梯度精修。V0.5 对照（update12）不受影响：fit.py 默认仍是 V0.5。
6. **数据问题**：
   - leaf 在 6 s 以后 E0 可信帧不到 20%，那一段输入不可靠。
   - 杯子倾斜的假设已排除：液面边界拟合椭圆的长短轴比为 0.94–0.99，长轴方向随机。


## 8 输入链路审查（"实测动作 → 入口"）与上限诊断

**动机。** 第 5–7 节的所有物理闭合变体，视频 IoU 都在 ±0.03 内打转。用户指出，以前用猜的动作 V0.5 能拉出郁金香，所以要先把"物理不够"和"输入不对"分开。

### 8.1 指标的尺度

视频自身的帧间 IoU：

| 帧间隔 | IoU |
|---|---|
| 0.07 s | 0.81–0.91 |
| 0.25 s | 0.69–0.83 |
| 0.5 s | 0.59–0.74 |

也就是说，一个时间上差 0.5 s 的"正确"模拟只有约 0.6；现在的 0.45–0.55 相当于时间差约 0.7 s 或位置差几毫米。合理的目标在 0.65–0.7。

### 8.2 输入上限诊断（`scratchpad/oracle/inlet_oracle.py`，物理固定为 S1）

用伴随梯度拟合平滑的入口修正：落点 x、y，Q·e^{s_Q}，U⊥·e^{s_U}，节点间隔 0.4 s。

| 图案 | 修正前 | 修正后 |
|---|---|---|
| tulip | 0.443 | 0.526 |
| push_heart | 0.383 | 0.536 |

tulip 需要的修正很小：沿射流方向约 2–4 mm，流量 ±15%，U⊥ 最多 +13%。但郁金香依然是 V 形人字层，**没有打开**。

结论：输入精度占了剩余 IoU 缺口的一大部分，但"打开"不是输入问题。

### 8.3 多角度审查（工作流 wf_61f4987d-e3b，五个角度，每条发现都经过对抗复核）

**发现并已修正的输入 / 观测缺陷：**
- **出流太竖直（LP1/LP2）。** 模型奶流的水平到达速度约 0.09 m/s，实测约 0.2 m/s；落点比相机看到的奶流落点短 8–10 mm，五个图案方向一致。
  - 已校准 `real_program.EXIT_CAL`（C_v 1.5，出流方向抬 9.5°，出流点前移 3 mm），只用 E0 的落点和斜率，不看图案。
  - 落点偏差降到约 2 mm（留出图案同样成立），斜率 0.15 → 0.30（实测 0.25–0.43）。
- **E0 的坐标系（LP4）。** 偏移沿噪声很大的 u_in 方向施加，产生 2–3.5 Hz 的落点抖动。新增 `e0='world'`（杯子坐标系）。在 S1 物理下 heart +0.05、tulip +0.01。
- **曝光瞬变（H5/F9）。** 抬壶时曝光下降，白度被夸大 10–60%。这些帧（tulip 5%、push_heart 6%、swan 2%）已不再计入观测（`run.EXPOSURE_TOL`）。

**排除的假设：**
- 手速已计入 u_in；
- 停顿期是真正的停流；
- χ 的开关时刻与视频吻合；
- 下落高度的参考面是逐帧实测的液面；
- 杯子倾斜（液面边界接近圆）；
- 杯子平移是刚性的（白团质心在杯子坐标系中稳定）；
- 光流测到的"40 mm 整体前移"主要是图案生长，不是液面输运。第 5 节的表面水流追的正是这个假象。

**出流校准后重新拟合（CMA-ES，V0.5 闭合，tulip+leaf）：**

| 入口 | 标定分数 |
|---|---|
| 只用出流校准 | 0.456 |
| 出流校准 + 杯子坐标系 E0 | 0.490 |
| 旧入口 V0.5 拟合 | 0.492 |

物理上更对，但没有提高 IoU；每帧剩下 5–8 mm 的落点误差仍要靠 E0 的直接测量。

### 8.4 真正的缺口：设计动作 vs 实测动作（审查 designed_vs_measured）

- **设计的郁金香靠什么打开。** 靠的是"半沉积（χ≈0.4）+ 牵引"：第二个心形一边沉积一边拖动薄膜，顶进一段很长的半沉积底层，把它包成新月形。
- **这位咖啡师的手法不同。** 三个**完全沉积**（χ≈1）的短心形，中间有约 0.8 s 的停顿，几乎没有摆动。按 V0.5 的逻辑，完全沉积时几乎没有牵引，所以只会长出紧凑的圆团。
- **视频里的打开发生在倒的过程中。** 第一个心形在**还在倒的时候**就铺成了前方的一条宽带。这是物理缺口：大流量完全沉积时，泡沫会向前、向两侧扇形铺开。
- **已排除的几种做法：**
  - 把足印放大（×3–×8），白色被摊薄、变窄；
  - 加大径向速度 κ_r，没有作用（被 VR 上限卡住）；
  - 加强推送动量（出流校准使 u_in ×2.3），配合重新拟合也没有提升。

**下一步要做的：**
- 一个对位置有容忍度、能看出层次的结构评分；
- 一个描述"完全沉积时泡沫扇形铺开"的机制。

> **对 §6、§8.3、§8.4 的更正（见 §9）。**
> - §8.4 的"物理缺口"结论是在有偏的 E0 落点上得出的。修正 E0 后，tulip 第一个心形的宽度从 0.64 R 升到 0.70 R（视频 0.77 R），大部分"缺口"消失。
> - §6 说"第一块白色在停顿期间被摊平"不对：视频里白带是在第一个心形还在倒的时候形成的（1.2–1.9 s）。
> - §8.3 中 EXIT_CAL"斜率吻合 0.25–0.43"用的是无符号斜率；有符号的沿航向弦斜率是 0.11–0.21，更接近默认出流。所以 EXIT_CAL 暂不作为参考入口。

### 9.2 结构评分（`diff/score.py`）

**动机。** IoU 看不见结构：
- 一个面积和位置都对的圆盘，比所有模拟的 IoU 都高（0.54–0.73）；
- 把视频里的棕线全部填平，IoU 仍有 0.82–0.94。

**定义。** 先做三步预处理：
- 被遮挡的格子取最近可见格子的值；
- 去掉 ≤ 2 格的斑点；
- 只对模拟场做 σ = 0.7 格的平滑（求解器不分辨单格细节，否则网格噪声会被奖励）。

然后对两类分别计算容差重合率 F_K：
- "白色" m = clip((x − 0.3)/0.4, 0, 1)；
- "内部棕色" b = closing(m, 半径 2) − m，即两侧 2 格内被白色夹住的棕线、层间缝和凹口。

F_K 是模拟与视频中能在同一格（全分）或相邻格（半分）找到同类对应的质量所占比例。最后在 ±2 格（约 4 mm）的刚性平移中取最佳，得分为 √(F_白 · F_棕)。

**标定目标（`diff/cmafit.py`）。**
- 帧的入选条件：可见白色 ≥ 40 格，且可见面积 ≥ 60%。
- 每个图案的结构分和 IoU，各自除以视频与自身 0.25 s 之后那一帧的值：1 表示"和视频自身相隔 0.25 s 一样接近"。
- J = 0.75 · 结构分 + 0.25 · IoU。IoU 权重 ≤ 0.3 时，填平棕线或画成一团的场不会胜出。

**验证。** 每格依次为 tulip / leaf / heart / push_heart / swan。

| 检验 | IoU | 结构分 |
|---|---|---|
| 视频自身，间隔 0.07 s | 0.80–0.84 | 0.73–0.82 |
| 视频自身，间隔 0.25 s | 0.69–0.77 | 0.65–0.74 |
| 同面积圆盘 | 0.54–0.73（高于所有闭合） | 0.23–0.44 |
| 填平棕线（闭运算 r = 3） | 0.82–0.94 | 0.31–0.54 |
| 随机重画棕线 | 0.66–0.88 | 0.48–0.58 |
| 平移 2 格 | 0.54–0.62 | 0.72–0.85 |
| 平移 5 格 | 0.30–0.38 | 0.44–0.48 |

- 单个圆盘、填平棕线、乱画线条，结构分都明显低于视频自身 0.25 s 的值；IoU 三项全部不合格。
- 平移 1–2 格几乎不扣分，5 格明显扣分。
- 设计时由两个独立方案（边界 F、区域两类 F）比较，再经对抗评审选定并修正（工作流 wf_d3de6c65-af9）。

**局限。**
- 现有闭合画出的棕线，位置与视频的相关只在随机水平。目前结构分区分出来的主要是"有没有层次、层次有多密"，还不是"层在不在对的位置"。
- 落点误差降到 1–2 格以内之后，这一项才会真正起作用。

### 9.3 扇形铺开

**修正 E0 后还剩什么。** tulip 第一个心形（0–2.9 s，S1，杯子坐标系）：

| 时刻 | 视频 后缘 / 前缘 / 宽度 [D] | 模拟 后缘 / 前缘 / 宽度 [D] |
|---|---|---|
| 1.5 s | −0.05 / +0.18 / 0.35 | −0.10 / +0.17 / 0.31 |
| 2.0 s | +0.03 / +0.26 / 0.43 | −0.10 / +0.20 / 0.34 |
| 2.5 s | −0.03 / +0.20 / 0.42 | −0.10 / +0.20 / 0.33 |

前后缘基本对上，面积也一样（0.14）。剩下的差距是**横向宽度**：视频把同样多的白色摊成一条宽 0.43 D、沿倒奶方向压扁的带（宽高比 1.65），模拟是宽 0.33 D 的 U 形心（宽高比 1.2）。

**试过的机制（Warp/numpy 原型，`scratchpad/fan/`）。**

| 机制 | 结果 |
|---|---|
| 扇形沉积核：浮出核横向拉宽 ×2 | 白团形状几乎不变：沉积会被薄膜压力摊开，核的形状被抹掉 |
| 落点处卷吸的咖啡以棕色上涌（与白色同位） | 落点周围变灰（单层混合）；放到落点后方也不压扁白团 |
| 射流把表面膜往下拽（只沉棕色，W = κ S K） | IoU 0.527 → 0.560，但结构分 0.436 → 0.392，宽度不变 |
| **射流动量驱动的表面流（V2 §2.1）** | **κ_M = 6：宽度 0.43、宽高比 1.61，与视频一致，形成宽月牙带**；但整体前移过多（后缘 +0.08，IoU 0.40） |

在近乎不可压的薄膜里，面积不变地把一团白色横向摊开，只能靠带旋度的流动。射流的水平动量在液面形成向前的表层流，在前方减速、向两侧分开，这个驻点应变正好把白团压扁、拉宽。

只开拖曳（宽度 0.38，前移 +0.03）和只开垂直交换（前移 +0.06，沿向压扁）两部分都有贡献。缩短传播长度 L_C 并不能把"横向铺开"和"向前输运"分开（L_C = 0.2 时前移更多）。

**基础改动。** 表面流的形状常数（传播长度 L_C、作用半径 R_F）改为闭合参数 `circ_L`、`circ_rf`：
- `solver.Params`；
- `DiffPour(circ_shape=...)`；
- `cmafit --circ-L`。

numpy / Warp 在非默认形状下一致到 1e-15。它们和强度 κ_M 一起，在新 E0 与结构评分下重新标定（§9.4）。

### 10.2 郁金香"尾巴"：是咖啡膜的物理，不是壶

逐帧（N=96）对比 v05g 和视频，白色前沿按沿倒奶方向的位置计：
- **前沿惯性滑行。** 第一团奶在 1.75 s 停注。此时模拟和视频的前沿一致（+17.6 / +17.1 mm）。停注后视频前沿停住甚至略回缩（+15.5～16.3 mm）；模拟靠惯性又滑了约 3 mm（停注时前沿速度 5 mm/s，β = 2 /s）。
- **推挤传递。** 第二、三团落在后方 20–40 mm，又把模拟前沿推出约 1.3 mm，视频约为 0。
- **收尾前已错位。** 到收尾开始（8 s），模拟前沿在 +22.2 mm，视频在 +17～18 mm。前方 20 mm 以外的白色面积：模拟 130 mm²，视频 25 mm²。
- **收尾阶段本身。** 7–13 s 时 χ = 0，没有新白色，模拟和视频一致。视频是被流股拉出的一条 1–2 mm 的细线。模型只有"向前拖曳"一项，近乎不可压的薄膜在它作用下形成一对涡，拖出一条宽舌头，在 256² 下卷成团。
- **κ_c = 0。** 收尾什么也拉不出来，但对沉积阶段的整体前漂没有影响。
- **κ_t = 0。** 模拟落后 7–9.5 mm。说明射流动量决定了白色往前走多远，但模型把它存成了会滑行的膜动量。

物理设计组（工作流 wf_692f5786）给出的机制，待在新数据上检验：
- **M1 运动学沉积。** 射流的水平动量进入咖啡本体，不进入浮筏。白色往前长，是因为泡沫在落点前方 Δx_f = u_in τ_f 处浮出（τ_f ≈ 0.06–0.1 s，即 6–9 mm），而不是靠存下来的膜动量。对应 μ_s = 1、τ_s ≈ 0.08 s。
- **M2 落点"火山口"。** 落点处涌出的是棕色液面（源项 e_F χ S K，不带奶），用它把新旧层隔开、形成月牙。
- **M3 下潜射流的卷吸汇。** 卷吸量 E_J = e_E (1−χ) Q/d。只卷走棕色，浮力泡沫留下并在尾迹里重新浮出；同样体积从远处返回液面。拖曳目标改为落点自身的移动速度 V_j，不再用 κ_t u_in。玩具模型里，这样能拉出 1.4–2 mm 宽的细线，没有卷团。
- **另一组的方案。** 用整层浮筏（奶泡 + crema）的塑性屈服让前沿在有限时间内停住，同时保住推挤。

### 10.3 "动作歪了"的核查与杯子配准重建（工作流 wf_f5b85fb0）

用户发现模拟和真实视频对比时"歪了"。

**核查结论：手部动作没有歪。**
- 用实测位姿画出的壶体线框，在三台相机里都贴合真实的壶。
- 壶嘴尖误差约 ±3 mm，没有固定偏置，没有偏航或倾角误差。
- 位姿和图像的时钟偏差为 0。
- 郁金香收尾阶段，壶嘴轨迹与视频细线只差 1–1.5 mm。
- 之前看到的"壶嘴偏左 12 mm"，是诊断脚本把模拟时钟和绝对时钟混用造成的，已撤回。

**真正的误差在杯子（液面圆）的配准：**

### 10.5 保留层间棕线的视频白度目标（2026-10-20）

**问题。** 用户看对比视频时指出：真实的郁金香在最后是三块——上面的泪滴、中间的心、下面的翅膀，之间隔着细棕线；监督目标（`video_obs` 的 w）却把三块连成一块。核查确认：
- 旧目标在 tulip 最后 3 帧只有 1 块（参照 3 块）。参照缝隙中线只有 14 % 被判为棕色（leaf 1 %，swan 10 %）。
- 标定只看白 / 棕的面积和结构分，填平缝隙的目标会奖励"把层糊在一起"的机制（见下文屈服应力）。

**参照与指标（`rig/topo_ref.py`、`rig/topo_metric.py`，`raw_data/rig/targets/<p>_ref.npz`）。**
- 参照只用倒完后的目标帧图像（相机 1，晚 0.5–2.9 s，已配准到视频网格），不用视频，也不用任何白度。五个图案一套常数：
  - 线性光下的 crema → 奶泡混合比例 f：局部端元（4 mm 归一化卷积），色度项排除暖色反光；
  - 局部半高：P = f 在 1.5 mm 内的最大值，P ≥ 0.5 且 f ≥ P/2 为白；
  - 缝隙 = 白色经 2 mm 圆盘闭运算后多出的棕色（≤ 4 mm 宽的线、层缝、缺口），< 1 mm² 的碎片去掉。
- 结果（≥ 20 mm² 的块）：tulip 3 块（翅膀 768、心 466、泪滴 303 mm²；Otsu 掩膜把泪滴和心连成一块），leaf、heart、push_heart 各 1 块，swan 2 块。半高比例取 0.35–0.65 时 tulip 都是 3 块；泪滴 / 心的鞍点处 f ≤ 0.32。
- 视频的最后 3 帧逐帧配准到目标图（相对漂移最多 1.6 mm，`targets/frame_offsets.json`），参照按 align-corners 面积均值重采样到 128。
- 指标（最后 3 帧平均）：

  | 列 | 含义 |
  |---|---|
  | iou | W > 0.5 与参照白的 IoU |
  | gapF1 | 缝隙召回（参照缝隙骨架上 W < 0.5 的比例）与精度（W 的内部棕色落在参照缝隙 1 px 内的比例）的 F1 |
  | bf1 | 边界 F 分，1 px 容差 |
  | dArea | 结构分，W 按格子面积平均（与现在的 `video_on_grid` 相同），N = 48 |
  | p20L40 | 最后 40 帧 ≥ 20 mm² 的块数均值 |
  | blink | 只闪一帧的像素比例（全视频） |
  | J2 | (iou + bf1 + gapF1 + dArea + 部件数项 + 厚度项) / 6，选择用的目标函数 |

- 可观测上限：把目标图的 f 模糊到视频的边缘模糊（σ ≈ 1 mm）再取阈值，缝隙召回也只有 0.62–0.77；σ = 1.2 mm 时泪滴和心就连上了。所以召回 0.6–0.8 已接近视频能给的。

**原因（三个）。**
1. **标签填缝。** seg_sup 的训练标签是 Otsu 掩膜，本身就填掉一半左右的缝（tulip / leaf / swan 缝隙召回 0.54 / 0.48 / 0.41）。分类器学会了填缝。
2. **时间平滑。** `seg_sup.temporal` 对证据和信念各做 1 px 模糊，把 1–2 px 宽的棕线抹掉。
3. **融合裂缝。** `cup_register` 的融合把"缺深度"当作可见。黑色釉面杯沿（相机 0、2）、不锈钢壶和空中奶流（相机 1）都不返回深度，它们的颜色进入两视角中位数，变成穿过圆盘和白区的灰黑阶梯状"裂缝"（裂缝窗口里 94–98 % 的暗像素由此解释）。这是假的棕线：任何保缝的步骤都会把它们一起切出来（第 1 轮的"接缝线"）。heart 3.3–4.1 s 的"白色射流桥"也是同一原因：壶嘴唇上的奶被相机 1、2 当成液面。

**新融合（`rig/fuse_occ.py`，`video_obs.frames()`）。**
- 每台相机在自己的图像里画遮挡物，全部外扩 8 px：
  - 近深度：比液面近 10 mm 以上，闭运算，补上边缘大多是近深度的缺深度洞；
  - 壶：实测半径剖面的回转体 + 壶嘴尖，按 tag 位姿放置（去掉时间上的离群位姿），取投影凸包；
  - 奶流：从壶嘴尖到液面、以及到实测落点的 3 mm 半径管（立体匹配分辨不出细流，深度读成液面）。
- 8 px 是实测的遮挡物边缘暗带宽度：相机 0、2 的视图除以其他相机深度确认的视图，按到近深度的图像距离分箱，10 % 分位在 8–10 px 回到平台；更远处液面上的缺深度无害，不当作遮挡。
- 双线性取样到 2 倍网格；逐相机对数增益对齐（全局偏置 + 平滑场，只在 ≥ 3 视角像素上求共识，平滑部分限幅 ±0.15）；权重 ∝ 最差方向地面采样步长的 −4 次方；≥ 3 视角时剔除离群；可用区边缘羽化。没有可用视角的像素无效。有效性规则沿用 `video_obs.observe()`。
- 效果（t < 4 s，比任何 crema / 奶泡混合都暗的像素，tulip / leaf / heart / push_heart / swan）：31877 / 43166 / 43628 / 36097 / 45050 → 3035 / 11868 / 9716 / 4826 / 9856。仅凭图像（不用 W）在最后 3 帧解析出的参照缝隙比例：tulip 0.66 → 0.82，leaf 0.60 → 0.73，swan 0.66 → 0.88。有效区内的裂缝消失（每个图案 24 个时刻人工检查）。
- 代价：
  - 早期帧（t < 4 s）有效面积 0.94–0.97 → 0.75–0.80，全程平均 0.97 → 0.84–0.87；
  - 落点 4 mm 内只剩 0.07–0.26 有效，早期沉积大多看不到；图像证据不支持更小的边距（相机 1 在奶流掩膜外 12 px 处仍比其他视角亮 7 %）；
  - 约 1/3 有效像素只有一个视角（`nview` = 1），无法交叉检验，杯沿附近的墙面反光和投影可能残留。
- 新增 `nview`（每像素可用相机数）、`frame_idx`、`pitcher_depth_conflict`（壶凸包内相机看到液面深度的比例，偏高说明位姿错）。

**新白度（`rig/seg_topo.py`，`video_obs.white()`）：W = 切谷（否决（时间（分类器）））。**
1. **分类器**：seg_sup 原样（特征、标签构造、增益增广、梯度提升树），在新帧上留一重训。标签重采样改为 align-corners 面积均值（`video_obs.hand_mask`；原来的 4×4 块均值把像素边缘放在 ±1.05，掩膜在杯沿处向中心偏 0.26 mm）。
2. **时间**：`seg_sup.temporal` 原样。
3. **暗度否决（z2）**：奶泡盖在 crema 上只会增加反射，所以比局部 crema 还暗（超出噪声）的像素不可能是奶泡。
   - x = 线性颜色 / 局部 crema（4 mm），投影到该帧"crema → 奶泡"方向得 f（crema 0，奶泡 1），5 帧中值；
   - cap = exp(−min(f, 0)² / 2σ²)，σ = 该帧 crema 种子上 f 的 1.4826 MAD；W ← min(W, cap)；
   - f ≥ 0 的像素一律不压（半透明奶泡、阴影里的奶泡）。除最少种子数（100 px，约 50 mm²）外没有可调常数，σ 每帧实测。
4. **持续切谷（run）**：
   - f = 线性光奶泡比例（局部 crema / 奶泡端元）；侧翼水平 P = f 在 4 mm 内的灰度闭运算；
   - P ≥ 0.5 且 f < P/2（半高）为谷证据，进逐像素两状态 HMM（切换率 0.1 / 帧）；Hessian 中线把 2 mm 内的弱谷（f/P < 0.75）接到强谷上；
   - 每个像素切 / 不切的状态至少持续 5 帧（约 0.3 s）；被切像素 W ≤ 1 − P(谷)，桥接像素 W ≤ 0.45。只降低 W。

物理依据：

| 量 | 值 | 来由 |
|---|---|---|
| 视频边缘模糊 σ | ≈ 1 mm（实测 0.7–1.5 mm） | 1–2 mm 宽的棕线降不到 crema 水平，全局阈值留不住它，但它总低于两侧白色平台的一半 |
| 侧翼闭运算半径 | 4 mm | 缝宽一半（约 2 mm）+ 2σ：P 取到缝两侧未被模糊的白色平台 |
| 半高 | 0.5 | 模糊阶跃边的真实位置；对缝隙给出半深处的全宽 |
| 最小持续 | 5 帧 ≈ 0.3 s | 层缝是持续的结构，单帧的谷是噪声 |
| 否决 | f < 0 超过噪声 | 奶泡只能加亮；σ 每帧实测 |

**选择流程与诚实性。**
- 共四轮。每轮先写规则、再跑网格，只用 tulip + leaf 选：J2 最高、在最优 0.005 以内取最简单的；可接受性上限为早期白 ≤ 0.01、中段远处假白 ≤ 0.01、翻转 ≤ 0.008、闪烁 ≤ 3e-4、后半程翻转 ≥ 8 次的像素 ≤ 32、最后 60 帧块数变化 ≤ 16。
- 前三轮的结果都被独立审查推翻：
  - 第 1 轮（参照做标签）：标定最优的候选因测试分被排除（诚实性），闪烁是旧目标的 10 倍，早期帧沿融合接缝切出假线；
  - 第 2 轮（更强的时间段 tx）：选择用的标定分类器在训练里含测试图案的掩膜；嵌套检查（只用标定图案训练）选的是 repo 时间段；
  - 第 2b 轮（n2 门：f < 0.25 不是奶泡）：在测试图案上去掉了真实的半透明奶泡（swan iou 0.835 → 0.728，heart dArea 0.831 → 0.687）。
- 第 2c 轮：规则选 repo 时间段 / 无否决 / run（官方网格用单图案分类器，J2 0.761）；LOPO-4 稳健性检查选同一个。连接闭合（junction closure）的变体都不在 0.005 以内（带持续的超出闪烁上限）。
- **采用的是 z2 否决（第 2c 轮消融 C2），这个选择是在第 2c 轮结果出来之后做的。** 规则的"取最简单"选了无否决；无否决版本在 leaf 0.81–1.25 s 壶旁有一块假白（L 71–79，局部 crema 145，最多 161 px，是阴影），z2 把它降到 ≤ 27 px。理由是物理（奶泡只能加亮）和这个标定图案上的缺陷。标定 J2 完全相同（0.824）；测试 J2 0.835 对 0.833，C2 的测试数在做消融时已算出并看过。
- 测试数不是干净的留出估计：五个图案在各轮开发中都看过，审查者在测试图案上的发现也读过。没有新的留出图案。

**剩余缺陷。**
- tulip 泪滴 / 心：最后 40 帧只有 8 帧分开。两条切出的谷在 V 形顶点处差 1–2 px 没接上（模糊使对比降到半高以下，Hessian 中线在顶点无定义）。连接闭合能分开 31/40，但闪烁超限（blink 4.4e-4，后半程多次翻转像素 37.5），没有采用。
- swan 早期 0.3–2.6 s 左上的亮光带（最多 139 px）：两台看到它的相机里都比 crema 亮，否决不了。
- 中段仍有缝被填：push_heart 2.7–3.4 s、tulip 3.6–4.3 s 环的底部。
- leaf 偏胖：完整目标下约 +0.8 mm（奶泡晕、相机 1 的灯光高光），白质量比 1.15。
- 块数变化比旧目标多（标定 8.0 对 4.5，留出 11.3 对 0.7）：一部分是保缝目标固有的（缝开合时块数跳变）。
- 早期有效面积小（遮挡边距）：N = 48 下每个图案有 0–11 个前 3 s 的帧观测格子少于 `score.MIN_OBS`（tulip / leaf / heart / push_heart / swan 6 / 2 / 0 / 11 / 7），通过 `frame_ok` 的帧少 1–7 个。
- 光流 `<p>_flow.npz` 仍基于旧帧（权重 0，未用）。
- 测试数不是干净的留出估计（见上）。

**复现。**
- `python3 -m latte_imex.rig.video_obs`：先 `fuse_occ` 生成帧，再 `seg_topo` 留一白度（缓存在 `SEG_TOPO_CACHE`，默认系统临时目录；单个图案约 7 分钟，2 线程）。
- `python3 -m latte_imex.rig.topo_ref`（参照）、`--offsets`（最后 3 帧的配准，`video_obs` 重建后要重跑）；`python3 -m latte_imex.rig.topo_metric <tag> video_obs` 给现存目标打分。
- 核查：repo 的 `fuse_occ` 与审查过的帧在 60 帧（每图案 12 帧，均匀分布）上逐位相同，提交的帧即这批；repo `seg_topo` 用空缓存重算的 W（连同分类器 logit）与第 2c 轮 C2 逐位相同（float16，五个图案类别翻转 0），存入 `video_obs` 的是 W × 255 取整（与 C2 相差 ≤ 0.0022，每个图案 4–20 个 W ≈ 0.5 的像素帧类别不同）；`topo_ref` 重建的参照与 `topo_metric` 对 C2 的 281 个数全部复现。

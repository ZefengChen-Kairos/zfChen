# 校准后（郁金香 + 树叶）冻结的闭合 vs 未校准的全物理闭合：六图末帧对真实视频（256²）

动作：两组都用同一套猜测的全物理动作 FS（固定，不随闭合重设计）。CAL = 校准最优闭合（起点 FSp2，N = 128 校准），FS = 未校准的全物理闭合。V0.5 = 原版（它自己猜的动作和入口），只作参照。1 D = 80 mm。
定义：compare.py 规范坐标；IoU = 模型 c > 0.4（或 0.5）对视频 w > 0.5（杯内 R = 0.49 D）；未对齐 = 原样；最佳 = 刚体 |θ| ≤ 25°、|d| ≤ 0.06 D（compare.best_align）；边界距离 = c > 0.4 白区边界的对称平均距离；白区比 = 模型白区分数 / 视频白区分数；L_fin 按预注册（自带 2.5° / 0.01 D 对齐），褐线数为该对齐下五条线 x = −0.10, −0.05, 0, 0.05, 0.10 D 上的计数（模型 / 视频）。

## 9. 逐笔沉积分数 χ（求解器收到的入口，S_eff 加权；chi_strokes.py）

FS 的每笔壶嘴高度是按 FS 闭合反设计的（让每笔 χ 配 V0.5）；动作冻结后换成 CAL 闭合，同样的笔 χ 变成：

CAL 的沉积开关比 FS 平（p_dep 1.79 对 8，B_dep 1921 对 1550；CAL 的起点 FSp2 是 p_dep 2，只有起点 FS 的那条 CMA 是从 8 降到 1.29）。同样的笔：
- '轻柔全沉积'的底座笔（FS 0.94–0.99）降到 0.73–0.81，少沉积约 20 %。
- 摆动底座，设计目标 0.335（各图 #1、郁金香 #3；这些笔已在 2.50 cm 的高度上界）：FS 0.31–0.34 升到 0.51–0.52。
- 摆动底座，设计目标 0.52（#0）：FS 0.51 升到 0.57。
- 细切（FS 0.00–0.02）升到 0.30–0.34，大白心的细切从 0.14 升到 0.40。

也就是说，同一套动作在 CAL 闭合下，底座变薄，摆动和细切都在往液面铺白：细切画出来的不再是褐线，而是细白条。
κ_r 同时从 0.037 升到 0.172（4.6 倍），冲击点的径向回流更强。

这些 χ 变化不是大白心变空心的原因：单换参数的检验（`ablate/`，N = 128 和 256²）里，FS 只换 (B_dep, p_dep) 时底座同样少沉积（256² 大白心沉积 −19 %，CAL −21 %），大白心仍是实心；FS 只把 β 换成 1.41 /s 时 χ 一笔不变（χ 的公式里没有 β），大白心就从凹口往下出现褐色空心楔形（N = 128 整颗空心，256² 空了上半）。沉积开关的变化主要改变白区大小：千层心、郁金香、树叶的白变大。

# 用咖啡师的真实动作跑 V0.5：结果（审稿后定稿）

> 用户的问题："用咖啡师的真实动作跑 V0.5 试试"。
> 模型：学长的 V0.5 单层模型（`latte_imex/solver.py`，闭合 'chi'，回流律 'v05'），求解器一行没改。
> 动作：`latte_imex/stage_scripts/<p>.json`，从六段视频读出的咖啡师动作（落点路径和摆动、壶嘴高 z(t)、想要的流量 flow × 15 mL/s、壶嘴方向 `barista_yaw_rad`）。时间轴用 `calib.physical_script(name, preroll=0)`（冻结帧去掉；V0.5 没有首白延迟，所以不加 pre-roll）。
> 入口：和全物理最终组 FS 同一套物理（`v05allphys/final/drvf.py` 的 'exitmin'）：壶嘴滞后 τ = 0.08 s，在倒时流量 ≥ 1 mL/s；U⊥ = √(0.35² + 2gz)；连续性足迹 r = √(Q/(πU⊥)) 加倾斜椭圆；水平速度 = 手速 + 沿壶嘴方向 u_exit = 0.15 m/s；不加流量脉动；S_eff = κ_Q·Q（Q 以 D³/s 计）。
> 闭合：FS（p_dep 8）和 FSp2（p_dep 2），**原样照搬**。这两组是给 Codex 的笔画反设计出来的，没有看过视频，所以这里是零调参检验。
> 单位：D = 8 cm 杯径（1 D = 80 mm，D³ = 512 mL）；速度 m/s，长度 mm，时间 s。
> 本文取代 `results.md`。审稿意见（`verify.md`，11 条）全部照改，逐条处理见 §10。新增的运行、表、图都在本目录，脚本在 `extra/`。

## 一句话结论

**真实动作把白放到了图案的大致方向上，但白整体往下游偏 4.6–7.4 mm、面积大 1.05–2.2 倍，六个图案的决定性结构没有一个完整出来；和 Codex 动作版在同闭合、同网格（256²）、同定义下比，只有 FS 一组明显变好（末帧原样 IoU 平均 0.426 → 0.487），FSp2 几乎不变（0.477 → 0.482），而且改善几乎全来自千层心，推推乐变差，郁金香在 FSp2 下也变差。**

- **同闭合比**（§2，256²）：
  - FS：原样 IoU 0.426 → 0.487（+0.061），calib 末帧 0.381 → 0.476；
  - FSp2：0.477 → 0.482（+0.005），calib 0.452 → 0.469；
  - 逐图：千层心 +0.12～+0.30，推推乐 −0.07～−0.08，郁金香 FS +0.07、FSp2 −0.04，其余 ±0.06 以内；
  - 边界距离没有变近（3.4–3.7 → 3.9 mm）。
- **白在哪里**（§3）：
  - 方向：郁金香、树叶、天鹅只需转 −1～+8°（Codex 动作版要 4–25°）。
  - 位置：五个图案的白沿 B→D（下游）偏 +4.6～+7.4 mm，质心平均偏 6.5–6.6 mm，Codex 动作版 4.7–5.3 mm。
  - 面积：真实的 1.05–2.2 倍，千层心 0.9 倍。
- **结构**（§5）：大白心部分/大体，树叶部分，天鹅部分（弱）；千层心否（外形对），郁金香否（只有位置和外形），推推乐否。
  - Codex 动作版虽然位置和大小不对，结构（天鹅颈、叶脉、叠心）反而更清楚：这组闭合只在为它反设计的笔画下出结构（§2）。
- **细纹**（§6）："χ 太高所以出不来"被诊断否定：
  - χ 降到 0.45 只让白变少变灰，阶段末细纹反而更差；
  - 足迹减半和加密网格各让阶段末白段的误差少 0.3–0.6 条（FSp2），但末帧纹数仍是 2–4 条（视频 2–12 条：千层心 2、郁金香 4、树叶 12、天鹅 7；千层心原写 4，已更正，见表 F 前的更正说明）；
  - 模型在阶段末留下的几道纹到末帧就并掉了。
- **入口的不确定度**（§7）：
  - u_exit 在 0.10–0.27 m/s 内变，郁金香的白质心移 4.6 mm、L 变 2.5，是两组闭合 L 之差的 14–55 倍；
  - 流量 ±50% 让面积比在 0.65–1.93 之间变。
  - 所以面积偏大可以由动作脚本的精度解释，下游偏移和细纹不能（§9.2）。

## 1. 怎么做的

**适配器** `latte_imex/v05_adapter.py`：`V05Model(base=FS|FSP2).run(script, params, N, t_out)` 返回 M 系的 c[n, N, N]、账本和入口日志，直接接 `calib.simulate_clip` 和 `make_videos.pattern_video`。公式全部写在模块说明里。求解器收到的入口经三种独立检验：
- 单元测试 `python -m latte_imex.v05_adapter test`：U⊥、r、d、S_eff、u_h 对独立公式 ≤ 2e-16；手速对中心差分 ≤ 1e-9 D/s；壶嘴滞后对 `solve_ivp` ≤ 6.5e-5 mL/s；零流量、账本、输出时刻、pre-roll。
- **新增** `test_raw_json`：直接读原始 `stage_scripts/<p>.json`（只借用 `calib.freeze_cuts / clip_to_phys` 做时间换算），自己重写缓动、Bezier、摆动和 0.25 s 渐入渐出，与入口的落点路径、高度、流量、yaw 比较：六图最大差 3e-16 D、4e-18 m、3e-15 mL/s，yaw 差 0。这一条不经过 `v3min_adapter` 和 `stages_to_moves`，所以是"脚本 → 路径"这一步的独立检验（审稿的 `verify/inlet_check.py` 也独立重算过，差 ≤ 2e-14）。
- **新增** `test_foot_scale`：诊断用的足迹缩放只改 r1、r2、d，不改 Q、U⊥、S_eff；配 B_dep/foot_scale 时 χ 逐点不变（差 0）。

**运行**（全部 `latte_imex/v05_real_run.py`，最多 3 个进程）：
- FS、FSp2 各六图，128² 和 256²（全程运行：c 存在视频 5 fps 分析帧和 15 fps 视频帧的并集上，评估和视频用同一次模拟）。**本轮新增 FSp2 256²**，所以两组闭合都能和 Codex 动作版（256²）同网格比。

读法：
- **FS**：六图平均原样 IoU +0.061、calib 末帧 IoU +0.095。但 FS 的 Codex 动作版起点低：calib 末帧 0.381 是四个 Codex 动作版里最低的，千层心只有 0.257（原样 0.349）。所以 FS 的提升有一部分来自起点低。
- **FSp2**：原样 IoU 只 +0.005（128² 上 +0.014），calib 末帧 +0.017（128² 上 +0.026）。逐图：千层心 +0.115，天鹅 +0.022，树叶 +0.012，大白心 −0.005，郁金香 −0.037，推推乐 −0.078。
- 两组共同的：**只有千层心明显变好**（白区从真实的 0.32–0.54 倍升到 0.90 倍）；**推推乐两组都变差**（−0.07～−0.08，白区是真实的 2.1–2.2 倍）；郁金香在 FSp2 下变差。
- **边界距离没有变近**：原样边界距离 FS 3.7 → 3.9 mm，FSp2 3.4 → 3.9 mm；calib 末帧 3.5 → 3.6 mm、3.4 → 3.6 mm。
- **结构反而是 Codex 动作版更像**（`codex_vs_real_actions.png`）：Codex 动作版的大小和位置不对，但每张都有清楚的结构：天鹅有颈和头，树叶有一排叶脉，郁金香有叠起来的心，推推乐有心形和内层褐线。换成真实动作后，这些结构都没了。FS/FSp2 是为 Codex 的笔画反设计的：逐笔高度让 χ 落在部分沉积，细切流量小，笔与笔之间有桥。闭合只在这样的笔画下出结构。咖啡师真实的手法是 z 1.0–2.0 cm、约 15 mL/s 的连续摆动，同一套闭合给不出结构；§6、§7 又表明，在脚本精度范围内改 χ、足迹、流量也给不回来。所以这组闭合的"动作 → 图案"映射是对 Codex 的笔画定制的，不是对真实的手法。
- 上一稿标题里"六图平均 0.49 对 0.38–0.41"是拿 128² 的真实动作去比 256² 的 Codex 动作，并且漏掉了 FSp2 的 Codex 动作版（0.477 / calib 0.452），已撤回。

## 6. 细纹为什么出不来：χ 还是足迹？（诊断，不是拟合）

**问题**：上一稿把"FS 让摆动段几乎全成白（χ 0.79–0.93），而 V0.5 的条纹靠 χ 0.34–0.52 的部分沉积"写成了细纹出不来的原因。审稿指出：
- 上一稿自己的流量 ×0.5 诊断否定了这一条：χ 降到 0.38–0.59，细纹反而更少；
- 足迹 d = 5.1–6.1 mm 比摆动半幅 2–4 mm、真实线距 2–3 mm 都大，至少同样可能是原因。

按审稿的建议补了诊断。这些都不是拟合，每次只改一两个因素：
- **(i) χ ≈ 0.45**：Q 和 d 不变，只把 B_dep 乘以 s，让摆动 + 后退段的流量加权 χ = 0.45（V0.5 自己摆动底座的范围）。FS 的 s = 0.67–0.73（B_dep 1045–1137 D/s²），FSp2 的 s = 0.45–0.50（B_dep 964–1069 D/s²）。这大约相当于把摆动段壶嘴高从 1.7 cm 抬到 2.6–2.9 cm（FS）或 4.1–4.7 cm（FSp2）。

**限制细纹的是什么**：不是 χ 的水平；足迹宽度和网格只是次要因素。下面三条是假设，没有证明，要靠标定和下一版模型去检验：
- **单层闭合**：新奶和底下的褐层在深度上混在一起，模型白区的 c 中位只有 0.64–0.85，真实接近 1。真实的褐线可能来自白层折叠后褐液从折缝里冒上来，单层模型没有这层机理。
- **筏面铺展和回流**：c_p、β、κ_r 可能把 5 mm 以下的间距抹平。这三个参数正好都在标定空间里（§9.1）。
- **摆动相位**：脚本的摆动相位是约定，和真实的手不同步（§8）。

- **摆动相位是约定，不是测量**：脚本把摆动写成 amp·sin(2πf·u)，u 从每段起点算起。加上摆动以后，摆动段的落点误差反而变大：树叶 0.023 → 0.043 D，郁金香 0.024 → 0.033 D，天鹅 0.018 → 0.023 D。这说明脚本的摆动相位和真实的手不同步。V0.5 的细纹对相位敏感（`ALLPHYS_RESULT.md` §6.2：千层心要 5 Hz 流量峰与 2.5 Hz 横摆 2:1 锁相），所以细纹对不上，有一部分可能来自相位。
- **高度和流量都不是测量值**：z 是目测（低位 1.0–2.0 cm）；流量只有相对值，Q_ref = 15 mL/s 是假设。
- **时间轴**：郁金香、树叶的视频从倒奶中途开始，开头那部分奶模型里没有。天鹅、千层心、郁金香、树叶都有冻结段，按 `physical_s` 处理；郁金香有一段的物理时长不确定（0.07–0.5 s）。
- **独立核对**：脚本 → 入口这一步经两次独立重算（`test_raw_json` 和审稿的 `inlet_check.py`），差 ≤ 2e-14。下游方向也逐帧核对过：yaw 没有转错，也没有镜像。

### 9.2 哪些差距是动作脚本的精度造成的，哪些是模型

动作脚本的精度：单目读出，落点中位误差 1.1–2.5 mm，高度目测，流量只有相对值（±50%），摆动相位是约定。

## 11. 局限

- **零调参的意思**：FS、FSp2 是为 Codex 的笔画反设计出来的，这里原样用在真实动作上，没有看视频调过一个数。这是检验，不是标定。
- **动作脚本**：单目读出；z 是目测；流量只有相对值，Q_ref 是假设；摆动相位是约定；推推乐没有落点核对；郁金香、树叶从中途开始；冻结段靠插值（§8）。
- **入口**：
  - 没有流量脉动，视频没测到。
  - 壶嘴滞后用一阶模型，τ = 0.08 s；漏流低于 1 mL/s 即断流。
  - u_exit 没有测量，敏感性只在两个图案上测过。
- **观测**：
  - 真实白度 w 会把 1–2 mm 的褐线糊成灰，所以真实的线数是下限。
  - 模型的白是灰的：单层闭合把新奶和底下的褐层在深度上混在一起。阈值 0.5 会把一部分灰算成褐，所以 §6 另加了不设阈值的峰数。
  - 视频的外观参数 k = 3 是暂定值，没有学过。
- **首白**：V0.5 没有延迟机理，损失 L 的约一半来自首白一项。
- **网格**：128² 一格 0.63 mm，256² 一格 0.31 mm。1–2 mm 的线在 256² 上只有 3–6 格。
- **对齐**：0.12 D 窗口用的是由粗到细搜索，不是原来的穷举搜索；在 0.06 D 下两者的 IoU 差 ≤ 0.002。
- **判定**：IoU 对结构不敏感（`compare_real.md` §4），结构判定靠看图和剖线计数，由我一人做。
- **诊断**：每次只改一两个因素，不是候选设定，也没有对视频优化。

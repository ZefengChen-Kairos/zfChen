## 3. 逐变体评语

### 3.1 Q（排名 1，不采用）

**做对了什么。**
- 在 (V) 中保留 −∫f_J·u。等压画布 + 筏面积不可压把 f_J 的势部分吸收进乘子，只剩旋度：

```
u=\nabla\phi+\mathcal P[U_J\chi_{fp}],\qquad U_J=v\sin\alpha_j\,\hat e+\dot x_j,\qquad m=|U_J|\,Q/v ,
```

  足迹外是势偶极，u_r = m cosθ/(2πr²)，θ̇ = m sinθ/(2πr³)。
- 偶极不保极角，这正是 v3-min 缺的月牙几何：周向拉伸、面积守恒、包裹率 ∝ 1/r³。实测移动 s₀ = 0.10 / 0.15 D 时 0.11 × 0.60 / 0.14 × 0.58 D，128 → 192² 不变。
- 旧块被推在 d* = √(m/(2πV_j)) ≈ 0.10 D 之外，进不了排除区，所以 L11′ 的"喂大 ×2.8"消失。
- 驻留凹口 0.055 D，与闭式 (r_c³ + 3mt/2π)^{1/3} 一致。

**为什么不能用（结构性的，λ_J 扫描已证明不是强度问题）。** 三个无量纲数要求互不相容：

```
\Pi_C=\frac{m}{S\,r_e}\lesssim0.2\text{–}0.3\ (\text{C 形存活}),\qquad \Pi_L=\frac{|U_J|}{2V}\lesssim0.5\ (\text{切线存活}),\qquad m\gtrsim1\text{–}2\times10^{-6}\ \mathrm{m^3/s}\ (\text{月牙、凹口}),
```

名义值 Π_C = 1.48，Π_L = 3.1。λ_J 窗口 ≲ 0.1–0.25 与 ≳ 0.5–1 不相交。同一个 m 同时决定远场推挤（r ≈ 1–2 cm）和供给环的近场扫掠（r ≈ 4–6 mm）。

**我补充的两点（报告中缺失）：**
1. Q 在出白前把壶侧 0.15 D 处的画布吸进射流脚 **0.084 D**（`test_Ccompres.md` §3 的分向表；v3-min-2 为 0.008 D），这是 W 的投影在足迹后方形成的汇。test_Qquasist 只报了 0.30 D 处的最大值。这一项应列入 Q 的 T1 回退。

**可保留的东西。** 月牙几何、驻留凹口 0.055 D、"旧块被推在排除区外就不被喂大"三组数字，作为后续变体的验收目标；T-Q0 单元检验保留为回归测试。

### 3.2 C（排名 2，不采用）

- **命题 G 是对的，而且具有一般性。** 径向模型：

```
\frac{d(\pi r_b^2)}{dt}=S\,\frac{\psi(r_b/\ell_s)}{\psi(R/\ell_s)}\le S=\frac{d(\pi R^2)}{dt},\qquad \psi(x)=xK_1(x),
```

  所以 d(r_b² − R²)/dt ≤ 0。原型在全部站位、全部时刻都满足 缝(ℓ_s)/缝(Q) ≤ 1（误差 1 格）。例如 s₀ = 0.25 D 定点 6 s：Q 0.047 D；ℓ_s = 4 / 2 / 1 / 0.5 cm 时为 0.039 / 0.039 / 0.023 / 0 D。

```
\begin{cases}
-\dot e\,|G|\le0 & \text{v3-min-2, Q, I（G 内无源）}\\[2pt]
\int_G(1-c)\,\phi/\ell_s^2\,dA\le0 & \text{C（受压处 }\phi<0\text{）}
\end{cases}
```

新白长大时 L 增加（旧块被包裹），两端开口的缝又在无剪切抗力的达西膜里自由排出，所以 w 单调下降。附加的力（Q 的偶极、I 的 Rayleigh 偶极）在射流前方都满足 ∂_r u_r = −2u_r/r < 0，只会加快变窄。三份实测都确认了这一点：有月牙时缝 ≤ 0.016 D；移动射流出白即接触。

**视频要求的是"生成"，不是"保持"。**
- 推心第 2 段逐帧（`min/judge.md` §3）：7.07 s 射流落进旧心凹口；7.13–7.20 s 落点出白卷，**一出现就与旧心隔着窄褐带**；7.27–8.27 s 旧心被撑成月牙，褐弧持续存在。
- 郁金香 10.9–12.3 s（"将底纹压开"，校准集）的缝从 0.05–0.08 D **变宽**到约 0.1 D（目测 ±20%，须重测）。

这两条都要求在缝里（新白外侧、朝旧块一侧）有画布面积**源**。只保护缝不被排空的机制（刚性块 + 画布剪切粘度的挤压膜）无法从接触状态生出缝，所以排在后面。

**5.2 月牙：力必须只作用在接触的筏上，不能作用在画布上。** Q 证明足迹力能做出尺寸正确的月牙。但要满足 Π_C ≲ 0.3 与 Π_L ≲ 0.5，画布上的拖曳不能超过推挤所需值的约 1/10。另有两条事实指向同一点：
- 重测 V7 显示白前几乎不推，月牙在射流进入旧块凹口之后才形成；
- v3.1 §4.7 第 4 条写的机制是"足迹进入旧块 → 局部屈服 → 被从中间撑开"。

这都是**筏—足迹接触**机制。v3-min-2 的 L11′ 是驻点压力 (P) 的一种刚性极限：压入后在供给环 K_f 上等面积重浮。它把旧筏混进新白，造成喂大 ×2.8–3.1，接触即并块。DQ §2.2 自己指出，另一种刚性极限是"推出到等压线"，或按 v3.1 §3.9 在原方位 r_cl = r_sub + a_cl 回浮。另一个值得一并检验的问题：在凹口几何（旧块绕射流张开 ≥ 120°）中，点源运动学本身会把被包住的块径向压薄、周向拉长，v3-min-2 的 T2 只测了"块在射流正前方"的几何。

**5.3 摆动：三个变体都没有触及原因。** Q、C 的 3–4 条离轴褐线是 W 在落点两侧横向拖出的条纹，轴上只有 0–1 条，节距 0.063–0.113 D，没有跨轴的弧；I 在可容许参数下 0 条。v3-min §8 第 1 条列出的原因（L7、L10、L11′、L13）一条都没被改动：
- 摆动时 V_j t_cl ≈ 8.8 mm ≫ r_e，L11′ 的判据本身失效；
- 摆幅 4 mm < 2r_e = 7.4 mm，节距 2.4–3.4 mm < r_e = 3.7 mm，即近场核比条纹还宽；
- 白内的褐只来自移动褐洞的尾迹（T1b 一族），所以是褐岛，不是弧。

## 7. 下一步的结构性改动

原则：不再给画布加力、加惯性、加可压性，这三条路已被 Q、I、C 关闭。缺的是**画布在正确位置的生成**。仍然一次只放开一个极限，每一步都写成 v3.1 的显式极限。

### S1（下一步，v3-min-3a）：表面涡回涌位置——解开 L13 里共用 r_e 的三个半径

**改什么。** v3-min-2 用同一个拟合的 r_e 表示三件物理上不同的事：
- 排除区半径。数值 3.72 mm，恰好等于 v3.1 §3.9 的压入半径 r_sub = 3.7–4.4 mm（低位）；
- 回涌新液面环的外径；
- 供给环的内径。

v3.1 的回涌新液面出生在滞止圆，先验带 r_c < r_e^{(3.1)} < r_0 + b_s = 2.9–11.7 mm。S1 只做两件事：
1. 把回涌出生环 K_e 移到供给环之外，环心为延迟落点、向下游偏移 Δ_e；
2. 保留 (1 − c) 门控，落在筏上的份额记"筏下回流"。

```
K_e\propto q\!\left(\frac{|x-x_j(t-t_r)-\Delta_e\hat e|-r_s}{\hat w_s}\right),\qquad r_s=r_0+b_s,\ \ b_s=0.15\,\min(z_m,H)\ (\text{v3.1 先验中心}),\ \ \hat w_s=\tfrac12 r_e ,
\sigma_e=F_{tr}(t-t_r)\,K_e\,(1-c),\qquad F=\alpha_F\,2\pi r_0 v,\qquad t_r=c_tT_f .
```

排除区（L11′，CR-1 不变）、供给环、吞汇环、(P)、(C)、账本全部不变。引理 F 不变：停倒后 t_r 内在途液面用完，之后精确冻结。

**为什么是合法极限，不是补丁。**
- r_s 取 v3.1 M2 的滞止圆在其先验带上端（MTT 回流套层外缘），是形状常数，不拟合；
- v3-min-1 否决"重生环外移（pxo）"的理由是"3 s 时褐洞被白填满"，但那是 v3-min-1 默认模型也有的致命缺陷，v3-min-2 已用 L11′ 修好（褐洞由排除区几何保证，与表面涡无关）。所以 pxo 当年的否决理由在 v3-min-2 上不再成立，而且当年它只在 F ≈ 1 cm²/s 下测过。

**参数（≤ 5）。**
- Γ、τ_w、r_{e,ref}、Π_coh 不变；
- α_F 从扰动量升为第 5 个拟合参数；c_t 仍为扰动量，若锚足够则再拆开。

**锚（郁金香 + 树叶内存在，且与 g1–g4 不同）：** 每次起倒后、首白前的深褐新液面区面积曲线 A_fresh(t)。
- 窗口：郁金香第 2 段 6.6–8.5 s、第 3 段 12.4–13.5 s，树叶 0–1.7 s；推心 5.73–6.93 s 在测试集，只作检验。
- 起始时刻给 t_r（钉 c_t），斜率给 F（钉 α_F）。这同时打破 v3-min §4.3 里 α_F 与 c_t 只以乘积出现的简并。
- 对 Γ、Π_coh 的灵敏度为 0。
- 若读面积而不是斜率，对 τ_w 的灵敏度为 τ_w/(τ_w − t_r) ≈ 1.6，但 τ_w 由 g1 单独钉住（sd 0.03–0.06）；读斜率则无此依赖。

**可行性风险（须先过）：** 深褐（新）与旧画布的亮度差，能否在 §7.2 的线性 Y 提取算子下以 ≤ 30% 的误差分出来。若不能，α_F 仍作扰动量，缝的预测只能给成带，S1 降为"带内检验"。

**预登记验收（拟合后冻结参数，不对缝重拟合）：**

| 检验 | 判据 |
|---|---|
| 凹口几何 | 按推心第 2 段实际输入：在 B 倒 1.2 s，再移入旧块凹口 |
| T2 缝（凹口几何与任务几何都测） | 出白后 +1.2 s 缝 ≥ 0.04 D，+2.6 s ≥ 0.03 D；用由 A_fresh 锚定的 α_F 预测，不另调 |

**失败时的分叉（按序，一次一个）：**
1. 若 A_fresh 锚定的 F ≤ 1 cm²/s，预测缝 ≤ 0.02 D：S1 在数量上被否定。

3. 最后才是"刚性块 + 画布剪切粘度"的挤压膜（PX-R + η_s，Bq_g = 12η_s/(ζw²)）。它只能保护缝，不能从接触状态生出缝。

### S2（S1 之后，v3-min-3b）：L11′ 的重浮位置——从"供给环 K_f"改为"原方位 r_cl"

- **改什么：** 漂进排除区的筏，按 v3.1 §3.9 在其原方位、r_cl = r_sub + a_cl 处重浮（a_cl 取先验中心 2 mm，形状常数），不再在 K_f 上与新白一起等面积重浮。效果相当于驻点压力 (P) 的"推出"刚性极限：只作用于接触的筏，对画布不施力。

- **验收：**
  - 面积比 ≤ 1.05（消除喂大 ×2.8–3.1）；
  - 凹口几何中 solidity ≤ 0.85、轴向厚 0.08–0.15 D × 横跨 0.4–0.6 D，以 Q 的 0.14 × 0.58 D 为对照；
  - 驻留凹口 0.04–0.06 D；
  - 白前位移不增加。
- **若月牙仍不出：** 只有到那时才考虑"只作用于接触筏的足迹侧推"（v3.1 (a6)，需要 h_eff），且必须同时满足 Π_C ≲ 0.3 与 Π_L ≲ 0.5。
- **规则：** 这改动的是 CR-1 的内容，须在 CR-1 中写明。失败证据是 v3-min-2 T2c 的喂大 ×2.8–3.1，而视频面积比 ≤ 1。

### S3（S1、S2 之后，v3-min-3c）：摆动

  - 原型的在途包是离散延迟（σ_t = 0），调制不衰减；
  - 视频要求每周期生成 0.13–0.45 cm² 画布；
  - 若 S1 + 修好的 T1b 仍不出跨轴弧，T4 的结构原因就在 L13：近场核宽 ≥ 节距。那时 σ_t 只能由台架 E3 测定，不拟合，v3-min-3 对内部纹理不作承诺。

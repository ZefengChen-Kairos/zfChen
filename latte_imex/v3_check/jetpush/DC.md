## 0. 结论（先给裁判）

1. **推导是干净的，最小形式只改 (P) 里的一项。** 在 v3.1 的 (V) 里把等压画布 L1 换成 v3.1 §3.5 的场形式画布（(C1) 达西膜、(C2) 带 τ_± 松弛的应变、(C3) 弹性 E + 坍塌平台 ΔΠ_c），得到一个额外标量场（画布应变 ε，或等价的表面压 π = −ζφ）。它有三个子极限：**C-D**（τ_d → ∞，ε 随画布输运，参数 D_Π = E/ζ）、**C-V**（应变松弛快于推挤，τ_s ≪ t_p，ε 被 ∇·u 从属，参数 ℓ_s = √(Eτ_s/ζ)）、**C-P**（坍塌平台，率无关，是 C-V 压缩支 ℓ_s → 0 的极限）。最小的是 C-V：v3-min 的 (P) 中"全杯均匀零压吸收"−ė(1 − c) 换成"与表面压成正比的局部吸收"+(1 − c)φ/ℓ_s²，ℓ_s → ∞ 精确回到 v3-min（加 L5Q 即回到 Q）；**不新增输运场**，引理 F（停倒精确冻结）原样成立；新参数 1 个（ℓ_s）。C-D 破坏引理 F（D_Π = 10⁻⁴ m²/s 时停倒后 t_r 处 max|u| = 2.2–2.6 mm/s，定点推挤中旧块近缘停倒后 2 s 内再走 0.012–0.018 D，而 v3-min、Q、C-V 只有 t_r 内在途液面造成的 0.002–0.005 D、之后为 0）。
2. **在 v3.1 的物理先验下 C 不起作用，C ≡ Q。** 推挤所需的应变扰动 ζUL/E 在三种参考工况都只有 0.07–4%；弹性扩散长度 √(D_Π t_p) 在推挤、摆动、切的时标上分别 ≥ 8 / 2.9 / 1.7 cm；压缩支屏蔽长度 √(Eτ_d/ζ) ≥ 7 cm > R（τ_d ≥ 1 s）。所以等压极限 L1 在全部工况成立，零参数（ℓ_s 取台架值）的 C 就是 DQ 的变体 Q。要让可压性在图案尺度（1 cm、1 s）起作用，须 Eτ_s ≲ 1×10⁻⁴ N·s/m（ℓ_s ≲ 1 cm），比 v3.1 先验 5×10⁻³–0.6 N·s/m 低 1.7–3.8 个量级；坍塌平台只有在全杯画布已压到距 Π_c 0.04–0.13 mN/m 以内时才局部化，那是全局状态，不是局部机制。
3. **核心负结果（命题 G）：可压性只会让缝更窄，不会保缝。** 新白是不可压的筏，以面积速率 S 长大，其边缘法向速度与画布是否可压无关；可压画布把这部分面积在途中吸收掉，旧块近缘的速度只会更小（径向模型：d(πr_b²)/dt = S·ψ(r_b/ℓ_s)/ψ(R/ℓ_s) ≤ S，ψ(x) = xK₁(x)）。被压缩的画布还使同样的画布物质占据更窄的宽度。实测 6 s 轴向缝（定点，s₀ = 0.15 / 0.25 D）：v3-min 0.008 / 0.047 D，Q 0.016 / 0.047 D；C-V ℓ_s = 4 cm 0.016 / –，2 cm 0.008 / 0.039，1 cm 0 / 0.023，0.5 cm 0 / 0 D；C-D D_Π = 3×10⁻⁵ 时 s₀ = 0.15 D 的缝 2.5 s 起为 0。C-D 中被压缩的缝在停倒后回弹变宽（10⁻⁴、s₀ = 0.25 D：停倒时 0.039 → 2 s 后 0.055 D），这是"被压缩的褐缝"唯一的痕迹，却出现在停倒之后并伴随整块回弹，违反 V2。移动射流（任务的 T2：射流在近缘后 0.15 D、1.5 s 前移 0.1 D）在所有变体下都接触（缝 0）。视频要求缝在 2–3 s 供料中保持 0.05–0.10 D。
4. **月牙：C 没有在 Q 之外增加东西。** 定点 s₀ = 0.15 D：Q 物质线 solidity 0.84，C-V 0.82–0.85，C-D 0.84–0.85；不带足迹推力时屏蔽本身给出很弱的月牙（ℓ_s = 1 cm：0.89，v3-min 0.94）。移动：Q 0.39（0.14 × 0.58 D），C-V ℓ_s ≥ 1 cm 0.41–0.45（0.15 × 0.55–0.58 D），ℓ_s = 0.5 cm 0.56 且旧块被喂大 ×1.29，C-D 10⁻⁴ 0.81 且 ×1.91。视频 0.10 × 0.5 D。s₀ = 0.25 D 时所有变体 solidity 0.99–1.00（无月牙）。
5. **C 的唯一正面作用在 T1：** 屏蔽把 Q 的偶极局部化，减轻了 Q 在 T1 的两项回退（C 形开口 Q 0°→ C-V ℓ_s = 0.5 cm 35°（v3-min 75°）；白内褐斑 Q 44 个 → 0 个）；代价是推挤、缝更差（第 3 条）。T3（切）：带足迹推力时与 Q 不可区分（驻留凹口 0.050–0.055 D 与 V 形缺口 ✓，外鼓 +0.029–0.033 D 对视频 ~0.05 D，**切线消失 ✗**）；不带时与 v3-min 不可区分（线 0.016 D ✓，凹口 0.016 D ✗）。T4（摆动）：所有变体都没有一周一弧（✗），强屏蔽只把乱纹与褐岛抹少（褐岛 137 → 50 mm²）。
6. **参数：1 个（ℓ_s），** 不能由 ρ_jQu_h 与 ζ 导出（它是画布的材料量 Eτ_s/ζ）。能钉它、又不同于 g1–g4 的校准集观测量是 tulip 6.6–8.5 s 第二段起倒的白前推挤中**褐线与白弧的面积比变化**（等压时二者同比变形，可压时只有褐线丢面积）；它与 α_j（足迹推力强度）只在位移量上补偿，在面积比上不补偿（§4）。零参数版本（ℓ_s 取台架 E7 值）就是 Q。
7. **与学长 V1 规则：** C 不违反 §3.1（画布不再被投影；C-D 正是学长 (ℓ, q) 方程去掉惯性、ν = D = 0 的准静态极限，D_Π = c_p²/β）；§1.2 不新增泡沫场，但 C-V 的松弛项是画布物质的去吸附/坍塌汇，学长的褐量账本 d/dt∫(ℓ − m) = 0 不成立（与 v3-min 的 ė 相同，须显式入账）；C-D 恢复了这个账本，却恰好落入学长 §5.6 表中"停流后图案反复回缩"的失败形态；§4 渲染、§5.4 度量相容。按 §5.6，现有证据不支持为 C 提变更申请（第 3–4 条：它没有修好它要修的 T2）。
8. **给 v3-min-3 的建议：不采用 C 作主干。** 它给出的可证伪结论是：缝的保持需要缝内画布**抵抗切向排出**（两端开口的缝在无剪切抗力的达西膜里总是自由排空），这只能来自旧块/新白抵抗变形（PX-R）与画布表面剪切粘度（缝的润滑数 Bq_g = 12η_s/(ζw²) = 19–2×10⁴，老化蛋白膜 η_s = 10⁻⁴–10⁻² N·s/m）的组合，或来自画布面积源（C5 的 F_net(π̄) > 0）。这两条都不是"可压性"（§8）。

## 1. 物理论证与无量纲数

### 1.1 画布与射流推力（v3.1 §3.5、§3.4 (a6)、§3.9）

**画布。** v3.1 §3.5 把褐色液面当作无质量的吸附膜，膜下粘性层给出达西型力平衡、面压缩应变 ε 的输运与松弛、带坍塌平台的本构：
```
(C1)\quad \nabla\pi=\zeta\,(U_l-u),\qquad
(C2)\quad \partial_t\varepsilon+u\cdot\nabla\varepsilon=-(\nabla\cdot u-\sigma_A)-\varepsilon/\tau_\pm ,
(C3)\quad \pi=W'(\varepsilon),\quad W=\tfrac12E\varepsilon^2\ (\varepsilon\le\varepsilon_c),\quad W=\tfrac12E\varepsilon_c^2+\Delta\Pi_c(\varepsilon-\varepsilon_c)\ (\varepsilon>\varepsilon_c),\quad \varepsilon_c=\Delta\Pi_c/E .
```
σ_A 是画布上的面积源（吞汇 σ_c、新液面 σ_e，新液面以 ε = 0 出生）；τ_+ = τ_d（压缩 → 慢去吸附或坍塌），τ_− = τ_a（扩张 → 快吸附）。合并弹性支得表面压扩散方程 ∂_tπ − D_Π∇²π = …，D_Π = E/ζ。v3-min 的 L1 取 t_Π = L²/D_Π ≪ t_p：每个画布区 π 均匀，且把均匀压缩 ė 当作"零压吸收"（π̄ 对供给的反馈略去）。

**射流推力。** 与 DQ 相同，把 v3.1 的 f_J 分成两部分：(P) 驻点压力梯度 −κ_h c h∇p_J 只作用于筏，在 r ≲ 1.5–2 r_e 内比拖曳能平衡的大 10²–10³ 倍，由其刚性极限（v3-min 的 L11′ 排除区、L12 打散核）代表，不重复计入；(M) 射流水平动量以"足迹内液面速度 U_J"的形式进入拖曳：
```
\zeta\,(u-W)=-\nabla\pi ,\qquad W=U_J\,\chi_{fp}\,\mathbb 1[Q>0],\qquad U_J=v\sin\alpha_j\,\hat e+\dot x_j,\qquad \chi_{fp}=\mathbb 1[|x-x_j|<r_0],\ \int\chi_{fp}dA=Q/v .
```
足迹外按 L4 取 U_l^σ = 0。这一闭合不含新参数（α_j 是 v3-min 已有的扰动量），在等压画布里 ζ 抵消（DQ §2.1）。本文把它记为 L5Q，直接继承。

**要检验的假设**（任务给出）：等压画布里推力的势部分被画布乘子全部吸收，只剩旋度，于是旧块只能被一个绕流的偶极推开、缝被侧向回流压窄（DQ §8 第 1、3 条）；若画布可压，射流前方的画布条带可以就地被压缩，而不必绕旧块流动，条带作为"被压缩的褐缝"留下。

**物理论证（先给答案再给数）。** 可压性改变的是"推力在画布中能传多远"，不改变"新白长多快"：筏不可压（L3），新白以 S = GwQ/Γ 长大，边缘法向速度由 S 决定；画布若可压，这部分面积在离新白边 ℓ（扩散长度或屏蔽长度）之内被吸收。缝是新白与旧块之间的画布：它的宽度变化率 = 旧块近缘速度 − 新白边速度；前者在可压画布中只会更小，所以缝只会更快变窄（§2.5 命题 G）。可压性能做的是：(i) 让远场少动（V5 的"远端几乎不动"、V7 的白前不推）；(ii) 让旧块近缘比远缘多动（局部化的推挤，月牙的一种来源）；(iii) 把 Q 的偶极局部化，减少它在近场对 C 形与白内的破坏。这三条都可以检验；但它们只在 ℓ 小到与图案尺度相当时才出现，而 v3.1 的材料先验给出的 ℓ 都远大于杯。

**读法。**
1. **有限弹性本身什么也不改变。** 三种工况的应变扰动都 ≤ 4%，弹性扩散长度在所有过程时标上都 ≥ 1.7 cm（大多 ≫ R）：E ≥ 5 mN/m 的画布在推挤、摆动、切的每个尺度上都是等压的，L1 成立。要让 ℓ_Π ≈ 1 cm 在 1.4 s 内成立，须 D_Π ≈ 7×10⁻⁵ m²/s，即 E ≈ 0.02–0.07 mN/m——这已是 v3.1 列为被 V7 重测否定的"可动画布"区（旧闭合拟合的 D_Π = 1.8–1.9×10⁻⁴ m²/s 在同一区）。
2. **能把压缩就地吸收的只有松弛（去吸附或坍塌）。** 压缩支 ℓ_d ≥ 7 cm > R：压缩照样传遍全杯（L1 对推挤成立）。扩张支 ℓ_a = 1.2–7.4 cm 与图案同量级：物理上真正可能偏离 L1 的是**扩张**（吞汇附近、移动射流尾迹），不是推挤。一个"只在扩张支屏蔽"的 C 对 T2 的推挤与缝不起作用（构造上），所以本文的数值复核用对称屏蔽（对推挤最有利的情形），扩张支的非对称版本只在 §8 讨论。
3. **坍塌平台是全局状态。** 平台要在旧块前方局部出现，须全杯 π̄ 已在 Π_c 的 0.3–4% 以内；v3.1 §3.5 的估计是白占比大、低位倒奶短的图案在后段才可能整体到平台。一旦整体到平台，压缩不再传递（ℓ_s → 0 的压缩支），新白就地吃掉相邻画布——v3.1 推论 C6 自己写的就是"该处的缝被优先吃掉"。
4. **缝的排空是另一个数。** 两端开口的缝在无剪切抗力的达西膜中，沿缝方向的排出阻力 ζuL 与缝宽无关，缝是自由排空的；若缝壁（旧块、新白）刚性而画布有表面剪切粘度，排出阻力按 12η_s/w² 增长，Bq_g ≫ 1 时缝几乎不能排空。v3-min 的 L2（筏全塑性）与 C1 的无剪切画布同时把 Bq_g 设成了 0；这才是"缝只按 w ∝ 1/R 变薄"的结构原因，可压性不触及它（§8）。

## 2. 推导：v3.1 的显式极限

### 2.1 场形式画布下的 (V)

v3.1 §3.6 的 (V) 在 L2（筏无偏应力阻力）、L3（筏厚钉扎）、L4（U_l^σ = 0、ζ_R = ζ_C）、L5Q（足迹拖曳）下，**保留画布的场形式**（v3.1 (K4) 与 §3.6 修订 (a) 的非等压情形），每一步的速度场是下列凸泛函的极小：
```
J[u]=\int_\Omega\tfrac12\zeta|u-W|^2dA+\int_\Omega(1-c)\,\Psi_{\Delta t}\big(\nabla\cdot u-\sigma\big)dA
\quad\text{s.t.}\quad c\,(\nabla\cdot u-\sigma)=0,\qquad u\cdot n=w_{\partial\Omega}\cdot n ,
\Psi_{\Delta t}(d)=\frac{1+\Delta t/\tau}{\Delta t}\,W\big(\varepsilon^{n+1}(d)\big),\qquad \varepsilon^{n+1}(d)=\frac{\varepsilon^\ast-\Delta t\,d}{1+\Delta t/\tau},\qquad \varepsilon^\ast=\varepsilon^n-\Delta t\,u^n\cdot\nabla\varepsilon^n .
```
σ = σ_c + σ_f + σ_e（v3-min §3.4 的同一组源）。Ψ_Δt 是 (C2)–(C3) 的隐式欧拉增量势，dΨ/dd = −W′(ε^{n+1}) = −π，所以它凸（W 凸、ε 对 d 线性）。量纲：ζ|u|² dA → W；(1/Δt)·W(ε)·dA → (1/s)(N/m)(m²) = W。Euler–Lagrange：
```
\zeta(u-W)=-\nabla\Pi,\qquad \Pi=\pi=W'(\varepsilon^{n+1})\ \ (\text{画布}),\qquad \Pi=\lambda\ \ (\text{筏，乘子}) .
```
令 φ = −Π/ζ（v3-min 的速度势就是这个 φ：v3-min §2.1 的乘子 λ = −ζφ），u = W + ∇φ。弹性支 π = Eε^{n+1}，把 ε^{n+1} 与 ∇·u 的关系代回，得到**一般的 C 方程**
```
\nabla^2\phi-(1-c)\,\frac{1+\Delta t/\tau}{D_\Pi\,\Delta t}\,\phi=\sigma-\nabla\cdot W+(1-c)\,\frac{\varepsilon^\ast}{\Delta t},\qquad D_\Pi=E/\zeta,\qquad \varepsilon^{n+1}=-\phi/D_\Pi,\qquad \partial_n\phi=w_{\partial\Omega}\cdot n-W\cdot n .
```
（W 在杯壁为零。）量纲：φ [m²/s]，φ/(D_ΠΔt) [1/s] 与 σ 同。混合格按画布份额 (1 − c) 加权，与 v3-min 的 ė(1 − c) 同一写法。

### 2.2 三个子极限

| 子极限 | 取法 | 方程 | 新参数 | 额外场 |
|---|---|---|---|---|
| **C-D**（弹性、不松弛） | τ_± → ∞，ε < ε_c | ∇²φ − (1 − c)φ/(D_ΠΔt) = σ − ∇·W + (1 − c)ε*/Δt，ε^{n+1} = −φ/D_Π | D_Π = E/ζ | ε（随画布输运） |
| **C-V**（松弛快于推挤） | τ_+ = τ_− = τ_s ≪ t_p（准稳态，略去 Dε/Dt） | **∇²φ − (1 − c)φ/ℓ_s² = σ − ∇·W**，ℓ_s² = Eτ_s/ζ ≡ κ_s/ζ | ℓ_s | 无（π = −ζφ 是解出来的） |
| **C-P**（坍塌平台、率无关） | π̄ = Π_c，ε > ε_c 处 E_eff = 0 | 压缩处 π = Π_c（障碍问题），扩张处弹性；即 C-V 的压缩支 ℓ_s → 0 | ε_c（与 π̄(t) 的全杯历史） | ε |
| **L1（v3-min）** | E → ∞ 且全杯均匀零压吸收 | ∇²φ = σ − ė(1 − c)（+ L5Q 时 −∇·W） | — | — |

C-V 的推导：τ_s ≪ t_p 时 (C2) 中 Dε/Dt 相对 ε/τ_s 是 O(τ_s/t_p) 的小量，略去后 ε = −τ_s(∇·u − σ) 被速度散度从属（Maxwell 型）；在上面的离散式中这等价于取 (1 + Δt/τ)/Δt → 1/τ_s 并略去 ε*/Δt（于是 C-V 不需要 Δt 与 τ_s 的大小关系，也不需要存 ε）。π = −Eτ_s(∇·u − σ) ≡ −κ_s(∇·u − σ)：**画布是一张有面积粘度 κ_s = Eτ_s 的达西膜**。屏蔽长度 ℓ_s = √(κ_s/ζ) 是压缩在被吸收之前能传多远。

**v3-min 是 C-V 的 ℓ_s → ∞ 极限（精确）。** 写 φ = φ̄ + φ₁，可解性要求 φ̄/ℓ_s² ∫(1 − c) = −∫σ（W 无净通量），于是 (1 − c)φ̄/ℓ_s² = −ė(1 − c)，ė = ∫σ/∫(1 − c)，φ₁ 满足 v3-min 的 (P)：**−ė(1 − c)（全杯均匀零压吸收）是 +(1 − c)φ/ℓ_s²（局部、与表面压成正比的吸收）的均匀极限**。这就是"解除 L1"在 v3-min 里的全部内容。

**为什么取 C-V 作最小形式。** (i) 它只改 (P) 的一项、不新增输运场；(ii) 引理 F 精确保留：停倒后 σ = 0、W = 0，齐次方程 ∇²φ − (1 − c)φ/ℓ_s² = 0 加齐次 Neumann 的唯一解是 φ ≡ 0，u ≡ 0（只要杯内还有画布）；(iii) ℓ_s → ∞ 连续回到 v3-min/Q，便于消融；(iv) 对"推挤处的画布就地吸收"这一假设它是最有利的形式（对称屏蔽）。C-D 作为对照一并实现：它保留 ε 的记忆，停倒后应变梯度驱动回弹（引理 F 失效，§2.4），这正是学长 §5.6 表中的"停流后图案反复回缩"。

### 2.4 不变的部分、账本、引理 F

- 面积源、L11′ 压入—重浮、L12 打散核、在途液面包、t_k 闸门、足迹推力 W 全部不变。**筏的方程不变**：c(∇·u − σ_f) = 0 仍成立（屏蔽项只乘 (1 − c)），dA_r/dt = GwQ/Γ 精确不变（实测全部变体 3.7975 cm²/s，`log_T1.txt`），账本 2（能成白的奶泡体积）逐字不变（foam_rel_err = 0）。
- **账本 1 加一项**：画布吸收面积 Ȧ_abs = −∫(1 − c)φ/ℓ_s² dA（v3-min 中为 ė∫(1 − c) dA），离散上 ∫∇·u dA = ∫σ dA − Ȧ_abs 精确成立（实测散度残差 × Δt ≤ 6×10⁻¹³，128²）。
- **账本 3（表面涡）不变**；C-D 另有画布物质账本 ∫(1 − c)(1 + ε) dA = 初值 + 新液面 − 吞汇（学长的褐量账本在 C-D 的连续方程中恢复成立，§6；本文的快速实现用非守恒的一阶迎风输运 ε，这一账本未检，正式实现须改为守恒形式 (K4)）。
- **引理 F**：C-V 精确成立（实测全部 C-V 变体停倒后 t_s + t_r 起 max|u| = 0、ΔA_r = 0）；C-P 近似成立（坍塌率无关、不可逆，源停即停；弹性部分的残余应变 ≤ Π_E ≈ 4%，停倒瞬间以 t_Π ≪ 0.1 s 松开，位移 ≤ Π_E·L ≈ 0.005 D）；**C-D 不成立**：停倒后残余应变以 L²/D_Π 回弹，实测 t_s + t_r 处 max|u| = 1.4 / 2.3 / 2.2–2.6 / 4.6 mm/s（D_Π = 10⁻³ / 3×10⁻⁴ / 10⁻⁴ / 3×10⁻⁵），定点推挤中旧块近缘停倒后 2 s 内再走 0.008–0.018 D、远缘 0.005–0.013 D（v3-min、Q、C-V 为 t_r 内在途液面的 0.002–0.005 D，之后严格 0），T1 中 0.30 D 处 6 s 位移 0.096 D（3×10⁻⁵，v3-min 0.041）。V2 要求 > 10 s 内 ≤ 0.01 D：C-D 只有在 D_Π ≥ 5×10⁻³（回弹 ≤ 0.08 s，即等压）时才不违反——又回到 L1。

### 2.5 命题 G（可压性不保缝）与月牙的来源

**径向模型。** 杯心附近新白近似为不可压圆盘，πR² = A₀ + St；旧块近缘是一条物质圆，半径 r_b。C-V 的画布在 r > R 上解 (∇² − ℓ_s⁻²)φ = 0，通过 r = R 的通量为 S，故 u_r(r) = S K₁(r/ℓ_s)/(2πR K₁(R/ℓ_s))，即
```
\frac{d(\pi r_b^2)}{dt}=S\,\frac{\psi(r_b/\ell_s)}{\psi(R/\ell_s)},\qquad \frac{d(\pi R^2)}{dt}=S,\qquad \psi(x)=xK_1(x),\ \ \psi'<0,\ \ \psi\le1 ,
\Rightarrow\ \frac{d}{dt}\big(r_b^2-R^2\big)=-\frac{S}{\pi}\Big(1-\frac{\psi(r_b/\ell_s)}{\psi(R/\ell_s)}\Big)\le0 .
```
等压（ℓ_s → ∞）时 r_b² − R² 守恒，缝只按 g ≈ (r_b0² − R₀²)/(2R) 变薄（这就是 v3-min 的"w ∝ 1/R"）；任何有限 ℓ_s 都使它严格减小。缝里的画布物质被吸收，所以"被压缩的褐缝"在 C-V 里不存在；在 C-D 里它存在（ε > 0），但同样的物质占更窄的宽度，且停倒后回弹（定点推挤中 C-D（10⁻⁴）的缝在停倒后 2 s 内从 0.008 回到 0.014 D（s₀ = 0.15 D）、从 0.039 回到 0.055 D（s₀ = 0.25 D）——这是"被压缩的缝"唯一留下的痕迹，量级 0.006–0.016 D，且发生在停倒之后）。

`gap_ode.py`（S = 3.8 cm²/s，R₀ = 6.5 mm，r_b0 含 0.025 D 白前推移）给出 s₀ = 0.15 D 的缝在出白后 1 / 2.6 / 4.6 s：ℓ_s = ∞ 0.063 / 0.046 / 0.037 D；4 cm 0.060 / 0.041 / 0.031；2 cm 0.056 / 0.035 / 0.023；1 cm 0.049 / 0.024 / 0.013；0.5 cm 0.038 / 0.012 / 0.004 D。s₀ = 0.25 D：∞ 0.148 / 0.117 / 0.097；1 cm 0.128 / 0.078 / 0.046；0.5 cm 0.120 / 0.059 / 0.024 D。二维原型的绝对值比径向模型小（C 形供给偏向旧块一侧、Δ_e 偏移、足迹推力），但相对次序与比例一致（§5.2）。

**月牙。** 同一模型给出旧块的径向厚度 r_f − r_b：等压时远缘与近缘以 1/r 之比运动，块按 1/r̄ 变薄（solidity 只降到 0.93–0.94，点源流保极角）；屏蔽时远缘再乘 ψ(r_f)/ψ(r_b) < 1，块被额外压薄，不可压的筏只能向两侧（周向）展开——**这是不依赖偶极的月牙机制**。但它的量级小：s₀ = 0.15 D、ℓ_s = 1 cm 时 4.6 s 厚度 0.199 D（等压 0.242 D），对视频的 0.10 D 不够；原型中不带足迹推力的 C-V（`sv1n`）定点 solidity 0.89（v3-min 0.94），带推力时月牙主要来自 Q 的偶极（0.84），屏蔽不再加深它。所以 C 中月牙的形成判据与 Q 相同：足迹进入旧块 r ≲ 2r_e 的近场（Q 的 Π_C）。

## 3. 原型中要加/换的方程（`spec_v2/px_model.py`），含离散

### 3.1 连续方程（替换 v3-min §3.4 的 (P)；C-V）

```
(P_C)\quad u=\nabla\phi+W,\qquad \nabla^2\phi-\frac{(1-c)}{\ell_s^2}\,\phi=\sigma_c+\sigma_f+\sigma_e-\nabla\cdot W,\qquad \partial_n\phi=w_{\partial\Omega}\cdot n ,
\qquad W=\big[v\sin\alpha_j\,\hat e+\dot x_j\big]\,\chi_{fp}(x;x_j,r_0)\,\mathbb 1[Q>0]\quad(\text{L5Q，同 DQ}) ,
\qquad \dot A_{abs}=-\int_\Omega\frac{(1-c)\,\phi}{\ell_s^2}\,dA\quad(\text{画布吸收面积，记账；取代 v3-min 的 }\dot e\!\int(1-c)) ,\qquad \pi=-\zeta\phi\ (\text{诊断}) .
```
(C)、源、核、压入、打散、在途包不变。ė 不再出现；若某一步杯内没有画布（c ≡ 1），(P_C) 奇异，退回 v3-min 的 (P)（实际不会发生）。

C-D（只作对照，不建议实现进主干）：
```
(P_{CD})\quad \nabla^2\phi-\frac{(1-c^n)}{D_\Pi\,\Delta t}\,\phi=\sigma-\nabla\cdot W+(1-c^n)\frac{\varepsilon^\ast}{\Delta t},\qquad \varepsilon^\ast=\frac{(1-c^n)\,[\varepsilon^n-\Delta t\,u^n\cdot\nabla\varepsilon^n]}{(1-c^n)+\Delta t\,\sigma_e^+},\qquad \varepsilon^{n+1}=-\phi/D_\Pi .
```
（新液面以 ε = 0 出生，按面积稀释；u^n·∇ε^n 一阶迎风。）

### 3.2 离散（MAC，与 v3-min §6.1 一致）

1. **算子。** 与 v3-min 同一个 5 点 Neumann 拉普拉斯 L_h（h² 标度、不钉点），每步组装 A = L_h − diag(h²(1 − c^n)/ℓ_s²)（c 取步初值：对 φ 隐式、对 c 显式）。A 负定（只要有画布格），无需钉点、无需 ė 配平。
2. **求解。** 以最近一次分解的 A 的 LU（SuperLU，`MMD_AT_PLUS_A` 排序）作预条件子的 PCG（相对残差 10⁻¹²，初值取上一步 φ）；迭代 > 12 次时重新分解。实测每步 4.6–10 次迭代（ℓ_s = 1 → 0.5 cm），Helmholtz 求解 9 ms/步（128²，单线程），整步 17 → 27–31 ms（T1），比 v3-min 慢约 1.7 倍；C-D 54–68 ms/步（Δt 更小、应变输运）。**必须单线程 BLAS**（`OMP_NUM_THREADS=1`），多进程时线程超订会慢 6–8 倍。
3. **速度与散度。** u_f = ∇_fφ + W_f（W 的面心化同 DQ：相邻格心均值，壁面置零）。离散散度 div_h u_f = σ + (1 − c)φ/ℓ_s² 精确成立（实测残差 × Δt ≤ 6×10⁻¹³）；吸收面积 Ȧ_abs 按同一离散式累加，账本 1 闭合到机器精度（实测 ∫σ dA dt − A_abs − Σdiv_h u h²Δt 的相对误差 ≤ 1.2×10⁻¹⁴，`ledger_check.py`）。
4. **时间步、VOF、标记点** 全部不变（u_max 含 W）。

代码（已在 `DC_check/px_model.py` 实现并验证；原型阶段照此在 spec_v2 副本上改）：
```python
# FIXED: canvas='iso' (v3-min-2) | 'screen' (variant C-V, parameter ell_d = l_s [m]) | 'elastic' (C-D, D_Pi; control only)
# Grid.__init__: keep the unpinned h^2-Laplacian
self.Lap = A.tocsc()            # before pinning
# Grid.solve_helm(rhs, kap2, x0): PCG on -(Lap - diag(kap2 h^2)) with a cached SuperLU preconditioner (refactor if > 12 its)
# PXSim.step, replacing  "edot = ...; rhs = (sig - edot*canv); phi = g.solve(rhs); u = grad phi (+ W)":
if P['canvas'] == 'screen':
    Ufx, Ufy = face_average(Wx, Wy)                       # L5Q footprint traction (DQ), zero on walls

    phi, _ = g.solve_helm((sig - g.div(Ufx, Ufy)) * g.inside, kap2, x0=self.phi)
    ux, uy = g.face_vel(phi); ux += Ufx; uy += Ufy
    self.L['A_abs'] += -float((kap2 * phi).sum() * g.cellA) * dt   # canvas area absorbed (ledger 1)
    edot = 0.0
```

## 4. 新参数与钉住它的观测量

**新参数：1 个，ℓ_s（m）。** 它是画布材料量 √(Eτ_s/ζ)，不能由 ρ_jQu_h、ζ 或射流几何导出：足迹推力 W 的强度已由 L5Q 零参数给定（ζ 抵消），可压性引入的是"画布把压缩吸收掉之前能传多远"，这只取决于膜。

## 6. 与学长 V1（2026-10-10）规则的对照

| 规则 | 是否冲突 | 说明；若要申请变更所需的失败证据 |

## 7. 校准协议（用户决定：只用 tulip + leaf 拟合流体参数、冻结，测 heart、push_heart、layered_heart、swan；另做只用 tulip 的 A 基线）

- **四个现有锚组在 C-V 下的状态。** 不带 W 时 g1–g4 全部保留（首白、dA/dt 严格不变，褐洞 0.0475 D 不变，切线终宽 0.0158 对 0.0162 D，−2%）。带 W 时与 Q 相同：**g4 消失**（leaf 中脉、tulip 收尾切的切线在 Π_L > 1 下为 0，Π_coh 失锚），g3 被 W 拉长（0.0475 → 0.050–0.064 D，随 ℓ_s 非单调）。所以"可压画布 + 足迹推力"在用户的协议下与 Q 一样破坏四参数的可辨识结构；"只有可压画布"不破坏它，但对 T2–T4 没有收益（§5）。
- **ℓ_s 在校准集里的唯一锚**是 tulip 6.6–8.5 s 白前推挤中 B 侧褐线/白弧面积比（§4）。leaf 只有一段倒奶（无推挤），对 ℓ_s 的约束只有单侧的：后退摆动后 0.01–0.02 D 褐线存活 > 10 s 要求近源吸收率 φ/ℓ_s² ≪ 1/τ_res（§5.4 的估计给 ℓ_s ≳ 2 cm），但 v3-min 本来就不出人字纹，这条在现模型里无法使用。所以在 tulip + leaf 协议下 ℓ_s **只有一个、且未重测的观测量**；若重测不可分辨，ℓ_s 必须固定为台架值（C ≡ Q）。
- **只用 tulip 的 A 基线**：同上，ℓ_s 的锚不变（tulip 第二段），g4 只剩 tulip 收尾切一处（带 W 时为 0）。
- **结论**：C 在该协议下不提供比 Q 多的可辨识信息；作为扰动量（宽界 ℓ_s ∈ [0.5 cm, ∞)）边缘化时，它把 T2 缝的预测带向下拉（0–0.016 D），不改变任何判定。

## 8. 失效条件、结构原因与给后续变体的输入

1. **可压性的符号是错的（主因，命题 G）。** 新白（不可压筏）以 S 长大，可压画布只能吸收这部分面积，不能把它更多地传给旧块；缝 = 新白边与旧块近缘之差，在任何 ℓ_s 下都比等压时窄。被压缩的画布在 C-D 中存在，但宽度按 1/(1 + ε) 缩小，停倒后回弹又违反 V2。C-P（平台）是 ℓ_s → 0 的压缩支，按 v3.1 C6 新白就地吃缝。**所以"缝作为被压缩的画布留下"在 v3.1 的画布本构里不成立。**
2. **物理先验让 C 消失。** E ≥ 5 mN/m、τ_d ≥ 1 s 时 ℓ_Π、ℓ_d 都 ≫ 杯径；C 起作用要 Eτ_s ≲ 10⁻⁴ N·s/m。台架 E7 若测得蛋白/咖啡液面的 Eτ_d 在先验内，C 直接作废（零参数版本 = Q）。
3. **C-D 违反冻结。** 应变有记忆就有回弹；V2（> 10 s 无可见变化）把 D_Π 推回 ≥ 5×10⁻³ m²/s，即等压。
4. **缝真正缺的是"切向排出的阻力"，不是可压性。** 两端开口的缝在无剪切抗力的达西膜中自由排空；L2（筏全塑性）下势流 u = ∇φ 又是 Brinkman 方程的精确解，所以单加画布表面剪切粘度也不改变势流解。缝的排空要被阻止，须同时有 (i) 缝壁抵抗变形（旧块/新白近刚性，PX-R，v3-min §8 第 4 条）与 (ii) 画布表面剪切粘度 η_s，使缝的润滑数 Bq_g = 12η_s/(ζw²) ≫ 1（老化蛋白膜 η_s = 10⁻⁴–10⁻² N·s/m 时 19–2×10⁴；但须与 L4 的"停倒冻结"、u = ∇φ 的失效一起处理，v3-min §2.4 L4 行已警告）；或 (iii) 画布面积源 F_net(π̄) > 0（v3.1 C5，v3-min §8 第 2、13 条）。这三者都不是 L1 的解除，应作为另外的变体（"刚性块 + 粘性画布"或"画布源"）一次放开一个地检验。
5. **可保留的结论（交给裁判与后续变体）。** (a) C-V 的实现成本很低（(P) 一项、PCG，17 → 27–31 ms/步），作为"画布局部吸收"的消融开关有用：它把足迹推力的偶极局部化，ℓ_s ≤ 1 cm 时 T1 的白内褐斑 44 → 0–4、开口 0° → 25–35°，说明 Q 在 T1 的回退来自偶极的远场尾巴；(b) 月牙的几何在 C 中与 Q 相同，判据仍是足迹进入 r ≲ 2r_e；(c) 远场位移衰减形状（1/r 对 e^{−r/ℓ_s}）是 E2a、heart V5 可以直接判别的量；(d) 任何新变体都应在 T2 站位扫描上报告"缝/等压缝"之比，命题 G 给出了它的上界 1。

**给裁判的一句话**：变体 C 是 L1 的干净解除（最小形式只改 (P) 的一项，1 个参数 ℓ_s，冻结精确保留），但在 v3.1 的材料先验下它退化为 Q；把 ℓ_s 放到能起作用的 0.5–1 cm，它让缝更窄（命题 G：可压性只能吸收新白推出的面积，不能把它传给旧块），月牙、凹口、切线、摆动都与 Q 或 v3-min 相同。不建议作为 v3-min-3 的主干；保缝需要的是缝内画布的切向排出阻力（刚性块 + 表面剪切粘度）或画布面积源，不是面积可压性。

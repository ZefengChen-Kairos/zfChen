## 0. 结论（先给裁判）

1. **推导是干净的。** 在 v3.1 的变分原理 (V) 中只解除 L5（保留 L1–L4、L6–L13），足迹力的势部分全部被画布乘子吸收，存活的只有它的旋度；响应是 u = ∇φ + 𝒫[U_J χ_fp]，𝒫 为杯内 Leray 投影，足迹外是一个**势偶极**，矩 m = U_J·Q/v。用"足迹内液面以射流水平速度 U_J 拖曳漂浮层、拖曳系数与别处同为 ζ"的闭合，ζ 在运动学中抵消，**新参数 0 个**：U_J = v sinα_j ê + ẋ_j 全由输入与现有扰动量 α_j 给出。它只用了射流水平动量通量 ρ_j Q u_h 的 η = ζ/(ρ_j v) = 0.7–2.0×10⁻³。
2. **它给出了 v3-min 结构上没有的东西**（快速复核实测）：月牙（推挤 T2 物质线 solidity 0.39–0.84，旧块轴向厚 0.14–0.20 D、横跨 0.47–0.58 D，面积比 0.995，旧块不再被"喂大"，v3-min-2 是 2.8 倍）；驻留切入口的凹口 0.055 D（视频 ~0.05 D；v3-min-2 0.016 D）与 V 形缺口，两侧盘缘外移 +0.031–0.033 D（v3-min-2 +0.023 D，视频外鼓 ~0.05 D）；白前推移 0.023 D（定点，重测上界 ≤ 0.03 D）。
3. **但它在同一强度下破坏了三条 v3-min 已经过的事实，并且没有修好缝与摆动：** C 形开口闭合（T1，3 s 开口 75° → 0°，192² 5°）；白内出现辐条状褐斑（T1：0 → 44 个 / 34 mm²，192²：111 个 / 62 mm²）；细流切线被射流"带走"、不留褐线（T3 积分亏量 0.0162 → 0 D，192² 同）；褐缝仍闭合到 0.016–0.021 D（定点）或接触（移动），视频 0.05–0.13 D；摆动无规则条纹（离轴 3–6 次穿越、节距 0.05–0.08 D，白内褐岛 40 个）。
4. **这些失败是结构性的，不是强度没调好。** 足迹外的响应是 u ∝ m/r² 的偶极，同一个 m 同时决定远处推挤（r ≈ 1–2 cm）与供给环的近场扫掠（r ≈ 4–6 mm）。三条无量纲判据互不相容：C 形存活要 Π_C = m/(S r_e) ≲ 0.2–0.3（m ≲ 3–4×10⁻⁷ m³/s）；切线存活要 Π_L = |U_J|/(2V) ≲ 0.5；月牙、凹口要 m ≳ 1–2×10⁻⁶ m³/s。名义值 Π_C = 1.57、Π_L = 3.1。加一个乘子 λ_J 拟合只会让它在相反方向的观测量之间折中（λ_J ≳ 0.5–1 对 ≲ 0.1–0.25），违反"参数不得互相补偿"的硬约束，**不建议**。
5. 缝的问题在任何面积守恒、径向速度随距离递减的流里都无解：偶极在射流前方给 ∂_r u_r = −2u_r/r < 0，只会加速缝变窄。保缝需要画布面积来源（L10/C5）、可压画布（变体 C）或旧块记忆（变体 I）。
6. 与学长 V1 规则：**直接冲突 §3.1**（u_J 本身就是二维无散投影）；不触及 §1.2（无新泡沫场、无新下沉；继承 CR-1 不变）；§4 渲染、§5.4 度量相容。按 §5.6，现有证据（第 3 条）不足以支撑为 Q 提变更申请。

## 1. 物理论证与无量纲数

### 1.1 足迹力有两部分（v3.1 §3.4 (a6)、§3.9、§3.5 推论 C1/C3′）

- **(P) 驻点压力梯度**，只作用于筏：f_P = −κ_h c h ∇p_J，κ_h = 1 − ρ_f/ρ_l ≈ 0.67，p_J = p_0 exp(−|x − x_j|²/r_0²)。画布是无质量吸附膜，驻点压力作用在液体上，液体的发散流被等压膜过滤（C1），画布不受 f_P。
- **(M) 射流水平动量**：射流相对杯的水平速度 u_h 由两部分组成——奶柱倾角（嘴的水平出流）u_tilt ê，与壶的运动。弹道奶柱的水平速度在下落中守恒，落点速度恰为 ẋ_j（嘴高不变时），所以在杯参考系 R 中
```
U_J(t) = u_{tilt}\,\hat e(t) + \dot x_j(t),\qquad u_{tilt}=v\sin\alpha_j ,
```
  α_j 是 v3-min 已有的扰动量（先验 5–12°，同时决定回涌偏移 Δ_e）。杯体平移由 R 系吸收；漂浮层无惯性，参考系加速度项（学长的 −ℓa_R）不出现。

### 1.2 在等压画布 + 筏厚钉扎下谁被吸收、谁存活

L1（等压）+ L3（筏厚钉扎）把漂浮层速度约束为 ∇·u = Σ（Σ 由面积源给定）。对任意力场作 Helmholtz–Hodge 分解 f = ∇Φ_f + ∇^⊥Ψ_f：∇Φ_f 只改变乘子 λ（画布表面压），不改变 u；**存活的只有 ẑ·∇×f。** 逐项：

| 来源 | 旋度在哪里 | 存活什么 |
|---|---|---|
| (P) 筏内部（c ≡ 1、h 均匀） | f_P = −∇(κ_h h p_J)，纯梯度 | 无，全被吸收 |
| (P) 轴对称筏缘（如完整白环） | ∇c ∥ ∇p_J，∇c × ∇p_J = 0 | 无 |
| (P) 落在足迹内的非轴对称筏缘（C 形端点、接触时旧块的近缘、切时打散核的前缘） | −κ_h h ∇c × ∇p_J，集中在 r ≲ 2r_e 内的筏缘 | 接触力（见 1.3 的量级：极强、极局部） |
| (M) 倾角 + 壶动 | ẑ·∇×(U_J χ_fp) = ẑ·(∇χ_fp × U_J)：足迹边缘与 U_J 平行的两侧，一对反号涡片（**"足迹边缘"**） | 一个偶极流，足迹外 1/r² 衰减 |

### 1.3 量级（由 ρ_j Q u_h 与 ζ 估计）

**(M) 的闭合（足迹拖曳）。** 足迹 |x − x_j| < r_0（面积 A_fp = πr_0² = Q/v，射流截面）内，漂浮层下方的液体就是射流液体，水平速度为 U_J；足迹外按 L4 取 U_l^σ = 0。漂浮层与液体之间的拖曳系数处处同为 ζ（v3.1 (a5)）。于是作用于漂浮层的净水平力
```
F_J = \zeta\,|U_J|\,A_{fp} = \zeta\,|U_J|\,Q/v = \eta\,\rho_j Q\,|U_J|,\qquad \eta=\frac{\zeta}{\rho_j v},\qquad \rho_j=(1-\phi_j)\rho_l .
```
η 是"粘性拖曳阻抗 ζ 与射流动量阻抗 ρ_j v 之比"。低位 v = 0.646 m/s、ζ = 0.33–1 Pa·s/m 时 η = 0.68–2.05×10⁻³；细流 v = 1.2 m/s 时 0.37–1.1×10⁻³。它落在 v3.1 推论 C3′ 的上界（η_h ≲ 0.03–0.1，由白前 ≤ 0.01–0.03 D 推出）之内，与 v3-min L4 的冻结判据 η_h ≲ 10⁻³ 同量级（边缘）。**响应只取决于 m = F_J/ζ = |U_J|Q/v，ζ 抵消**（§2.1）。

**(P) 的量级（为什么不能按拖曳平衡处理）。** 低位 r_e = 3.72 mm 处 p_J = 24 Pa（≈ Δρ_f g h，正是压入阈，r_sub ≈ r_e），筏缘线力 κ_h h p_J = 18 / 32 mN/m（h = 1.1 / 2 mm），是筏自身静水线力 N(h) = ½ρ_f g′h² = 1.3 / 4.4 mN/m 的 7–14 倍；若由拖曳平衡，速度 κ_h h p_J/(ζ r_e) ≈ 5–9 m/s。1.5 r_e 处仍 0.5–0.8 m/s，2 r_e 处 2–3 cm/s。所以 (P) 在 r ≲ 1.5–2 r_e 内是**刚性**的（相对时间 r_e/u ~ ms）：筏在这里压入、屈服、增厚（v3.1 L-R1、M5），而不是被拖曳平衡地推走。它的刚性极限是一条几何规则——"筏不能停留在 p_J 超过其承载的区域"——这正是 v3-min 的 L11′ 排除区（低位）与 L12 打散核（细流）。把 (P) 再按拖曳平衡加进投影，需要独立的 h_eff（Γ 只给出 φ_r h_eff/(F_white φ_j)，h_eff 不可辨识），且数值上是 m/s 级的刚性项。本文因此只把 (M) 作为新的远场力，(P) 由其刚性极限（现有 L11′/L12）代表，不重复计入。

## 2. 推导：v3.1 的显式极限

### 2.1 从 (V) 出发

v3.1 §3.6 的 (V) 在 L1（单一等压画布区）、L2（筏无偏应力阻力）、L3（筏厚钉扎）、L4（U_l^σ = 0、ζ_R = ζ_C）下、**保留 −∫f_J·u**，成为
```
\min_u \int_\Omega \tfrac12\zeta|u|^2\,dA-\int_\Omega f_J\cdot u\,dA\quad\text{s.t.}\quad \nabla\cdot u=\Sigma\equiv\sigma-\dot e(1-c),\qquad u\cdot n=w_{\partial\Omega}\cdot n .
```
Euler–Lagrange：ζu − f_J + ∇λ = 0。代入约束得 ∇²λ = ∇·f_J − ζΣ，∂_nλ = f_J·n − ζw·n。令 λ = −ζφ + λ_J：
```
u=\nabla\phi+u_J,\qquad \nabla^2\phi=\Sigma,\ \ \partial_n\phi=w_{\partial\Omega}\cdot n\quad(\text{即 v3-min 的 (P)，不变}),
u_J=\frac{1}{\zeta}\big(f_J-\nabla\lambda_J\big)\equiv\frac1\zeta\,\mathcal P[f_J],\qquad \nabla^2\lambda_J=\nabla\cdot f_J,\ \ \partial_n\lambda_J=f_J\cdot n .
```
𝒫 是杯内法向通量为零的 Leray（Helmholtz–Hodge）投影。等价写法：u_J = ∇^⊥ψ_J，−∇²ψ_J = ω_J，ψ_J|_∂Ω = 0，**ω_J = ẑ·∇×f_J/ζ**——只有旋度存活。量纲：f_J [N/m²]/ζ [Pa·s/m] = m/s。

**(M) 的足迹拖曳闭合。** 足迹内漂浮层下的液面速度取 U_J，足迹外 0（L4）：拖曳项 ½ζ|u|² 换为 ½ζ|u − U_Jχ_fp|²。展开后与 (V) 相差常数，并给出 f_J = ζU_Jχ_fp（"−ζu"部分本来就在拖曳项里）。于是
```
u_J=\mathcal P\big[U_J\,\chi_{fp}\big],\qquad \chi_{fp}=\mathbb 1\big[|x-x_j|<r_0\big],\qquad \int\chi_{fp}\,dA=Q/v ,
```
**ζ 抵消**：v3-min "运动学零参数"的性质保持。

**两条恒等式（单元检验 T-Q0 的依据）。** (a) 无界平面中均匀 U 在半径 a 圆盘上的投影 = 以 U/2 平移的刚性圆盘的势流：盘内 u = U/2，盘外 u = [2(m·x̂)x̂ − m]/(2πr²)，m = πa²U。(b) 盘外是**无旋**的：投影足迹力在足迹外等价于一个势偶极，与"源点偏移"同型。极坐标（θ 从 m 量起）：
```
u_r=\frac{m\cos\theta}{2\pi r^2},\quad u_\theta=\frac{m\sin\theta}{2\pi r^2},\quad \partial_r u_r=-\frac{2u_r}{r},\quad \frac{u_r}{r}+\frac{\partial_\theta u_\theta}{r}=+\frac{2u_r}{r},\quad \dot\theta=\frac{m\sin\theta}{2\pi r^3}.
```
前方一切物质环径向压缩、周向拉长（面积守恒），极角以 1/r³ 增长——**这就是月牙**：点源流保极角（v3-min §8 第 2 条），偶极不保；而 1/r³ 使包裹只在射流贴近时才显著，与重测"月牙在接触后 0.3–0.8 s 形成"相容。同一组式子也说明 ∂_r u_r < 0：缝（射流与旧块之间的褐带）只会被压窄（§5.2）。

**移动足迹。** 足迹以 V_j 移动时，远场物质的一阶净位移为零（∫u dt 沿通过路径的积分对称抵消），只留下 Darwin 漂移：路径附近面积 m/(2V_j) 被向前带。驻留时（V_j = 0）不抵消：轴向前方的筏被推开到 r³ = r_c³ + 3mt/(2π)（凹口），两侧（θ ≈ 90°）的筏被推向后方（外鼓）。

**为什么 (P) 不单独加。** (P) 在 r ≲ 1.5–2r_e 内比拖曳能平衡的大 10²–10³ 倍（§1.3），这一区域里筏的响应是压入/屈服/增厚（v3.1 (R1) 的 ∇N(h) 与屈服项），不是拖曳。v3-min 在 L2、L3 下没有这些项，(P) 只能以刚性几何规则出现：低位 p_0 ≤ Π_coh 时就是 L11′（排除区 r_p = r_e，r_sub(Δρ_f g h) ≈ r_e），细流时就是 L12（打散核 r_d）。把 (P) 再写成拖曳平衡的力会 (i) 引入不可辨识的 h_eff，(ii) 重复计入同一物理。**代价**（不在本变体内修）：L11′ 把漂进 r_e 的旧筏"压入并在 K_f 重浮"，而 (P) 的刚性极限也可以是"推出到等压线"；两者对旧块是否被喂大（T2c 的 ×2.8）结论不同。

### 2.3 与学长方程的关系（为 §6 的变更申请准备）

学长 V1 §3.3 的动量方程在准静态（略 ∂_t q 与对流）下为 0 = −∇p_eff − βℓu + Λ(v* − u) + s v*。取 (a) D_Π = c_p²/β → ∞（v3-min 已论证：物理值 5×10⁻³–0.18 m²/s，旧拟合 1.9×10⁻⁴ 落在已被重测否定的可动画布极限），p_eff 退化为约束乘子；(b) ℓ ≡ 1、Λ ≪ β；则 u = ∇φ + 𝒫[((Λ + s)/β) v*]。**变体 Q 就是这一极限下取 (Λ + s)/β → χ_fp、v* → U_J（κ_t = 1、κ_r = 0），不再拟合 κ_t、κ_c**。所以 Q 不是"另加"的投影，而是学长方程在 D_Π → ∞ 极限下的结果；但规则 §3.1 的字面要求仍被违反（§6）。

### 2.4 不变的部分

面积源、吞—浮、L11′、L12、在途液面包、t_k 闸门全部不变。u_J 无散，所以**账本 1–3 逐字不变**（∫c 只由源改变），dA_r/dt = GwQ/Γ 不变（实测 3.7975 cm²/s 不变）。**引理 F 保持**：Q = 0 时 χ_fp 不存在、U_J 不作用，u_J ≡ 0，停倒后在途液面用完即精确冻结（实测 max|u| = 0、ΔA_r = 0，所有 λ_J）。准静态意味着推挤在停倒瞬间停止——与 V5"停倒即停"一致，但这是 Q1 的构造，不是检验。

## 3. 原型中要加/换的方程（`spec_v2/px_model.py`），含离散

### 3.1 连续方程（替换 v3-min §3.4 的 (P)）

```
(P_Q)\quad u=\nabla\Phi+W,\qquad \nabla^2\Phi=\sigma_c+\sigma_f+\sigma_e-\dot e\,(1-c)-\nabla\cdot W,\qquad \partial_n\Phi=w_{\partial\Omega}\cdot n,
\qquad W(x,t)=\big[v\sin\alpha_j\,\hat e+\dot x_j\big]\,\chi_{fp}(x;x_j,r_0)\,\mathbb 1[Q>0],\qquad \int\chi_{fp}\,dA=Q/v .
```
（∇Φ = ∇φ − ∇λ_J/ζ 合成一次求解；u − ∇φ = W − ∇(λ_J/ζ) = 𝒫[W]。）ė 的定义不变（∫∇·W dA = 0，W 在杯壁处为零）。

### 3.2 离散（MAC，与 v3-min §6.1 一致）

1. **每个子区间 k（路径细分，M 段，现有循环内）**：用输入差分得落点速度 ẋ_j ≈ (x_j(t_b) − x_j(t_a))/(t_b − t_a)；u_tilt = v sinα_j（α_j 同 Δ_e 所用）；χ_fp 用现有 `kernel(xj, yj, 'ann', 0, r0)`（4×4 子样、杯内重新归一化，∫K dA = 1）乘 πr_0² 得到格心份额；累加格心场 W_c += U_J,k χ_fp,k / M。
2. **面心化**：W_x 在 x 面取相邻两格均值，W_y 同理；杯外/壁面（`mx`、`my` 为假）置零。
3. **一次求解**：rhs_Q = rhs − div_h(W_f)（`g.div`，乘 `inside`）；用现有 LU 回代得 Φ；u_f = ∇_fΦ + W_f。离散散度精确等于原 rhs（单元检验 max|∇_h·u_J| = 4×10⁻¹² /s（128²）、3×10⁻¹¹ /s（256²））；可解性 Σ div_h(W_f) h² = 0 自动成立。
4. **CFL**：u_max 含 W_f（足迹内 ≈ |U_J|/2）。128² 上低位 Δt ≈ 6.5 ms、细流 ≈ 3 ms。实测代价：T1/T2 +30%（2.25 → 2.9 s/模拟秒，同批负载），T3 ×2.9（1.4 → 4.1 s/模拟秒）。
5. **VOF、源、压入、打散、账本、标记点**全部用 u_f，不另改。

## 7. 校准协议（只用 tulip + leaf 拟合、冻结，测 heart、push_heart、layered_heart、swan，另做只用 tulip 的基线）

- Q 不加拟合参数，四个现有参数的锚组不变，但两组被 Q 直接改变：**g4（切线终宽，Π_coh 的唯一锚）在 Q 下消失**——leaf 中脉、tulip 收尾切都是 g4 在校准集里的来源，Q 预测它们为 0（Π_L = 2–4 > 1），Π_coh 失去观测量，四参数的可辨识性破坏；**g3（褐洞内切半径）**被偶极拉长（ray 中位 0.0475 → 0.059 D），并新增对 α_j 的敏感度（λ_J 0.1 → 1 时 0.0475 → 0.059 D），r_{e,ref} 与 α_j 的相关上升。
- 校准集里唯一对 m 敏感、又不同于 g1–g4 的过程观测量是 tulip 第 2 段（6.6–8.5 s）白前底纹 B 侧边缘的位移（原表述 0.05–0.1 D，未按 V7 方法重测）。Q 在 α_j = 8° 定点下给 0.023 D；要达到 0.05 D 须 α_j 超出先验上界（12° 时约 0.035 D）。这条应先用 v3.1 §8.3 的固定杯沿参照重测，再作检验，不作拟合。
- 只用 tulip 的基线：同上，g4 只剩 tulip 收尾切一处，Q 下同样为 0。
- 结论：在用户决定的协议下，Q 不能保持"四参数、各有独立观测量"的可辨识结构。

## 8. 失效条件、结构原因与给后续变体的输入

1. **远近场同一个 m（主因）。** 足迹外 u_J 是势偶极，速度 ∝ m/r²、包裹率 ∝ m/r³。推挤与月牙要求在 r ≈ 1–2 cm 有 1–3 mm/s，同一 m 在供给环 r ≈ 4–6 mm 处给 1.6–2.5 cm/s 的侧向回流（Π_C ≈ 1.6），把 C 形两臂扫到壶侧、把褐色画布泵进新白（褐丝）。窗口：C 形要 m ≲ 3–4×10⁻⁷ m³/s；推挤/月牙/凹口要 m ≳ 1–2×10⁻⁶。**无交集。**
2. **足迹内液面跑得比射流快（细流）。** Π_L = |U_J|/(2V) = 2–4：打散核产生的画布被带着走，线不留。线留存要求足迹内的漂浮层几乎不被拖动，与"足迹拖曳给出凹口/外鼓"矛盾。
3. **缝在面积守恒的减速流中只会变窄。** 偶极给 ∂_r u_r = −2u_r/r，与源流的 −S/(2πr²) 同号。Q 只把出白时的缝变宽一倍（白前推移的结果），终值 0.016–0.021 D。保缝必须有画布面积来源（L10 → C5 的 F_net(π̄) > 0）、画布可压（变体 C：缝作为被压缩的画布存住）或旧块的动量记忆（变体 I：推出去的块以 t_in ≈ 0.3–4 s 滑行，而近场不必有同等的稳态流）。
4. **准静态本身的边界。** 筏的 St = ρ_f h_eff/(ζT) 在推挤时标为 0.3–4，在摆动时标为 6–80。摆动条纹若来自射流的横向推力，必须由有惯性的筏来回应（变体 I 的范围）。
5. **可保留的结论（交给 I、C 作验收目标）：** 月牙的几何是"周向拉伸、面积守恒、包裹率随距离 1/r³ 衰减"（Q 给出 0.14 × 0.58 D、solidity 0.39–0.84）；驻留射流的凹口 + V 形缺口在 m ≈ 5×10⁻⁷ m³/s（细流，α_j = 8°）时量级正确（0.055 D），外鼓仍偏小（+0.03 对 ~0.05 D）；移动射流若把旧块推在排除区之外，CR-1 的"喂大"副作用自动消失。任何新变体都应在 T1 开口角、白内褐斑、T3 切线留存三项上不回退。

**给裁判的一句话**：Q 是 L5 的干净、零参数解除，能做出月牙、凹口与 V 形缺口，但同一个偶极在近场破坏了 C 形开口、白的洁净和切线；缝与摆动仍不出。不建议作为 v3-min-3 的主干；它的月牙与凹口数字可作为 I、C 两个变体的对照。

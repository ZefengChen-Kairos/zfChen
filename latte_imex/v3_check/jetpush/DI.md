## 0. 结论先行

1. **漂浮层的有效惯性是它拖着的液体边界层，不是筏。** 漂浮层底面无滑移，相对运动开始 t 秒后动量扩散到 δ_ν = √(πν_l t)，被拖动液体的面质量 m_BL = ρ_l δ_ν，拖曳系数 ζ = μ_l/δ_ν（v3.1 (a5) 的 ζ 正是这个）。二者之比 τ_m = m_BL/ζ = δ_ν²/ν_l = π t：**惯性对拖曳的比 St_m = τ_m/t = π，与时间无关**。不存在可分离的弛豫时间，精确的响应是 Rayleigh（Basset）核 1/√(πρ_lμ_l t)，不含任何参数。v3.1 用 Fr_f² ≈ 5×10⁻³ 删去惯性（N3、(a4)）比较的是浮力铺展力；相对拖曳，边界层惯性是 π 倍、筏自身惯性 ρ_f h/(ζt) = 0.7–2.4 倍（t = 1 s）。所以这个估计对边界层是错的。
2. **但惯性在 f_J = 0 时完全无害，这是一条精确的定理（§1.2，定理 I）。** 均匀的惯性与记忆（边界层对筏与画布相同）与面积约束 ∇·u = σ − ė(1 − c) 对易：势流部分 ∇φ 在任意 St_m 下都与 v3-min 相同，惯性只改变画布压乘子 λ。v3-min 的 (P) 是"惯性漂浮层 + f_J → 0"的**精确**极限，不是 O(Fr_f²) 近似；引理 F（停倒冻结）在边界层记忆下照样成立。推论：**旧闭合的"活塞"在任何面积不可压层里都不存在**。它是可压膜（ℓ 可变）的压力波加 Rusanov 动量输运；不可压层里向前的传递由 λ 瞬时完成，且无旋。
3. **只有 f_J 的旋度部分能驱动运动，其响应是带 √t 记忆的二维源偶极**：轴上 u = η_J M_h √t/(π√(πρ_lμ_l) r²)，衰减 ∝ r⁻²（v3-min 的面积源 ∝ r⁻¹）。射流水平动量通量 M_h = ρ_j Q u_h：低位 1.02 mN（α_j = 8°，5–12° 时 0.64–1.52 mN），细流 0.46 mN。若全部转入漂浮层，1 cm 处 1 s 后速度 1.8 m/s，比视频大三个量级。由 v3.1 C1 的过滤论证，**领头阶转移效率 η_J = 0**：没入液体的射流动量在体相产生无旋流，它在液面的迹 ∇_hΦ 无旋，被等压画布全部吸收。剩余的 η_J 就是 v3.1 M6 的 η_h，一个不能从二维推出的新参数。
4. **记忆使停倒后必然蠕变**：固定射流倒 T 秒后，停倒后 Δ 秒内的漂移与倒奶期间推移之比为 [(T + Δ)^{3/2} − Δ^{3/2} − T^{3/2}]/T^{3/2}，T = 1.5 / 3 s、Δ = 10 s 时为 3.0 / 1.9。V2（停倒后 10 s 内 ≤ 0.01 D）因此要求 η_J ≲ 4×10⁻⁵ – 1×10⁻⁴（0.10–0.15 D 处）；重测的白前位移（≤ 0.01–0.03 D）要求 η_J ≲ 6×10⁻⁴（按 0.01 D）至 1.7×10⁻³（按 0.03 D）。
5. **实测（128²，η_J = 0 / 3×10⁻⁴ / 10⁻³ / 2×10⁻³）**：
   - **T2 定点**（s₀ = 0.15 D）：缝在 4 s 时**全部是 0.0078 D**（1 格，与 η_J 无关；视频 0.05–0.10 D）；旧块 solidity 0.935 / 0.927 / 0.876 / 0.805（有月牙趋势），停倒后继续降到 0.932 / 0.912 / 0.830 / 0.715（蠕变）。
   - **T2 移动**（0.1 D / 1.5 s）：所有 η_J 都在出白时接触，缝始终为 0。
   - **T1**：停倒后 max|u| 0 / 8.2 / 27 mm/s；10 s 漂移在 0.10 D 处 0 / 0.042 / 0.255 D；C 形开口 75° / 35° / 15°；η_J = 10⁻³ 时白内出现 20 个褐斑。
   - **T3**（驻留 0.7 s）：凹口 0.016 / 0.035 / 0.058 / 0.077 D，入口外鼓 0.024 / 0.035 / 0.046 / 0.059 D（视频各约 0.05 D，η_J ≈ 8×10⁻⁴ 落带）。但茎宽 ×1.6–2.7（η_J = 10⁻³），"V 形"只是沿切线宽约 0.02 D 的前拖舌，切后 3 s 内还长一倍。
   - **T4**：条纹 0 / 0 / 0 / 4 条（间距 0.065 D），停倒后 max|Δc| = 1（不冻结）。
6. **判词**：变体 I **修不了** T2 的缝和 T4 的条纹，原因是结构性的。前向偶极在射流前方沿轴压缩（∂_x u_x = −2u_x/x < 0），前方的缝必然更快变窄；短记忆的对照（τ = 0.1 s，停倒即冻结）缝同样是 0.0078 D。摆动的横向动量被 Rayleigh 核低通掉：η_J = 10⁻³ 时 4 mm 处振荡位移 0.10 mm，而条纹间距要 2.4–3.4 mm。它**能**给出月牙趋势、凹口和外鼓（η_J ≈ 10⁻³），代价是破坏六段视频都有的 V2 冻结。T3 要求的 η_J（≈ 8×10⁻⁴）与 V2 允许的（≲ 10⁻⁴）相差约 10 倍，没有补偿空间。新参数只有 η_J 一个，其物理值是 0；按用户的郁金香 + 树叶校准协议，它会被停倒静止钉在下界，变体退化为 v3-min-2。**不推荐作为 v3-min-3 的主体**，推荐作为负结果记录：它关闭了"动量记忆"这条路，把 T2 的缝归还给画布来源（变体 C / C5 的 F_net(π̄)），把凹口与外鼓归还给接触力的局部阻力（筏的屈服，L2）。

## 1. 物理论证与无量纲数

### 1.1 谁有惯性：筏、画布、被拖的液体

- **画布**：吸附膜无质量（v3.1 §2.5、N5）。
- **筏**：面质量 ρ_f h_eff。v3-min §2.1 由 Γ 配 F_white 带得到 h_eff = 1.1–3.9 mm；新生筏 φ_r ≈ 0.66，ρ_f = (1 − φ_r)ρ_l = 342 kg/m³，所以 ρ_f h_eff = 0.38–1.33 kg/m²。
- **被拖的液体**：漂浮层底面（筏底是液体连续相，画布是吸附膜）对液体无滑移。相对运动开始后，动量按 Rayleigh 第一问题向下扩散：

```
\rho_l\partial_t v=\mu_l\partial_{zz}v,\qquad v(z=0,t)=u(t)\ \Rightarrow\
\tau_b=\mu_l\partial_z v|_{0}=-\sqrt{\rho_l\mu_l/\pi}\int_{-\infty}^{t}\frac{\partial_{t'}u(t')}{\sqrt{t-t'}}\,dt' .
```

反过来写，给定面力 f(t) 时的面速度为

```
u(t)=\frac{1}{\sqrt{\pi\rho_l\mu_l}}\int_{-\infty}^{t}\frac{f(t')}{\sqrt{t-t'}}\,dt' .                                      (R)
```

阶跃运动 t 秒后，被拖层厚 δ_ν = √(πν_l t)、面质量 m_BL = ρ_lδ_ν、等效拖曳 ζ = μ_l/δ_ν，这正是 v3.1 (a5) 的 ζ = μ_l/δ_ν(t_rel)。所以 (a5) 是核 (R) 的"准定常"用法。

| t (s) | δ_ν (mm) | ζ (Pa·s/m) | m_BL (kg/m²) | τ_m = m_BL/ζ (s) |
|---|---|---|---|---|
| 0.1 | 0.56 | 1.79 | 0.56 | 0.31 |
| 0.3 | 0.97 | 1.03 | 0.97 | 0.94 |
| 1 | 1.77 | 0.57 | 1.78 | 3.14 |
| 3 | 3.06 | 0.33 | 3.08 | 9.42 |
| 10 | 5.59 | 0.18 | 5.62 | 31.4 |

**St_m := τ_m/t = π，与 t 无关**：惯性与拖曳永远同量级，不存在"惯性在 τ_m 后被拖曳吃掉"的分离。任挑一个 t_ref，把 (R) 换成 m ∂_t u + ζu = f（任务提示里的形式），记忆时间就是 τ = πt_ref；这个时间是激励持续多久，不是物性。所以本变体用参数为零的 (R)，不用常数 τ。旧闭合拟合出的 β = 2.4 s⁻¹ 相当于 t_ref = 1/(πβ) = 0.13 s（δ_ν = 0.65 mm），没有物理依据。

**v3.1 的 Fr_f² 估计比较的对象不同。** v3.1 (a4) 把筏惯性与液面坡度项合并为 ρ_f h D(u − u_l)/Dt，再以 Fr_f² = U²/(g′h) = 1–3.5×10⁻³（U = 5 mm/s，h = 3.9–1.1 mm）相对**浮力铺展力** ∇N(h) 删去。在 L3 下 N 为常数，主平衡是拖曳对画布压，所以该删的判据是相对拖曳：

- 边界层：m_BL/(ζt) = π；
- 筏自身：ρ_f h/(ζ t) = 0.66 / 1.21 / 2.36（h = 1.1 / 2.0 / 3.9 mm，t = 1 s）。筏质量主导边界层的时间是 t_a = (ρ_f h)²/(ρ_lμ_l) = 0.14 / 0.46 / 1.77 s。

两者都不小，所以"Fr_f 小 ⇒ 惯性可略"对本问题**不成立**。下一节说明为什么这在 v3-min 里无害；筏自身质量的残余后果见 §1.2 末尾。

### 1.2 定理 I：均匀惯性（含记忆）与面积约束对易

设漂浮层的线性惯性—记忆算子 𝓑（(R) 的逆，即 √(ρ_lμ_l) 乘以 Riemann–Liouville 半阶导数，加上任意均匀的 m∂_t）在全杯相同，即边界层对筏与画布相同（ζ_R = ζ_C，v3-min L4 的一部分），并忽略筏自身质量。层的力平衡与约束为

```
\mathcal B[u]+m\,(u\cdot\nabla)u=\mathbf f_J-\nabla\lambda,\qquad \nabla\cdot u=S(x,t):=\sigma_c+\sigma_f+\sigma_e-\dot e(1-c),\qquad u\cdot n=w_{\partial\Omega}\cdot n .
```

作 Helmholtz 分解 u = ∇φ + ∇^⊥ψ，取 ∇²φ = S、∂_nφ = w·n、ψ|_∂Ω = 0，记 ω = ∇×u = −∇²ψ。对力平衡取旋度，𝓑 是空间上标量的时间算子，与 ∇× 对易：

```
\mathcal B[\omega]+m\,\big(u\cdot\nabla\omega+\omega\,\nabla\cdot u\big)=\nabla\times\mathbf f_J .
```

推论：

- **(a)** 若 ∇×f_J ≡ 0 且初始 ω = 0，则 ω ≡ 0 for all t：u = ∇φ 由 S 瞬时决定，与 m、𝓑、St_m 无关。非线性项 m(u·∇)u = m∇(|u|²/2) 也是梯度，同样被 λ 吸收。所以 **v3-min 的 (P) 是"惯性漂浮层 + f_J = 0"的精确解**。
- **(b)** 引理 F 在边界层记忆下成立。线性 Stokes 流中竖向涡量自成一个方程 ∂_tω_z = ν_l∇²ω_z。液面的速度史无旋，所以其边界值为 0，ω_z ≡ 0（杯壁无滑移角区的竖向涡量生成除外，v3.1 N14；v3-min 同样忽略）。停倒后液体中残余的动量对漂浮层的牵引 μ_l∂_z v|₀ 的旋度为 μ_l∂_zω_z|₀ = 0，是梯度，被 λ 吸收。S = 0 时 u ≡ 0。
- **(c)** **活塞不存在。** 旧闭合（skeptic A3/A4）的推挤是"足迹注入的动量被可压膜（ℓ 自由、p = ½c_p²ℓ²）向前对流、并以 c_p√ℓ 的压力波传开"，0.15–0.2 D 处 1 s 推 0.11–0.15 D。面积不可压层里压力波速无穷大，向前传递由 λ 瞬时完成且无旋，被 (a) 吸收。所以给 v3-min 加惯性**不会**重现活塞。
- **(d)** 唯一的作用通道是 ∇×f_J：u = ∇φ + P G，其中 G = 𝓑⁻¹f_J，P 是 Leray 投影（P G = G − ∇Δ⁻¹∇·G，带 G·n = 0）。
- **(e) 本变体没有包含的筏质量残余。** 筏面质量 ρ_f h c 不均匀，m(u·∇)u 在筏缘有旋度 ∇(ρ_f h c) × D(∇φ)/Dt。对 T2 旧块，停倒时速度 u_stop ≈ 3–4 mm/s，其动量的无旋分量约一半会以 (R) 滑行，估计 X ≈ ρ_f h u_stop √t/√(πρ_lμ_l)，10 s 约 0.02–0.05 D。这是 v3-min 引理 F"漂浮层无惯性"前提的另一个可检验后果；变体 I 与 v3-min 一样不含此项，列为消融（§7）。

**(i) 射流水平动量通量。** 落面奶的水平速度（杯系）为 u_h = v sin α_j ê + ẋ_j：倾角项，加上嘴的速度，奶离嘴时继承它。

**(ii) 足迹压力作用于筏（v3.1 (a6)）**：f_p = −(1 − ρ_f/ρ_l) h c∇p_J，旋度 −0.7h∇c×∇p_J，只在筏缘穿过足迹处不为零。

- 低位时 L11′ 每步把 r < r_e 的筏压入。残余力不超过半平面筏缘在 r_e 处的值 F_p = 0.7h p_0√π r_0 e^{−r_e²/r_0²} = 0.082h N/m，h = 2 mm 时为 0.16 mN。
- 细流落在筏上时 F_p ≈ 0.66 mN。

**若全部转入漂浮层**（由 (R) 与 P）：轴上 u(r, t) = F√t/(π√(πρ_lμ_l) r²) = 0.179 F√t/r²（SI）。F = M_h 时，1 cm 处 1 s 后 1.8 m/s，5 mm 处 7.3 m/s。视频里的元素速度 ≤ 1 cm/s（V5 边缘 0.1 → 0.04 D/s），**高三个量级**。

**为什么物理上转移效率很小（领头阶为 0）。** 没入式射流（We_j ≈ 25–68，无弹坑，v3.1 §2.2）把动量带进体相：

- 体相在射流涡层之外是无旋流 ∇Φ，它在液面的迹 ∇_hΦ(x, y, 0) 的竖向涡量为零。按 v3.1 C1（等压画布过滤发散型表面流）它被 λ 全部吸收。
- 液面竖向涡量只能来自终止在液面上的涡线，即射流剪切层被倾角拧出的竖向分量。它位于射流脚 r ≲ r_c，正是吞汇（M1），被吞下。
- 压力项 (ii) 则由筏下液体的局部等静补偿与压入承担（p_J > Δρ_f g h 的 r < r_sub 内筏被压下，v3.1 §3.9），不由层的拖曳承担。按 (a6) 的深度积分值放进只有拖曳的层，会得到 0.1–1 m/s，与一切观测不符。

所以本变体只保留 (i)，带一个转移效率 η_J（物理值 0，即 v3.1 M6 的 η_h 的"附着在液面上"的版本），不保留 (ii)。

### 1.4 推移距离、随距离的衰减、停倒蠕变（解析，自由空间，固定射流）

```
u_{axis}(r,t)=\frac{\eta_J M_h}{2\pi r^2}\cdot\frac{2\sqrt t}{\sqrt{\pi\rho_l\mu_l}},\qquad u_{lat}(r,t)=-u_{axis}(r,t),\qquad
X_{axis}(r,t)=\frac{2}{3\pi}\,\frac{\eta_J M_h\,t^{3/2}}{\sqrt{\pi\rho_l\mu_l}\,r^2}=0.119\,\eta_J M_h t^{3/2}/r^2\ \ (\text{SI}) .
```

- **衰减**：∝ r⁻²。距离从 0.15 D 到 0.30 D，位移降为 1/4。实测 T1（η_J = 10⁻³ 减去 η_J = 0）的出白前位移比为 5.2。杯壁像使圆盘中心偶极再乘 (1 − r²/R²)。单元测试：10–20 mm 处与解析式差 ≤ 2%，5 mm 处差 5%（有限足迹）。
- **前方的缝必然变窄**：轴上 ∂_x u_x = −2u_x/x < 0，宽 s、距离 x 的缝满足 ds/dt = −2s u_x(x)/x。叠加 v3-min 的面积源（同样使缝变窄），没有任何保缝项。侧向 ∂_y u_y = +2u_x/x 把旧块拉宽，这就是月牙趋势的来源。
- **停倒蠕变**：停在 T 时，X ∝ t^{3/2} − (t − T)^{3/2}，比值见 §0 第 4 条。
- **所需与允许的 η_J**（r = 0.15 D = 12 mm）：
  - 1 s 推 0.05 D：η_J = 4.8×10⁻³；
  - 白前 1.4 s 内 ≤ 0.01 D：η_J ≤ 5.7×10⁻⁴；
  - 3 s 倒奶后 10 s 内漂移 ≤ 0.01 D：η_J ≤ 9×10⁻⁵（0.10 D 处 4×10⁻⁵，0.30 D 处 3.8×10⁻⁴）。
- **摆动**：振荡分量的响应为 η_J M_h,osc/(2πr²|Z|)，与定常分量 t 秒后的响应之比为 √π/(2√(ωt)) = 0.20（t = 1 s）。η_J = 10⁻³ 时，4 / 8 mm 处的振荡位移幅为 0.10 / 0.026 mm，条纹间距 0.030–0.043 D = 2.4–3.4 mm。**记忆把每周期的横向动量低通掉，不产生逐周期的调制。**

## 2. 作为 v3.1 显式极限的推导

**出发点**：v3.1 漂浮层力平衡 (R1)–(R2)、画布 (C1)、变分形式 (V)，加 (a4) 惯性、(a5) 底剪切、(a6) 足迹载荷、M6 涡量。把 (a5) 写成其本来的历史形式（§1.1 的 (R)），惯性不删：

```
\rho_f h c\,\frac{D(u-u_l)}{Dt}+\mathcal B[u-U_l^\sigma]=\nabla\cdot[hR(u)]-\nabla N(h)+\mathbf f_J-\nabla\lambda,\qquad
\mathcal B^{-1}[\,\mathbf f\,](t)=\frac{1}{\sqrt{\pi\rho_l\mu_l}}\int_{-\infty}^{t}\frac{\mathbf f(t')}{\sqrt{t-t'}}dt' ,
```

约束沿用 v3-min：(1 − c)(∇·u − σ_A − ė) = 0 加筏面积不可压 c(∇·u − σ_raft) = 0（L3），合起来就是 ∇·u = S。

**取极限**（与 v3-min-2 的差别只在最后一行）：

| 极限 | v3-min-2 | 变体 I | 判据（本杯） | 失效症状 |
|---|---|---|---|---|
| L1、L3、L6–L13 | 同 v3-min-2 | 不变 | 见 v3-min §2.4 | 同 v3-min |
| L2 全塑性（hR → 0） | 是 | 不变 | 经验选择（v3-min §2.1） | 同 v3-min |
| L4：U_l^σ = 0，ζ_R = ζ_C | 两者都取 | **保留 ζ_R = ζ_C（𝓑 均匀），保留体相 U_l^σ = 0**；射流在液面生成的涡量改由本层的 P G 表示 | \|ζ_R/ζ_C − 1\| ≲ 3%（未验证） | 停倒后整体漂移/转动 |
| N3/(a4) 惯性 | 删（Fr_f²） | **边界层惯性与记忆保留（精确核 (R)）；筏自身质量 ρ_f h c 仍删** | 边界层：定理 I，f_J = 0 时精确无害。筏：St_raft = ρ_f h/(ζt) = 0.7–2.4，**不小**，只经筏缘旋度起作用（§1.2 (e)） | 筏在停倒后单独滑行 ≥ 0.01 D |

由此得到

```
\mathcal B[u]+\nabla\lambda=\mathbf f_J,\quad \nabla\cdot u=S\ \Rightarrow\ u=\nabla\phi+P\,\mathcal B^{-1}[\mathbf f_J],\quad \nabla^2\phi=S .
```

λ 只是画布压的诊断量，不进入任何输运。

**说明一（与 L4 的关系）**：变体 I 的 P G 与 v3.1 M6 的 U_l^σ 是同一物理（射流水平动量 → 液面竖向涡量），只是动量的存放处不同。M6 假定动量进入体相，响应是三维偶极 ∝ M_h t/(4πρ_l r³)；本变体假定动量附着在液面薄层，响应 ∝ M_h √t/(√(ρ_lμ_l) r²)，比前者大 2r/δ_ν 倍。v3-min L4 从冻结得到 η_h ≲ 10⁻³（三维估计），本文从同一事实得到 η_J ≲ 10⁻⁴（薄层估计），量级一致。

**说明二（是不是合法极限）**：均匀惯性的部分是 v3.1 的精确细化：(a5) 的准定常 ζ 换成它本来的核，并由定理 I 证明对 v3-min 无影响。L5-I 则是一个物理上效率为零的力项。把它放开是一个参数化，不是由小参数推出的修正，它唯一的支撑是"或许 η_J ≠ 0"。§5 的实测表明它在数据允许的范围内不起作用。

## 3. 方程与离散（加到 `min/spec_v2/px_model.py`）

### 3.1 连续方程（替换 v3-min-2 §3.4 的 (P)，其余不变）

```
(I\text{-}1)\quad u=\nabla\chi+\mathbf G ,
(I\text{-}2)\quad \nabla^2\chi=\sigma_c+\sigma_f+\sigma_e-\dot e\,(1-c)-\nabla\cdot\mathbf G,\qquad \partial_n\chi=w_{\partial\Omega}\cdot n\ \ (\mathbf G\cdot n=0\ \text{on the wall}),
(I\text{-}3)\quad \mathbf G(x,t)=\frac{1}{\sqrt{\pi\rho_l\mu_l}}\int_{-\infty}^{t}\frac{\mathbf f_J(x,t')}{\sqrt{t-t'}}\,dt' ,
(I\text{-}4)\quad \mathbf f_J=\eta_J\,\rho_j Q\,\mathbf u_h\,K_J(x-x_j),\quad \mathbf u_h=v\sin\alpha_j\,\hat e+\dot{\mathbf x}_j,\quad
K_J=\frac{e^{-|x-x_j|^2/r_0^2}\,\mathbb 1[|x-x_j|<3r_0]}{\int_\Omega e^{-|x-x_j|^2/r_0^2}\mathbb 1[\cdot]\,dA},\quad \rho_j=(1-\phi_j)\rho_l .
```

- 等价写法：u = ∇φ_{v3-min} + P G，其中 φ_{v3-min} 是 v3-min-2 原来的势。
- ė 的公式不变：∮G·n = 0，所以可解性不变。
- (C)、全部源与核、L11′ 压入、打散核、在途包、账本 1–3 都不变。
- **量纲**：ρ_jQu_h [N]，K_J [m⁻²]，f_J [N/m²]；√(ρ_lμ_l) [kg m⁻² s⁻¹ᐟ²]，∫f dt′/√t′ [N s^{1/2}/m²]，所以 G [m/s]；∇·G [1/s] 与 S 同量纲。
- **新参数**：η_J（无量纲）。ρ_l、μ_l、φ_j、α_j、v 都是 v3-min 已有的量。

### 3.2 核的指数和表示（无参数的近似，误差可控）

```
\frac{1}{\sqrt{\pi t}}\approx\sum_{k=1}^{K}c_k e^{-s_k t},\qquad s_k=e^{y_k},\ y_k=\ln 10^{-6}+0.9(k-1),\ K=31\ (s_K=5.3\times10^{5}\,\mathrm{s^{-1}}),\qquad c_k=\frac{0.9}{\pi}e^{y_k/2},
\mathbf G=\sum_k\mathbf G_k,\qquad \partial_t\mathbf G_k=-s_k\mathbf G_k+\frac{c_k}{\sqrt{\rho_l\mu_l}}\mathbf f_J .
```

这就是 1/√(πt) = (1/π)∫₀^∞ s^{−1/2}e^{−st}ds 在 ln s 上的梯形求积。

- 核本身在 [1 ms, 30 s] 上误差 ≤ 0.5%；其积分在 t ≥ 5 ms 时误差 ≤ 0.9%，t ≥ 1 ms 时 ≤ 1.9%。
- 下截断 s_1 = 10⁻⁶ s⁻¹ 留下的常数偏差为 2e^{y_1/2}/π = 6×10⁻⁴，对 30 s 内的积分 < 0.3%。
- 步长取 0.9 可降到 22 个模（步长 1.2，误差 ≤ 1.5%）。

### 3.3 离散（MAC，与 v3-min-2 的 Poisson/VOF 共用）

1. **状态**：G_k 存在面心上，x 面 (N + 1)×N、y 面 N×(N + 1)，k = 1…K。128² 时 8.2 MB，256² 时 33 MB。杯外与壁面的面恒为 0（用 `g.mx`、`g.my` 掩模）。
2. **力的面平均**：沿用 v3-min-2 每步把路径细分为 M 段（≤ Δx/2）。第 m 段取中点状态，
   ```
   \bar f_f=\frac1M\sum_{m=1}^{M}\eta_J\rho_jQ_m\,(\mathbf u_{h,m}\cdot\hat x_f)\,K_J(x_f-x_{j,m}),\qquad
   \mathbf u_{h,m}=v_m\sin\alpha_j\,\hat e_m+\frac{x_j(t_{m+1})-x_j(t_m)}{t_{m+1}-t_m} .
   ```
   K_J 在面心以 4×4 子样计算，在杯内的 x 面与 y 面上**分别**归一化（Σ_f K_J h² = 1）。Q_m = 0 的段不施力。
3. **本步平均的投影前速度**（力在步内为常数时精确）：
   ```
   a_k=\frac{1-e^{-s_k\Delta t}}{s_k\Delta t},\qquad
   \bar{\mathbf G}_f=\sum_k\Big[a_k\,\mathbf G^n_{k,f}+\frac{c_k}{\sqrt{\rho_l\mu_l}}\,\frac{1-a_k}{s_k}\,\bar f_f\Big]\ \ (\text{壁面面置 }0) .
   ```
4. **Poisson（同一个 LU、同一个钉住格）**：RHS′ = RHS_{v3-min} − div_h(Ḡ)（只在杯内格）。Σ RHS′ = Σ RHS = 0。回代得 χ，面速度 u_f = ∇_fχ + Ḡ_f。离散散度 div_h u = RHS_{v3-min}，与 v3-min-2 完全相同（实测残差 0）。
5. **CFL 与试步**：Courant 用含 Ḡ 的 u_f。G_k 只在接受时更新，被拒的试步不改动 G_k。
6. **接受后更新**：
   ```
   \mathbf G^{n+1}_{k,f}=e^{-s_k\Delta t}\,\mathbf G^n_{k,f}+\frac{c_k}{\sqrt{\rho_l\mu_l}}\,\frac{1-e^{-s_k\Delta t}}{s_k}\,\bar f_f .
   ```
7. **账本**：
   - 冲量 I_x += Σ_{x 面} f̄ h² Δt，必须等于 η_Jρ_jQu_{h,x}Δt 到舍入（实测 2.0317×10⁻⁶ 对 2.0317×10⁻⁶ N·s）；
   - 账本 1–3 不变（实测 foam_rel、surf_err 均为 0）；
   - (∇·u − RHS)Δt 不变（实测 0）；
   - 增加"停倒后位移"诊断（学长 §5.4 的停流位移）。

**单元测试 T-I0（先于一切图案）**：杯心定点倒奶，关掉源（Γ → ∞、α_F → 0、L11′ 关），比较轴上 u_x 与 (η_J M_h/(2πr²))·2√t/√(πρ_lμ_l)·(1 − r²/R²)：

- 实测 r = 10 / 15 / 20 mm，t = 0.25–2 s：比值 0.983–0.998；
- r = 5 mm：0.94–0.95（足迹有限）。
- 验收：r ≥ 3r_0 处 ±3%。

**代价**：31 个模的逐格更新使 128² 每步多约 80–110%（3 进程并行实测，每模拟秒墙钟 3.0 → 5.4–6.5 s）。只在路径包围盒内存模，或用 22 个模，可降到 +30% 以内。

## 7. 失效条件、消融与建议

- **会否定本文结论的观测**：
  - 三脚架俯拍（E1）显示停倒后旧纹路在 1–10 s 内有 ≥ 0.01 D、按 √t 增长的漂移，指向射流的水平动量方向。那时 η_J ≈ 10⁻⁴–10⁻³，变体 I 成为必要。
  - 胡椒示踪（v3.1 E2(c)）在射流脚两侧量到竖向涡量偶极。
- **消融（下一步原型顺带做，不改主体）**：
  - 筏自身质量 ρ_f h c 的惯性（§1.2 (e)）：预测 T2 旧块停倒后 10 s 内滑行 0.02–0.05 D。若原型证实，"漂浮层无惯性"这一 v3-min 前提本身需要另一条理由（例如筏—画布界面的屈服），这对 v3-min 的引理 F 是一个比本变体更重要的检验。
  - 单模 τ 的灵敏度对照（已做，§5.2）。
- **对 v3-min-3 的建议**：
  - 本变体关闭了"动量记忆 / 活塞"这条路。
  - T2 的缝需要画布来源（变体 C；或 v3.1 C5 的 F_net(π̄)，κ > 0 且位置正确）。缝不能靠任何前向力保持（§1.4：前方轴向压缩是偶极的几何性质）。
  - T3 的凹口与外鼓确实需要足迹力，但其阻力应是筏的局部屈服（放开 L2 的足迹区，v3.1 §3.9 的塑性区 r_pl），而不是全杯的边界层拖曳。后者给出无界的偶极与蠕变。
  - T4 的条纹需要逐周期的画布产生（v3.1 §3.10 的回涌卷积、σ_t），与惯性无关。
  - 若以后测得老化膜的表面剪切粘度 η_s 显著（Boussinesq 数 η_s/(μ_l L) = 10–10³，当 η_s = 10⁻⁴–10⁻² N·s/m、L = 1 cm），它会把核 (R) 截短为短记忆、使停倒冻结。那是另一个变体（表面流变），不是惯性。

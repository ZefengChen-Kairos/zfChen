**模型改动**（`diff base_v2/px_model_v2_orig.py px_model.py`，共 4 处，全部受开关 `FIXED['jetU']` 控制，缺省 0 = v3-min-2，`VQ = dict(V2, jetU=1.0)` = 变体 Q）：

```
(P_Q)\quad u=\nabla\Phi+W,\qquad \nabla^2\Phi=\sigma_c+\sigma_f+\sigma_e-\dot e\,(1-c)-\nabla\cdot W,\qquad \partial_n\Phi=w_{\partial\Omega}\cdot n ,
W(x,t)=\big[v\sin\alpha_j\,\hat e(t)+\dot x_j(t)\big]\,\chi_{fp}(x;x_j,r_0)\,\mathbb 1[Q>0],\qquad \int\chi_{fp}\,dA=\pi r_0^2=Q/v ,
\Rightarrow\ u-\nabla\phi=\mathcal P[W]\ (\text{杯内法向通量为零的 Leray 投影}),\qquad \nabla\cdot u=\sigma_c+\sigma_f+\sigma_e-\dot e(1-c)\ (\text{不变}).
```

1. 每个路径子区间 k（现有的 M 段细分循环内）：ẋ_j = [x_j(t_b) − x_j(t_a)]/(t_b − t_a)（输入差分，分段线性输入下精确），u_tilt = v sin α_j（α_j 与 Δ_e 用的是同一个扰动量，缺省 8°），χ_fp = `kernel(x_j, y_j, 'ann', 0, r_0)`·πr_0²（4×4 子样、杯内重新归一化），W_c += U_J,k χ_fp,k / M；只在 Q > 0 的子区间累加。
2. 面心化：W_f 取相邻两格均值，杯外与壁面面（`mx`、`my` 为假）置零。
3. 一次求解：Φ = LU 回代(rhs − div_h W_f)，u_f = ∇_fΦ + W_f。离散散度恰为原 rhs，可解性自动成立（W_f 在壁面为零）。
4. CFL、VOF、源、压入、打散、账本、标记点全部用新的 u_f，未另改。没有加入驻点压力部分 (P)，没有新参数；ζ 不出现。

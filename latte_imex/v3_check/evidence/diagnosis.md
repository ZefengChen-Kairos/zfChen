## 1. 家族 A：旧闭合（χ 沉积 / Λ 牵引 / κ_r 返流）+ §14 时延补丁

### 1.1 物理模型缺陷（物理错或缺）

**A1 [fatal] 白度是被动示踪，拉伸永远不出褐色；褐缝只能是被压缩的原有褐条。**
机制：`solver.py` L360 `c = m/ℓⁿ`；步 C（L476–511）用与 ℓ 完全相同的面通量 G 输运 m，`m⁺ = mⁿ + dt·s − dt∇·(G c_f)`，因此膜被拉薄时 ℓ、m 同比例减小，c 不变；D = 10⁻⁷ 惰性。新白只能"覆盖"旧表面，褐色只能来自原来就是褐色的流体被搬运/压缩，其宽度只能≤初始褐条宽度（推心 B 点到旧块后缘约 0.06 D）并随压缩变窄（code_map §4 old 步 2–4）。
证据：160 组九维闭合扫描、足迹 ×0.3、85% 脉动、ν→0、256²→512² 加密（缝中位 2.5→2.0 mm）全部出不来 ≥4 mm 褐带（notion_z1 F10、F11；conv part2 E-11/E-12/E-18）；真实褐缝 4–9 mm / 0.04–0.13 D（video_obs §2）。C:L561 结论"宽褐带不是参数问题，是 2D 闭合的表达力问题"。

**A2 [fatal] 沉积与推挤在同一核、同一时刻发生；白当帧出现在落点，与 V1 完全相反。**
机制：L331–350：`s = χ S K`、`Λ = κ_c(1−χ) S K` 都 ∝ 同一个足迹核 K（支持 ≈ 8×5 mm）；#9 低位 s_peak = 23.9 /s，核峰 c 在 0.1 s 内到 0.7（code_map §4 old 步 1）。视频：落点 0.9–2.1 s 内无白，之后白在落点**周围**出现而落点始终褐（video_obs §0 "impact spot stays brown"，§9 rank 1，9/9 阶段）。模型没有"落点是褐洞、白环在外"的几何；心形的 C 形开口、推心每块的 B 侧缺口都来自这个几何。
证据：PITCHER_MODEL L218（"沉积和推挤同时发生在同一个核里"）；video_obs §1 "the hit point is the last place to turn white"。

**A3 [fatal] 没有把 0.1–0.3 D 外的旧白块整体推开的力。**
机制：作用在足迹外膜上的只有各向同性膜压力 −c_p²ℓ∇ℓ（已经是白的堆高才产生）和已运动膜的 Rusanov 对流惯性；κ_r V_R 径向返流在 #9 拟合为 0.07 D/s（κ_r = 0.0085 ≈ 0）；Λ(v*−u) 只在 K 内（code_map §3 表、§1.1 数字）。真实推挤是**先推后白**（V7：白出现前旧块已位移 0.05–0.15 D 并变形成月牙）。
证据：PITCHER L270 "到目前为止唯一出过宽褐带的是第 14 节水下奶堆用压力推开旧层的补丁"；video_obs §7；physics_prior §2.4（落点 r ≲ 2d 的向外表面薄层是真正的推力来源，模型没有）。

**A4 [major] 推挤速度量级和衰减方式都不对。**
机制：K 内目标速度 v* = κ_t u_in ≈ 1.5–1.7 D/s（13 cm/s），s v* + Λ(v*−u) 让足迹内膜在 ~10 ms 内达到此速度，再以 −βq（β = 2.4 /s）滑行 u/β ≈ 0.7 D（code_map §3 "coasting distance"）；视频里旧块位移只有 0.05–0.15 D，且随离落点距离快速衰减（>0.3 D 不动），图案漂移 0.1–0.16 D/s。模型把动量集中注入 1 cm² 的足迹再靠惯性/压力扩散，而不是一个随 r 衰减的表面速度场。
证据：video_obs §7 item 4、§9 rank 5；physics_prior §0（射流动量通量 8–10 mN 给出的杯内速度尺度 4–5 cm/s = 0.05–0.06 D/s）。

**A5 [major] 膜是单相牛顿流体：无屈服应力、无自选厚度，堆高后以重力流速度摊开，条纹必然合并、边缘必然变软。**
机制：p = ½c_p²ℓ²，重力波速 √(c_p²ℓ) ≈ 1.8 D/s（c_p 0.97, ℓ 3.4），D_eff = c_p²ℓ²/β = 0.39ℓ² D²/s；Laplace 粘性 ν = 1.4e-3 可忽略；没有任何介于网格和整杯之间的长度尺度（TWOLAYER L79）。真实奶泡筏 Bn = τ_y R/(Δρ g h²) ~ O(1)，厚度自选 h_stop = √(2τ_y R/Δρ g) ≈ 2–5 mm，条纹存活条件 τ_y ≳ Δρ g h²/(2w)（physics_prior §1.1、§3c）。
证据：V2（界面 10 s 不糊）；优化器把 c_p 推到下界 0.11（conv part1 E-3）、ℓ_max 2.87 是因为只有"堆高不摊开"才给出损失喜欢的实白锐边（conv part1 E-9 [76]）——这是缺屈服应力的症状。

**A6 [major] 白度 = 混合比 c = m/ℓ，渲染 clip(c/0.6)，与光学/厚度无关，使"露出褐色"成为质量搬运问题而非薄层问题。**
机制：`render.py:16` / `optimize.visible` c_sat = 0.6：c ≥ 0.6 全白，褐线要 c < 0.3，即必须把 >70% 的膜质量移走；而光学上白度在奶泡 ≈1 mm 饱和、褐 = 奶泡 < 0.2 mm（physics_prior §1.5）。"厚度 1" 实为 D_L/kQ = 60 mm（code_map §1.0），所以 ℓ、m 既非膜厚也非覆盖度，渲染器拿不到物理量（学长规范要求一个有界组分 c 线性混材质，notion_senior §5）。
证据：docs_map O1、C4；conv part3 [537] 点 3（旧模型锐边来自硬阈值）。

**A7 [major] 沉积/穿透开关 χ = 1/(1+(U⊥²/(B_dep d))^p) 是效果参数，"切"只是 1–2 mm 的拖带，不是穿透分断。**
机制：B_dep 在文档内 4 → 2.5 → 240 → 1719 → ≈2800（docs_map C7）；#9 高位细切 χ = 0.057 仍沉积 s_peak 1.3 /s；联合搜索退化到 B_dep 1470 → 细切 χ 0.7 "切刀也在沉积"（conv part1 B-4）。切的唯一机制是 Λ(v_jet−u) 把 1–2 mm 宽的膜拖走（PITCHER L257 "去掉以后心形没有缺口"）；没有"细流穿透白层、把两侧分开、露出褐色、之后部分愈合成细线"的过程（V4：细褐线 0.01 D + 两侧鼓起 + 茎到杯沿；physics_prior §3d）。`stage_actions.py` 的抬缸甚至不穿过白块（conv part3 [555] "没有切穿白团"）。
证据：video_obs §0 "final cut"；docs_map §4.3 item 6。

**A8 [major] 没有咖啡基底：膜被拖向静止（−βq），新奶的液体部分、杯面流场、停倒后的残余环流全部不存在。**
机制：POUR L19（O2）；S_eff 全部进入膜（kQ·Q），没有"液体奶进入咖啡、只有奶泡浮在面上"的区分（docs_map C22）。好处是图案冻结（见 §1.5），代价是 A3/A4 的推力只能靠膜本身。
证据：conv [539] "结构一旦形成，没有东西再把它带走"。

**A9 [minor] 杯几何固定：无杯倾（V11，6/6）、无液面上升（150 mL 升 3 cm）、杯壁自由滑移、杯壁褐环（V3）只靠"白没铺到"。**

### 1.2 闭合 / 参数化缺陷（物理方向对，形式错）

**A10 [major] "先推后白"补丁抓住了唯一正确的要素（水下未显白体积对旧层施压），但实现是三个肉眼折中的数、时延量级错 6 倍、且在所有拟合与网页默认中关闭。**

证据：PITCHER §14 L240–247、L259；video_obs §0；docs_map §4.3 item 4。

**A11 [major] 牵引目标 v* = κ_t u_in 把推力全部挂在"奶柱水平速度"上，而这个量在 V0.5 时代是 ±1.4 D/s 的合成摆动，物理壶链只有它的 1/7；整套 (B_dep, κ_t, κ_r, kQ) 是围着 Codex 不可实现的入口（0.6 mm 奶柱需 48 m/s、85% 锁相脉动）调出来的。**

**A12 [minor] κ_r 径向返流"不受体积守恒约束"（docs_map O4），V_R 的 v05 封顶律无物理依据；拟合结果 κ_r ≈ 0 说明末帧根本不需要它，但 Codex 反算要 0.03–0.07（差 3–10 倍，notion_z1 G11）。**

### 1.3 数值缺陷

**A14 [major] 细纹宽度由网格和数值扩散决定，不收敛。**
机制：Rusanov α = 2max|u| ⇒ ν_num ≈ |u|h = 0.005–0.021 D²/s（u 0.5–2），为物理 ν 的 4–15 倍；步 B 对 ℓ 的 Rusanov 型项 ν_num,ℓ ≈ |u|h/2；van Leer 把界面抹 2–3 格；96² 一格 0.83 mm = 学长的"可分辨宽度"4/384 D（code_map §6；notion_senior §3.7）。256²→512² 条数 19→23、中位宽 2.5→2.0 mm（E23）；学长三网格暗缝 0/3/21 条（notion_senior §3.2）。
证据：TWOLAYER L84–88 自认"细纹宽度由网格和数值扩散决定"。

**A15 [minor] 核半轴下限 1.5h：96² 上高位细切足迹 0.93 mm 被抬到 1.25 mm（面积 ×1.8，K_peak 2684 而非 ≈4800），Λ、s 峰值随之缩小；所有拟合常数（κ_c、B_dep）与分辨率耦合，96² 拟合 ≠ 256² 出图（code_map item 3）。**

**A16 [minor] 帧级冻结：入口、Λ、v* 在 8.3 ms 内常数；u_max 取帧首值，不含帧内产生的重力波速 √(c_p²ℓ)；违例只靠非有限/ℓ 下限重试捕获，否则表现为额外 Rusanov 耗散（code_map item 11）。细切阶段 ROI 时间步不收敛（notion_senior §3.2）。**

### 1.4 方法学缺陷

### 1.5 家族 A 做对的、必须保留的

- **S-A1 局部接触推力。** 新奶动量直接注入落点膜（s v* + Λ(v*−u)），形成一个局部前沿——这是三个闭合里唯一能在推心视频脚本下把第一块和后两块分开的机制（conv part3 [545]），也是心形凹口/尖端、郁金香 U 形瓣的来源。v2 丢掉它之后只剩非局部势流（conv [537]）。
- **S-A2 图案冻结。** 停倒后膜被拖向静止（−βq），已成形的结构不再被带走，与 V5/V7"远端不动"一致。
- **S-A3 χ 开关的方向正确**："高细流少出白但仍作用于液面"（学长 V1 §3.2），Λ 牵引给出凹口和切线。B_dep·d 的量纲即 g′Fr_c²·d（conv [336]），可换成物理的 We/Fr 开关而不丢功能。
- **S-A4 §14 补丁的核心洞见**："已经在推、但还没变白"的水下体积对旧层施压，是唯一出过 6–10 mm 宽带的机制（PITCHER L270）。保留概念（水下/未显白体积有力学存在），重做形式（时延 ~1 s 且随高度变化、压力来源是奶泡浮力/落点向外薄层而非 w·∇m_sub）。
- **S-A5 数值骨架可靠**：守恒 1e-14，IMEX+Rusanov 在同输入下与 HLLC 768 给出同一结构（IoU 0.80–0.98），步数与 c_p 无关（F1、F2、F3），JS 对拍 3e-8。
- **S-A6 硬阈值可见量给出锐边**——理由错（应是光学饱和 ≈1 mm），效果方向对；新模型的白度映射应保留"饱和快"的性质。

## 2. 家族 B：双层 + 卷吸胞（twolayer）与 v2（H/H_f、SSA+Bingham、不透明度）

### 2.1 物理模型缺陷

**B1 [fatal] v2 在落点处让表面向射流汇聚（div U_s = −126 /s 低位，−341 /s 细切），把旧白块往新奶里吸，与观测到的推开方向相反。**

### 2.2 闭合 / 参数化缺陷

**B15 [major] twolayer（v1）浮出奶泡以零动量加入膜：L363 `s_mom = s` 绑定的是 `inlet_fields` 返回的零数组（L316），L402 重绑 `s` 但 `s_mom` 不变 ⇒ 一个 s ≈ 28–40 /s ≫ β 的假阻力恰落在褐缝生成区；v* = (s U_s + Λ v_jet)/(s+Λ) 把牵引目标减半。所有 twolayer/cell 拟合（cf02 0.416、25 维 CMA）都带着这个缺陷，却被当作无缺陷基线反复引用。**

**B16 [major] v1 的褐色源项（上涌生成褐色表面 D_s⁺、下卷只除褐液 D_s⁻）是"往 ℓ 里加褐"的源，不是露出——得到的是灰环"变糊"（code_map §4 twolayer 步 3）；低位 S_E ≈ S_eff 时 D_s⁻ ≈ 0，什么都不下卷。v2 删了它只留 s_skin，是把一个错的机制换成一个正则化状态。**

**B17 [minor] 空间/时间尺度全靠一个拟合系数支撑：胞内散度 27 /s（R_c 4 mm）在 R_c = 1 cm 时降到 4.2 /s、R_c = 3 cm 时 0.5 /s（"0.1 s 稀释到 5%"变 6 s）；换成文档自己声称的物理胞尺度（∝ 喷泉深度，cell_frac ≈ 1）后 v2 的褐缝机制消失（docs_map §4.2 行"胞内散度"、§4.3 item 2）。**

### 2.4 方法学缺陷

**B23 [fatal] 与 A17 相同的末帧面积损失，外加 gap 项的盲区：`gap_stats` 用 6 mm 圆盘闭运算，>6 mm 的褐带不算缝（code_map item 16）；gap 项分不出瓣间缝与图案外褐块（郁金香 0.196 是白团外的一大块褐，conv [528]）；J_A 仍被卷带骗过。32 维联合 CMA ~220 个候选"远远不够收敛"（conv [537]）。**

**B24 [major] 文档给出的可测预测与标定实验一个都没做：白盘扩张速度（LATTE L309）、单点定高倒奶清圈半径/速度定 R_c 与 ent（TWOLAYER L94–96）、"多高开始不出白"定 Fr_c²、τ_d 从视频读、l_skin / ν_max / ε 不敏感性（YIELD L75、L166、L174–182）。学长的诊断顺序（输入→数值→闭合→渲染）和"一次改一个机制、保留失败对照"被跳过：屈服应力在 256²/superbee 与 c_p 扫描这两个门槛实验之前就加了（conv part3 O-1、O-2、C-4）。**

### 2.5 家族 B 做对的、必须保留的

- **S-B1 两个厚度尺度分开**：咖啡深度 H（5–6 cm）与漂浮层 H_f（mm 级）；膜厚进入物理单位；c_p² = g′H_f/D_L 由浮力导出而非自由参数——方向正确（physics_prior §2.5：√(g′h) ≈ 0.13 m/s）。只是 H_f 必须有自选机制（h_stop），不能当拟合旋钮。
- **S-B2 "先推后白"从机制里涌现**而非打补丁：奶泡先入水下、后浮出；χ(Fr)、Fr² = U²/(g′d) 是正确的无量纲组（B_dep = g′Fr_c²）。需换成团块存活（We_R = ρv²R/σ ≈ 1）并让延迟随高度变化。
- **S-B3 有咖啡基底速度场拖膜**（β(u − U_s)）：概念必要；但 U_s 必须是"近场向外薄层 + 远场向内回流 + 滞止环"（physics_prior §2.4），且要有记忆。
- **S-B4 运动学露褐**（表面散度拉薄漂浮层 ⇒ 透出褐）是物理上正确的褐缝生成机制（code_map §4 v2 步 2），前提是散度场方向对、膜是薄的奶泡筏而不是总厚度。
- **S-B5 Bingham/SSA 膜应力算子已验证**：由离散耗散泛函导出、对称半正定、零空间只有刚体运动、周期通道与 1-D 解精确一致、能量单调（YIELD §4.5；conv part3 B-5/B-6 修复）。保留算子，改用法：τ_y 取物理值（1–20 Pa）、作用于奶泡相自身的压力、每子步施加。
- **S-B6 白度应由奶泡层而非混合比决定**（physics_prior §1.5）——保留"饱和在 ≈1 mm"的光学事实，把它折算成规范允许的有界覆盖度 c，而不是 W 直接进损失。
- **S-B7 工程**：咖啡层算子只分解一次、JS 对拍 3e-8、守恒 −4e-15、v2 2 s 模型时间 16 s。

**一句话**：A 把"推"做成了落点内的局部牵引、把"白"做成了当帧覆盖的示踪，所以能出局部前沿和切线却永远出不了先推后白的宽缝；B 把"白"做成了延迟浮出、把"推"做成了无局部前沿的势流且在落点方向反了，再用一个过强的均匀膜压力把一切压平，所以连 A 能出的前沿和切线也丢了。两者共同缺的是：一个有屈服应力、自选厚度、浮在不可压液体画布上并与之相对滑动的奶泡筏相；一个近场向外、远场向内、有记忆的画布表面速度场；一个由毛细内聚决定、延迟随高度变化的沉积/穿透开关；一个在 ≈1 mm 饱和并折算成有界覆盖度的白度；以及一个用过程帧里可直接量到的运动量（延迟、边缘速度、推开位移、缝宽、条纹间距）来标定的目标函数。

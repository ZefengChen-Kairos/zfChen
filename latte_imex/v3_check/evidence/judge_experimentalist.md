# 实验者评审：用手机、厨房秤和六段参考视频去标定、去证伪五个提案

评审视角：实验者。我能用的工具只有手机（30–240 fps、可加 10 元夹式微距镜）、厨房秤（0.1–1 g，另可借 0.001 g 首饰秤）、透明玻璃杯、胡椒粉/可可粉、量筒、斜板，再加六段参考视频。评审标准是：每个参数能不能在拉花视频之外独立测到、用什么手段、精度多少；每个提案对视频里能直接量的量（首白延迟、褐核/白环半径、边缘速度/面积速率、推开位移随距离的关系、褐缝宽、条纹间距、切线宽）给出什么预测，和实测对不对得上；哪一条预测会推翻它。只能靠拟合末帧才能定下来的参数要扣分。

读过的材料：design_brief、diagnosis（含 §0 硬指标）、physics_prior、video_obs、notion_senior §7、code_map §1/§3、orchestrator_hypotheses、verdicts.json（31 条裁定），以及 PA–PE 全文。我自己写的测量脚本放在 `scratchpad/judge_exp/`（`seg2.py`、`shape.py`、`tot3.py`、`mont.py`），帧图是 `ph_push2.png`、`seg_check2.png`、`seg_check3.png`、`ph_start2.png`、`ph_start3.png`、`heart_start.png`。

**胜者：PE。** 它的推导最不"从根上"：收集器是一条没有推导出来的规则，可动画布 A4 是一个强假设。但它是五个提案里唯一一个满足三条的：参数几乎全能在厨房里测到；每个核心机制都有一个一天之内能做完的判别实验（B7、B9、B10）；我对推推乐视频做的定量复核（§1）支持它预先登记的预测 P5（"射流没碰到旧块时，旧块只平移不变形，月牙只在接触后出现"）。其余四个提案都把 diagnosis §0 的 V7（"白出现之前约 1 s 内，0.15–0.2 D 外的旧块已被推开 0.05–0.15 D"）当成硬事实来设计机制。按我的测量，这条事实在推推乐第 2、3 段不成立，或者至少被高估了 3 倍以上。综合方案应当以 PE 的运动学骨架和测量协议为底，嫁接 PD、PA、PB、PC 的若干部件（§6）。

## 1. 先复核一条被所有人当作输入的"事实"：V7 先推后白

五个提案都把 V7 当作必须复现的硬指标："新一笔开始后、白出现之前约 1 s 内，旧白块被推离 0.05–0.15 D 并变成月牙，褐缝在此时生成"。这条来自 video_obs §2/§7 的目测，而视频是手持拍摄，杯子在画面里会移动、会倾斜。按学长的诊断顺序（先查输入和几何），在比较机制之前我先把它重新量了一遍。

**方法**：逐帧（15 fps）把咖啡液面分割出来：褐色连通区经填洞，教学叠加线先修补掉。再用液面区域的二阶矩把液面椭圆仿射映射成单位圆（半径 1 = D/2），这一步消掉相机缩放、平移和杯子倾斜的一阶效应。在这个坐标里量白色连通块的面积分数（白块面积 / 液面面积，仿射不变）、质心、沿 B→D 轴的两端位置，以及与参考帧的形状 IoU（扣除最佳平移后）。系统误差：位置约 ±0.03 D，主要来自奶柱遮挡液面右上角、带偏液面质心；面积约 ±10%；同一静止块相邻帧之间的 IoU 噪声底约 0.86–0.89。

**推推乐第 2 段**（帧图：`ph_start2.png`、`seg_check2.png`）。奶柱约在 t = 5.70 s 触到 B 点杯沿附近的液面，随后一边倒一边向旧块移动，t ≈ 7.07 s 到达旧块 B 侧的凹口，新白在 7.13–7.20 s 出现。

| t (s) | 旧块面积分数 | 与 5.4 s 形状的 IoU（平移后） | 备注 |
|---|---|---|---|
| 5.40 | 0.189 | — | 第 1 段停倒后 |
| 5.80 | 0.174 | 0.89 | 第 2 段已开始倒 |
| 7.00 | 0.187 | **0.91** | 白出现前；奶柱已到凹口边 |
| 7.13 | 0.159 | 0.78 | 接触、白出现 |
| 7.27 | 0.154 | 0.73 | 开始被撑开成 C |
| 7.6–8.2 | 0.124–0.130 | — | 月牙形成，新白在其内 |
| 9.0–10.0 | 0.091–0.096 | — | 定型月牙 |

5.4 s 到 7.0 s 之间，旧块质心移动 0.06 个单位圆半径，约 0.03 D，方向**朝向**射流。它的 B 侧端和 D 侧端也都朝射流移了约 0.03 D，这正是奶柱遮挡液面右上角造成的系统偏移。所以白出现之前，**背离射流方向的位移 ≤ 0.03 D，形状不变（IoU 0.91 处在噪声底），面积不变（±3%）**。这 1.4 s 里，射流离旧块从 0.3 D 一路缩到几乎为零。

**推推乐第 3 段**（`seg_check3.png`、`ph_start3.png`）。奶柱从 ≤ 9.53 s 起停在 B 点倒，新白在 11.1–11.3 s 作为孤立小团出现。9.8 s 和 11.2 s 两帧比较：外月牙面积 0.094 → 0.100，内心 0.103 → 0.104，质心变化 ≤ 0.02 单位（≤ 0.01 D）。**白出现前的 1.3–1.6 s 里，0.15–0.25 D 外的旧元素完全没有动。**

郁金香第 2 段（`tu_push.png`）条纹太多，我没能可靠分割，只做了目测：6.2 s 到 8.3 s（B 点倒、尚未出白）之间看不出底纹被压。可见的压开发生在 8.6 s 之后，那时壶已经推进、射流贴到底纹的凹侧、新白也已经出现。

**月牙形成时机与面积**：月牙在射流碰到旧块之后 0.3–0.8 s 内形成，与新白出现同时。月牙的顶视面积分数是原块的 0.52。按扩口杯液面上升使液面面积增加 10–20%（第 2 段倒入约 40–80 mL）做修正，再计入月牙细尖被欠分割约 10%，**旧块顶视面积降到原来的 0.6–0.75**。

**这对评审的含义**：
1. "远程先推后白"（白出现前 0.15–0.3 D 外的块被推 0.05–0.15 D）在推推乐第 2、3 段被否定到 ≤ 0.03 D。按这条错误输入调出来的机制（PA 的透镜头压、PC 的全杯均匀膜压缩、PD 在 r_N ≈ 0.25–0.3 D 内的拖曳、PB 的 L2′ 全局压缩中心值）都**高估**了远场推挤。PE 的 1/r 置换流在 1.3 s 内给 0.2–0.3 D 处 0.03–0.06 D，最接近实测，处在边缘。
2. 月牙与褐缝都在**接触之后**形成：射流（或它的近场、或新长出的筏）碰到旧块，旧块才被撑开。这与 PE 的预言 P5 完全一致；PA 的"新筏以 h_stop 顶旧块 → Bn = 1 屈服"和 PD 的"新筏经卡死条压旧块"也一致；PB 的"白前由薄层冲击屈服"和 PC 的"白前推压成弧"与之矛盾。
3. 旧块面积损失 25–40% 是一条新的定量约束：必须以增厚（侧拍可判）或在射流足迹下被压入（再在附近浮出）的形式记账。PA 的"面积守恒塑性流"与之冲突。PB 自己写下的证伪线"月牙面积损失 > 30% 且不增厚"已被触及；它还说处于 h_y 的筏不能增厚，所以只剩足迹压入 k_J 一条出路。
4. 推推乐第 2 段的新白恰好在射流到达旧块凹口时出现。这既符合约 1.4 s 的成核延迟，也符合 PE 的"收集器"假说和 PD 的 J3（低位压入的旧奶泡成团就地回浮），这里分不开。§5 实验 E4 用"在已有白边上倒**无泡液奶**"可以把三者分开。
5. 大白心起笔（`heart_start.png`）：0–1.2 s 壶嘴离液面约 1–2 cm，杯向壶倾斜；1.2 s 前后壶嘴再压低约 0.5–1 cm；1.47 s 首白出现，它**紧贴奶柱脚的下游侧**，呈 C 形，褐核直径约 0.05–0.08 D。这否定了 PB 的入口假说 D2（"起笔嘴高 > 3–4 cm"），也说明白环半径约等于奶柱半径加几毫米，即 r_e ≈ (0.5–1.5)d（PB、PD、PE 的取法），而不是 r_lift ≈ 0.6–1.4 cm（PA、PC 的取法）。

**局限**：手持相机、透视，只量了推推乐两段，郁金香只做了目测。这些不足以对 V7 下终审结论，但足以说明 V7 不能再当无争议的输入。综合方案的第一件事，应当是三脚架俯拍 + 杯放在秤上重做这几段动作（§5 E1）。

## 2. 厨房能测什么、能测多准（所有提案共用）

| 量 | 手段 | 精度 | 备注 |
|---|---|---|---|
| Q(t)（入口流量） | **杯放在厨房秤上，手机同时拍秤显示和液面** | 1 s 窗口内 ±10–20%（秤刷新 2–5 Hz；射流动量约 0.8 gf 的偏置可扣除） | 直接消掉学长 §4 的"Q 单目不可测、16× 歧义"；对所有提案都是第一优先 |
| 落差、柱径 d | 侧拍 + 尺 | 落差 ±1 mm；d ±15% | |
| φ_mix、φ_f、ρ_f | 量杯定体积称重（立刻称，防排液） | ±0.02–0.03 | 起笔第 1 s 单独接一杯：直接检验"壶内分层"假说（PB 的 D1） |
| R_32 / d_b | 夹式微距镜拍黑玻片上的薄层泡沫，数 ≥ 200 个泡 | ±20% | 没有微距镜就只能 ±×2 |
| τ_y | 斜板起滑角（±50%，有壁滑移）；坍落筒；**侧拍漂浮筏的自选厚度 h_y**（±10%）再反推 | 独立手段 ±50%；h_y 反推 ±15% | h_y 与盘半径无关（膜区）还是 ∝ √R（润滑区），本身就是一个判别实验 |
| μ | 钢珠落球 + 量筒计时 | ±15% | |
| σ | 细管毛细上升 / 悬滴照片 | ±10% | |
| v_b(φ)、Kynch 层 | 量筒延时摄影，看上清界面与泡层 | ±15% | |
| z_e / h_n（成白厚度） | 垫片控制厚度的泡层放在黑底和咖啡上，拍照加灰卡 | ±30% | |
| 表面速度场 u_s(r) | 胡椒/可可粉示踪，俯拍 60–240 fps | 方向确定；幅度 ±20% | 最有判别力的单个实验（§5 E2） |
| 射流穿透 z_m、回流时间 t_r | 透明杯侧拍 + 染色 | z_m ±0.5 cm，t_r ±0.05 s | |
| 画布 Π–面积曲线、E、Π_c | 自制 Wilhelmy：载玻片（周长约 5 cm）+ 0.001 g 首饰秤 + 烤盘内滑动挡板 | 分辨 ±0.2 mN/m；E ±50%（60 °C 下液面老化、蒸发，重复性差） | 0.3–1 mN/m 的量正好落在噪声底 |
| τ_a（ms–s 级动态吸附）、E″、表面剪切粘度 η_s | 最大气泡压力法、振荡悬滴、界面流变仪 | **实验室才有** | 厨房做不到 |
| 筏厚、月牙是否增厚 | 透明杯侧拍 + 尺 | ±0.3 mm | |

结论：凡是依赖画布吸附膜动力学（τ_a、τ_d、E″、η_s）或射流内问题深度剖面（J = 2πrρ∫u²dz）的参数，厨房都量不准，最多 ±×2。这是对 PB、PC、PD 扣分最重的地方。

## 3. 逐个提案

### PA：牛顿画布上的粘塑性筏 + 透镜层 + 表面膜 + 析出延迟

**参数可测性**：ρ_l、μ_l、φ_f、φ_m、σ、z_e、杯几何可在厨房测到；τ_y ±50%，可以用侧拍 h_stop 自洽核对；d_b 要微距镜。E、Π_0、ΔΠ_c 写的是"Langmuir 槽"，厨房只能做 ±50% 的 DIY 版本。α_e 用文献值，而 Re ≈ 10³ 处在过渡区，至少 ×2 的不确定。f_leak（每周转泄漏比 0.1–0.5）写成"染色台架俯视"，实际很难量，差不多是一个效率旋钮，直接控制 ε_dep（0.2–0.56）。能用视频精修的三个量（d_b、α_e/f_leak、ΔΠ_c）都对应过程帧量，不对应末帧，这一点做得对。

**我核算过的数**：h_stop = 4τ_y/(ρ_f g′) = 4 × 1.5/(352 × 6.38) = 2.7 mm ✓；Bn_push = 2τ_y/(ρ_f g G) = 1.6 ✓；r_lift（低位）≈ 1.0 cm ✓；v_b0 = 3.65 mm/s ✓。

**对视频量**：
- 首白延迟：τ_w = τ_ret + φ_f h_w/(φ_l v_b) 给 1.0–2.3 s（d_b 150 → 80 µm）✓，**∝ d_b⁻²**，是一个尖锐预测。
- 褐核：2r_ret = 0.15–0.33 D，对视频 0.05–0.12 D。PA 自己写"偏大 1.5–2×"，按中点算其实是 **×2.5–3**。§1 第 5 点的帧图显示白环紧贴奶柱脚，这是这个机制的系统偏差，不是常数没取好。
- 白区增长 4.5–9 cm²/s，视频 3.5–5，偏大 ×1.2–2.5（Q 未测）；边缘速度 0.09–0.18 D/s ✓。
- 推开：透镜作用到 r_st ≈ 0.3–0.37 D，1 s 推 0.1–0.2 D。实测远场 ≤ 0.03 D，**高估 3–6 倍**。
- 月牙：PA 写"透镜头压只平动，新筏以 h_stop 顶到旧块时接触力等于屈服膜力，在接触弧上屈服"。这与 §1 的时机一致 ✓；但它写"面积守恒的塑性流"，与面积损失 25–40% 冲突 ✗。
- 缝 0.04–0.12 D ✓；褐线 b_w = u_push/(2f) = 0.011–0.023 D ✓；间距 0.036 D ✓。
- 切：凹口 0.045 D ✓，侧鼓 0.034 D ✓，线 0.01–0.015 D ✓，茎 0.29 D 对 0.1–0.2 D，偏长 ×1.5–2。

**会推翻它的预测**：(i) 换粗泡（d_b 150 → 250 µm）后首白延迟不缩短（PA 预测降到 < 0.6 s）；(ii) 胡椒示踪显示 0.2–0.35 D 处倒奶时位移 < 0.03 D（§1 已初步给出）；(iii) 褐核直径与流量无关。

**评分**：严谨 6.5（三层新场推导清楚；透镜动量用 Bernoulli 转向，ε_cell ∈ {0,1} 是尖锐开关，f_leak 近似旋钮）；解释 6；可测 6；兼容 7（c = χ + (1−χ)b/b_min，接口映射清楚）；数值 7（约现有代价 ×3，NumPy 每图 12 min）。

**致命缺陷**：由"底流抬离 → 羽流 → 透镜"给出的近场尺度系统性偏大。白环半径和褐核大了约 3 倍，透镜把推力送到 0.3 D 之外，与实测的"远场不动、只在接触后变形"相反。

**可嫁接**：(1) τ_w ∝ d_b⁻² 这条最干净的首白证伪实验（同一杯咖啡、两壶不同粗细的奶）；(2) 筏方程里的 −ρ_f g h∇G 项，它是"水下未显白体积施压"的正确形式，系数不是旋钮；(3) "新筏以 h_stop 顶旧筏 → 接触力 = 屈服膜力 → Bn = 1 → 月牙"的接触屈服机制。

### PB：双薄层浅水 + 吉布斯膜画布 + 三相线 + 射流内问题

**参数可测性**：最差的一档。画布那一组 Π_0、E′、E″、τ_a、τ_d、Π_c、η_s 共 7 个量是实验室量（最大气泡压力法、振荡悬滴、界面流变），而推挤、缝宽、缝宽演化、切线、合并判据全都挂在它们上面。射流内问题的输出 J_mom、J_buoy、E_j、r_h/d、r_e/d、r_c/d、r_t/d 要在水槽里测；其中 J 需要表面流的深度剖面，用手机至少 ±×2。S_0、σ_r 只能定性测。好的一面是 PB 明确写了"视频只用于检验"，并给出 15 条预登记的证伪实验（P1–P15）和执行顺序。但 §4.1-5 用大白心首白后 0.83 s 的半径反求 Q_f/h_y = 5.4 cm²/s，再"预测"后续半径，这一步实际上是用视频标定。

**我核算过的数**：L3 取 J = 1.6 mN、f = 0.75、E = 40、Δ_M = 5 mN/m，解得 r_s ≈ 1.6 cm ≈ 0.2 D ✓。L2′ 取 ε̃ = (r_s/R)² ≈ 0.16，r = 0.15 D 处 Δr ≈ 0.12 D，0.25 D 处约 0.06 D。

**对视频量**：
- 首白延迟：**内禀只有 0.3–0.7 s ✗**，差额全部外包给入口时程 D1（φ_mix(t) 上升）或 D2（起笔嘴高 > 3–4 cm）。D2 被帧图否定（§1 第 5 点：起笔嘴高约 1–2 cm）。D1 可以测，但尚未证实。
- 褐核 2r_h = (0.8–1.8)d = 0.05–0.12 D ✓（r_h/d 是台架量，几乎就是把视频数直接代进去）。
- 白区增长 ✓（但如上，是标定出来的）。
- 推开：中心参数下 0.25 D 处 0.06 D，相对实测 ≤ 0.03 D 偏大；只有 ε̃ 的下端吻合。
- 月牙：PB 的机制是"白出现前，薄层冲击力 F′_s > 余量 s_c，被冲击的湿泡筏屈服"。但第 2 段在 6.8–7.07 s 射流已贴到凹口边，旧块仍不变形，直到白出现 ✗。面积"无汇、h_y 不能增厚"对上实测损失 25–40%，**触及 PB 自己的证伪线**，除非把足迹压入 k_J 算进去。
- 缝 0.04–0.13 D ✓（依赖 τ_d）；褐线 0.007–0.025 D ✓；成形间距 0.05–0.1 D，略大。
- 切：Marangoni 收拢槽给 0.005–0.025 D ✓，茎 0.06–0.21 D ✓。
- 杯倾：晃动模给液面中心漂移 ξ_c = 0.12–0.20 D（P11），这是零参数、可测的漂亮预测。

**会推翻它的预测**：P6（预倒掉 20 mL 后首白延迟缩到 < 0.5 s，即 D1）不成立而延迟仍 ≥ 1 s；P12（往画布加 0.05% 吐温后切线宽不变）；P5（已触及）。

**评分**：严谨 8（筏缘线力平衡、零余量引理、画布等压引理、Kármán–Pohlhausen 表面层、晃动解，五个里最严；储库是集总闭合，PB 自己也承认）；解释 5；可测 4；兼容 7；数值 6（隐式画布有刚性，加 ALG2 和 HLLC，编译后 1–3 倍实时，NumPy 慢 10–30 倍）。

**致命缺陷**：五个提案里只有它解释不了最稳的视频事实 V1（9/9 段 0.9–2.1 s 延迟），把它外包给尚未证实的入口时程，其中 D2 已被帧图否定。同时，推挤、缝和切全挂在七个厨房测不到的画布吸附膜参数上。

**可嫁接**：(1) 筏缘线力平衡与"零余量"引理（h_y = 4τ_y/(ρ_f g′) − S_0/(k_y τ_y)，且须 S_0 < s_c，用滴管放泡就能检验）；(2) 由实测 θ(t) 给出的准静态晃动位移场，零参数，P11 用胡椒就能测；(3) 预登记的证伪表和执行顺序，尤其是吐温实验 P12 和面积守恒检验 P5。

### PC：拉格朗日筏（MPM）+ 欧拉画布膜 + z 分层近表层 + 粗三维池

**参数可测性**：E_s、Π_c 是实验室量或 ±50% 的 DIY 量；τ_y(φ)、G(φ)、a_τ、a_G、E_b、K、n_HB 要叶片流变仪；C_k 取文献值；κ_λ 靠计算；α_e(Re) 用染色台架。能用视频精调的是 E_s 和 α_e，各对一个过程量，这一点合理。f_M 写成导出量（约 Z_b/z_m），其实是粗估。

**对视频量**：
- 首白：Kynch 激波 t_w = h_n(φ_J − φ_L)/(φ_L v_b)，加 t_ret，得 0.6–2.1 s ✓，**∝ μ/d_b**（不是 d_b⁻²）。这与 PA、PD、PE 的 ∝ d_b⁻² 不同，可以用同一个两种泡径的实验区分。
- 褐核：PC 写"半径 r_ret ≈ 0.08–0.17 D，视频 0.05–0.12 D，偏大 1.5 倍"。这里拿半径和视频的**直径**比了，实际直径偏大 **×2–3** ✗，与 PA 同源。
- 白区增长 3.5–13 cm²/s ✓（区间很宽）。
- 推开：膜在全杯均匀压缩，位移 Δ = ε·L_f，即到对侧杯壁的膜长乘应变。0.2–0.3 D 外的块应位移 0.05–0.17 D，**实测 ≤ 0.03 D ✗**；PC 自己预告这是硬检验（P2：线性剖面对指数衰减）。
- 月牙：PC 让它发生在推挤过程中、白出现之前（Bn_p < 1），与 §1 的时机矛盾 ✗；预测增厚 1.7–2 倍，与面积损失相容 ✓。
- 停倒后白盘再长 0.5–1.5 s、面积增 1–3 cm²（P3）：我在推推乐第 1 段停倒后（5.0 → 5.4 s）量到面积分数 +15–20%（约 1.3 cm²），但同时杯子在回正，透视在变，**不确定**。
- 缝 0.03–0.06 D：s_0 = 0.1–0.15 D 时偏窄，推心的 0.13 D 需要很大的 s_0。
- 条纹间距 0.02–0.035 D ✓，褐线 0.01–0.03 D ✓；切线 ∝ 1/V_j，0.006–0.025 D ✓。

**会推翻它的预测**：P5（往千层心旁滴一滴洗洁精，细褐线 1–3 s 内合并而白条不变形；若线不合并，"线靠膜压存活"就错了），这是五份提案里唯一能把"膜压"和"屈服"分开的实验；P2（实测远场位移不是线性剖面，且与 E_s 无关）；P1（泡越细延迟越长，且 ∝ 1/d_b）。

**评分**：严谨 7.5（漂移通量、EVP、Kynch、Rankine 半体面汇都严格；P_push = ρU_p²Z_m 和 U_p 是启发式估计）；解释 5.5；可测 5；兼容 4.5（ℓ ≡ 1、milk ≡ c 可行，但引入粗三维池和 z 分层，正是学长说"证据不足以投入"的完整三维）；数值 3.5（多速度场 MPM 加 256²×10 液柱再加三维池，只能在 GPU 上接近实时，NumPy 每图数小时）。

**致命缺陷**："全杯膜压近似均匀 → 位移 ∝ 到壁距离"给出的远场推挤是五个里最大的，被 §1 的 ≤ 0.03 D 直接否定；而为了支撑这个机制，它付出了最重的计算代价（MPM + 三维池）。

**可嫁接**：(1) 滴洗洁精实验（P5）：区分细线靠膜压还是靠屈服存活，所有综合方案都必须先做；(2) Kynch 激波加光学阈值 h_n = z_e 的成核定义（t_w ∝ 1/d_b 对 ∝ 1/d_b² 可判）；(3) 移动面汇的捕获宽 2b_cap = Q_A/V_j，即"切得越慢线越宽"（P6），对已有视频就能检验。

### PD：三区匹配渐近（射流内区 + 近场浮力胞 + 漂浮筏/单层泡画布）

**参数可测性**：材料量（φ_j、R_32、n_RZ、φ_c、τ_y、z_e、σ、μ）可在厨房测到。但两个承重的画布量 **a₀ = 0.3–0.5 和 Π_col = 0.3–1 mN/m，PD 自己承认是"由视频反推出的一致窗口"**，而且 Π_col 正落在 DIY Wilhelmy 的噪声底（1 mN/m 对 4 cm 周长只有 4 mg）。a₀ 和 a_J 可以用"塑料条平推画布"加俯拍测（±20%），这是个好实验。最重的负担是内区标准解：P_s、S、p_t(s)、r_up、r_c、r_N、g_N、Ψ 和偏心项共约 9 个函数，要靠台架加约 50 个工况的轴对称两相 DNS 制表，每个只有 ±30–50%。名义上没有一个从视频拟合，实际上近场的全部形状都待测。

**对视频量**：
- 首白：t_r + t₁ + Kynch = 0.9–1.6 s（R_32 = 50 µm）✓，**∝ R_32⁻²**。另有两条独到的预测：延迟随液面上升变短（推推乐第 1 段 2.1 s → 第 2、3 段 1.2–1.5 s ✓；郁金香 0.9/1.3/1.0 s 不构成反例）；出白临界落差 ∝ H^{4/3}（P2）。
- 褐核 2r_c…2r_up = 0.07–0.2 D，部分吻合。
- 白区增长 2.6 cm²/s（1–8）✓。
- 推开：r_N（0.25–0.3 D）内由拖曳推 0.06–0.15 D。按 §1，0.05–0.3 D 处实测 ≤ 0.03 D ✗；r_N 外 Ma_col > 1 不动 ✓。
- 月牙：新筏经卡死条把旧块往外压，发生在白出现之后 ✓。增厚约 1.7 倍，与面积损失相容 ✓。J3（低位倒到已有白上时，压入的湿奶泡成团就地回浮）还能顺带解释"接触即出白"。
- 缝 R_cz a₀/(2a_J) = 0.036–0.09 D（上界 0.12）✓。
- 条纹间距 0.036–0.055 D，偏大 ×1.3；褐线 0.008–0.015 D ✓。
- 切线 2r_c(1 − F_heal) = 0.01–0.04 D，F_heal 未知；颈 0.03–0.05 D ✓。

**会推翻它的预测**：E3（Π_col 实测 ≫ 3 mN/m，或塑料条推出的压实是均匀的而非推土机前沿）；P3（撇去 crema 使 a₀ → 0 后缝仍在）；P2（半杯和满杯的出白临界落差相同）。

**评分**：严谨 7（凸变分准静态问题、Hazen 浮选效率、Rankine–Hugoniot 推土机前沿都推得干净；但"匹配"本质上是查表，Π_col 窗口是反推）；解释 6.5；可测 4.5；兼容 6.5（要求把接口 ℓ > 0 放宽为 ℓ ≥ 0；U_N 作用到 r_N ≈ 0.3 D，超出射流足迹，是否算"入口只作用于足迹"需要学长认可）；数值 6.5（活动窗口下 NumPy 每图 5–10 min，GPU 接近实时，另加离线 DNS）。

**致命缺陷**：决定"推不推、冻不冻、缝多宽"的两个画布量 a₀ 和 Π_col 是按视频反推的窗口，其中 Π_col 低于厨房可测精度；近场的全部几何又依赖约 9 个尚未测得的内区函数。所以这个模型在独立测量到位之前不可证伪。

**可嫁接**：(1) 出白阈值随液深变化（z_m/H，v_c ∝ H^{4/3}Q^{−1/3}φ_j^{2/3}）以及"后段延迟更短"，用半杯对满杯就能判；(2) 画布单层泡的拥塞/推土机前沿 w = s₀a₀/a_J，配塑料条平推实验；(3) 凸变分准静态求解（屈服塞区和卡死区精确刚性，停倒后 u ≡ 0 精确成立，不用 β），以及 J3"压入—成团就地回浮"。

### PE：置换铺面 + 粘塑性浮筏 + 入口分相（DRE）

**参数可测性**：最好。参数表本身就是按"手机 + 秤 + 斜板级别"写的：ρ_c 称重，μ 落球，σ 毛细上升，φ_m 称重（起笔第 1 s 单独接），R_32 微距，φ_f 舀筏称重，τ_y 斜板或侧拍 h_s，杯形逐次加水，杯倾转轴从视频读。三个不确定度最大的量都给了厨房实验：Π_c 用 B10（从 1/2/3/5/7 cm 倒到预置筏上，找开始打洞的高度 z*），η_c 用 B9（筏旁倒奶，侧拍厚度乘面积），r_c 用 B8（胡椒）。扣分点有三：Π_c 的 195–420 Pa 括号是从视频读出来的；收集器保留率 η_c 是一条规则的效率，不是推导出来的；A4 的判定完全押在 B7 一个实验上。

**我核算过的数**：u_s = Q/(2πrH)，Q = 15 mL/s、r = 1.2 cm、H = 4.5 cm 时为 4.4 mm/s，1.3 s 内 5.8 mm ≈ 0.072 D，加镜像项后与 PE 表里的 0.077 D 一致 ✓。大白心面积 4.5 → 12.6 → 21.2 cm²（2.3/4.6/6.7 s）✓，dA/dt = 3.5–4.1 cm²/s。

**对视频量**：
- 白区增长：**dA/dt = Q/δ_o，零参数**，Q = 15–20 mL/s 时 3.3–4.4 cm²/s ✓；面积线性、半径按 √t，边缘速度从 0.1 降到 0.035 D/s ✓。附带好处：把 Q 杯放秤上一测，这条律就能被直接证伪；反过来用 Q = H·dA/dt 也可以从视频读出流量。
- 首白延迟 1.2–1.9 s ✓（∝ R_32⁻²），并且只在"落在褐面起笔"时出现；推推乐第 2 段新白恰在射流到达旧块时出现，与收集器一致（不排他，见 §1 第 4 点）。
- 褐核直径 0.08–0.2 D，部分吻合；C 形开口朝壶 ✓。
- 推开：0.2–0.3 D 处 0.03–0.06 D，最接近实测 ≤ 0.03 D，处在边缘。
- 月牙"只来自接触"（P5）：**被 §1 支持** ✓✓；面积损失由接触压缩解释 ✓。
- 缝 ≈ Q t_w/δ_o 除以弧长，典型 0.09 D，范围很宽 ✓。
- 条纹：PE 写的间距律 (u_s + V_r)/(2f) 在不后退时只给 0.012–0.02 D，**偏小 ×2** ✗；后退时 0.041–0.049 D ✓。改用"每半周新面积 Q/(2fδ_o) 除以弧长 L"来估，得到约 0.025 D，在区间内，说明它的骨架能给对，只是 PE 文中的公式选错了。
- 切线 w = Q_c/(δ_o V_p) = 0.012–0.035 D，偏宽一端 ✓；"快切更细"可用已有视频检验。
- 杯倾 P10：回正期间图案相对杯沿刚体平移 0.09–0.17 D，可以和 PB 的 P11 直接对决。

**会推翻它的预测**：B7（胡椒示踪显示表面是停滞帽，或倒奶时表面向内流，A4 即错）；B9(b)（在落点下游预置一块筏后首白延迟不消失，收集器即错）；P1（白区面积不随时间线性增长，或斜率不等于 Q/H，比如换干泡或湿泡后斜率明显变化）；B10（z* < 1 cm）。

**评分**：严谨 5.5（置换势流、Neumann 格林函数、水平阿基米德耦合都推得严；收集器 C_j 是没有推导的开关，违反 brief 第 2 条；A4 与其余四家的蛋白膜论证正面冲突，需要实验裁决）；解释 7.5；可测 8；兼容 8（c = α 有界、无厚度→alpha、入口只经足迹和体积源；但接口里 q ≡ 0 只是占位，应补上 q = ℓu_F）；数值 9（解析势流 + 几何 VOF + 连通筏刚体投影 + 局部 SSA，单核快于实时）。

**致命缺陷**：整个运动学骨架（面积律、推开场、缝面积）建立在 A4"画布表面随置换流走"上，而其余四家给出 Ma ≈ 10³ 的停滞帽论证。出白的关键一步是一条没有推导的收集器规则。只要 B7 测出停滞帽，PE 的面积律和推开场就同时失效。

**可嫁接**（作为骨架）：(1) 零参数置换势流 Q/δ_o，以及由 dA/dt 反演 Q；(2) "刚体筏 + 只在接触时变形"的连通分量刚体投影数值法；(3) 一套全部能在厨房做的标定与证伪实验（B7–B13）。

| E5 | 往已拉好的千层心旁加一滴洗洁精水 | 细褐线在 1–3 s 内是否合并，白条本身是否变形 | PC 预测线合并、白条不动；PA、PB、PD、PE 预测线靠屈服或拥塞存活、不合并 |
| E6 | 透明杯侧拍推推乐的月牙 | 月牙厚度与原块厚度之比 | PC、PD 预测 ×1.7–2；PB 预测筏处于 h_y、不能增厚，若面积损失 > 30% 即被证伪；PA 的面积守恒 |
| E7 | 塑料条匀速平推不拉花的画布；同时用自制 Wilhelmy（首饰秤）测 Π–面积曲线 | 推土机前沿（a₀/a_J）还是均匀压缩；E、Π_c 或 Π_col | PD（0.3–1 mN/m、锐前沿）对 PB、PC（E 20–60、ΔΠ_c 5–15 mN/m）对 PE（几乎无抵抗） |
| E8 | 半杯对满杯，同 Q，落差 1/2/3/5 cm，定点倒 2 s | 出白的临界落差 | PD 预测随 H 变（Δz_c 0.8 → 2.4 cm）；PB 预测在 We_R ≈ 1（3–4 cm）且与 H 无关；PE 预测 z* = 2–5 cm（Π_c）；PA 预测 r_lift = R_cup（约 4 cm） |
| E9 | 不倒奶，只把杯倾 20° 后在 1–2 s 内回正，胡椒俯拍 | 液面中心相对杯沿的漂移 | PB 预测朝 D 侧 0.12–0.20 D；PE 预测朝低侧刚体平移 0.09–0.17 D；PA、PC、PD 只改域形 |
| E10 | 侧拍不同半径（1、2、4 cm）的漂浮筏厚度 | h 是否与 R 无关 | 五家都预测膜区 h = 4τ_y/(ρ_f g′)、与 R 无关；physics_prior 的润滑式预测 ∝ √R |

建议顺序：E1 → E2 → E3 → E4 → E5，前五个一个周末能做完。E2 与 E1 合起来，一次就能决定"可动画布（PE）"与"停滞帽（PA–PD）"之争，这是五个提案最大的分歧，也是综合方案最需要先定下来的结构选择。

## 6. 给综合方案的建议（实验者立场）

1. **先修输入，再选机制**（学长的诊断顺序）。V7 的"白前远程推挤"要先用 E1 重测。综合方案应把"接触后撑开成月牙、旧块面积降到 0.6–0.75"列为回归目标，把"白前 0.15–0.3 D 外位移 ≤ 0.03 D"列为失败对照。
2. **骨架用 PE**：可动画布的置换势流，加刚体筏投影和几何 VOF。成本低于实时，参数全部能在厨房测到。同时**保留一个停滞帽开关的物理替代**，即 PB 的画布等压 L2 或 PD 的 Π_col 拥塞，由 E2、E7 二选一，而不是两者都写进去。
3. **首白延迟**：用 PD 的"喷泉回流 + Kynch 浮选"（带液深依赖）替换 PE 的收集器规则。对"倒在已有白上不延迟"，先用 E4 判定它是 PE 的拦截还是 PD 的 J3 回浮，再决定写哪一个。环半径取 r_e ≈ (0.5–1.5)d（PB、PD、PE），不要用 r_lift（PA、PC，大了约 3 倍）。
4. **月牙与缝**：用 PA 和 PD 的"新筏顶旧筏 → 接触弧上 Bn ≈ 1 屈服"，加上 PD 的足迹压入—就地回浮（J3），来给 25–40% 的面积损失记账；侧拍 E6 决定这部分是增厚还是压入。
5. **筏本构与筏缘**：用 PB 的线力平衡和零余量引理（含 S_0）、h_y = 4τ_y/(ρ_f g′)，配 E10 和滴管放泡（S_0 < s_c）。
6. **杯倾**：用 PB 的晃动位移场（零参数），并用 E9 对决 PE 的刚体平移。
7. **细线存活**：先做 E5。若线遇洗洁精合并，就引入 PC 的膜压项；否则只靠屈服或拥塞就够了。
8. **标定目标**：只用过程帧量（首白时间、dA/dt、白前与接触后的位移、缝宽随时间、条纹间距、切线宽随切速），全部在液面椭圆归一化坐标里量（`judge_exp/seg2.py`、`shape.py` 的做法）。不用末帧面积损失。

# Skeptic check of CLAIM A3 (旧闭合 "没有把 0.1–0.3 D 外的旧白块整体推开的力")

Verdict: **refuted**（机制陈述错；证据不支持"没有力"，只支持"推力被白色同步掩盖"）。

Repo HEAD 读到的是 `7c25e3a`（diagnosis.md 写的 258de63 之后又有 4 个 commit；`git diff --stat 258de63 HEAD -- solver.py` 为空，solver.py 行号未变）。未修改仓库文件；数值检查脚本 `review/skeptic_A3_push.py`，输出 `review/skeptic_A3_L1.txt`、`skeptic_A3_L1b.txt`、`skeptic_A3_L25.txt`。

## 1. 代码里对"足迹外的膜"起作用的项（逐行核对）

`solver.py`：

- L331–350（`inlet_fields`，closure="chi"）：`s = chi*S_eff*K`，`Lam = kappa_c*(1-chi)*S_eff*K`，`vsx/vsy = kappa_t*u_in + rad*dx/den`，`rad = kappa_r*V_R`（return_law="v05"，L343–346）。**s、Λ 都 ∝ K**（紧支撑椭圆核，L257–287，半轴下限 1.5h）；v* 虽然全场定义，但只通过 `kernels.stepB_prepare` L165–175 的 `f = dt*(s+Lam)`、`a = (q* + f*v*)/theta` 进入，所以 **v* 在 K 外无作用**。这点和 claim 一致。
- L363 `s_mom = s`；L433–438 步 A Rusanov 对流 ∇·(q⊗u)；步 B（L444–474）压力 `coef = cp² l/θ`、`q⁺ = a − dt coef ∇l⁺`，拖曳 −βq（θ 内）。所以 **K 外只有 −c_p²ℓ∇ℓ 和惯性** —— claim 的这句陈述是对的。
- 老闭合 s_ℓ = s_m = s（L457 `s_l = s`，L501 `s_m = s`）：堆高与变白同一瞬间 —— "压力（白堆高后才有）" 也对。
- κ_r：#9 `kappa_r = 0.008466`，低位入口（NX 壶链实测 U⊥ = 9.27 D/s、d = 0.0783 D，见 `closure_numbers.py`）：z_c = 0.639，χ = 0.668，V_R = min(9.27·0.668^{1/(2·1.556)}, 9.27, √(1718·0.0783)) = 8.14 D/s，**κ_r V_R = 0.069 D/s**；切向 κ_t|u_in| = 0.905×1.88 = 1.70 D/s。数字对。

所以 claim 里**每一条事实陈述都对**；错的是从这些事实推出"没有力把旧块整体推开"。它把"惯性"当作可忽略的残项，而惯性恰恰就是旧闭合的整块推力。

读法：
1. **旧闭合里存在把旧块整体推开的力，而且是定向的**：s_mom·v*（落下奶的冲击动量，峰 24 /s × 1.70 D/s）把足迹内及其前方的膜加速到 ≈ 1.6 D/s（umax 1.65），这股**褐色**膜（ℓ 只到 1.15，没有白、没有堆）靠惯性（Rusanov 对流 + 轻微 ℓ 压缩）像活塞一样顶进旧块。只开这一项（V1/V8），块的近缘退 0.16–0.24 D、远缘只动 0.01–0.03 D、x 跨度 +13–30 %、轴线厚度 0.10 D —— 正是 video_obs §7 的"近缘动得多、径向变薄、周向拉长成月牙"（视频 0.33 D 圆 → 0.10 D 厚 × 0.5 D 跨；位移 0.05–0.15 D）。模型的推力不是没有，而是**偏大**（这是 A4 的内容）。
2. **各向同性堆高压力确实不是整块推力**（V5/V6 ≈ 0.01 D）—— claim 对这一项的贬低是对的，但它不是唯一的非局部通道。
3. **κ_r 无论取多少都与推开无关**（V4：κ_r = 0.5 与 0.0085 完全一样），因为径向目标只通过 K 内的 s、Λ 权重起作用；"κ_r ≈ 0" 是真的但不是 A3 的证据。
4. **基线里看不到推开的原因是白色同步**（s_m = s）：推块的活塞本身就是白的，扫过的缝当帧被它填满，新白与旧块合为一体（V0 倒奶期间轴线无缝）。这是 A2/A10（沉积与推挤同核同时）的问题，不是"没有力"。
5. claim 引用的 PITCHER L270（"唯一出宽褐带的是 §14 补丁"）其实支持相反的读法：§14 补丁没有加任何新的推力到 K 外（它只把 m_sub 加进压力，L447–451；冲击动量 s_mom = s 保持"落下当帧生效"，L363），它只是**把白推迟**，推力就露出来了。PITCHER §14 第 1 轮的解释"推挤靠层量堆高的压力，白没浮上来压力就没有"是作者的推断，不是测量；本检查直接测到不堆高也推（V1 lmax 1.15）。可能的差别是第 1 轮带 D_sub 0.002 抹层、α = 0 的储量沿路径出条杠、以及用真实动作（射流边走边倒）评图，但这些都不能把 0.2 D 量级的活塞推力抹掉。

## 4. 修正后的陈述（建议并入 A2/A4）

旧闭合**有**推开旧块的定向力：落下奶的冲击动量 s_mom·v*（+ Λ(v*−u)）注入足迹膜后靠惯性向前传，0.3–1 s 内把 0.07 D 外的旧块近缘推 0.16–0.24 D、0.38 D 外的远缘推 0.01–0.03 D，块变成月牙，量级不小于视频（0.05–0.15 D）。各向同性堆高压力贡献 ≈ 0.01 D，κ_r 取任何值都不改变推开（径向目标只在 K 内有权重）。真正缺的是：(i) 推力载体与白色在时间/空间上的分离——s_m = s 让活塞本身是白的、当帧填满它扫出的缝（A2/A10）；(ii) 让扫出的褐缝在射流继续前进后仍是褐色的机制（A1：c 是被动示踪）；(iii) 推力随距离的衰减律和量级（A4：β = 2.4 /s 的滑行 0.7 D、近缘 0.24 D 偏大）。

# 双层 + 卷吸胞表层模型（two-layer closure with the entrainment cell）

代码：`latte_imex/solver.py`（`closure="twolayer"`），浏览器版 `web/latte2d.js`（与 Python 对拍，最大差 3×10⁻⁸）。
本文所有长度以杯径 D_L = 8 cm 为单位，时间以秒为单位；"层厚"以参考表层厚度为 1。

## 1. 物理图像

倒奶时杯面上有三样东西：

1. **表面膜**（film）：漂在最上面、我们看得到的一层，由褐色的 crema / 咖啡表面液和白色奶泡组成。状态量是膜厚 ℓ、膜动量 q = ℓu、膜里的奶泡量 m，可见白度 c = m/ℓ。
2. **水下奶泡**（submerged foam）：被射流带进咖啡里、还没浮上来的奶泡 f，以及它的"剩余上浮时间"矩 f·τ。
3. **咖啡层**（coffee）：膜下面的液体。它的流动不单独求解动量，而是由两个准稳态势流给出：
   - **体积铺展** U_v：倒进来的体积要把周围的咖啡推开（深度平均，表面和深层一样）；
   - **卷吸胞** U_c：下落的射流把周围咖啡拖下去，咖啡在半径 R_c 内又涌上来。这是一个竖直环流，深度平均为零，所以它表现为**表面流向射流**、**深层流离开射流**。

于是：表面速度 U_s = U_v + U_c 拖着膜走；深层速度 U_d = U_v − U_c 带着水下奶泡走。

## 2. 方程

### 2.1 落点（每帧由壶模型给出）
落点强度 S（体积通量）、冲击速度 U⊥、射流直径 d、水平速度 u_in、归一化足迹核 K（∫K = 1）。

| 量 | 表达式 | 含义 |
|---|---|---|
| 密度 Froude 数 | Fr² = U⊥² / (g′ d) | g′ 是奶泡的约化重力 |
| 奶泡存活率 | χ = 1 / (1 + (Fr²/Fr_c²)^p) | 冲得越猛，奶泡破得越多 |
| 水下奶泡源 | χ · φ_foam · S · K | 只有存活的奶泡会变白 |
| 上浮时间 | τ = 2U⊥ / g′ | 喷泉上升时间 |
| 卷吸通量 | S_E = ent · Fr · S | Ricou–Spalding 0.32 z/d × Turner 喷泉深度 2.32 Fr d → ent ≈ 0.74 |
| 卷吸胞半径 | R_c = cell_frac · 2.32 · Fr · d（上限 0.45） | 胞的尺度 ∝ 喷泉深度 |
| 射流牵引 | Λ = κ_c S K，指向 v_jet = κ_t u_in | 射流把它打到的膜往自己的水平方向拖（切线、心尖） |

### 2.2 咖啡层（每帧解两次泊松方程，Neumann 壁面；常系数矩阵只分解一次）
- ∇·U_v = S K − ⟨S K⟩
- ∇·U_c = D_s，D_s = S_E (K_c − K) − ⟨·⟩，K_c 是半径 R_c 圆盘上的均匀分布
- U_s = U_v + U_c（表面），U_d = U_v − U_c（深层）

D_s > 0 的地方咖啡上涌，D_s < 0（射流处）表面液被卷下去。

### 2.3 水下奶泡
∂f/∂t + ∇·(U_d f) = χ φ S K − f/τ_f，其中 τ_f 由随流输运的矩 f·τ 给出。
浮上来的速率 s_f = f/τ_f 就是膜里白色奶泡的来源。

### 2.4 表面膜
- 质量：∂ℓ/∂t + ∇·q = s_f + D_s⁺ − min(D_s⁻, 0.9 (ℓ − m)/Δt)
  - D_s⁺：上涌处**生成褐色表面**；
  - D_s⁻：卷下处**只移除褐色液体**（ℓ − m），奶泡有浮力留在表面堆积。
- 奶泡：∂m/∂t + ∇·(c q) = s_f（只有浮上来的奶泡算白）
- 动量：∂q/∂t + ∇·(q⊗u) = −c_p² ℓ∇ℓ − β(q − ℓU_s) + Λ(v* − u) + ∇·(νℓ∇u)，v* = (s_f U_s + Λ v_jet)/(s_f + Λ)

账本：膜体积 = 初始 + 浮上的奶泡 + 净生成褐色表面，守恒到机器精度（−4×10⁻¹⁵）。

### 2.5 数值
IMEX：Rusanov 显式动量对流 → 隐式质量 + 压力 + 拖曳（PCG）→ 奶泡量用同一面通量 van Leer 限制 → 粘性；水下奶泡一阶迎风；咖啡层势流用一次分解的稀疏 LU（JS 用带状 Cholesky）。

## 3. 参数

| 参数 | 含义 | 值 | 来源 |
|---|---|---|---|
| c_p | 膜内重力波速 | 0.97 D/s | #9 联合扫描 |
| ν | 膜粘性 | 1.4×10⁻³ D²/s | #9 |
| κ_t | 射流水平速度传给膜的比例 | 0.90 | #9 |
| p | 存活率陡度 | 1.56 | #9 |
| kQ | 流量到落点强度 | 1.33 | #9 |
| g′ | 奶泡约化重力 | 125 D/s²（≈10 m/s²） | 拟合 |
| Fr_c² | 奶泡存活临界 Froude² | 41 | 拟合（估计值 23） |
| φ_foam | 奶里奶泡的体积分数 | 0.91–0.94 | 拟合 |
| β | 膜被表面流拖曳的速率 | 2.7–3.3 /s | 拟合 |
| κ_c | 射流牵引 | 0.78–0.94 | 拟合 |
| ent | 卷吸系数 | 0.37–0.62 | 拟合（文献推导 0.74） |
| cell_frac | 胞半径 / 喷泉深度 | 0.10–0.12 | 拟合 → R_c ≈ 3–4 mm |

拟合：先固定动作做 7 维拉丁超立方（40 组），再对 7 个物理参数 + 6 个图案的 (h, q, s) 做 25 维联合 CMA-ES；目标 = loss + |褐缝占比 − 目标褐缝占比|，六个图案平均。

## 4. 这个模型理论上能出褐缝吗

**宽褐缝（4–9 mm）：能，而且宽度来自物理长度尺度。**

- 没有卷吸胞时，模型里白和褐之间只有被拉伸、被混合，没有任何把它们分开的机制，也没有介于网格和整杯之间的长度尺度。所以褐缝只能以 1–3 mm 的数值细线出现，网格加密也不会变宽（之前 256²/512² 的诊断）。
- 卷吸胞带来了一个物理长度 R_c ∝ Fr·d：射流周围 R_c 以内，表面被拉向射流、白色奶泡在射流处堆积，而胞内咖啡上涌生成新的褐色表面。射流来回摆动时，每一摆都在白色前后留下一条宽约 R_c 的褐带。拟合出的 R_c ≈ 3–4 mm，和目标图测得的平均缝宽 4–5.5 mm 同一个量级。
- 这个尺度随动作变化的方式和咖啡师经验一致：倒得高 → U⊥、Fr 大 → R_c 大、奶泡存活率低 → 射流周围清出一圈干净的褐色，出不了白；倒得低 → R_c 小、奶泡大量存活 → 出白。
- 现状：96² 上已经出现 3.3–4.8 mm 的褐缝，郁金香褐缝占比 0.27（目标 0.34）、天鹅 0.18（0.32）、树叶 0.11（0.19）；推推乐、千层心还偏少。

**极细的纹（≲1–2 mm，比如千层心的层纹、叶脉的细线）：原则上可以，但现在这个模型给不出它们的宽度。**

- 细纹来自界面被反复拉伸和折叠（运动学），任何保持界面的输运都能把褐色带拉细，模型里也会出现。
- 但模型没有设定细纹宽度的物理机制（真实世界里大概是泡沫气泡尺度、表面张力），所以细纹宽度由网格和数值扩散决定。学长的网格分析也显示：384/768/1536 下细暗纹的数量 0/3/21，不收敛。
- 所以细纹要么当作网格相关的现象看待（只在固定网格上比较），要么以后加入泡沫的有限厚度和表面张力，给它一个物理宽度。

**模型目前做不到的：** crema 厚度的不均匀、奶泡层之间的三维翻折（白压白时在折痕处露出褐色）、Marangoni 效应。

## 5. 可测量性（给后续采集）

- R_c 和卷吸强度可以直接从俯视视频测：在只有 crema 的咖啡上定高、定流量倒一股奶，射流周围清出的褐色圆圈半径就是 R_c，清圈的速度对应卷吸强度。改变高度和流量，就能拟合出 cell_frac 和 ent，不依赖拉花图案。
- g′ 来自奶泡密度（ρ_f/ρ），Fr_c² 可以从"多高开始不出白"测出。
- 剩下的 β、φ_foam 再从拉花视频拟合。动作用 Point2Pose / AprilTag + 电子秤实测后，动作就不再是自由度，参数补偿的空间最小。

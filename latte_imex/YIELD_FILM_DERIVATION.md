## 0. 为什么需要它

双层 + 卷吸胞模型里，表面膜被当作牛顿流体：膜里的压力 c_p² ℓ∇ℓ 会把浮上来的奶泡一直摊开，粘性 ν 很小（1.4×10⁻³ D_L²/s），白块会持续变形、边缘变软，推开后的褐缝也会被重新填平。

真实的微泡奶泡是**粘塑性流体**（和剃须泡沫、牙膏、蛋黄酱同一类）：应力低于屈服应力 τ_y 时不流动，整块平移或转动；应力超过 τ_y 才流动。这正是拉花图案拉完会"定住"、白块边缘锐利、褐缝能保留下来的原因。

## 1. 物理量级

湿泡沫屈服应力的经验式（Mason–Bibette–Weitz / Princen）：

  τ_y ≈ a · (σ / R) · (φ − φ_c)²，a ≈ 0.5，φ_c ≈ 0.64

- 奶的表面张力 σ ≈ 0.045 N/m，微泡半径 R ≈ 50 μm，气体体积分数 φ ≈ 0.7–0.8；
- 代入得 τ_y ≈ 0.5 × 900 Pa × (0.06–0.16)² ≈ 1.6–11 Pa；
- 奶泡浮到咖啡上以后被稀释、变湿，φ 下降，τ_y 会更低。

模型里用的是 **τ̂ = τ_y / ρ_f**（单位 D_L²/s²）。奶泡密度 ρ_f ≈ 300–500 kg/m³，D_L² = 6.4×10⁻³ m²：

  τ̂ ≈ (1.6–11) / 400 / 6.4×10⁻³ ≈ 0.6–4 D_L²/s²

这个范围不确定（湿度、气泡尺寸都会变），要拟合，搜索范围定为 0.01–3。可以用"倾斜平板上奶泡开始流动的坡度"测：sin θ_c = τ_y / (ρ_f g h_f)。

## 2. 连续方程：薄膜的面内应力

膜很薄，上表面无应力，下表面在咖啡上滑动（膜和咖啡之间的剪切已经单独作为拖曳 −β(q − ℓU_s) 处理）。这种"浮在液体上的薄片"的深度积分面内应力，在冰架理论里叫 **shallow-shelf approximation（SSA，MacAyeal 1989）**，在粘性薄片理论里叫 Trouton 型拉伸。把三维不可压条件 D_zz = −(D_xx + D_yy) 代入、对厚度积分，得到

  T / ρ = 2 ν_eff ( D + (tr D) I )，D = ½(∇u + ∇uᵀ)（二维）

各分量：
- T_xx/ρ = 2ν_eff (2u_x + v_y)
- T_yy/ρ = 2ν_eff (u_x + 2v_y)
- T_xy/ρ = ν_eff (u_y + v_x)

动量方程里的粘性项（和现在一样以膜厚 ℓ 加权）：

  ∂q/∂t + … = … + ∇·( ℓ T/ρ )

耗散率密度（后面证明能量稳定用）：

  ε̇ = ℓ T:∇u / ρ = 2ν_eff ℓ [ u_x² + v_y² + ½(u_y + v_x)² + (u_x + v_y)² ] ≥ 0

Bingham 有效粘性用三维应变率的第二不变量（含 D_zz）：

  |D|_e² = ½ D:D = u_x² + v_y² + u_x v_y + ¼(u_y + v_x)²
  ν_eff = ν + τ̂ / (2|D|_e + ε)，上限 ν_max

（三维 Bingham：τ = 2(η + τ_y/(2|D|))D，|D| = √(½ D:D)。）注意耗散率里的方括号 I = u_x² + v_y² + ½(u_y + v_x)² + (u_x + v_y)² 恰好等于 2|D|_e²，所以 ν_eff 可以直接由 I 算出：2|D|_e = √(2I)。

**屈服应力只属于奶泡。**膜是奶泡和褐色表面液（crema、翻上来的咖啡）的混合，可见白度 c 就是奶泡的比例。从上涌处翻上来的咖啡液没有屈服应力，crema 本身也是泡沫但弱得多。所以

  τ̂(c) = c · τ̂_foam + (1 − c) · τ̂_crema，先取 τ̂_crema = 0

这一点决定了对比度：白块被锁住、整块平移，褐缝里的液体照样流动，缝不会被白块挤进来，也不会被摊薄的白填回去。

### 2.1 和现在的粘性项的区别
现在代码里用的是逐分量的 Laplace 形式 ∇·(νℓ∇u)。ν 是常数且很小时，这样近似没问题；但 **ν_eff 随空间变化时，Laplace 形式不是客观的**：一块做刚体转动的奶泡（u = −Ωy, v = Ωx，应变率为零）在 ν_eff 有梯度的地方会受到假的力 ∇ν_eff·∇u ≠ 0。屈服应力的核心就是"刚体运动不受力"，所以必须用对称应变率的形式。

结论：τ_y > 0 时整个粘性项换成 SSA 形式；τ_y = 0 时 SSA 形式也是更正确的牛顿膜，但为了和已拟合结果可比，保留 Laplace 形式作为 τ_y = 0 的旧行为，并在测试里报告两者的差别（ν 很小，预计可忽略）。

## 3. 正则化

Bingham 本构在 |D| = 0 处不光滑。两种做法：
- **增广拉格朗日（ALG2）**：屈服面精确，但每步要迭代几十次，太贵；
- **正则化**：ν_eff = ν + τ̂/(2|D|_e + ε)。未屈服区不是严格刚体，而是以应变率 ≲ ε 缓慢蠕变。

选正则化。误差判据：
- 图案存在约 T ≈ 10 s，未屈服区累计应变约 ε·T，要求 ≪ 1 → **ε ≈ 0.01–0.03 /s**；
- 上限 ν_max 决定"塞流区"的实际粘度。刚性判据：在尺度 L 上粘性应力要压过拖曳，即 ν_max ≫ β L²。β ≈ 3 /s、L ≈ 0.1 D_L → βL² ≈ 0.03，所以 **ν_max ≈ 0.5–1 D_L²/s** 足够刚；
- 同时要求 τ̂/ε 和 ν_max 不要差太多，否则上限一直在起作用，正则化参数就失去意义。τ̂ = 0.5、ε = 0.02 时 τ̂/ε = 25 > ν_max，塞流区由 ν_max 决定，这是可以接受的：此时 ν_max 就是"塞流区粘度"，它的效果要在测试里扫描确认（结果对 ν_max 不敏感才算正确）。

## 4. 离散：用二次型构造，保证对称、正定、客观

速度在单元中心（共位网格）。不直接离散 ∇·(ℓT)，而是先离散耗散泛函 Φ(u)，再取 **力 = −∂Φ/∂u**。这样离散算子是 K = ½ Gᵀ (W⊗Q) G（4.2 节）：
- 对称、半正定是构造性的，PCG 可用；
- 能量不等式在离散层面严格成立（第 5 节）。

### 4.1 面上的应变分量
对每个开放的 x 面 f（左右单元 L、R）：
- 法向导数用紧凑差分：u_x = (u_R − u_L)/h，v_x = (v_R − v_L)/h；
- 切向导数用两侧单元中心差分的平均：u_y = ½(∂_y u|_L + ∂_y u|_R)，v_y 同理（单元中心差分在壁面处退化为单侧差分，和现有 cell_grad 一致）。

y 面对称地处理（u_y、v_y 紧凑，u_x、v_x 取平均）。

### 4.2 泛函
连续形式 Φ = ½ ∫ w I dA，w = 2ν_eff ℓ（对 u 变分得 −δΦ/δu = ∇·(ℓT/ρ)，已逐项验证：½w δI 中 δu_x 的系数是 νℓ[2u_x + 2(u_x + v_y)] = ℓ·2ν(2u_x + v_y) = ℓR_xx，δu_y 的系数是 νℓ(u_y + v_x) = ℓR_xy）。

离散：两套面各自覆盖一遍杯面，取平均：

  Φ = ¼ Σ_{x 面} h² w_f I_f + ¼ Σ_{y 面} h² w_f I_f
  I_f = u_x² + v_y² + ½(u_y + v_x)² + (u_x + v_y)²（用该面上的分量）
  w_f = 2 ν_eff,f ℓ_f，ℓ_f 取两侧平均
  ν_eff,f = ν + τ̂(c_f) / (√(2 I_f) + ε)，上限 ν_max，I_f 用滞后速度 u⁻ 计算

把每个面上的四个应变分量记成 s_f = (u_x, v_y, u_y, v_x) = (G z)_f，z = [u; v]，则 I_f = s_fᵀ Q s_f，

  Q = [[2, 1, 0, 0], [1, 2, 0, 0], [0, 0, ½, ½], [0, 0, ½, ½]]（半正定，零空间就是"u_x = v_y = 0、u_y = −v_x"的刚体转动方向）

单元上的粘性力 F = −(1/h²) ∂Φ/∂z = −K z，K = ½ Gᵀ (W⊗Q) G（h² 相消；W 是对角的面权重 w_f，G 把单元速度映射到面上的四个应变分量）。

（初稿把系数写成 ½ + ½，多算了一倍，复核时更正。）

### 4.3 要逐条验证的性质
1. **对称半正定**：K = ½ Gᵀ (W⊗Q) G，W ≥ 0、Q 半正定 → 成立（构造性）。
2. **客观性**：线性速度场的紧凑差分和中心差分都精确。刚体转动在每个面上 u_x = v_y = 0、u_y + v_x = 0 → I_f = 0 → 力为零，与 ν_eff 怎么变无关。刚体平移同理。
3. **没有棋盘格零模态**：u = (−1)^{i+j}、v = 0 时，x 面上紧凑的 u_x = ±2/h ≠ 0 → I_f > 0，会被耗散。
   一般证明：I_f = 0 等价于该面上 u_x = 0、v_y = 0、u_y = −v_x。所有 x 面上紧凑的 u_x = 0 ⇒ u 只依赖行号 j；所有 y 面上紧凑的 v_y = 0 ⇒ v 只依赖列号 i。x 面上的条件 (V(i+1) − V(i))/h = −(U(j+1) − U(j−1))/(2h)：左边只依赖 i、右边只依赖 j，所以两边都是常数 Ω，V 是 i 的线性函数，U 等于"线性 + 可能的交替项 a(−1)^j"（中心差分看不见交替项）。再用 y 面上紧凑的 u_y = (U(j+1) − U(j))/h = −Ω，交替项会贡献 ∓2a/h，所以 a = 0。因此零空间只有刚体平移和转动，这正是物理上应该的零空间。
4. **相容性**：常 ν、常 ℓ 时，−∂Φ/∂u / h² 应收敛到 ∇·(2νℓ(D + trD I))，二阶精度。用人造解检查收敛阶。
5. **壁面**：关闭的面不计入 Φ → 壁面无应力（自由滑移），和现有处理一致。物理上奶泡在杯壁的弯月面处会粘一点，暂不考虑。

## 5. 和 IMEX 的结合

现在每个子步：A 显式动量对流（Rusanov）→ B 隐式质量 + 压力 + 拖曳 + 牵引（PCG）→ C 奶泡量用同一面通量 → D 隐式粘性与混合。

屈服应力放在 **D 步**，替换现在的粘性：

  ℓⁿ⁺¹ (u⁺ − u⁻)/Δt = −(1/h²) ∂Φ/∂u |_{u⁺}，ν_eff 用 u⁻ 计算（滞后一步的 Picard 线性化）

即解线性系统 (M + Δt K(ν_eff(u⁻))) u⁺ = M u⁻，M = diag(ℓⁿ⁺¹)，K = ½ Gᵀ (W⊗Q) G。两个速度分量通过交叉项耦合在一起，作为一个 2N² 维对称正定系统，用 Jacobi 预条件 PCG 求解（对角元可以由 G 的列和 W 直接算出）。

### 5.1 稳定性（与 ν_eff 大小无关）
用 u⁺ 左乘、求和：
  Σ ℓ u⁺·(u⁺ − u⁻) = −Δt · u⁺ᵀ K u⁺ ≤ 0
再用 u⁺·(u⁺ − u⁻) = ½|u⁺|² − ½|u⁻|² + ½|u⁺ − u⁻|²，得到
  ½ Σ ℓ |u⁺|² ≤ ½ Σ ℓ |u⁻|²
所以 D 步的动能不增，**对任意 Δt、任意 ν_eff ≥ 0 都无条件稳定**。滞后的 ν_eff 不影响这个结论，因为对任何非负的 ν_eff，K 都是半正定的。

### 5.2 守恒
- 膜厚 ℓ 和奶泡量 m 在 D 步不变 → 原有的质量守恒、0 ≤ c ≤ 1 都不受影响；
- 粘性力是 Gᵀ(·) 的形式，内部面的贡献两两抵消，总动量只在壁面变化（壁面无应力，所以也不变）。

### 5.3 时间步与精度
- D 步是隐式的，不改变 CFL；CFL 仍由 A 步的物质速度决定；
- Picard 滞后是 O(Δt) 误差，和整体一阶 Lie 分裂同阶；
- 屈服面附近 ν_eff 跳变很大，滞后可能让少数单元在屈服和未屈服之间来回切换。能量不等式保证这种切换不会发散，但可能有小振荡，测试里要检查。

### 5.4 代价
条件数约 1 + c·ν_max Δt / h²，SSA 系数让 c ≈ 8–16。96²、Δt ≈ 2×10⁻³ s、ν_max = 0.5 时约 75–150，PCG 约 20–40 次迭代；256² 时约 500–1000，约 50–80 次。每个子步多一次 2N² 的 PCG，大约让总时间翻倍，可以接受。JS 版需要同样的稀疏矩阵向量积（G 是常数矩阵，只需构造一次）。

### 5.5 和 B 步的相互作用
B 步的压力会压缩或拉伸膜（ℓ 改变）。SSA 里的 (tr D)² 项让奶泡块也抵抗压缩和拉伸，所以浮上来的奶泡被膜压力往外推时，未屈服的奶泡块会整体平移，而不是被摊薄。这正是我们希望的行为。B 步本身不需要改。

## 6. 验证计划（写代码之后、跑图案之前）

1. **刚体运动**：在杯内放 u = −Ωy、v = Ωx，ν_eff 设为随机场 → 力的最大值应为舍入误差量级。
2. **零空间**：数值计算 K 的最小几个特征值，应只有三个接近零（两个平移、一个转动）。
3. **对称性**：‖K − Kᵀ‖ 为舍入误差量级。
4. **相容性**：常 ν、常 ℓ 的人造解 u = sin(πx)cos(πy) 等，在 32²、64²、128² 上计算 −K u 和解析 ∇·(2ν(D + trD I)) 的误差，收敛阶应约为 2。
5. **能量**：随机初速度单独做 D 步，动能单调不增。
6. **Bingham 解析解**：平面 Poiseuille 型流动（两块平行壁之间、由均匀体力驱动的 Bingham 流）有解析的塞流宽度 y_p = τ_y / G。用一个矩形条带检查塞流宽度随 ε、ν_max 的收敛。
7. **回归**：τ_y = 0 时和现在的结果比较（Laplace 形式与 SSA 形式的差别）。
8. **图案**：在联合优化的最优参数上扫 τ̂ ∈ {0, 0.03, 0.1, 0.3, 1}，看褐缝占比、缝宽、清晰度，以及结果对 ε、ν_max 是否不敏感。

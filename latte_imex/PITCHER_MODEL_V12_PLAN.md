# 第 0 层壶模型：牛奶壶 → 倾斜出流 → 自由射流 → 2D 表层模型的输入

> **V1.2 文件说明（2026-10-08）：** 本文 §0–10 保留原始 `PITCHER_MODEL.md` 内容，不改写已报告实现和测试；**§11–24 为新增加的候选物理模型、设计假设及尚未执行的测试方案**。

实现：`latte_imex/pitcher.py`；演示：`python -m latte_imex.run --control pitcher --N 256`，`python -m latte_imex.pitcher_demo`；
网页交互版：`web/pitcher_playground.html`。

## 0. 为什么不用三维流体

壶里的牛奶在倾斜过程中自由面近似保持水平（重力主导；壶的运动周期 ≳ 1 s，远慢于壶内第一阶晃荡周期 ≈ 0.3 s 的倒数，
所以液面来得及跟上）。壶嘴是一个尖顶 V 形堰口，出流只由"液面高出堰口多少"决定，这是 Francis/Kindsvater 以来的堰流
公式。出壶后的奶柱是抛体运动，直径按连续性收缩，10 cm 以内不会破碎。所以整条链是几个代数式加一个常微分方程，
不是偏微分方程，每帧微秒级，浏览器里就能跑。三维 CFD（VOF/FLIP）只用来离线标定两三个系数（§6）。

## 1. 坐标与姿态

- 世界系：z 向上，咖啡液面 z = 0，杯面中心为原点。杯坐标（2D 求解器用）= 世界 (x, y)/D_L，D_L = 杯径 8 cm。
- 壶体系：Z 沿壶轴向上，X 指向壶嘴。姿态 R = R_z(yaw)·R_y(tilt)·R_x(roll)，tilt > 0 使壶嘴向下。
- 姿态的参考点取壶嘴 V 口的顶点 **tip**（奶离开壶的地方），因为用户拖的是壶嘴而不是壶底：
  世界点 = tip_world + R·(P_body − tip_body)。

## 2. 壶的几何（参数化，7 个数）

旋转体轮廓 r(z) 分段线性过 (0, r_bottom)、(z_belly, r_belly)、(H, r_top)，默认 350 mL 壶：
H 9.5 cm，r 3.4 / 4.0 / 3.0 cm，容量 378 mL。壶嘴：壶沿在方位角 |φ| < φ_w 处下切成 V 形，
z_rim(φ) = H − s·max(0, 1 − |φ|/φ_w)，s = 1.5 cm，φ_w = 25°（对应 V 口张角约 82°）；壶沿在壶嘴处径向外凸 12%（鸟嘴）。
V 口以上没有壁，所以内部采样点排除 z > z_rim(φ) 的区域。

内部体积用 34 200 个带权采样点表示（z、φ 均匀，r² 均匀），权重 dv = π r_body(z)²·dz/(n_r n_φ)。
任何姿态下"平面以下的体积"= 把采样点转到世界系后对 z 做加权分位数，O(N log N)，2.5 ms。
网页版同样做法（JS 里 2 万点排序约 1 ms），或者预先按倾角做成 V(tilt, c) 查找表。

## 3. 准静态液面

给定姿态和剩余体积 V，液面高度 c 由 Σ_{z_i < c} dv_i = V 决定（加权分位数，线性插值）。若 V 超过该姿态下壶能
容纳的体积，多出的部分当作溢出，本帧直接流走。

液面高出壶沿的 **水头** h(l) = c − z_rim,world(l)，沿壶沿曲线 l 取值；h_max 是它的最大值。

## 4. 堰流出流

尖顶堰（sharp-crested weir）积分形式，对壶沿上所有 h > 0 的弧元：

    Q_ss = C_d · (2/3) · √(2g) · ∮ h_eff(l)^{3/2} dl_h,     h_eff = max(h − h_k, 0)

dl_h 是弧元在水平面上的投影长度。对纯 V 口它退化成教科书的 V 形堰公式
Q = (8/15) C_d √(2g) tan(θ/2) h^{5/2}；代入 θ = 82°、C_d = 0.6：h = 9 mm → 9.5 mL/s，h = 13 mm → 25 mL/s，
正好落在学长估计的 6–24 mL/s。积分形式的好处是倾斜过头、侧滚、从整圈壶沿溢出都自动包含。

系数：C_d = 0.60（V 形堰 0.58–0.60），Kindsvater–Shen 水头修正 h_k = 0.8 mm（表面张力、粘性）。

瞬态修正（第 1 层的最小版本）：
- 起流/停流滞回：未流动时需 h_max > h_on = 2.5 mm 才起流（表面张力把奶扣在壶沿）；流动中 h_max < h_off = 0.5 mm 才停。
- 壶嘴通道的充放：dQ/dt = (Q_target − Q)/τ，起流 τ = 0.08 s，停流 τ = 0.15 s（停倒的拖尾）。
- 体积守恒：dV/dt = −Q。

**倾角不能单独决定流量**：同样 60° 倾角，壶里 250 mL 时 Q ≈ 105 mL/s，200 mL 时 31，150 mL 时 3。曲线很陡
（8 → 22 mL/s 只差 2°），这正是咖啡师靠手腕微调流量的原因，也说明从视频里读倾角估流量必须同时知道壶里剩多少
（学长 V1.2 的 T12 + M12）。见 `results/pitcher_demo/tilt_flow.png`。

## 5. 自由射流与冲击量

- 出口速度：Torricelli 在流量加权水头上，u₀ = √(2g h̄)，h̄ = ∮h^{5/2}dl / ∮h^{3/2}dl（V 口解析值 5h/7）。
- 出口截面：A₀ = Q/u₀，等效直径 d₀ = 2√(A₀/π)。
- 出口方向：沿壶嘴方向，在壶体系里比水平低 lip_slope = 10°，再转到世界系：v₀ = u₀·R·(cos α, 0, −sin α)。
- 射流起点：堰口上的流量加权点（V 口顶点附近）。
- 抛体：z(t) = z₀ + v₀z t − ½ g t²，落到 z = 0 的时间 t* = (v₀z + √(v₀z² + 2g z₀))/g；
  落点 x_hit = x₀ + v₀h t*；冲击速度 v = (v₀h, v₀z − g t*)。
- 2D 模型要的量：U⊥ = −v_z，u_h = v₀h（水平分量不变），d_jet = d₀·√(u₀/|v|)（连续性收缩）。
- 是否成束：Weber 数 We = ρu₀²d₀/σ，层流射流破碎长度 L_b ≈ 19.5 d₀ We^{0.325}（Grant & Middleman）。
  典型 d₀ 5 mm、u₀ 0.4 m/s：We ≈ 18，L_b ≈ 25 cm，远大于拉花的 2–8 cm 落差，所以"连续奶柱"假设成立。

典型数值（200 mL、tilt 56°、壶嘴离液面 1.5 cm）：Q 15 mL/s，h̄ 7 mm，u₀ 0.37 m/s，d₀ 7 mm，落差 1.7 cm，
U⊥ 0.68 m/s，u_h 0.14 m/s，d_jet 5.3 mm；抬到 7 cm 后 U⊥ 1.2 m/s，d_jet 2.2 mm。

## 6. 接到 2D 表层模型（Coupling）

位置量按几何直接换算（除以 D_L，精确）。三个速率量各带一个尺度常数，因为 V0.5 的控制量是"有效单位"而非 SI：

| 2D 输入 | 来源 | 换算 |
|---|---|---|
| x_hit | 抛体落点 | /D_L |
| S_eff | Q | c_S·Q，c_S 使 15 mL/s ↦ 0.05（V0.5 心形圆盘段的值） |
| U⊥ | 冲击法向速度 | c_U·U⊥，c_U 使低位 0.70 m/s ↦ 0.263 D_L/s |
| u_in | 射流水平速度 | c_u·u_h，c_u 使 0.15 m/s ↦ 0.5 D_L/s，再按 V0.5 的 60° 限幅 |
| d_jet, r₁, r₂, φ | V0.5 的连续性椭圆规则 | 由 (S_eff/κ_Q, U⊥, u_in) 算出 |

三个常数是"要从视频学的物理参数"的一部分；现在的取值只是把物理量级对到 V0.5 的量级上。
因为 U⊥ 现在只在低位/高位之间变 2 倍（物理值），而 V0.5 靠把足迹半径缩到 0.0015 让 U⊥ 变 34 倍来关掉沉积，
沉积开关尺度要相应改：B_dep = 4（低位 χ ≈ 0.85，高位切割 χ ≈ 0.1），其余参数同 θ05。见 `PHYSICAL_PARAMS`。

## 7. 虚拟咖啡师（动作的"意图层"）

输入不再是入口记录，而是咖啡师的意图：奶柱落点路径（杯坐标）、壶嘴高度、想要的流量 Q_want。
- 瞄准：壶嘴位置 = 目标落点 − 上一帧的射流水平偏移（咖啡师看着奶柱落点而不是壶嘴）。
- 手腕：倾角速率 = K_p (Q_want − Q) + K_i ∫(Q_want − Q)，限幅 60°/s；奶还没到壶沿时按 60°/s 甩到起流；
  停倒按 60°/s 回正。这样"倒得越久要越倾斜"（V 掉、h 掉）会自动出现，倾角从 56° 爬到 63°。
- 心形脚本 `heart_moves()` 按 V0.5 的心形写成意图：远侧低位圆盘 15 mL/s 4 s → 9 mL/s 回到中心 → 抬到 7 cm 从中心
  向近侧切 0.8 s，流量 4 → 1 mL/s → 停。

结果：`results/pitcher_demo/`（inputs.png 八个时间序列；side_view.png 四个时刻的侧视；final.png / movie.mp4 是
IMEX 求解器在 N = 256 下用这些输入跑出的心形，共倒出 61 mL）。

## 8. 第 0 层没管的事（第 1、2 层）

- 壶与杯的碰撞：60° 倾角、壶嘴离液面 1.5 cm 时，壶壁在杯口上方最低点比咖啡面低 2–4 mm（`Pitcher.clearance`）。
  咖啡师的做法是把杯子向壶倾斜 25° 左右、从近侧杯沿上方倒；第 0 层只报告这个间隙，不做碰撞。
- 晃荡：画叶子时 5–8 Hz 的横向抖壶接近壶内第一阶晃荡模态（7 cm 口径约 3.6 Hz），会调制流量；可加一个阻尼振子
  描述液面倾斜。
- 奶泡分层：壶内上层是微泡沫，出壶的泡沫比例随时间变；先按常数。
- 出口方向与收缩系数、C_d、h_k、h_on：要用"水 + 色素 + 秤 + 尺"的自拍实验或离线 VOF 标定。

## 9. 第 1 层：壶的加速度、晃荡、带出速度（已实现，`OutflowLaw.slosh`）

第 0 层假设液面水平，只在壶匀速运动时成立。咖啡师抖壶时壶在加速：横向抖动 3.6 mm、2.5 Hz 的加速度约 0.9 m/s²，
8 mm、4 Hz 约 5 m/s²，与 g 同量级。在壶的参考系里有效重力是 g − a，液面要垂直于它。

- 运动学：壶嘴位置按帧差分得速度 v 和加速度 a，加速度经 τ = 0.02 s 低通（`acc_tau`）。
- 准静态斜率：s_qs = −a_h/(g + a_z)，a_h 为水平加速度。
- 第一阶晃荡模态当受迫阻尼振子：s'' + 2ζω s' + ω² s = ω² s_qs，ω² = g·k·tanh(kH)，k = 1.841/R，
  R 取壶腹半径，H 取当前液深 V/(πR²)；默认 ζ = 0.08（待标定）。200 mL 的参数化壶 ω/2π ≈ 3.1 Hz。
  抖壶频率（2.5–6 Hz）就在共振附近，所以不能只用准静态。
- 液面法向 n = (−s_x, −s_y, 1)/‖·‖；液面高度、壶沿水头、湿周弧元都改为沿 n 度量；堰流和出口速度里的 g 换成 |g − a|。
- 带出速度：奶柱离开壶嘴时带着壶的速度，v₀ = u₀·e_spout + v_pitcher，之后仍只受重力。横向抖壶 3.6 mm、2.5 Hz 的
  壶速幅值 0.06 m/s，与出口速度 0.37 m/s 相比不小，落点摆幅因此从 0.045 增大到 0.059 杯径并带相位差。
- 虚拟咖啡师相应改成"看平均流量"（Q 经 0.25 s 低通再进 PI）和"瞄平均落点"（偏移经 0.3 s 低通），抖动起止各有 0.25 s 的包络。

结果（`results/pitcher_level1/wiggle_pulsation.png`）：横向抖壶使壶嘴处水头在 V 口两侧反向涨落，净流量脉动只有 10%
（3.6 mm，2.5 Hz）到 40%（8 mm，4 Hz）；前后抖壶 3.6 mm、2.5 Hz 就能让流量在 5 到 25 mL/s 之间脉动，更大幅度时每个周期
断流。V0.5 千层心靠猜的 flow_modulation = 0.85 在物理上对应"抖动里有前后分量"。
但把这条物理链接到 2D 模型后，千层心（横向、前后、大幅三种抖法，N = 128）都只得到一个圆盘或带缺口的盘，没有同心弧纹
（`results/pitcher_level1/*_final.png`）。原因是 V0.5 的叠层来自 ±1.4 杯径/s 的射流横向速度，而物理壶速只有它的 1/7；
也就是说奶柱横向动量传给表层的效率（c_u）或 2D 模型里奶柱推开表层的机制，是下一步要从视频学的东西，壶模型本身给不出。

## 10. 用你的 NX 壶（STEP）替换参数化壶（`pitcher_cad.py`，`GridPitcherGeometry`）

`python -m latte_imex.pitcher_cad latte_imex/pitcher_geom/pitcher_nx.stp` 把 STEP 实体细分、按水平面切片，取壁环的
内孔为内腔，用柱坐标描述：内壁半径 r_in(z, φ)、外壁半径 r_out(z, φ)、每个方位角的壶沿高度 z_rim(φ) 与半径 r_rim(φ)，
壶嘴（壶沿半径最大处）转到 +x，单位换成米。内部采样点按 (z, φ, r²) 均匀生成，权重 ½ r_in² dφ dz / n_r。
JSON 不依赖 CAD 库；网页用同一份 JSON（`web/pitcher_nx.json`）。

这只壶：内腔 519 mL，高 100.7 mm，内径 81 mm 的直筒，壁厚 2.1 mm，壶沿是平的（没有 V 口），壶嘴是约 ±10° 宽、
外伸 7 mm 的鸟嘴。倾斜时鸟嘴尖是最低点，堰流积分自动把它当堰顶，湿周约 17 mm。
装 275 mL 时 15 mL/s 需要倾角 55°，8 到 22 mL/s 只差 3°（`results/pitcher_nx/tilt_flow.png`）。
直筒加鸟嘴的几何比参数化壶更不容易撞杯：低位铺盘时壶壁最低点在咖啡面上方 0.6 到 1.0 cm（`results/pitcher_nx/side_view.png`）。

## 11. 为什么要继续升级，而不是只调原有参数？

### 11.1 从原文能直接得到的证据

1. §2–5 已有参数化壶、几何体积采样、准静态水头、堰流积分、起流/停流滞后和弹道射流；§9 已有一个横向加速度驱动的晃动实现，§10 已有 NX STEP 内腔导入路线。**可复用这些模块，不应重写整个管线。**
2. §7 报告了一个 N=256 的人工意图驱动心形演示，但其 `Q_want`、高度和落点脚本来自已知成功控制，属于**正向可表达性/控制演示**，不是视频反演出的真实 Q。
3. §9 报告千层心在三种摆动下于 N=128 主要变成圆团，而不是目标的同心弧；原文推测水平材料速度与 2D 表层耦合偏弱。**该解释尚不是唯一归因**：入口面形、出流非对称、尺度转换、近接触机制、数值分辨率和表层闭合均需隔离测试。
4. §6 的 `c_S, c_U, c_u` 是为匹配 V0.5 有效入口幅值而给出的三个自由缩放；`B_dep: 240 → 4` 又改变了沉积闭合。**这两个更改不能同时算作“仅换了物理出流模型”**，也不能当成真实流量/速度已被视频标定。
5. §8 已记录低位动作中的缸体—咖啡杯几何干涉；§10 的 NX 壶来自一个几何夹具，**并未证明与目标视频的实际奶缸同款**。低位的杯体姿态、奶束—奶池合并和未知器具尺度不可忽略。

### 11.2 改进原则：增加观测能力，而不是盲目增加自由度

- **优先级 1：一个守恒账本。** 内腔、缸嘴暂存、自由奶束和杯中接收量必须在同一体积预算中；出口面积与速度只用同一股流量推导，不允许三个互相独立的“物理真值”。
- **优先级 2：让 3D 缸嘴形状真正参与出流。** 不只输出一个标量 Q，还要输出沿实际唇沿的空间通量分布，从而决定射流起点、方向、宽度/扁平形状及其变化。
- **优先级 3：动力学状态尽量少。** 从准静态几何律开始；若启停/切尾失败，增加一个有限储液状态；若周期摆动的频率或相位失败，再增加 1–2 个液面模态。每增一个状态都要求可检验的残差证据。
- **优先级 4：跨视频共享。** 几何、材料/出流参数和 2D 模型参数的身份严格分离；真实视频每段只允许少数 nuisance 参数（如初始余奶量、相机尺度与必要的姿态修正）。
- **优先级 5：物理预测与视觉演示双轨。** 可使用 V0.5 成功参数制作较好的最终影片，但该视觉成果不得证明 Q、速度或真实物性已经被识别。

## 12. 推荐主方案：几何分布式唇沿出流＋保守滞后储液（GLF）

**候选名称（便于项目追踪，不表示论文首创）：** *Geometry-aware Lip Flux with Conservative Memory*（GLF，几何感知的唇沿通量与守恒记忆模型）。它是将原文堰流积分改成**局部离散通量**，再引入**可以盘点体积的缸嘴暂存区**，最后输出完整的 3D 出流状态。

### 12.1 输入、状态与输出

| 类型 | 建议内容 | 来源/能否直接观测 |
|---|---|---|
| 固定几何 | 内腔 `G_p`、真实唇沿 `Γ_lip`、外轮廓、缸嘴导流方向；杯内腔 `G_c` | SAM 3D/TRELLIS/CAD/多帧拟合给候选；隐藏内腔不视作真值 |
| 每帧控制 | 缸 `T_p(t), v_p(t), ω_p(t)`；杯 `T_c(t)`；重力参考 | 视频姿态估计＋时间平滑/不确定区间 |
| 缸内状态 | `V_b`（内腔主体牛奶量），可选自由面晃动 `a_x, a_y` 及其速度 | 隐变量，用守恒推进 |
| 唇部状态 | `V_l`（缸嘴/近唇口暂存奶量），可选单一湿润开关 `w` | 隐变量；只在出现滞后残差时加入 |
| 空中状态 | 有体积、释放时刻与速度的少量流体包（parcels） | 非完整CFD，用于飞行时延和到达守恒 |
| 2D求解器入口 | `Q_hit, x_hit, v_hit, U_perp, v_parallel, footprint, phase` | 模型输出；其中真实 Q/速度仍可不可辨 |

**必须用三个互不混淆的量：** `Q_feed`（主体牛奶流入唇部）、`Q_out`（真正离开奶缸）、`Q_hit`（真正到达咖啡）；它们在非稳态时**不应被强制相等**。

总量账本（无飞溅/粘壁不可回收损失时）：

$$
V_b(t)+V_l(t)+V_{jet}(t)+V_{cup,added}(t)=V_{initial}.
$$

杯中原有咖啡体积是另一个初始状态，不应进入新增牛奶的恒等式；若后来需要考虑飞溅或永久残留，应给它们明确的体积状态，而不是悄悄漏掉。

## 13. 几何→液面→沿缸嘴的局部供液通量

### 13.1 准静态主体：沿用 §2–3，但改进数值可微性

给定内腔 `Ω_p`、刚体姿态 `R_p,p_p`、主体体积 `V_b` 与单位自由面法向 `n(t)`，求截面常数 `c(t)`：

$$
V_b = \int_{\Omega_p} \mathbf1[\mathbf n(t)^\top(R_p\mathbf x+\mathbf p_p)<c(t)]\,d\mathbf x.
$$

原文加权粒子分位数可以保留作准确性基线；为了反演和跨帧平滑，新增**保守的体积—高度单调查找表、连续插值或光滑裁切体积计算**，对比两者的体积误差、导数跳变与运行时间。不要通过平滑图像中的液面高度来偷偷改变杯/缸体积。

当快速倾倒造成 `V_b` 暂时超过该姿态的**准静态无溢出容量**时，不能直接把超额体积当作一个无时延的“本帧落入杯中”瞬时流量；应标记准静态假设失效，并把有限超额量转入唇口暂存/供液通道，或切换待检验的更高阶状态，仍保持总量守恒。

### 13.2 与加速度一致的自由面（建议对照）

慢动作：世界自由面法向近似与重力反向。明显平移加速度时，用缸体参考点的惯性加速度构造有效重力 `g_eff = g_world − a_ref`，决定准静态斜率；角速度与角加速度会造成空间非均匀的惯性作用，不能仅靠一个常数 `|g_eff|` 精确表示。

从 §9 的受迫振子扩展到**至多两个可选模态**：

$$
\ddot a_i +2\zeta_i\omega_i\dot a_i+\omega_i^2 a_i=\omega_i^2a_{i,qs}(t),\quad i\in\{x,y\}.
$$

`a_i` 是**实际自由面额外斜率状态**，`a_{i,qs}` 是等效加速度给出的目标，不允许既把它用于瞬时自由面、又叠加同一响应一次（避免加速度作用重复计数）。仅在观察到可重复的倾倒/摆动相位残差后才开启这两个状态；参数 `ζ,ω` 先共享，不为每个动作单独拟合。

### 13.3 沿真实唇沿积分：保留“在哪里流出”的信息

把真实有效出流唇沿分为 `j=1,...,M` 个短段，记录其世界位置 `r_j`、局部导流方向 `d_j`、有效水平投影长度 `Δℓ_{h,j}` 和局部液头 `h_j`。准静态候选供液为：

$$
q_{feed,j}^{(0)} = \frac23 C_{d,j}\sqrt{2g_{eff,j}}\,\Delta\ell_{h,j}\,[h_j-h_{crit,j}]_+^{3/2},\qquad Q_{feed}^{(0)}=\sum_j q_{feed,j}^{(0)}.
$$

这里 `q_{feed,j}` 的单位是体积/时间；`C_d`、`h_crit` 和 `Δℓ_h` 是**有效几何—水力参数**，需根据真实缸嘴是否锐边、厚唇、贴壁或绕流区分，不能将经典锐边V堰系数当普适牛奶常数。局部形态极端变化、较厚唇口或低水头时保留另一个经校准的流量律作竞争基线。

将 `Q_feed` 裁剪到该步实际可用 `V_b/Δt`，记录裁剪次数；若频繁触发，说明当前模型/步长超出适用范围，不能以裁剪掩盖错误。

## 14. 如何模拟真实启停、短时拖尾而不凭空产生牛奶

### 14.1 首选 F1：**保守唇部暂存体积**（与原文一阶 Q 滞后做等价/优劣对照）

使用一个额外体积状态 `V_l≥0`：

$$
\dot V_b=-Q_{feed},\qquad
\dot V_l=Q_{feed}-Q_{out},\qquad
Q_{out}=\frac{V_l}{\tau_l}\,\psi_{wet}.
$$

`ψ_wet` 是有界非负湿润/出口连通因子，可先固定为 1；在存在可信滞回证据时再引入简单的干/湿状态。该模型在供液停止后允许 `V_l` 排空形成短时细流，又能从方程上解释残留流量来自哪一份体积；相比简单的 `dQ/dt=(Q_target−Q)/τ`，更容易保证瞬态总量守恒并作液量盘点。

**最小参数化：** 首轮只允许一个全局 `τ_l`；若不同启停方向的残差稳定存在，才放开 `τ_on / τ_off` 或一个湿润滞回阈值。`V_l` 并非视频逐帧真值，不能为了贴合单一教程片段无限增大。

为得到沿唇沿的真实离口分布，记供液分布权重 `π_j=q_feed,j/Q_feed`；停流时沿用有界的最近湿润分布或一个单独的通道记忆，而不把唇部剩余液体重新随机分配到不湿润的侧面。每步满足 `Σq_out,j=Q_out`。

### 14.2 条件升级 F2：嘴部有效惯性／阻力方程（**不要和F1一起无约束开放**）

当一个暂存体积仍不能解释已可观测的非稳态速度或相位时，再测试局部控制体形式：

$$
\frac{\rho L_j}{A_j}\frac{dq_j}{dt}
=\rho g_{eff}h_j -\Delta p_{cap,j}-R_{\mu,j}q_j
-\frac{\rho}{2}\left(\frac{q_j}{C_{A,j}A_j}\right)\left|\frac{q_j}{C_{A,j}A_j}\right|.
$$

它是假设嘴部流体可由有效长度 `L_j`、湿润截面 `A_j`、阻力和毛细压强描述的**候选降阶近似**，不是已从牛奶/真实视频识别的定律；随时间变化的 `A_j` 和控制体体积会带来额外惯量变化项，实际实现需与守恒控制体推导一致，不能直接拿此式替代完整动量账本。干口 `A_j≈0` 时必须安全退化为零流量/离散补液状态，而非数值发散。

**决策规则：** F0准静态、F1保守暂存、F2局部惯性为复杂度逐级上升的竞争模型；只有留出观测确实支持新增状态时才升级，避免 `C_d,A_j,R_μ,τ_l,Δp_cap` 全部同时不可辨。

## 15. 从沿唇沿的流量分布推导真实出口位置、面积与动量

原文 §5 用 `u_0=√(2g h̄)`、`A_0=Q/u_0`、圆柱等效直径作为主要接口，这在高位、近圆形奶束时是有效的**第一近似**；但低位拉花可能形成沿导流槽展开的液片、非圆椭圆奶颈，并且左右唇沿的供液可以非对称。

GLF 使用每个湿润唇沿段的离口通量 `q_out,j`，得到：

$$
\mathbf x_0=\frac1{Q_{out}}\sum_j q_{out,j}\mathbf r_j,
\quad
\mathbf v_0=\frac1{Q_{out}}\sum_j q_{out,j}\mathbf v_{0,j},
$$

$$
\mathbf v_{0,j}=\mathbf v_{ref}+\boldsymbol\omega_p\times(\mathbf r_j-\mathbf r_{ref})+u_{rel,j}\mathbf d_j,
\qquad q_{out,j}=A_{liq,j}u_{rel,j}.
$$

**重要：** `A_liq,j` 是真实流体湿润的有效截面，不等于金属缸嘴几何空隙，也不能只由 `Q/u` 重算后再宣称“截面被独立验证”。可用几何约束其可容纳上界，再用视频可见奶束宽度限制侧向尺度，并给隐藏轴比一个**共享的有界先验**；在没有充分观测前保留区间。

此外保存二阶通量矩 `Σ_0=Σ q_out,j (r_j−x_0)(r_j−x_0)^T / Q_out`，它自然携带出口液片的宽度、主轴方向和非对称性，避免把所有出流强行圆化为一个 `d_0`。若实验表明只需一个近圆束，则自动退化回原 §5 的简单接口。

**建议保留逐段速度分布，而非只保留平均值。** 两个相同的 `Q_out` 可以来自不同的嘴部湿润范围和速度分布，对奶束宽度、位置与后续细切可能有不同影响。

## 16. 奶束到咖啡杯：飞行、移动液面和低位接触

- **离口后的自由束：** 为每个步长释放少量携带体积 `ΔV=Q_out Δt` 的 parcel，记录释放时间、源位置、速度与可能的方向协方差。以真实重力积分到杯内**世界坐标自由液面**，而非固定 `z=0`；撞击时将 parcel 体积转入 `V_cup,added`。
- **到达时延：** 一般 `Q_hit(t)≠Q_out(t)`；必须用 parcel 到达事件累计得到 `Q_hit`，不可以把视频操作帧间隔当作奶粒的飞行时间。
- **杯体倾斜：** 从杯内腔、杯Pose和初始杯内体积的有界估计计算自由液面；杯口椭圆 ≠ 实际液面。对每个候选 `G_c,T_c,z_surface` 同时进行缸壁—杯体无穿透检查。碰撞失败的倾倒场景不能只凭漂亮图案保留。
- **低位模式：** 当嘴到液面的距离 `H_hit` 接近奶束横向尺度，或可见奶颈与白池连为一体时，弹道与独立圆射流假设不可靠；增加一个**接触/短液桥分支**，将到达面积与法向动量以有界接触核给 2D 表层。切换由距离、接触可见性和前一时刻状态共同决定，防止一帧开/关跳变；其阈值不是仅凭最终图案反向调参。
- **重要边界：** 如果出流唇口实际浸入奶池、形成持续液桥，杯端可能反馈影响排流；只有发生该物理状态时，才考虑相应的背压/毛细反馈模型，不应默认杯倾角直接决定 `Q_out`。

以 `V_b+V_l+V_jet+V_cup,added` 的守恒误差验收整个 F→J 接口，并记录每个时刻的 `Q_feed,Q_out,Q_hit`、嘴部湿润范围、自由束与近接触模式。

## 17. 与 V0.5 / V1.1 表层动力学连接：应当立即修正的参数接口

### 17.1 先做明确单位映射，避免三个自由倍率

原文 §6 的 `c_S,c_U,c_u` 用于**对齐 V0.5 生成效果**，对演示可以保留；但在物理反演路线里，不能让三个倍率分别自由调整并又声称出口速度/流量来自物理模型。

若真实杯径未知，把 `L_0=D_cup` 当作**待约束的全局尺度**，模型时间与真实 PTS 相容时取 `T_0` 为相应计算时间单位，则：

$$
\hat{\mathbf x}=\mathbf x/L_0,\quad
\hat{\mathbf v}=\mathbf v\,T_0/L_0,\quad
\hat Q=Q\,T_0/L_0^3,\quad
\hat A=A/L_0^2,\quad
\hat g=g\,T_0^2/L_0.
$$

这是纯量纲换算；`T_0` 不可随最终图案任意压缩/拉伸。视频若含教学定格、变速或剪辑，先构造有效真实动作时钟，并保留不确定区间。它只决定 3D 量怎样进入求解器，**不能自动解决二维“有效层”与真实三维奶量间的闭合**。

允许保留一个**共享、跨动作固定**的有效接收系数（使用原 V1 `κ_Q` 或经明确重新定义的等价参数）表示三维接收量到二维有效表层源的转换；横向和法向速度先使用物理一致的同一个单位转换，不设置两个独立的自由倍率。只有能够在合成或独立可见材料运动中证明必要时，才开放一个有界动量传递效率，而不是把未知物理速度全部埋入 `c_u`。

### 17.2 不预先把 `B_dep=240` 改成 `4`

原文这个改动显著改变原沉积开关 `χ=[1+(U_perp²/(B_dep d))^{p_dep}]^{-1}`。在 V1.2 的归因实验中，必须先使用**同一份** V1.1/θ05 参数和同一入口比较，观察出流模块带来的净效果；再将新参数尺度的 `B_dep` 作为单独候选/敏感性对照，而不是混入几何效果。

建议把 `Π_dep=U_perp²/(B_dep d)` 及 `Q_hit`、沉积源 `s`、交换源 `Λ`、传递到旧奶纹的有符号水平动量同时输出；否则“看起来更像心形”并不能定位是沉积阈值、源量还是旧材料推动的变化。

### 17.3 千层心负结果应成为模型诊断，而不是调参许可

针对原文 §9 的 N=128 千层心圆团：在同一真实缸运动、流量和几何下，分别冻结并检查 `Q_hit` 的周期分量、横向入射动量、脚印椭圆及已有奶纹位移；用 N=256→384/512 的**针对性自身数值比较**排除宏观网格伪差，再做原源与新空间分布入口的受控对照。

若物理合理的横向材料速度始终不足以形成真实层状弧纹，应如实记录：这可能是 2D 材料推动/返流闭合的限制，不可仅通过增大 `c_u` 或为每个图案人为强化 `flow_modulation` 来伪装真实物理识别。

## 18. 单目视频反演：必须把“可测”和“不可辨”分开

### 18.1 观察量与隐变量

**从视频尽量直接约束：** 刚体轮廓/杯沿/壶口/缸嘴关键点，姿态与相对高度、操作启停、真实自由束的中心线/宽度/方向、落点可见范围、咖啡表面图案时序。**不直接可测：** 隐藏内腔、缸内实时奶量、离口流体截面、真正材料速度、绝对 `Q(t)` 以及泡沫比例。低位白池融合时没有独立落点标签，应为范围或 `null`。

真实视频只允许同时优化少量弱可辨识变量（例如共享 `C_d`/`τ_l` 中的1–2个、各视频初始 `V_p0`、必要的姿态/尺寸小修正）；其余先固定或构造有界候选库。不要把高维缸嘴网格、相机姿态、奶量、黏性系数和二维物性一次放开。

### 18.2 可实际优化的目标（非照片级奶束渲染）

$$
\mathcal L=\lambda_{rigid}L_{sil/keypoint}
+\lambda_{jet}L_{visible\ jet}
+\lambda_{event}L_{start/stop}
+\lambda_{geom}L_{geometry}
+\lambda_{con}L_{conservation}
+\lambda_{prior}L_{bounded\ priors}.
$$

`L_visible jet` 只在**可辨识的真实自由奶束**上对中心线、宽度和方向评分；反光、教学标记、已成形白纹和低位融合不可作为真实射流。存在外部体积称重时才加入 `L_total volume`；没有实测体积时该项为缺测，而非用自己推算的体积验证自己。奶束照片级可微渲染损失留到后续版本，不作为 V1.2 的主校准路径。

**两层反演：** 先分别冻结几何/相机与 Pose；再在有限有界几何候选上反演缸内初始量与共享出流参数；最后只做小范围联合精修并检查每个参数的局部可辨识性。图案评价先不介入 Q 的高维拟合，以免“好看”等同“物理正确”。

### 18.3 尺度的根本歧义

没有同款器具的实测尺寸时，**只能先可靠报告杯径归一化几何与高度**。如果器具几何整体放大 `a` 倍、有效液头随之放大，在固定 g 的相似 V形堰近似下，物理流量大约满足 `Q ∝ a^{5/2}`，体积随 `a³` 缩放；视频的时间、出流系数与初始奶量可能部分约束它，但在单目及未知系数条件下不能假定绝对 SI 尺度已唯一恢复。

应把 `L_0`、`V_p0`、`C_d` 和隐藏截面先验组成一个**可解释的不确定性族**；以 profile loss / 参数扫描展示不同合理几何和速度的共同投影误差、Q范围、H_hit范围。没有真值时不报告“实际 Q 误差 5%”。

| **E6** | 真正新动作，在冻结共享模型后只提供新的缸与杯轨迹 | 姿态/射流/图案误差和拒绝样本 | 检验泛化，不用留出动作二次选参 |

**所有 E 项至少包含：** 原生帧图、遮挡/可见区间、参数和时钟配置、守恒账本、成功与失败视频、运行成本和数值误差；观察不足时报告 `null` 而不是通过。不要因新增模型看起来复杂就跳过零流量、初始余量过小、突然回正、侧滚、视频变速、杯体碰撞等边界测试。

## 20. 阶段2专用的验收与停止规则

1. **几何先行：** 视频叠加必须同时对准奶缸缸嘴、杯口与相关刚体轮廓，且多个帧间使用同一器具形状；深度网络仅作软约束，反光区域不赋予虚假的高可信度。
2. **出流守恒必须优先通过：** `V_b,V_l,V_jet,V_cup` 全部非负、总量不漂移；严禁负 `Q`、时间混淆、离口面积/速度与 Q 不一致。
3. **新增状态须有判别力：** 只在其对冻结留出动作的启停、束形、落点或相位误差改善大于人工读图分歧与数值噪声时保留；否则回退到更简洁的上一阶模型。
4. **物理与视觉分开许可：** θ05＋新入口得到好看的心形/千层心只说明表达能力；只有有外部实测或可靠独立观测支持时才能宣称 Q、速度、液头或真实物性精度。
5. **出现多个近似等价解时必须呈现多解：** 不将优化器最优点当唯一真值；重要输出给区间及使区间变窄的新增观测建议。
6. **分辨率匹配：** 细射流、细切、孔缝低于网格解析度时，不能用宏观误差通过代替它们的细结构通过；在影响决策的例子上做自身细化核验。

## 21. 建议实现接口与守恒积分步骤（伪代码；未编写/运行）

```python
# Inputs: shared mesh, camera-calibrated pitcher/cup poses, unknown global length scale
# States: bulk_volume, lip_volume, optional slosh, in_flight parcels
# Choose exactly ONE outflow memory branch for a given ablation.

def step_pitcher(state, pose_p, pose_c, dt, geom_p, geom_c, params):
    # 1. Differentiate/smooth poses once, with confidence and true motion timestamps.
    motion = pose_kinematics(pose_p, dt)

    # 2. Solve volume-consistent bulk free surface and optional slosh state.
    plane = volume_constrained_surface(geom_p, pose_p, state.bulk_volume,
                                       state.slosh, motion, params)

    # 3. Compute NONNEGATIVE local feed flux on the actual wet spout curve.
    feed_segments = lip_feed_flux(geom_p.spout, plane, motion, params)
    feed_volume = min(sum(feed_segments) * dt, state.bulk_volume)
    state.bulk_volume -= feed_volume

    # 4. Move mass into a physical lip buffer, then drain it once.
    state.lip_volume += feed_volume
    release_volume = min(state.lip_volume,
                         lip_drainage_volume(state.lip_volume, params, dt))
    state.lip_volume -= release_volume

    # 5. Assign the released volume to wet lip segments, preserving their moments.
    outlet = distribute_release_over_lip(release_volume, feed_segments,
                                         state.wet_lip_memory, pose_p, geom_p)
    parcels = generate_parcels(outlet, motion, dt, geom_p, params)
    state.jet_parcels.extend(parcels)

    # 6. Advance EXISTING and new parcels to the moving coffee surface.
    arrivals, remaining = advance_to_moving_cup_surface(
        state.jet_parcels, pose_c, geom_c, state.cup_volume, dt, params)
    state.jet_parcels = remaining
    state.cup_volume += sum(p.volume for p in arrivals)

    # 7. Convert arrivals to consistent surface fields, with no arbitrary per-frame gains.
    surface_inlet = moment_and_footprint_of_arrivals(arrivals, pose_c, params)
    state.slosh = update_slosh(state.slosh, motion, dt, params)
    assert_mass_nonnegative_and_conserved(state)
    return state, surface_inlet
```

## 23. 推荐的实际执行顺序与是否升级判据

**MVP-A（首先交付）：** 原文实现可复现＋统一 SI/归一化单位审计＋守恒账本＋视频缸嘴/杯体 pose 的固定输入重放；阶段结果必须能直接指出出流是被谁驱动的。

**最终一轮：** 用已经冻结的 `a12` 驱动 θ11 / θ05 的对照影片，报告第2阶段白团铺展、分层/瓣、细切与停流全过程，以及在新动作下的泛化和模型时延。若出流模块守恒良好但仍无分层，应允许结论为“表层耦合/材料闭合待改”，不能无限用出流系数调出人工效果。

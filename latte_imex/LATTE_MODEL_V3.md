# 拉花杯面模型 v3：漂浮奶泡筏 + 等压吸附膜画布 + 水下含气储层（实现规范）

版本：v3.0-spec（2026-10-11），尚未实现。本文是本项目接下来要实现的模型的**完整、自足**规范，取代 `LATTE_MODEL.md`（v2）、`TWOLAYER_CELL_MODEL.md` 以及 `PITCHER_MODEL.md` §12–15 的全部杯面闭合。

来源与分工：骨架取评分最高的提案 PE（"置换铺面 + 浮筏 + 入口分相"，DRE）的状态、运动学与台架实验体系；按三位评审（物理、实验、实现）的"可嫁接"清单，从 PD（凸变分准静态漂浮层、喷泉/浮选、Hazen 效率、储层 ψ）、PB（筏缘线力平衡与零余量引理、画布表面压方程与等压引理）、PA/PC（Kynch 浮选延迟、光学成核阈值、移动汇捕获宽度）取更严的部分。凡与提案冲突之处，在 §2.10 与各节逐条写明谁错、错在哪里。所有数字由附录 A 的公式与同一组输入算出（脚本见附录 A），可手算复核。

记号：D ≡ D_L = 0.08 m（杯内径），R = D/2 = 0.04 m，A_cup = πR² = 50.27 cm²；g = 9.81 m/s²。方程一律按 SI 书写；"D""D/s"只在与视频比较时使用（1 D = 8 cm，0.01 D = 0.8 mm，0.1 D/s = 8 mm/s）。下标 l = 杯中液体（咖啡 + 已混入的液奶），j = 奶柱（jet），f = 奶泡筏（raft foam），N = 近场含气储层，b = 气泡。"低位"= 嘴高 z_s = 1–2 cm、Q = 10–20 mL/s；"高位细流"= z_s = 5–9 cm、Q = 2–5 mL/s。视频事实编号 V1–V11 见 `diagnosis.md` §0，并按 `judge_experimentalist.md` §1 的重测修正 V7（§4.7）。

## 0. 一句话与适用范围

**一句话**：杯面是一张由两相组成的漂浮层——白色的**粘塑性奶泡筏**（堵塞奶泡，厚 3–5 mm，七成露出液面，膜（SSA）区 Bingham 板，自选厚度 h_m = κτ_y/(ρ_f g′)）与褐色的**画布**（液面 + 蛋白/类黑素吸附膜 + 其下尚未成白的 Kynch 气泡层）；画布吸附膜的表面压在 0.02–0.2 s 内全杯均衡，因此画布对一切**发散型**的液体表面流"不可见"，只随**面积源**（筏的铺展、射流近场的汇与回涌环）按面积守恒运动；白色只来自射流带入的稀含气液在近场储层中**浮选（Kynch）**到液面、在固定的液面下堆到光学阈值 h_* = z_e 后成核；射流对已有奶泡的作用是驻点压力的**接触推压 + 压入**，由内聚压 Π_coh 决定压入的奶泡成团回浮还是被打散。可见白度 c ∈ [0,1] 是筏相的面积占据率（物质相标记，几何 VOF 输运），厚度只进动力学。

**适用范围**：只模拟**绘制阶段**——注满（高位混合）之后，从第一笔低位倒奶到最后抬缸细流收尾，时长 ≤ 30 s；包括低位出白、摆动、前推/后退、多段推挤、抬缸、高位细流切、细流画线、杯倾回正与液位上升。

**刻意不做的（及理由）**：
1. **注满阶段**（5–10 cm 高位大流量混合）：它决定画布初态（底色、体相分散气泡 φ_B、吸附膜状态），本模型把它当作测得的初态输入，不求解（学长 V1 §1.2 范围声明）。
2. **完整三维多相流**：射流近场（r ≲ r_N ≈ 0.25–0.3 D）的喷泉/回涌是一个与图案无关的轴对称内问题，本模型用**台架或一次性轴对称 DNS 制表**的输出（§3.7）代替，在杯面二维网格上不解；理由是 d/D = 0.02–0.07、它的输出是普适的射流性质，且学长明确"证据不足以投入完整三维"。
3. **排液、粗化、破泡**（1–10 min）：t_dr = 30–100 s ≫ 绘制 10–20 s，τ_y、φ_f、R_32 在绘制期内取常数（近似 N11）。
4. **奶–咖啡化学 Marangoni**（Δσ ≤ 10 mN/m）：被蛋白膜的高 Gibbs 弹性吸收进画布表面压 Π_0，作为二阶量不单列（近似 N12）。
5. **表面重力波与晃动的动力学**：只保留液面水平这一准静态结果（Fr_cup ≈ 2×10⁻⁴，晃动周期 0.30 s ≪ 回正 1–2.5 s）。
6. **超过饱和的光学**：渲染只拿一个有界组分 c；画布因体相小泡浮出而变浅、深层液体上涌变深等色差需要第二组分，默认关闭（需学长改规范）。

## 1. 为什么前两个模型从根上不行

比较对象：**家族 A** = `closure="chi"`（Codex V0.5 式 χ 沉积 + Λ 牵引 + κ_r 返流，#9 参数；§14 "先推后白"时延补丁默认关闭）；**家族 B** = `closure="twolayer"`（双层 + 卷吸胞）与 `closure="v2"`（H/H_f、Bingham 膜、白度 W = 1 − e^{−m/m_o}）。只引用 `verdicts.json` 中**确认**或**修正后成立**的条目；被驳回的条目（A1、A3、A4、A5、A11、A16、B1、B2）在 §1.6 单列，说明它们改变了什么结论。数字出自 `diagnosis.md`、各 `skeptic_*.md` 与 `code_map.md` 的实算。

两代模型共享同一个结构假设：**杯面是一层单相"有效材料"，由一个速度场搬运；白是这层材料携带的一个量（示踪比 c = m/ℓ 或不透明度 W(m)）；一切推力都是这层材料自身的压力、惯性或落点核内的牵引。** 下面五组失败都是这个假设的直接后果——改参数改不掉，因为错误的是"什么东西在动、白是什么"。

### 1.6 被驳回的条目改变了什么

- A3/A4 被驳回说明：**局部、定向的推力本身是对的**（旧闭合的活塞推在 0.15–0.2 D 处给出 0.11–0.15 D 位移），v3 保留"射流近场直接作用于已有材料"这一要素，但把它交给与白色无关的载体（驻点压力、面积源）。
- A5 被驳回说明：在旧闭合拟合点上图案"冻结"靠的是 β 拖曳；v3 要用一个**精确**的冻结机制（屈服 + 等压画布）取代 β，而不是再加一个阻尼。
- B1 被驳回说明：v2 落点处的向内汇聚只在 r ≲ 4 mm 内、并没有反转推挤方向；v3 的近场正是"r < r_e 向内、外面静止"（§2.3），v2 符号对、范围与机制错。
- B2 被驳回说明：v2 的远场主要推力是奶泡堆的各向同性压力而不是 1/r 势流；v3 中远场位移完全由面积守恒给出（§3.5 引理 L-C），既不是势流拖曳也不是压力流。
- A11、A16 被驳回：入口形态与帧内冻结不是宽褐带缺失的原因（足迹 ×0.3、85% 脉动都不改变 2–3 mm 缝；CFL/帧长敏感度比失配小 2–3 个量级）。

### 1.7 为什么这些不是参数问题

1. 160 组九维闭合扫描、足迹 ×0.3、85% 脉动、ν → 0、256² → 512² 加密都出不来 ≥ 4 mm 的块间褐带（家族 A）；家族 B 的 τ_y 从 0 加到 20 Pa、c_p 从 2.5 降到 0.97 都保不住 4 mm 缝（B3）。
2. 拟合出的"物理量"撞界或不物理：cell_fit g′ = 10 m/s² > g（意味着 ρ_f < 0）；H_f、m_o、κ_t、cell_frac、tulip 的 h 全在边界（`code_map.md` §2）。
3. 根本原因在状态定义：单一材料场 + 单一速度下，(i) 推力载体必然同时是白色载体（S1），(ii) 厚度对比必然被同一个压力抹平（S2），(iii) 褐色只能是被压缩的原有褐色（A1 性质）。v3 因此改变**状态**本身：两相（筏 / 画布）各有自己的力学，加一个水下储层，白是相标记。

### 1.8 两代模型做对的、v3 保留的

- 局部定向推力的存在（S-A1）→ v3 中由射流驻点压力（接触）与面积源给出。
- 沉积/穿透的方向（S-A3）、"水下未显白的东西有力学存在"（S-A4、S-B2）→ v3 的储层 ψ + Kynch + 内聚压 Π_coh。
- 浮层厚度与杯深分开、c_p² = g′H_f 来自浮力（S-B1）→ v3 中 N(h) = ½ρ_f g′h² 只作用于筏相自身。
- 已验证的 SSA/Bingham 离散算子 K = Gᵀdiag(w)G（S-B5，`solver.py` L628–712）→ v3 筏块的线性子问题。
- 守恒 1e-14、JS 对拍 3e-8 的工程骨架（S-A5、S-B7）。

### 2.2 一次低位倒奶的时间线（Q = 15 mL/s，z_s = 1.5 cm；数字来自 §2.9 与 §4）

```
  壶嘴 ─┐ 奶柱：气泡液 φ_j≈0.25，v≈0.65 m/s，d≈5.4 mm，倾角 α≈5–12°（离壶方向）
        ▼

   画布静止（只随面积源平移）             │ U_N →→→ 含气储层 ψ（g_N≈1 cm）│  ↓汇
                                         └─── 在 r_N≈2–2.5 cm 下沉 ←──── 回涌环 r_e
   体相：射流下行 → 喷泉在 z_m≈H 附近反转 → 回涌；未浮选的气随下沉进入体相（3–30 s 才回面）
 ═════════════════════════════════════════════════════════════════════ ← 杯底
```

1. **0 – t_r（≈ 0.4–0.8 s）**：奶柱插入液面。光滑、We_j ≈ 25–68 的层流/过渡射流**不卷气、不成弹坑**（We_j 远低于 Lin–Donnelly 卷气阈 10 Re_j^0.74 ≈ 3–5×10³），它把周围液面卷入：半径 r_c ≈ (0.3–0.5) d 内画布连同吸附膜以面积通量 F_c 被吞下。气泡液作为负浮力强迫喷泉下潜，到 z_m ≈ 2.46 Fr₀ r₀ ≈ 5.3 cm ≈ 1.2 H 附近（已触底区）反转，沿下行射流外侧回涌，在**回涌环** r_e ≈ (0.5–1) d 处到达液面下方，带来新液面（面积通量 F_up ≈ F_c）。于是 r < r_e 是一个**闭合的表面涡**：新液面在 r_e 出生、向内流向 r_c 被吞；r > r_e 的画布不动。画布上没有任何白，落点略暗、反光（新液面）。
2. **t_r – t_w**：回涌的稀含气液（φ_N ≈ 0.06–0.1）在液面下 g_N ≈ 1 cm 厚的层里以 U_N ≈ 3–12 cm/s 向外流（**在膜下**，不拖动等压画布，§3.5），其中 50 µm 量级的小泡以受阻 Stokes 速度 v_b ≈ 2–5 mm/s 上浮，抵达液面后挂在膜下堆成 φ_J ≈ 0.64 的 Kynch 层，以 φ_N v_b/(φ_J − φ_N) ≈ 0.3–0.9 mm/s 的速度增厚。r < r_e 内的气泡随向内的表面流被吞回射流——**落点保持褐洞**。
3. **t_w ≈ 1.0–1.7 s**：r ≳ r_e 处 Kynch 层先达到光学半饱和厚度 h_* = z_e ≈ 0.3 mm，成核为筏——**白以环出现在落点外**。射流倾角使回涌环向下游偏移 α z_turn ≈ 0.4–0.9 cm，上游扇区落在汇里 ⇒ **C 形开口朝壶**。
4. **t > t_w**：之后浮上来的气直接并入筏底（筏是"收集器"——这不是规则，而是"筏底下的气泡没有成核阈值"的直接结果），筏增厚到超过自选厚度 h_m 后侧向铺展，面积以 dA/dt = F_white φ_j Q/(φ_f h) ≈ 1.3–4.8 cm²/s 增长（§4.5）；铺展的筏把画布按面积守恒推开，已有元素以 (R² − r²)/r 的规律被推离源点。
5. **停倒**：吞汇与回涌在 ~t_r 内消失，储层中剩余的气继续浮选 1–3 s（少量补白 0.5–1.5 cm²，落点小缺口部分被填），然后：没有面积源 ⇒ 画布不动；筏 h ≤ h_m ⇒ 不自铺；**图案在有限时间内精确冻结**（变分问题的解精确为 u ≡ 0，§3.6），而不是以 β 指数衰减。

### 2.3 两区表面流（本模型最核心的运动学事实）

- **内区 r < r_e（射流的表面涡）**：液面从回涌环流向射流（u_r ≈ −F_c/(2πr) ≈ −0.2…−1 cm/s，F_c = 0.7–1.5 cm²/s，r = 2–5 mm）；进入的画布、Kynch 层、薄筏被吞下；新液面不断出生。白在这里永远形不成——**落点褐洞**；直径 2r_e ≈ (1–2) d ≈ 0.07–0.13 D。
- **外区 r > r_e（等压画布）**：吸附膜的表面压在 t_Π = L²ζ/E ≈ 0.015–0.18 s 内全杯均衡，画布只能做"散度处处均匀"的运动；液体在膜下的一切**发散型**表面流（体积置换流 Q/(2πrH)、近场储层外流 U_N、杯尺度子午环流、晃动模）都被过滤掉；画布与嵌在其中的筏只随**面积源**——筏的侧向铺展、内区的净面积通量 F_net = F_up − F_c、杯壁处液面面积的变化（锥形杯液位上升）——按面积守恒移动，外加液体表面流的**无散（涡）部分**。
- **滞止圆 r ≈ r_e**：两区的分界；白在这里出生。
- 与以往图像的区别：physics_prior §2.4 的"坑缘向外快速薄层"对光滑入水射流不成立（无弹坑、近场液面被卷入，判据 We_j ≪ Lin–Donnelly 阈值）；v2 的"落点向内汇聚"符号对，但它把汇聚放在一个拟合的胞 R_c 里、且画布跟随它；PE 的"整个液面随深度平均置换流走"（A4）对蛋白覆盖液面不成立（§2.10-1）。

### 2.4 筏

- **薄板、膜区**：h/L ≈ 0.05–0.2；筏底是 1 mPa·s 液体，底剪切与筏内伸展应力之比 Λ_m = μ_l L²/(δ η_f h) ≈ 0.01–0.12 ≪ 1 ⇒ 竖向近似塞流，面内是深度积分的 Bingham 膜（冰架 SSA 的同构），**不是**底部无滑移的润滑层。
- **浮力铺展压只作用于筏自身**：深度积分水平力 N = ½ρ_f g′h²，g′ = g(1 − ρ_f/ρ_l) = 6.87 m/s²（不是 ½Δρ g h²，后者大 ρ_l/ρ_f ≈ 3.3 倍）。
- **自选厚度**：h_m = κτ_y/(ρ_f g′)，κ = 4（平面应变）或 2√3（轴对称），τ_y = 2 Pa 时 3.86 / 3.35 mm，与筏的大小无关。画布表面压升高 π̄ 时，正在被供料铺展的筏会更厚：h_π 满足 ½ρ_f g′h² − kτ_y h = π̄ − S_0（π̄ = 5 / 10 / 15 mN/m ⇒ 轴对称 4.4 / 5.2 / 5.8 mm）。
- **刚体性**：远离射流的筏所受拖曳差与屈服之比 Bn_d = ζΔU L/(2τ_y h) ≈ 0.006 ⇒ 塞流，整体平移/转动；等压画布对它只施加各向同性压 π̄，压垮它需要 π̄ > kτ_y h + ½ρ_f g′h² ≈ 21–33 mN/m（h = 3–4 mm），大于画布坍塌余量 ΔΠ_c ≈ 5–15 mN/m ⇒ **画布永远压不坏筏，筏只在被射流足迹直接压到时才屈服**（月牙只在接触后出现，§4.7）。
- **惯性可忽略**：Fr_f = U/√(g′h) ≈ 0.07；水平阿基米德耦合（筏吃水部分受的水平压力梯度恰等于让它与周围液体同加速度所需的力）使筏随液体加减速，PA 的"透镜坡度力 ρ_f g h∇G"就是这一耦合，不是额外推力（§2.10-10）。

### 2.5 画布

- 力学上是一张**无质量的二维可压吸附膜**，经膜下 δ_ν = √(πν t) ≈ 1–3 mm 的粘性层与液体耦合（拖曳系数 ζ = μ_l/δ_ν ≈ 0.3–1 Pa·s/m）。表面压扩散系数 D_Π = E/ζ ≈ 0.01–0.1 m²/s，跨杯 4 cm 的均衡时间 t_Π = L²ζ/E ≈ 0.015–0.18 s ≪ 一段倒奶 1–3 s ⇒ **等压**（引理 L-C，§3.5）。
- 推论：(a) 发散型液体表面流被过滤；(b) 画布的局部面积变化率处处相同，ė_k(t) = (dA_k/dt)/A_k；(c) 嵌在画布中的两块筏之间的褐带**保面积**地随画布运动，只按全杯统一的应变与几何拉伸变窄——**缝生成后保持**；(d) 新液面在 τ_a ≲ 0.03 s 内吸附到平衡（蛋白浓度 1–3%，扩散限制 (Γ/c)²/D_p ≈ 10⁻⁴–3×10⁻² s），因此"新/旧液面"的表面压差只在落点 sub-mm 范围内重要。
- 若测得 E ≲ 2 mN/m（几乎干净的液面），t_Π ≳ 1 s，等压失效，画布退化为"随液体表面流走"——这就是 PE 的可动画布，作为本模型的极限与失败对照保留（§3.5）。

### 2.6 水下储层（"下面有什么"）

- 是喷泉回涌形成的液面下 g_N ≈ 1 cm 厚、半径 r_N ≈ 2–2.5 cm 的稀含气液层，是 PITCHER §14 的 m_sub 与 v2 的 f/f_t 的**物理版本**：有空间分布（ψ(x,t)，气体体积/面积），随 U_N 输运，按受阻 Stokes 速度浮选到液面（通量 j = (ψ/g_N) v_b(ψ/g_N)），未浮选的部分在 r_N 处随下沉液体进入体相。
- 它**不对液面施力**（在等压画布下，膜下发散外流的拖曳被过滤；筏与画布拖曳系数相同时净力为零，§3.5 推论 C3），它只决定"白在何时、何处出现"。

### 2.7 抬缸与高位细切

- **抬缸收流**（Q 15 → 2–5 mL/s，z_s 1.5 → 5–9 cm）：气通量 φ_j Q 降到 1/3–1/7，细柱的卷吸稀释 S 更大，φ_N 降到 ≈ 0.007–0.02（P_s 0.3–0.5，S 5–10）⇒ Kynch 时间 ≈ 2–6 s ≫ 一次切 0.7–1.2 s ⇒ **不再出白**（连续地，不是开关）；面积源消失 ⇒ 冻结；各元素之间是等压画布，没有任何力把它们推到一起 ⇒ **不合并**。
- **高位细流**（Q = 3 mL/s，z_s = 7 cm：v = 1.22 m/s，d = 1.8 mm，½ρ_j v² = 564 Pa）落在筏上：驻点压力远大于筏的抗压入 Δρ_f g h ≈ 23 Pa ⇒ 足迹 r_sub = r_fp √ln(p_0/Δρ_f g h) ≈ 1.6 mm 内的筏被压到水下；其中驻点压力超过奶泡内聚压 Π_coh（200–400 Pa）的核心 r_d ≈ 0.5–0.9 mm 内的奶泡被打散成单泡（3–30 s 才回面），其余成团、在 t_cl ≈ 0.2–0.4 s 后于射流后方回浮。射流以 V_p = 0.3–0.6 D/s 移动：在筏里留下宽 ≈ F_up/V_p ≈ 0.5–2 mm 的新液面槽（**细褐线**）；足迹的塑性区把两侧筏向前、向外推（**V 形、两侧外鼓**）；入口处驻留 ~1 s 吞出一个半径 2.4–4.4 mm 的洞（**凹口**）；出白区后，被推在前面的筏料与延迟回浮的团块沿路径拖出一条长 V_p t_cl ≈ 0.06–0.24 D 的细白带（**茎**）。
- **低位射流落在已有白上**（We_coh = ½ρ_j v²/Π_coh = 0.4–0.8 < 1）：足迹 r_sub ≈ 3.7 mm 内的筏被压下但不被打散，0.07–0.12 s 后在旁边成团回浮 ⇒ **落点被填回、没有褐洞**（heart 4.7–6.7 s）；同时射流带来的气直接并入筏底，**不需要成核延迟**。

### 2.8 杯倾与液位

- 液位：dH/dt = (1 − φ_j)Q/A_cup = 1.5 / 2.2 / 3.0 mm/s（Q = 10 / 15 / 20）；倒 100 mL 升 1.5 cm。锥形杯（壁倾 β_c = 5–10°）液面面积每 100 mL 增加 6.6–13.6%，这部分新面积出现在杯壁处，是画布的一个面积源（释放画布压缩、使图案整体略微外扩）。液位上升使固定嘴高的落差减小（v 降），也使 z_m/H 降低（P_s 升高，后段出白更快，§4.1）。
- 杯倾 θ = 15–25°、1–2.5 s 回正：回正时间 ≫ 晃动周期 0.30 s ⇒ 液面始终水平、液体按第一反对称晃动模准静态重分布。晃动模的表面流是**无旋发散**场，在等压画布下被过滤；画布与筏只经历液面截面从椭圆（长轴 R/cosθ）变回圆的**仿射收缩**，沿倾斜轴缩短 1 − cosθ = 3.4 / 6.0 / 9.4%，**不平移**。低侧 B 处局部液深多 R sinθ = 1.0–1.7 cm（进入内区表的 z_m/H）。（可动画布极限下才会有 0.72 R tanθ coth(k₁₁H) = 0.10–0.17 D 的朝 D 侧漂移——这是区分两种画布的零参数实验，§8 E9。）

### 2.10 对既有假说的取舍（谁错、错在哪里）

## 3. 推导链：三维守恒律 → 命名近似 → 二维方程

### 3.1 三维出发方程（真实多相体系）

相：液体 l（咖啡 + 液奶，不可压，ρ_l、μ_l，牛顿）；分散气泡（体积分数 φ < φ_c，Sauter 半径 R_32）；奶泡（φ ≥ φ_c 的堵塞气泡集合，当作连续介质）；液面吸附层（面浓度 Γ）；空气。

(E1) 气泡液（漂移通量，Ishii）：
  ∇·j = 0，j = (1 − φ)u_l + φu_g；
  ∂_t φ + ∇·(φ u_g) = 0，u_g = j + (1 − φ) v_b(φ) ê_z；
  ρ_l(1 − φ)(∂_t j + j·∇j) = −∇p + ∇·[2μ_m(φ) D(j)] − ρ_l(1 − φ) g ê_z；
  v_b(φ) = v_St (1 − φ)^{n_RZ}，v_St = 2ρ_l g R_32²/(9μ_l)（蛋白覆盖的泡表面不动：刚球 Stokes），n_RZ ≈ 4.65（Richardson–Zaki）。
(E2) 奶泡（φ ≥ φ_c）：ρ_f Du/Dt = ∇·σ_f + ρ_f g，σ_f = −p I + τ；Bingham（Herschel–Bulkley 的 n = 1 情形）：|τ|_vM ≤ τ_y ⇔ D = 0，否则 τ = (τ_y/|D| + 2η_p) D；排液为 Darcy 流 q = −(C_k R_32² ε_l^{3/2}/μ_l)(∇p_l − ρ_l g)（ε_l = 1 − φ，N11 中略去）。τ_y 的 Mason–Bibette–Weitz / Völp–Willenbacher 标度 τ_y ≈ k_y ((σ + 2E_s)/R_32)(φ − φ_c)² 只用作一致性检查，τ_y 本身直接测（§5）。
(E3) 自由液面 z = ζ(x, y, t)：运动学 ∂_t ζ + u·∇_h ζ = w；法向 −p + 2μ_l ∂_z w = −p_atm + σκ；切向（Boussinesq–Scriven，表面粘度略去，N5）μ_l ∂_z u_∥ = ∇_s σ_s = −∇_s Π；吸附层 ∂_t Γ + ∇_s·(Γ u_s) = j_ex(Γ)，Π = Π(Γ)。
(E4) 奶泡–液体界面：速度与应力连续（奶泡的连续相就是同一种液体，界面张力 ≈ 0）；奶泡顶面 σ_f·n = (−p_atm + σ_r κ) n（σ_r 为泡沫顶面宏观张力）。
(E5) 筏缘三相线（筏在画布上的接触线）：单位长度水平力平衡——画布张力 σ_w − Π 向外拉，泡沫顶面张力 σ_r 向内拉，净向外线力 S = S_0 − π，S_0 := σ_w − Π_0 − σ_r，π := Π − Π_0。筏缘下是液体，无接触角滞后、无钉扎。
(E6) 杯壁：液体无滑移、无穿透；漂浮层零法向通量；壁面边界层集总为切向自由滑移（学长约束 4）。
(E7) 入口：落点圆盘上给定混合物通量 Q(t)、速度 v ê_J（与竖直成 α）、气分数 φ_j(t)；奶柱自由飞行由 `pitcher.py` 给出。
(E8) 杯：内轮廓 R(z) = R_b + z tan β_c，倾角 θ(t)（输入），液体体积账本。

守恒量：液体体积、每一气泡群的气体体积、吸附物质量、动量。没有任何"白色物质"——白是"哪里有堵塞奶泡筏"这一相态。

### 3.4 筏：从三维到膜方程

(a1) 薄板竖向静力（误差 O(ε_f²)）：σ_zz = −ρ_f g (s − z)，s 为筏顶面。
(a2) 浮态：ρ_f h = ρ_l d_f（d_f 为吃水），s = ζ + (1 − ρ_f/ρ_l)h，筏底 b_f = ζ − (ρ_f/ρ_l)h。
(a3) 水平动量从 b_f 积到 s，顶面无牵引，底面受液压 p_l = ρ_l g(ζ − z) 与剪切 τ_b。用 tr τ = 0 把竖向偏应力消去后，压力项合并为 −ρ_f g h ∇s = −ρ_f g h ∇ζ − ∇N，
  N(h) = ½ ρ_f g′ h²，g′ = g(1 − ρ_f/ρ_l)
（N 的推导：筏内压 ρ_f g(s − z) 积分得 ½ρ_f g h²，减去液体对吃水部分的反推 ½ρ_l g d_f² = ½(ρ_f²/ρ_l) g h²）。
(a4) 水平阿基米德耦合（N4）：液面坡度项 −ρ_f g h∇ζ 与筏惯性合并为 ρ_f h D(u − u_l)/Dt，后者 O(Fr_f²) ≈ 5×10⁻³，略去。**PA 的透镜坡度力 ρ_f g h∇G 即此项，它只让筏随液面同加速度，不提供相对推力。**
(a5) 底剪切：τ_b = ζ(U_l − u)，ζ = μ_l/δ_ν，δ_ν = √(πν_l t_rel)（Rayleigh 第一问题；t_rel 为相对运动开始以来的时间，取 0.3–3 s 得 ζ = 1.0–0.33 Pa·s/m）。
(a6) 射流足迹载荷（N3、N4 的失效区，§3.9）：f_J = −h ∇p_J。

得到筏内（c = 1）的准静态面内力平衡：
  ∇·[h R(u)] − ∇N(h) + ζ(U_l^σ − u) + f_J = 0，                                                       (R1)
  R(u) = 2η_eff [D(u) + (tr D(u)) I]，η_eff = η_p + τ_y/(2|D|_e)，|D|_e² = D_xx² + D_yy² + D_xx D_yy + D_xy²，
未屈服处（由 R 重构的三维 von Mises 偏应力 ≤ τ_y）D = 0（精确塞流，不正则化）。U_l^σ 只取液体表面流的无散部分（推论 C3）。

筏缘（∂R，n 由筏指向画布）的线力条件：
  [h R(u) − N(h) I]·n = (S_0 − π) n。                                                                  (R2)

**引理 L-R1（止停厚度与画布压的作用）**。无射流时，筏缘处于屈服极限 h R_nn = ±kτ_y h（k = 2 平面应变，k = √3 轴对称均匀扩张）。由 (R2)：
- 筏**向外铺展**当且仅当 N(h) + S_0 − π > kτ_y h，即 h > h_π，
  h_π = [kτ_y + √(k²τ_y² + 2ρ_f g′(π − S_0))]/(ρ_f g′)；π = S_0 时 h_m = 2kτ_y/(ρ_f g′) = κτ_y/(ρ_f g′)，κ ∈ {4, 2√3}。
  τ_y = 2 Pa：h_m = 3.86 mm（平面应变）/ 3.35 mm（轴对称）；π − S_0 = 5 / 10 / 15 mN/m 时轴对称 h_π = 4.44 / 5.20 / 5.83 mm。与筏半径无关（对比润滑式 ∝ √R）。
- 筏**被压屈服（增厚）**当且仅当 π − S_0 > kτ_y h + N(h) =: P_y(h)；h = 3 / 4 mm 时 P_y = 21 / 33 mN/m（k = 2）。
- 静止筏存在的必要条件：S_0 ≤ s_c = k²τ_y²/(2ρ_f g′) = 3.9 mN/m（k = 2，τ_y = 2 Pa）（PB 的 L1；若测得 S_0 > s_c，任何筏都会被画布拉成薄膜——可证伪）。
- 处于 h_m 的筏对**额外外拉**线力的余量为零（PB 的"零余量"）；新生液面若表面压偏低会把筏缘拉开。

推论：(i) 白盘以"多少奶泡体积就铺多大面积"的方式长大，厚度 h_π ≥ h_m，不是重力流（自由重力流前缘 √(g′h) = 0.15 m/s = 1.9 D/s，0.3 s 到杯壁，被 Bn_m ≥ 1 排除）；(ii) 画布表面压 π̄ ≤ ΔΠ_c ≈ 5–15 mN/m < P_y，**画布压不坏筏**；(iii) 条纹存活：宽 w ≫ h 的条纹自持 ⇔ h ≤ h_m ⇔ τ_y ≥ ρ_f g′h/(2k) = 1.0 / 1.6 Pa（h = 2 / 3 mm，k = 2），与 w 基本无关；w ~ h 时截面坍塌判据 h ≲ cτ_y/(ρ_f g)，c = O(2–4)，同量级。

筏体积（奶泡体积）守恒（K2）见 §3.11。

### 3.5 画布：吸附膜的力学与等压引理

膜无质量，(E3) 的切向条件在膜下粘性层上写成膜的力平衡：
  ∇π = ζ (U_l − u)  ⇔  u = U_l − ∇π/ζ  （"Darcy 膜"，迁移率 1/ζ = δ_ν/μ_l）。                          (C1)
吸附层守恒线性化（ε := (Γ − Γ_0)/Γ_0 为面压缩应变）：
  ∂_t ε + u·∇ε = −∇·u − ε/τ_±，  τ_+ = τ_d（ε > 0，压缩 → 慢脱附），τ_− = τ_a（ε < 0，新生/拉伸 → 快吸附），  (C2)
本构（弹性 + 坍塌平台；坍塌的超额物质记入 Γ_coll 账本）：
  π = W′(ε)，W(ε) = ½Eε²（ε ≤ ε_c），W(ε) = ½Eε_c² + ΔΠ_c (ε − ε_c)（ε > ε_c），ε_c = ΔΠ_c/E。           (C3)
(C1)–(C3) 合并（弹性支）得表面压扩散方程（PB 的 (C5)）：
  ∂_t π − (E/ζ) ∇²π = −E ∇·U_l − π/τ_±，  D_Π = E/ζ。                                               (C4)

**引理 L-C（等压画布）**。设 t_Π = L²ζ/E ≪ t_p（源项的时间尺度）。则在每个画布连通区 C_k 上：
  π = π̄_k(t) + O(t_Π/t_p)，  ∇·u = ė_k(t) + σ_A(x, t)，                                               (C5)
σ_A 为内区给出的局部面积源密度（回涌环 +，吞汇 −，§3.7 M1–M2），ė_k 为膜物质的均匀面应变率；u 的 Helmholtz 分解为 u = U_l^σ + ∇φ_k，∇²φ_k = ė_k + σ_A，∂_nφ_k 由边界（筏缘、杯壁）的法向速度给出；π̄_k 满足
  dπ̄_k/dt = −E ė_k − π̄_k/τ_d（π̄_k ≤ ΔΠ_c，超出部分为坍塌）。
证明要点：(C4) 中 π 的空间起伏以 t_Π 衰减；剩余梯度 ∇π = ζ(U_l − u) 对应的应变扰动 ζ U L/E = 0.4%（U = 5 mm/s，L = 4 cm，E = 30 mN/m），即膜的局部应变在 0.4% 内均匀，散度均匀。数值：E = 5 / 10 / 30 / 60 mN/m 时 t_Π = 0.18 / 0.09 / 0.030 / 0.015 s（ζ = 0.57 Pa·s/m）。

推论：
- **C1（过滤）**：U_l 的发散部分——体积置换流 Q/(2πrH)、储层外流 U_N、杯尺度子午环流、晃动模——不移动画布；只有 U_l 的无散部分 U_l^σ（液面的垂直涡量）与面积源移动画布。
- **C2（保面积）**：任何一条画布物质带的面积只按全区统一因子 exp∫ė_k dt 变化；夹在两块筏之间的褐带随画布平移，宽度只因 (i) 全区统一压缩、(ii) 外移时被几何拉长而变窄——**缝生成后保持**。
- **C3（嵌入筏不受发散底流的净力）**：设筏底与画布的拖曳系数相同（ζ_R = ζ_C = μ_l/δ_ν）。发散底流 U_l^d 在画布中由压力梯度 ∇π = ζ(U_l^d − u) 平衡；该压力作用在筏缘上的合力 −∮π n dl = −∫_R ∇π̃ dA（π̃ 为把画布压力解析延拓进筏的场）恰抵消同一底流对筏底的拖曳 ∫_R ζ U_l^d dA，净力为 O(ζ_R − ζ_C)。故储层外流 U_N（3–12 cm/s）不推筏。
- **C4（压力只起各向同性作用）**：π̄_k 经 (R2) 以各向同性压作用于所有筏缘：使供料铺展的筏变厚到 h_π，从不压坏筏（π̄ ≤ ΔΠ_c < P_y）。
- **可动极限**：E → 0（或 t_Π ≫ t_p）时 π → 0、u = U_l：画布随液体表面流走，U_l 在 r ≳ H/2 处为深度平均置换势流（PE 的 R2：∇²Φ = Σ_j (Q_j/δ_{o,j}) δ(x − x_j) − λ，δ_o = min(H, z_m)）。这一极限保留为失败对照（§9）；中间情形解完整的 (C4)。

**画布表面流的来源、记忆与壁面（逐项）**：
1. *射流动量*：竖直动量通量 M = ρ_j Q v（4–11 mN）驱动喷泉（内区）与杯尺度子午环流；后者在液面的迹是发散型，被 C1 过滤（这正是物理评审对 PE 的批评——"可动液面会被子午环流污染"——在等压画布中不成立的原因）。水平动量 M_h = ρ_j Q u_h（u_h 为落面时相对液体的水平速度，含壶速，≈ 0.05–0.15 m/s ⇒ ~1 mN）产生垂直涡量，进入 U_l^σ（M6，系数 η_h 待测）。
2. *回流*：回涌环的新液面面积源 σ_A^+（M2，延迟 t_r）与吞汇 σ_A^−（M1）；膜下的储层外流 U_N 只输运气体，不移动画布（C1、C3）。
3. *记忆与衰减*：近场对入口历史的响应是延迟卷积 ∫p_t(s)(…)(t − s) ds（起笔后 t_r 才出现回涌，停倒后回涌再持续 ~t_r）；储层在停倒后以 g_N/v_b ≈ 2–4 s 排空；画布应变以 τ_d 松弛；体相环流 206 s 衰减但被膜过滤。**没有 β**：停倒后漂浮层的精确静止来自 (V) 的屈服 + 等压结构，而不是拖曳衰减（B8 所缺的记忆由卷积提供，A5/β 的"冻结"由屈服提供）。
4. *壁面*：u·n = w_∂Ω·n、切向自由；锥形杯液位上升在壁处产生面积源；杯倾回正为域的仿射变化（§3.13）。

**引理 L-A（面积守恒运动学的解析形式）**。等压画布中，若筏为刚体、面积源为点源 S_A(t) 位于 ξ，则画布与筏的位移场就是圆盘 Neumann Green 函数
  u(x) = S_A [ (x − ξ)/|x − ξ|² + (x − ξ*)/|x − ξ*|² − x/R² ]/(2π)，ξ* = ξR²/|ξ|²（镜像点），
外加 U_l^σ。它与 PE 的置换势流**形式完全相同**，区别只在源强：等压画布中 S_A = 筏的侧向铺展面积速率 + F_net（内区净面积通量），白出现之前 S_A ≈ F_net ≈ 0；可动画布中 S_A = Q/δ_o 从倒奶开始就存在。**PE 的解析骨架因此原样保留**，作为等压画布在"刚体筏 + 点源"下的精确解与单元测试。

### 3.6 漂浮层速度：每一步一个凸极小问题

把 (R1)、(R2)、(C1)–(C5) 写成弱形式，漂浮层速度 u 与各画布区应变率 ė_k 是下列凸泛函的唯一极小（PD 的变分框架，画布项换为 L-C 的等压膜）：

  J[u, ė] = ∫_Ω c [2hτ_y|D(u)|_e + 2hη_p|D(u)|_e² − N(h)∇·u] dA
          + ∫_Ω ½ζ|u − U_l^σ|² dA
          + Σ_k (A_k/Δt) W(ε_k^n − Δt ė_k)
          − ∫_Ω f_J·u dA − S_0 ∮_∂R u·n dl，                                                         (V)
约束：(1 − c)(∇·u − ė_k − σ_A) = 0（画布区 C_k 内）；u·n = w_∂Ω·n（杯壁，w_∂Ω 为液面域边界的运动：锥形杯液位上升、杯倾回正）。

性质：
1. **凸且强制**：屈服项 1-齐次凸，拖曳项严格凸，W 凸，其余线性，约束线性 ⇒ 解唯一。约束的拉格朗日乘子就是画布表面压场 π(x)，其区平均 = W′(ε_k^{n+1})。
2. **精确塞流**：未屈服区 D = 0 由增广拉格朗日（ALG2）精确求出，不用 ε 正则化（对比 B9（未单独复核，`code_map.md` §3 实算）：v2 的 τ̂/ε = 36 ≫ ν_max 使屈服失效）。
3. **精确冻结**：若 f_J = 0、σ_A = 0、U_l^σ = 0、各筏缘 N(h) + S_0 − π̄ ≤ kτ_y h（筏不超厚）且 ε 已平衡，则 u ≡ 0 满足极小的次梯度条件——**停倒后图案精确静止**，不是以 β 指数衰减。
4. **两个极限**：W ≡ 0 且去掉约束 ⇒ 画布 u = U_l（PE 可动极限，U_l 取完整液体表面流）；τ_y → ∞ ⇒ 筏为刚体（PE 的连通分量刚体投影，每块筏 3 个自由度）。
5. **局部性**：远离射流、筏不超厚、无面积源的区域解为 u = 0 或刚体运动；只需在射流近场与超厚筏处解完整问题（§7 的活动窗口）。

### 3.8 储层、浮选、Kynch 层与成核：首白延迟的推导

储层气体（K5，对 (E1) 在外流层厚度上积分，漂移通量）：
  ∂_t ψ + ∇·(ψ U_N) = σ_ψ − j − d_N ψ，  j = (ψ/g_N) v_b(ψ/g_N)，  d_N = max(0, −Φ)/(r_N² g_N)（M4 中 Φ ≤ 0，−Φ/r_N² 是外流层的下沉通量：漏到体相 → G_B）。      (K5)
到达液面的浮选通量 j 在画布处进入 Kynch 层，在筏处直接并入筏底：
  ∂_t B + ∇·(B u) = (1 − c)(j + j_B) − 成核 − 吞汇移除 − 筏缘扫入，                                    (K3)
  j_B = φ_B v_b(φ_B)（体相分散气的缓慢均匀浮出，使画布逐渐变浅，10 s 内远达不到成核）。
**Kynch 激波**：到达液面的泡在膜下堆成 φ_J 的层，其下沿以 φ_N v_b/(φ_J − φ_N) 向下推进（静止堵塞层通量为零的跳跃条件），φ_N = ψ/g_N。
**成核（相变，c 的唯一产生方式）**：画布上 b ≥ b_* := φ_J h_* 处该点由画布相变为筏相，h_* = z_e（奶泡漫反射外推长度，反射率 R = h/(h + z_e) 的半饱和厚度）。新筏厚 h = b_*/φ_f ≈ 0.27 mm，之后由浮选并入增厚。h_* 同时是力学上的连贯厚度（3–6 层 90 µm 泡 = 0.27–0.54 mm），光学与力学阈值同源（PC）。
**首白延迟（导出，非参数）**：
  t_w = t_r + t_K，  t_K = h_* (φ_J − φ_N)/(φ_N v_b(φ_N))，  φ_N = P_s φ_j/(1 + S)。

视频 0.9–2.1 s（中位 1.3 s）落在 R_32 = 35–60 µm 的带内。
**延迟随撞击速度连续变化（替代 χ 开关）**：t_r ∝ T_f = v/(φ_j g) ∝ v；回涌稀释 S ≈ (1–2)α z_m/r₀ ∝ Fr₀ 随 v 增大（低位 1.6–3，细柱 r₀ 小、S ≈ 5–10），φ_N = P_s φ_j/(1 + S) 随之下降，t_K ∝ 1/φ_N 上升；z_m/H 超过 1 后 P_s 下降。所以 t_w(v, Q, H) 随落差单调增大、随流量与液深减小，到高位细流（φ_N ≈ 0.007–0.02）时 t_K ≈ 2–6 s 已超过一次切的持续时间——"出白/不出白"是同一条连续曲线的两端，没有阈值参数。
依赖关系（全部可证伪）：t_K ∝ μ_l/(R_32² φ_N)——**泡越细延迟越长**；φ_N 随稀释 S 增大而降、随 P_s（液位升高 ⇒ z_m/H 降低）而升——**后段比前段出白快**；高位细流 φ_N ≈ 0.007–0.02 ⇒ t_K ≈ 2–6 s ≫ 切的 0.7–1.2 s ⇒ **不出白**。
**白的位置**：j 在回涌环附近最大（ψ 最浓、到得最早）；r < r_e 内的 Kynch 层被向内的表面流带进吞汇（M1）——**落点保持褐洞**；成核首先在 r ≳ r_e 的下游扇区——**白以 C 形环出现、开口朝壶**。
**ψ 的径向分布是一个硬约束**：若外流层厚 g_N 与气分数 φ_N 在 r_N 内近似均匀，j 也近似均匀，整个 r_N ≈ 2–2.5 cm 的圆盘会在首白后 ~π g_N r_N²/Q_r ≈ 0.3–0.4 s 内几乎同时变白——与视频"先一个 0.1 D 小斑、再以 ~0.1 D/s 长大"矛盾。所以视频要求 φ_N 随 r 衰减：外流层像径向壁射流一样从下方卷吸清液而增厚（g_N(r) ∝ r 时 φ_N ∝ r_e/r，t_K(r) ≈ t_K(r_e) r/r_e），Kynch 阈值等值线以 dr_w/dt ≈ r_e/t_K(r_e) ≈ 3 mm/0.6 s ≈ 0.06 D/s 外推。早期白盘因此有两个并存的增长来源——**成核前沿外推**与**供给铺展**（§4.5），其比例由内区输出 g_N(r)、φ_N(r) 决定（E3 侧拍染色测量），M4 中的 g_N 应按 g_N(r) 取用。
**并入（"收集器"的物理形式）**：已有筏覆盖处 c > 0 的浮选通量 c j/φ_f 直接成为筏体积；筏缘前进扫过画布时，被覆盖面积上的 B 并入筏体积（B/φ_f）。因此**落在已有白上或白边上的倒奶没有成核延迟**，而落在褐面上的每一段新起笔都要重新经历 t_w——这是 PE 收集器规则的导出版本，与网格无关。

### 3.9 射流对已有奶泡：驻点压力、压入、内聚与回浮

足迹压力 p_J(r) = p_0 exp(−r²/r_fp²)，p_0 = ½ρ_j v²，r_fp = d/2。
- **侧推**：作用于筏的深度积分水平力密度 f_J = −h∇p_J；沿半径积分的线力 ≈ p_0 h = 0.53 N/m（低位）/ 1.9 N/m（细流），≫ 屈服线力 2τ_y h ≈ 13 mN/m ⇒ **足迹接触的筏局部屈服**（塑性区 r_pl ≈ 1.7 mm（细流）至 r_sub）。
- **压入**：p_J > Δρ_f g h（≈ 23 Pa，h = 3.35 mm）处筏被压到水下：r_sub = r_fp √ln(p_0/(Δρ_f g h)) = 3.7 mm（Q 15，z_s 1.5）、4.4 mm（Q 20，z_s 2）、1.6 mm（细流 Q 3，z_s 7）、2.0 mm（Q 5，z_s 9）。压入作为快汇（时间常数 r_sub/v ~ ms，指数积分）从 c、V_f 中移除。
- **内聚判据**：压入奶泡被打散成单泡需要驻点压力超过内聚压 Π_coh（理论界：平衡渗透压 Π_osm ≈ (σ/R_32)φ_f²(φ_f − φ_c) ≈ 30–130 Pa 为下界——~10 ms 的压力脉冲来不及让液体渗入 Plateau 网络，故偏低；单泡毛细压 2σ/R_32 ≈ 2000 Pa 为上界）。打散半径 r_d = r_fp √ln(p_0/Π_coh)（p_0 ≤ Π_coh 时为 0），打散份额 f_disp = (r_d/r_sub)²：低位 0（Π_coh ≥ 200 Pa）；细流 Q 3 / z_s 7 时 0.11–0.32，Q 5 / z_s 9 时 0.17–0.37（Π_coh 400…200 Pa）。**这是一个由足迹压力分布导出的连续函数，不是开关。**
- **回浮**：未打散的压入奶泡在 t_cl 后于回涌环（及射流后方的历史路径上）回到液面，作为筏体积源 s_cl（落在画布上时以 h_m 厚度成筏、落在筏上时并入）；打散部分进入 G_B（3–30 s 才回面，只调浅画布）。
- 后果：**低位倒在白上**——压入的奶泡 0.07–0.12 s 内就地回浮，落点被填回、不留褐洞（heart 4.7–6.7 s）；**高位细流切**——核心被打散、留下新液面槽，其余在后方 t_cl 后回浮成茎与部分愈合。

### 3.10 移动射流：尾迹律、切、摆动褐线

M1 与 M2 的卷积在射流移动时自然给出（不需要任何开关）：
- 落点速度 V_j 满足 V_j t_r ≪ r_e：回涌落回当前吞汇附近，闭合表面涡，无尾迹。
- V_j t_r ≫ r_e：延迟 t_r 的回涌落在射流**已经离开**的路径上，产生宽
  w_tr = F_up/V_j                                                                                     (T1)
的新液面带（PE 的移动源线宽律在等压画布中的形式：源强由 Q/δ_o 换成内区的 F_up；也是 PC 的移动汇捕获宽 Q_A/V_j，因为定点时 F_up ≈ F_c）。
- **细切线宽**：w_line ≈ F_up/V_p + (打散核未被回浮填回的部分)；F_up = 0.25–0.5 cm²/s、V_p = 0.3–0.6 D/s ⇒ 0.5–2.1 mm = 0.007–0.026 D（§4.4）。新液面在 τ_a ≲ 0.03 s 内吸附，两侧筏的 Marangoni 收拢（PB 的槽愈合）只是 ≤ 2 倍的次级修正。
- **摆动褐线**：横向速度 4af ≈ 8.8 cm/s（a = 0.8 cm，f = 2.75 Hz），每次扫过留下 b_line = F_up/(4af)（§4.6）。
- **凹口**：切前在入口驻留 t_dwell ≈ 0.7–1.2 s，吞汇 + 打散在筏缘吃出面积 ≈ F t_dwell 的洞（半径 2.4–4.4 mm = 0.03–0.055 D）。
- **V 形与茎**：移动足迹的塑性区把前方筏料向前、向两侧推（条纹被拉成指向运动方向的 V，两侧外鼓 ≈ r_sub…2r_sub）；吞汇使两侧液面向路径汇聚（Rankine 半体）；未打散的压入奶泡在后方 t_cl 后回浮，出白区后沿路径留下长 ≈ V_p t_cl 的细白带——**茎**。

### 3.11 覆盖运动学与相体积守恒（锐界面）

全部写成守恒形式，由同一组几何面通量输运（§7）：
  (K1) ∂_t c + ∇·(c u) − c∇·u = Ṡ_nuc − Ṡ_sub + Ṡ_cl,R − Ṡ_rup（几何 VOF：c 是物质相标记，界面以 u 运动，无扩散项）；
  (K2) ∂_t V_f + ∇·(V_f u) = c(j + j_B)/φ_f + (成核转入 b_*/φ_f) + (筏缘扫入 B/φ_f) − (压入) + (团块回浮)；
  (K3) 见 §3.8；
  (K4) ∂_t[(1 − c)ε] + ∇·[(1 − c)ε u] = (1 − c)(−∇·u − ε/τ_±)（非等压情形；等压时为每区一个 ODE，§3.5）；
  (K5) 见 §3.8。
相变项成对记账：成核把画布面积 + B 转为筏面积 + V_f；破裂（筏被拉薄到 h < h_* 时，Ṡ_rup）反向；压入把筏转为水下团块/单泡；回浮反向。**没有扩散、没有裁剪、没有归一化。**

### 3.12 白度：由光学饱和导出的有界组分 c

- 定义：c(x,t) = 液面被"光学厚奶泡相"（h ≥ h_* = z_e）占据的面积分数。
- 光学根据：多重散射的漫反射 R(h) = h/(h + z_e)，z_e ≈ 0.7 l* ≈ 0.25–0.35 mm。筏一经形成就被并入推到 h ≈ h_m–h_π ≈ 3.4–5.8 mm，R = 0.92–0.95（饱和白）；画布 b/φ_J < z_e，R < 0.5（褐/浅褐）。所以 c = 1/0 与光学一致，误差只在筏从 h_* 长到 ~1 mm 的 0.5–1 s 内、位于新元素内缘。
- 这**不是**厚度→alpha：c 是相标记，只由输运与相变改变；同一 c 不因 h、ψ、ε 改变外观（学长 §5 "保持 c 不变、只改变 ℓ 不应无故变白"）。
- 学长接口映射：ℓ ≡ 1，milk ≡ c，q ≡ u，cell_area 照旧；0 ≤ m ≤ ℓ 自动成立。旧账本 d/dt∫(ℓ − m) = 0（褐面积守恒）被 §3.15 的显式账本取代——褐面积确实会被筏的铺展、吞汇与坍塌改变，这是物理（学长 §7-1 允许新增状态，只要显式入账）。物理快照（h、B、ε、ψ）另行导出给诊断显示。
- 第二组分 c₂ = B/b_* ∈ [0,1)（画布被体相小泡调浅）默认关闭，需学长同意。

### 3.13 液位、杯形与杯倾

- 液位：V_cup(ζ) = V_l + G_sub + (ρ_f/ρ_l)∫V_f dA，V_l = V_l(0) + ∫(1 − φ_j)Q dt，G_sub = 水下全部气体（射流缓冲 + ∫ψ + G_B + 膜下 B）。由杯形 R(z) 唯一解出 ζ(t) 与 A_cup(t)。dH/dt ≈ (1 − φ_j)Q/A_cup = 1.5–3.0 mm/s。
- 锥形杯：dA_cup/dt = 2πR tan β_c dζ/dt；新面积出现在杯壁，是画布区的面积源（杯壁边界 w_∂Ω·n = tan β_c dζ/dt），释放画布应变。
- 杯倾（输入 θ(t)）：液面恒水平，二维域 Ω(t) = 倾斜杯在液位处的水平截面（椭圆，沿倾斜轴半轴 R/cosθ）；局部液深 H(x) = H_c + (x·ê_t) tanθ 进入内区表（z_m/H(x_j)）。回正时域边界法向速度给出 w_∂Ω；在等压画布中解为仿射收缩，沿倾斜轴缩短 1 − cosθ。可动极限下另有晃动模漂移 0.72 R tanθ coth(k₁₁H)（k₁₁ = 1.841/R）。

### 3.14 边界条件与初始条件

- 杯壁：u·n = w_∂Ω·n，切向自由（学长约束 4）；c、V_f、B、ε 零法向通量；筏不能穿壁（在 (V) 中为约束）。
- 筏缘：(R2) 是 (V) 的自然边界条件，不需另加。
- 吞汇与压入：体内汇，不是边界条件。
- 初始：c = 0，V_f = 0，B = B₀（可为 0），ε = 0，ψ = 0，u = 0，H = H₀，θ = θ(0)；再注奶从已有状态继续（学长约束 3）。

### 3.15 账本（逐步、到机器精度）

- **液体**：V_l(t) = V_l(0) + ∫(1 − φ_j)Q dt；筏内 Plateau 边界液 (1 − φ_f)∫V_f 从杯液中单列。
- **气体**（射流是唯一的源，绘制期无破泡汇）：
  ∫φ_j Q dt + G₀ = G_jet + ∫ψ dA + ∫B dA + φ_f ∫V_f dA + G_B + G_coll,sub；
  每个转移（回涌、浮选、漏层、成核、并入、吞汇再卷吸、压入、打散、回浮）在两边以同一数值出现。
- **筏奶泡体积**：d/dt∫V_f = ∫[c(j + j_B) + 筏缘扫入]/φ_f + 成核 − 压入 + 回浮 − 破裂。
- **面积恒等式**：∫c dA + ∫(1 − c) dA = A_cup(t)；∫σ_A dA = F_up − F_c；画布膜物质：产生（回涌）、消灭（吞汇、坍塌 Γ_coll、成核时成为筏顶面）、弛豫（τ_d、τ_a）全部入账。
- **禁止**：对 c、V_f、B、ψ、ε 做任何"接受错误状态"的裁剪；数值裁剪若发生必须记账，并在验收中为零。

### 4.1 V1：首白延迟、白环、褐洞、C 形

- **延迟**：t_r（喷泉回涌）+ t_K（Kynch 层长到 h_*）。§3.8 表：R_32 = 45 µm、P_s = 1 → 0.99–1.39 s；P_s = 0.6 → 1.27–1.66 s；R_32 = 35–60 µm 覆盖 0.73–2.23 s。视频 0.9–2.1 s。没有任何时间常数是拟合的：t_r ∝ v/(φ_j g)，t_K ∝ μ_l h_*/(R_32² φ_N)。
- **为什么是环、落点为什么褐**：r < r_e 内液面向射流流动（闭合表面涡），浮上来的泡与薄层被吞回；成核只在 r ≳ r_e 的静止画布下发生。褐洞直径 2r_e = (1–2)d = 5.4–10.8 mm = 0.07–0.13 D（视频 0.05–0.12 D；heart 起笔帧白紧贴奶柱脚、褐核 0.05–0.08 D，取 r_e ≈ 0.5 d 一端）。
- **C 形开口朝壶、远侧先亮**：奶柱倾角 α ≈ 5–12° 使回涌环向下游偏 Δ_e ≈ α z_turn ≈ 0.4–0.9 cm ≈ r_e，上游扇区落入吞汇 ⇒ C 开口朝壶（heart 1.47 s "brighter on the side away from the spout"）。
- **倒在白上没有延迟**：筏底并入（§3.8），heart 4.7–6.7 s 壶移入盘内时褐芯被填回（低位 We_coh = 0.52 < 1：压入的奶泡 0.07–0.12 s 内就地回浮）。
- **后段更快**：液位每段升 0.5–1 cm ⇒ z_m/H 降低 ⇒ P_s 升高 ⇒ φ_N 升高 ⇒ t_K 缩短（推心 2.1 → 1.2 → 1.2 s 方向一致）。第一段特别慢还可能来自壶起倒时 φ_j(t) 偏低（PB 的 D1）——由 E1 的"第一秒单独接奶称重"判定（§6-7）。
- **停流留缺口**：停倒后吞汇消失，储层剩余气继续浮选 1–3 s，只部分补白，留下小褐咬口（push_heart 5.6 s）。

### 4.2 V2：界面锐利并长期保持

1. c 是物质相标记，(K1) 没有扩散项；数值上几何 VOF 保持 1–2 格界面（§7）。
2. 远离射流的筏 Bn_d = 0.006 ⇒ 刚体平移，不被剪糊；画布等压 ⇒ 相邻两块筏之间没有净力（C3、C4），褐带只按全区统一应变变窄（C2）。
3. 停倒后 (V) 的解精确为 0：没有残余输运、没有回弹（体相环流 206 s 衰减，但被膜过滤）。
4. 物理界面宽度：泡径 2R_32 ≈ 0.09 mm；筏缘弯月面 l_c = 2.1 mm 只改变高度剖面，不移动"有泡/无泡"的边界。⇒ ≤ 0.01 D 保持远超 10 s；排液在 1–3 min 后才改变边缘（N11）。
5. 条纹存活条件 τ_y ≥ ρ_f g′h/(2k) = 1.0–1.6 Pa（h = 2–3 mm）："奶太湿不出层次"（τ_y < 1 Pa）是可证伪推论。

### 4.3 V3：杯壁褐环与白占比

总白面积 = Σ_段 ∫F_white φ_j Q dt/(φ_f h) − 压入损失；筏永远不会被画布压坏、画布也不会被消耗到零（它是液面），图案越大，画布被均匀压缩越多（π̄ → ΔΠ_c 后坍塌）。杯壁 u·n = 0，面积源引起的位移 ∝ (R² − r²)/r 在壁处为零。居中圆形图案的褐环宽 R(1 − √f_w) = 0.18 / 0.26 D（f_w = 0.42 / 0.23）。视频 0.10–0.25 D；不居中的图案（心形尖端靠壁）一侧更窄。**白到不了壁不需要任何"壁上特殊物质"**；预测：奶泡量加倍时褐环按面积律变窄。

### 4.4 V4：高位细流切

- **不出白**：细流 φ_N ≈ 0.007–0.02、t_K ≈ 2–6 s ≫ 切的 0.7–1.2 s（§3.8）。
- **凹口**：切前在 B 侧驻留 0.7–1.2 s（heart 6.8–8.0 s），吞汇（F 0.25–0.5 cm²/s）+ 打散核吃出面积 0.17–0.60 cm² ⇒ 半径 2.4–4.4 mm = 0.030–0.055 D（视频 ~0.05 D）。
- **细褐线**：尾迹律 w = F_up/V_p，F_up = 0.25 / 0.35 / 0.5 cm²/s、V_p = 0.3–0.6 D/s ⇒ 0.52–2.08 mm = 0.007–0.026 D（视频 ≤ 0.01–0.02 D）。**快切更细**（∝ 1/V_p）、**更高的细流线更宽**（打散核 r_d 随 p_0 增大：Q 3/z_s 7 时 0.5–0.9 mm，Q 5/z_s 9 时 0.8–1.2 mm）——两个可在现有视频上检验的依赖。
- **V 形与两侧外鼓**：足迹线力 1.9 N/m ≫ 2τ_y h = 13 mN/m，塑性区 r_pl ≈ 1.7 mm–r_sub 内的筏被向前、向外推；吞汇使两侧液面向路径汇聚（Rankine 半体）⇒ 条纹被拉成指向 D 的 V；外鼓 ≈ r_sub–2r_sub = 1.6–3.2 mm = 0.02–0.04 D（视频 ~0.05 D，偏小 ≤ 2 倍：压入体积的侧向塑性堆积未计入）。
- **茎**：未打散的压入奶泡（细流 68–89%）在后方 t_cl ≈ 0.2–0.4 s 后回浮；射流离开白区后仍以 V_p 前进，回浮沿路径延伸 V_p t_cl = 0.06–0.24 D（视频 0.1–0.2 D），宽 ~2r_sub 被吞汇汇聚到 ≈ 1–2 mm（0.01–0.02 D）。供料终止 ⇒ 茎尖锐利、不成球（筏不自铺，Bn_m ≥ 1）。
- **白面积判据（可证伪）**：切只"分开 + 压入 + 部分回浮"，切前后白面积减少 ≈ f_disp × 2r_sub × 路径长 ≈ 0.1–0.3 cm²（白区的 1–2%）。

### 4.5 V5：白盘生长、停倒即停、远端不动

- **生长律**：dA/dt = F_white φ_j Q/(φ_f h)，F_white = P_s f_loc，h = h_π。Hazen 单程估计 f_loc = Hz/(1 + Hz)，Hz = v_b π r_N²/Q_r：R_32 = 45 µm、r_N = 2.0 / 2.5 cm ⇒ 0.083 / 0.125；60 µm ⇒ 0.14 / 0.20。Q = 15 mL/s、h = 3.35 mm 时 F_white = 0.1 / 0.2 / 0.3 ⇒ 1.60 / 3.20 / 4.80 cm²/s。视频 heart 2.3 → 6.7 s 直径 0.3 → 0.65 D：(21.2 − 4.5) cm²/4.4 s = 3.80 cm²/s，需要 F_white ≈ 0.24。**这是本模型偏差最大的一处**：单程 Hazen 低 1.2–3 倍，可能来源 (i) Q 实际 > 15 mL/s（单目不可测，16× 歧义），(ii) 近场胞的闭合回流使气多次经过浮选区（多程捕获），(iii) R_32 偏大。按规矩它不被调：E1（杯放秤上读 Q + 侧拍 h）直接给出 F_white = φ_f h (dA/dt)/(φ_j Q)，再与 Hazen 比较。
- **面积线性、半径 √t**：边缘速度 dR/dt = (dA/dt)/(2πR) = 0.105 / 0.063 / 0.038 D/s（R = 0.09 / 0.15 / 0.25 D），视频"~0.1 D/s，之后变慢（0.04 D/s）"✓。对照：自由重力流 A ∝ t^{3/2}、前缘 1.9 D/s，0.3 s 到壁，与视频差 20–40 倍。
- **停倒即停**：面积源只剩储层残余气的浮选（停倒时储层内 ~1.1 mL 气，局部浮出 30% ⇒ +1.4 cm²，量级 0.5–1.5 cm²），1–3 s 内结束，然后 u ≡ 0。可证伪：停倒后白区面积再增 5–15%，之后精确不变。
- **远端不动、壶侧生长**：生长由并入和超厚筏铺展提供，发生在射流附近；远处位移按 L-A：2 s、3.8 cm²/s 的源使离 B 0.48 D 的点移 0.041 D。

### 4.6 V6、V8、V9：摆动、前推回包、后退人字

- **一弧一个（半）周期**：壶嘴横向速度 4af ≈ 8.8 cm/s ≫ 筏的铺展/漂移速度（≤ 1.3 cm/s），每次横扫沿回涌环的下游半环（C 形）铺一条弧 ⇒ **弧凸离壶**（C 形的几何直接给出，不需要额外机制）。
- **间距（面积律）**：弧堆相对源的后退速度 U_rel = (dA/dt)/L_s + u_p。dA/dt = 2.6–3.8 cm²/s、L_s = 3–4 cm ⇒ U_rel = 0.08–0.16 D/s（视频千层心堆栈 0.35 D/2.9 s = 0.12 D/s ✓）。半周期间距 U_rel/(2f) = 0.015–0.029 D；若两个半周期的弧在中线相接（视频 2.9 s 内计 6–8 弧 ≈ 2.75 Hz × 2.9 s = 8 个周期，即每周期一弧），间距 U_rel/f = 0.030–0.058 D。视频近源 0.04 D、远侧 0.025 D ✓。
- **远侧更密**：外移的弧带保面积（C2）并经历 1/r 几何拉伸与全区统一压缩：两倍远处间距约减半；刚体弧不被压缩，压缩全部由弧间褐线吸收——预测：最外侧几条褐线先闭合、弧合并。
- **褐线宽**：每次横扫的尾迹 b_line = F_up/(4af)：F_up = 0.25 / 0.5 / 1.0 / 1.5 cm²/s ⇒ 0.0036 / 0.0071 / 0.0142 / 0.0213 D。视频 0.01–0.02 D ⇒ 低位 F_up ≈ 0.7–1.5 cm²/s（过渡区 Re = 3500，处在层流下界 0.25 与湍流上界 8.8 cm²/s 之间）。**可证伪**：b_line ∝ 1/(af)——摆得越快越大，褐线越细。
- **前推回包（V8）**：壶向 C 推进时射流进入弧堆的凹侧：被足迹 r_sub ≈ 3.7 mm 碰到的弧屈服并沿足迹圆弧包裹（与月牙同一机制），没被碰到的弧整体平移；新铺的弧的面积源把整堆外推、沿两侧绕行。
- **快速后退（V9）**：u_p = 0.16 D/s，(U_rel + u_p)/(2f) = 0.044–0.058 D（视频人字 0.03–0.05 D + 褐线 0.01–0.02 D）✓；每条弧中部离源最近、被后续面积源推得最多 ⇒ 尖指向 D；收流 + 减幅 ⇒ 向叶尖变窄。
- **覆写成实白**（千层心 7.3–10.2 s 在 B 侧停留 ~2 s）：低位射流在弧上（We_coh < 1）压入并就地回浮 + 并入，弧之间的褐线被回浮奶泡覆盖、相邻筏接触合并 ⇒ 实白 V 区 ✓。

### 4.7 V7：推挤、月牙与褐缝（按重测事实）

**事实的修正**：diagnosis V7 说"新一笔开始后、白出现前 ~1 s 内旧块被推离 0.05–0.15 D 并变成月牙"。实验评审在液面椭圆归一化坐标中逐帧重测推心第 2、3 段：白前位移 ≤ 0.03 D（第 2 段，朝向射流，在系统误差内）与 ≤ 0.01 D（第 3 段），形状 IoU 0.91（噪声底 0.86–0.89）；月牙在射流到达旧块凹口（7.07 s）之后 0.3–0.8 s 内形成，与新白同时；月牙顶视面积降到原块的 0.6–0.75（扣除锥形杯液面面积增加 10–20% 与欠分割后）。v3 按重测事实设计，原表述保留为可证伪分叉（§8.4）。

1. **白前几乎不推**：白前唯一的面积源是 F_net = F_up − F_c（闭合表面涡 ≈ 0）。|F_net| ≤ 0.1 / 0.3 cm²/s、t_w = 1.3 s ⇒ 离 B 0.10–0.30 D 处位移 ≤ 0.004 / 0.011 D。对照可动画布（PE，S_A = Q/H = 3.33 cm²/s）：0.15 / 0.20 / 0.30 D 处 0.077 / 0.063 / 0.045 D——比重测大 3–8 倍。一个可检验的细节：起笔最初 t_r 内吞汇已在工作而回涌尚未到达，净面积**汇** F_c t_r ≈ 0.3–1.2 cm² 把画布拉向射流，0.2 D 处约 0.004–0.02 D（推心第 2 段重测到的"0.03 D 朝向射流"在系统误差内，方向一致）；停倒后则反过来，回涌延续 ~t_r 而吞汇已停，旧块被外推同样的量级。

3. **白后被推、缝保持**：新筏以 2.6–3.8 cm²/s 铺展，按 L-A 推开旧块；新筏边缘（离源近、速度 ∝ 1/R）比旧块近缘（离源远）快，缝变窄，但夹在中间的画布带保面积（C2），变窄自限：

   | 源强 | s₀ | 白出现时缝 | 1 s 后 | 2 s 后 | 旧块近缘位移（2 s） |
   |---|---|---|---|---|---|
   | 2.6 cm²/s | 0.12 / 0.15 / 0.20 D | 0.070 / 0.100 / 0.150 D | 0.053 / 0.075 / 0.116 D | 0.053 / 0.071 / 0.106 D | 0.101 / 0.090 / 0.074 D |

6. **> 0.3 D 外**：白前不动（≤ 0.004 D）；白后 2 s 内 ≤ 0.04 D。

### 4.8 V10：天鹅颈与头

- **颈**：细流（Q 2–3 mL/s）沿身体边缘慢移（V_p = 0.8–1.6 cm/s），浮上来的气在已有筏缘直接并入（无成核阈值），新筏以 h_π 沿边缘铺成带：w = F_white φ_j Q/(φ_f h V_p)。F_white = 0.10 / 0.15（中高位 P_s ≈ 0.5、Hz ≈ 0.3），⇒ 0.025–0.075 D（视频 0.05 D）✓。带内的细褐线 = 吞汇尾迹 F_up/V_p。**可证伪**：同样的细流在褐面上慢移，前 2–3 s 不出白（φ_N ≈ 0.03，t_K 长）——颈必须从已有白的边上"长出来"。同一细流"快走切开、慢走画线"由 V_p 连续决定，没有开关。
- **头**：大流量 0.5–1 s 的出白期（扣除延迟），面积 F_white φ_j Q t/(φ_f h)：F_white = 0.14 ⇒ 1.1–2.2 cm²，直径 0.15–0.21 D（视频 0.15 D）✓；其 B 侧缺口是停倒留下的褐洞。

### 4.9 V11：杯倾与液位

- 液位：dH/dt = 1.5 / 2.2 / 3.0 mm/s（Q 10 / 15 / 20）；100 mL 升 1.5 cm；锥形杯（5–10°）液面面积 +6.6–13.6%，作为画布在杯壁处的面积源使图案整体略外扩、释放画布应变；落差 z_s 随液位减小（固定嘴高时 v 降低、p_0 降低）。

- design brief 的"液面上升（几十 mL 进 ~150 mL）、杯常倾斜"由 §3.13 的账本与域运动完整表示。

## 6. 模型做不到的事与失效条件（诚实的边界）

1. **内区不是解析的（最弱处）**。Re_j = 1600–4300 的含气负浮力喷泉处在过渡区，经典湍流常数（α、2.46、c_t）只有 ±30–50%；绘制倒奶与细切的 z_m/H 都在 0.96–1.57，正好跨在"局部回涌 / 触底混合"的分界上，P_s 对 H、z_s、φ_j 敏感。没有 E2/E3/E8 的制表，F_white、t_r、r_N 只有量级——§4.5 的生长速率偏差（1.2–3 倍）就在这里。
2. **画布是否等压由测量决定，不由本文决定**。若 E7 测得 E ≲ 2 mN/m 或 E2 测得白前远场位移 ≥ 0.05 D 且 ∝ Q/H，近似 N5 失效，画布退化为可动画布（同一方程组 W ≡ 0 的极限）；那时还必须加上射流竖直动量驱动的杯尺度子午环流的表面迹（M ≈ 7 mN，表面速度 ~1–4 cm/s，物理评审对 PE 的批评），本文没有给出它的约化。
3. **最细的线处于薄板近似与毛细的边缘**：褐线 0.8–1.6 mm < l_c = 2.1 mm，条纹 h/w ≈ 0.5–1。两块相距几 mm 的筏之间的弯月面毛细吸合未计入（若台架显示 3 mm 筏在 < 4 mm 内自发吸合，最细缝的下限 ~2l_c²/h_p ≈ 3–4 mm，与 1–2 mm 褐线矛盾——所以预期它可略，但需检验）；止停判据在 w ~ h 时差 O(1) 常数。
4. **近场胞线性叠加**：两个落点间距 < 2r_N（快速重定位、细切穿过刚倒的区域）时胞的非线性相互作用被忽略；落点移动速度 ≈ U_N 时（细切）储层只有量级精度。
5. **涡量强迫 η_h 未知**：倾斜/移动射流的水平动量（M_h ≈ 1 mN）转为液面垂直涡量的份额没有可靠估计；偏心切向倒奶带起的整杯旋转会使图案整体转动（仍不糊，刚体）。
6. **单一组分的光学**：筏从 h_* 长到 1 mm 的 0.5–1 s 内亮度被高估；湿奶（τ_y < 0.3 Pa，h_m < 0.5 mm）筏本身是灰的；画布因体相小泡变浅、深层液体上涌变暗、细线的半透明都不在 c 里（需第二组分）。
7. **入口时程**：首段白特别慢（推心 2.1 s 对后段 1.2 s）可能来自壶起倒时 φ_j(t) 偏低，这属于壶模型，杯面模型只能吃测得的 φ_j(t)；Q(t) 单目 16× 歧义——模型不能修复缺失的输入，只能在 Q 有界未知时给出预测带。
8. **嘴贴液面（z_s → 0）**：射流不再"插入"，J 区换成贴面浮力源，褐洞可能缩小或消失；本模型此时的 r_c、r_e 不可靠。
9. **月牙的面积损失分配**：足迹压入与塑性增厚各占多少，由 E6 侧拍决定；若面积损失 > 30% 且既不增厚也找不到压入证据，筏的 Bingham 膜本构不足。
10. **时间窗**：> 30 s（排液使 τ_y 上升、边缘变硬）、> 3 min（粗化、crema 退化）、注满阶段——均不做。
11. **温度、壶内分层、杯壁弯月面对筏的吸/斥（只在 l_c 内）**——忽略。

### 7.2 刚性、时间步与 IMEX 位置

- 没有任何重力波 CFL：漂浮层无动量状态（准静态），c_p 被删除；画布等压是一个椭圆约束（隐式）。
- 刚性项：吞汇（F_c/(πr_c²) ≈ 10–100 /s）、压入（~10³ /s）用局部指数积分；浮选（v_b/g_N ≈ 0.3 /s）、Kynch 增长、τ_d 弛豫为非刚性，显式。
- 时间步 Δt ≤ min(0.5Δx/max|u|, Δx/|ẋ_j|)：256² 下摆动 3.55 ms、细切（0.6 D/s）6.51 ms、天鹅快扫 ≈ 1.2 ms；384² 下 2.37 / 4.34 ms。U_N 最大 ≈ 12 cm/s（r = 5 mm），ψ 用半拉格朗日以免 1.3 ms 的输运 CFL。
- 变分问题每子步在活动窗口内求解：射流足迹 ± 1 cm、超厚筏（h > h_π）与它们的连通区；其余筏按刚体（每块 3 个自由度，PE 的连通分量刚体投影）进入画布 Poisson。

### 7.4 分辨率

最细物理结构：褐线 0.01 D = 0.8 mm；细切柱径 1.6–2.2 mm；细切 r_c ≈ 0.5–0.9 mm。按学长"可分辨宽度 4 格"：256²（Δx = 0.312 mm）上 0.8 mm 线只有 2.6 格——临界；**384²（0.208 mm，3.8 格）为出图分辨率，512²（0.156 mm，5.1 格）为收敛参照**；0.04 D 以上结构 256² 足够（参数搜索用 256²、在 384²/512² 复核）。收敛检查：128/256/384/512 × Δt、Δt/2、Δt/4 × 子像素 1×1/2×2/4×4；宽于 4 格的线宽须收敛，窄于 4 格的标 unresolved；褐线条数不得随网格单调增加（学长 §7-7）。

### 7.6 写成回归测试的单项物理检验（先于任何图案运行）

- T1 止停厚度：平面/轴对称单筏松弛到 h_m = 2kτ_y/(ρ_f g′)（误差 < 5%，与网格无关）；给定 π̄ 时到 h_π。
- T2 精确冻结：无源时 u ≡ 0（到求解器容差）；10 s 后 c 逐点不变。
- T3 等压画布：无筏圆盘中点面积源的位移与 L-A 解析解误差 < 1%；嵌入一块刚体筏时筏平移、不变形。
- T4 过滤：给定发散 U_l（源流）不移动任何东西（到 O(ζUL/E)）；给定无散 U_l 带动画布与筏。
- T5 Kynch：一维柱中堵塞层增长速度 φv_b/(φ_J − φ) 误差 < 2%；首白时间对解析 t_K。
- T6 尾迹律：强度 F 的移动源以 V 移动留下宽 F/V 的新液面带（< 3%），V t_r/r_e 从 0.1 扫到 10 时连续过渡。
- T7 足迹：高斯压力作用下的屈服区、r_sub、r_d 对解析值。
- T8 账本：全部账本每步 10⁻¹² 闭合；裁剪为零。
- T9 收敛（§7.4）。
- T10 失败对照（预期失败形态先写下，作为回归保留）：τ_y → 0 ⇒ 白盘 ~0.3 s 到壁；E → 0（W ≡ 0）⇒ 白前远场位移 0.06–0.08 D（0.15–0.2 D 处）；F_white → 1 ⇒ 高位也出白；p_t → δ、S → 0 ⇒ 延迟只剩 Kynch、褐洞变小；F_up → 0 ⇒ 切不留线、摆动无褐线；Π_coh → ∞ ⇒ 切不留线、全部回填；Π_coh → 0 ⇒ 低位倒在白上打出褐洞。

### 8.2 对六段参考视频的预测（只检验，不标定）

- P1 各段首白时间落在 t_w 带内（§3.8）；后段比前段快；倒在已有白上（含白边）无延迟。
- P2 褐洞直径 0.07–0.13 D，随柱径（流量）增大；C 形开口朝壶，远侧先亮。
- P3 每个出白阶段白区面积对时间线性，斜率 F_white φ_j Q/(φ_f h)；边缘速度 ∝ 1/R。
- P4 白前远场位移：背离射流方向 ≤ 0.01 D（0.15–0.3 D 处）；起笔最初 t_r 内允许 ≤ 0.02 D 的朝向射流的拉动（吞汇先于回涌），停倒后同量级外推。

- P7 停倒后白区面积再增 5–15%（1–3 s），之后所有元素速度 < 0.002 D/s。
- P8 切线宽 ∝ 1/V_p（快切更细），更高的细流线更宽；凹口半径 ∝ √(F t_dwell)。
- P9 摆动褐线 ∝ 1/(af)；间距 ∝ U_rel/f；弧凸离壶；远侧更密，最外侧褐线先闭合。
- P10 茎长 ≈ V_p t_cl。
- P11 天鹅颈只能从已有白边长出；在褐面上同样的细流前 2–3 s 不出白。
- P12 杯倾回正期间图案沿 B–D 缩短 3–9%，不平移。
- P13 切前后白面积减少 ≤ 1–2%。
- P14 白占比 0.23–0.42 与褐环宽度由总供给决定，奶泡量加倍时褐环变窄。

### 8.3 六图验收（学长协议）

1. **输入**：实测动作（落点轨迹、嘴高、Q(t) 由称重回放或作为有界未知、φ_j(t)、θ(t)），按视频分段（不是 V0.5 脚本 × (h,q,s)）；推心必须包含末尾贯穿收尾与第三段 B → C 推进（A18 修正）。

3. **观测算子**：同一提取算子 P 处理渲染（只读 c）与视频（学长 §5）；全部在液面椭圆归一化坐标中。
4. **指标**：(i) 过程帧量——各段首白时间、dA/dt、被跟踪旧元素在白前与接触后的位移、缝宽随时间、预定剖面上的条纹间距与褐线宽、切线宽与茎长；(ii) 末帧白概率 MAE、固定阈值 IoU、双向边界距离；(iii) 预定剖面上的棕白交替数。
5. **建议通过线**（须与学长确认）：首白时间 ±0.3 s；褐洞直径 ±0.03 D；白前远场位移 ≤ 0.02 D；末态缝宽 ±0.03 D；条纹间距 ±30%；树叶中线剖面褐线条数 ±2；切线 ≤ 0.02 D；茎长 ±0.05 D；白占比 ±0.05；边界距离中位数 ≤ 0.02 D；收敛符合 §7.4；≥ 3 组确定性初始化。
6. **失败对照与消融**：T10 的每个对照与"逐项关闭机制"的消融一起报告，且必须按预写的形态失败。

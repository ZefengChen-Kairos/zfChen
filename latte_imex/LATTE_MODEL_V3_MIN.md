## 0. 一句话、适用范围、与 v3.1 的关系

**一句话。** 杯面是一张等压漂浮层，白（奶泡筏，相占据率 c）与褐（画布）共用一个只由面积源驱动的势流 u = ∇φ；白只来自附在当前射流上、每次加流后延迟 τ_w 才建立、以 wQ/Γ 在射流外环上生成的成团奶泡；低位射流的内区 r < r_e 是筏的排除区（漂进来的筏被压入、立即在供给环重浮），这就是落点褐洞和朝壶的 C 形开口；高位细流的驻点压力超过内聚压 Π_coh 时就地把筏打散成画布，这就是切线。停倒后图案静止由 L1、L4 推出（引理 F），是假设的推论，不是机制。

**适用范围。** 只模拟绘制阶段（注满之后、≤ 30 s）：低位倒奶、移动、摆动、前推后退、多段推挤、抬缸细流画线与切、杯倾回正、液位上升。输入是从视频提取的动作，参数取自六段联合拟合。

**与 v3.1 的关系。** v3-min 是 v3.1 在 13 个命名极限 L1–L13 下的约化（推导、判据与失效症状见 §2）。其中 L11′ 打开了 v3.1 默认关闭的 M5 压入，是向学长的变更申请 **CR-1**（§2.3）。v3.1 的储层 ψ、Kynch 层 B、膜应变 ε、压实 φ_r、体相柱 G_B,k、团块库存 𝒞、ALG2 都不进入 v3-min；任何扩展都只能一次放开一个极限（§8）。

与学长 H0 门的关系（裁判嫁接 G-H1）：H0 的 c_p、β 只以膜压扩散率 D_Π = c_p²/β 出现，物理上 D_Π = E/ζ = 5×10⁻³–0.18 m²/s；旧拟合值 1.8–1.9×10⁻⁴ m²/s 落在 v3.1 的"可动画布"极限里，该极限预言的白前推挤 0.06–0.08 D 已被重测否定（≤ 0.01–0.03 D）。H0 取 D_Π → ∞ 给出全层统一散度 ∇·u = σ − ė，没有相区分；再加 L3（筏面积不可压）才得到 (P)。所以 v3-min 是 H0 的刚性极限加 L3 与射流附着出白律。

## 1. 物理图像

1. **漂浮层**：白是奶泡筏，褐是画布（液面 + 吸附膜）。画布等压，发散型液体表面流推不动它，漂浮层只随面积源运动；筏与画布共用势流 u = ∇φ（L2 是经验选择，§2.1）。
2. **出白**：成团奶泡在射流外的环上 ≲ 0.1 s 内浮出，生成筏面积 wQ/Γ；环随奶柱倾角向下游偏 Δ_e，落进内区 r < r_e 的部分被卷回、在环的其余部分重浮，所以上游空缺：C 形开口朝壶，远侧更亮。
3. **延迟**：每次加流（起倒，或抬缸后压低加大流量）后的 τ_w 内没有成团奶泡（壶内屈服的奶泡层要滑到嘴才出来，或近场需要重建，对杯面等价）；减流不重新计时，所以紧接抬缸的细流仍能画茎、画天鹅颈。
4. **内区**：低位射流外 r < r_e 的液面向射流流动并被吞下（只吞画布），t_r 后作为新液面在内区环 [r_0, r_e] 重生；漂进内区的筏被压入、立即在供给环重浮。所以落点褐洞的半径就是 r_e，C 形开口靠同一规则保持。停倒后在途新液面在洞内重生，咬口扩大。
5. **切**：细流驻点压力超过 Π_coh，核 r_d 内的筏就地变成画布（切线宽 2r_d）；慢走时供给沿路径画出宽 wQ/(ΓV) 的白线（茎、天鹅颈）。
6. **停倒**：供给、吞汇、排除区立即消失，在途液面 t_r 内重生完；之后在 L1、L4 下精确静止（引理 F）。

## 2. 推导：每一项都是 v3.1 的命名极限

### 2.1 运动学：从 (V) 到 (P)

v3.1 §3.6 的漂浮层速度是凸泛函 (V) 的唯一极小。依次取 L1（画布合并为一区，π̄ 对筏厚的反馈可略，W 项与筏缘线积分退出运动学）、L2（筏的偏应力阻力，即屈服项 2hτ_y|𝐒|_e 与塑性粘度项 2hη_p|𝐒|_e²，相对拖曳可略）、L3（筏厚钉扎在 h_eff，N(h)∇·u 由体积约束 c(∇·u − σ_raft) = 0 取代）、L4（U_l^σ = 0，ζ_R = ζ_C）、L5（f_J = 0），剩下

```
\min_u \int_\Omega \tfrac12\zeta|u|^2 dA \quad s.t.\quad \nabla\cdot u = \sigma - \dot e\,(1-c),\qquad u\cdot n = w_{\partial\Omega}\cdot n .
```

Euler–Lagrange 方程为 ζu + ∇λ = 0，所以 u = ∇φ（乘子 λ = −ζφ 就是画布表面压的扰动部分）。ζ、E、ΔΠ_c、τ_d、τ_y、η_p 全部从运动学中消失：**运动学零参数**。

**L2 是经验选择，不是被判据证明的极限。** 单独看，L2 要 Bn_d = ζΔU L/(2τ_y h) ≳ 1 且 Bq = 4η_p h/(ζL²) ≲ 1（PX §2.1）。但在 L1 下 L3 把筏厚钉在止停厚度 h_m = 2kτ_y/(ρ_f g′)（v3.1 L-R1），代入得

```
Bn_d = k\,\zeta\,\Delta U\,L/(\rho_f g' h^2) \gtrsim 1 \iff h \lesssim \sqrt{k\zeta\Delta U L/(\rho_f g')} .
```

本杯（推心旧块 L = 2.6 cm，ΔU/L = 0.27 /s，ζ = 1 Pa·s/m，k = √3，φ_r = 0.64）：Bn_d = 1.4×10⁻⁷ m²/h²，要求 h ≤ 0.37 mm（ζ = 0.33 时 0.21 mm）。名义 Γ 配 v3.1 的 F_white 带 0.08–0.25 给 h_eff = 1.1–3.9 mm、Bn_d = 0.003–0.1；要 h ≈ 0.3 mm 须 F_white ≈ 2%，那时光学反射 R = h/(h + z_e) = 0.45–0.58，是灰的，违反 c 二值（N13）与 §4.5 的"饱和白"。（v3-min-1 举的 h = 0.3 mm、τ_y = 0.1 Pa 本身违反 L3：h_m(0.1 Pa) = 0.15 mm。）所以保留 L2 的理由只剩"视频里被推元素变形而非平移"这一定性观察；全塑性既不给月牙（点源流保极角，欧拉物质线 solidity ≥ 0.93），也不保缝（§8 第 2 条）。刚体极限 **PX-R**（无源连通筏块作刚体投影，v3.1 性质 4）因此作为并列主模型，与 PX 同样拟合、同样检验（§6.3 T12、§7.6），由数据选，不只作消融。

### 2.2 白源：L6–L9

v3.1 的出白链（回涌 t_r → 储层浮选 → 画布下 Kynch 层累积到 b_* 成核，或并入筏底）把空间记忆放在液面上。三条视频证据否定了这种"液面附着剂量"（PX §2.2，裁判 §3 复核）：推心第 2 段 B 在 5.73–6.93 s 被倒 1.27 s 不出白，射流移入凹口后 7.13–7.20 s 在当前落点出白（剂量阈预言 B 在 7.20 s 出白、凹口不早于 8.54 s）；推心第 1 段停倒后补白 ≈ 0（在途剂量律给约 2 cm²）；推心第 3 段压低加流 1.1–1.3 s 后在落点出白。这三条用来**构造** L8，所以在 §5 只算"构造"，不再算独立检验（T9 仍做，验的是代码）。由此取四个极限，全部是 v3.1 已列出的分支：
- **L6**（§3.8a H-B2 强极限 k_s b_* > r_K 处处成立）：单泡不在画布成核；v3.1 的 F1（体相气使全杯变白）与 F2（三难）在结构上消失，因为缝、线、杯壁处没有剂量。
- **L7**（§3.9 t_cl → 0）：成团奶泡在射流外就近浮出。判据是浮出途中的平流距离 U_N t_f ≪ r_e；v3.1 的 U_N = 3–12 cm/s、t_f = 0.07–0.13 s 给 2–15 mm，不小于 r_e = 3.7 mm，**判据不成立**。供给环半径 [r_e, 1.5 r_e] 因此是形状常数（§2.3 L13），不是推导量。
- **L8**（§6-7 PB-D1，φ_j(t) 本是输入）：能成白的流量 G(t)wQ，G = 𝟙[t − t_k ≥ τ_w]。t_k 是最近一次加流事件：Q 自下而上穿过 Q_* = 8 mL/s，或从 Q = 0 恢复。减流不重新计时。**附加假设**：Γ 与流量区间无关。若抬缸细流取的是壶内表层奶泡（这正是减流不重计时的理由），则 Γ_thin < Γ_thick；茎、颈宽用低位拟合的 Γ 预言，因此也是对这条假设的检验。
- **L9**（§3.9 高斯足迹律）：已有筏被压入足迹 r_sub 时的打散份额 f_d = (r_d/r_sub)² = ln(p_0/Π_coh)/ln(p_0/p_sub)，截断到 [0, 1]。**射流自带的供给（闭合 C-w，新增，未推导）**：v3.1 的 f_disp 只对已有筏；射流自带的团块穿过射流截面，若按截面归一化，份额是 (r_d/r_0)² = ln(p_0/Π_coh)。二者之间没有推导，取 w = 1 − f_d 为缺省并报告带：名义细流（p_0 = 564 Pa、Π_coh = 300 Pa）w = 0.85 … 0.37，茎、颈宽同比例 ×0.43。低位 p_0 = 120–194 Pa < Π_coh 时二者都是 0。

Q_* 只用来切段：它落在细流 2–5 mL/s 与大流量 10–20 mL/s 之间，5–10 mL/s 内取值不改变切段（T8）。

### 2.3 近场：L10–L13

- **L10 时间闭合表面涡**（v3.1 M1–M2 中 F_up ≈ F_c 取精确，加 C5"画布被覆盖处不回涌"）：吞汇在 r_0 < |x − x_j| < r_c 以 F = α_F·2πr_0v 吞掉液面。按 v3.1 M1，吞汇只处理画布；低位时 L11′ 使吞汇环内无筏，细流时偶尔被吞的筏 F c̄_s 不打散、按 L11′ 的规则在供给环重浮。进入在途的液面 F_tr = F(1 − c̄_s)；t_r = c_tT_f 后在延迟落点的内区环 K_e 上按当地画布份额 (1 − c) 重生，落在筏上的份额不生成液面，记"筏下回流"。**L10 的失效症状已在视频中出现**：推心第 2 段 B 处无白期深褐新液面区扩大到 1–2.5 cm²（裁判 §3 第 4 条），本模型的新液面只在 r < r_e（≤ 0.45 cm²）内：标 ✗，回到 v3.1 C5 的 F_net(π̄)（§8 第 3 条）。
- **L11′ 内区排除 = v3.1 M1 + M5，取内区停留 τ_in → 0、回浮 t_cl → 0**（**CR-1**：v3.1 把 M5 默认关闭，直到 E6/E1 排除遮挡，学长 #8；本版打开它，因为不打开就没有持久褐洞，§0 改动 1）。v3.1 §3.9 判据 2 要求内缘筏向内的面积通量 < F_c，否则筏漂进 r ≤ r_sub 被压入、在 r_cl 回浮。C 形供给环在射流脚的穿流（4.6–6.5 mm/s）与吞汇入流（r = 3 mm 处 5.3 mm/s）同量级，判据 2 不能保证，v3-min-1 实测白正是这样漂进去的；所以漂进内区的筏要按 M5 被压入。取极限：p_0 ≤ Π_coh 时排除区 E_j = {|x − x_j| < r_e}，每步开始时其中的筏相变为画布（面积守恒），同一步在 K_f 上以等面积重浮。判据 V_j t_cl ≪ r_e（低位 t_cl = 0.07–0.12 s，heart 移动 0.1 D/s 时 0.6–1 mm ≪ 3.7 mm）。细流 p_0 > Π_coh 时 V_j t_cl = 0.6–1.3 cm ≫ r_sub，回浮发生在路径后方约原处，取为无操作，只保留打散核。推论：落在 r_e 内的供给被同一规则卷回再浮出，几何级数的不动点就是"供给核限制在 r_e 外并重新归一化"；上游扇区因此被排除，这就是 C 形开口。**K_f 的位置**：裁判 F-2 要求放在 v3.1 的 r_cl = r_sub + a_cl（低位 4.7–6.7 mm）；本文的 K_f 是绕 x_f 的 [r_e, 1.5 r_e] = 3.7–5.6 mm，与 r_cl 先验带重叠，不新增常数，作为形状常数报告灵敏度（§4.2）。**代价**：射流移到白上时排除区照样存在；v3.1 说那时内区没有画布、不回涌、应被填回。T1b ✗（§5、§8 第 12 条）。

### 3.3 核与排除区（紧支撑，在杯内重新归一化，∫K dA = 1；q(s) = (1 − s²)₊²）

```
K_c \propto \mathbb 1[r_0<|x-x_j(t)|<r_c]                                                            （吞汇环）
E_j=\{|x-x_j(t)|<r_p\}                                                                                  （内区排除区，L11′）
K_f \propto q\big((|x-x_f|-1.25r_e)/(0.25r_e)\big)\cdot \mathbb 1[|x-x_j(t)|\ge\max(r_c,r_p)],\quad x_f=x_j(t)+\Delta_e\hat e(t)   （供给环）
K_e \propto q\big((|x-x_j(t-t_r)|-\bar r)/\hat w\big)\cdot\mathbb 1[|x-x_j(t)|\ge r_0(t)],\quad \bar r=\tfrac12(r_0+r_e),\ \hat w=\tfrac12(r_e-r_0)   （内区环）
```

K_e 中 r_0、r_e 取延迟时刻的值；射流柱只在倒奶时排除。圆与网格单元的相交用 4×4 子样固定求积，不设核宽下限（v3.1 T11）；核在杯壁截断后重新归一化。

### 3.4 方程

```
\Delta A_{in}=\int c^n\,\chi_E\,dA:\quad c^n\leftarrow\min(c^n,1-\chi_E)\ \ (\chi_E=\text{格内 }E_j\text{ 面积份额；压入，面积守恒相变}),
\bar c_s=\int c\,K_c\,dA,\qquad \sigma_c=-F\,K_c,\qquad \sigma_f=\big[G\,w\,Q/\Gamma+F\,\bar c_s+\Delta A_{in}/\Delta t\big]\,K_f,
F_{tr}(t)=F(1-\bar c_s),\qquad \sigma_e=F_{tr}(t-t_r)\,K_e\,(1-c),\qquad \dot S_{ur}=F_{tr}(t-t_r)\int K_e\,c\,dA\quad(\text{筏下回流，记账}),
\dot R_{core}:\ c\to 0\ \text{在本步扫过的胶囊}\ \{\mathrm{dist}(x,\text{射流路径})<r_d\}\ \text{内（面积守恒相变）};

(P)\quad u=\nabla\phi,\quad \nabla^2\phi=\sigma_c+\sigma_f+\sigma_e-\dot e\,(1-c),\quad \partial_n\phi=w_{\partial\Omega}\cdot n,
\qquad \dot e=\Big[\int(\sigma_c+\sigma_f+\sigma_e)\,dA-\dot A_{cup}\Big]\Big/\int(1-c)\,dA ;
(C)\quad \partial_t c+\nabla\cdot(c\,u)=\sigma_f+c\,\sigma_c-\dot R_{core}.
```

压入与重浮在同一步成对，筏面积净零；低位时压入后 c̄_s ≈ 0（实测吞汇中筏份额 < 1%）。画布方程 ∂_t(1 − c) + ∇·((1 − c)u) = σ_e + (1 − c)σ_c − ė(1 − c) + Ṙ_core 与 (C) 相加正好是 (P)。量纲：σ、ė、Ṙ 为 1/s；GwQ/Γ 与 F 为 m²/s，乘 K [1/m²] 后为 1/s；φ 为 m²/s。

**引理 F（停倒冻结；前提是 L1、L4 与漂浮层无惯性，是这三条假设的推论）。** 设最后一次 Q > 0 的时刻为 t_s，杯倾与液位静止（Ȧ_cup = 0）：t > t_s 时供给、吞汇、排除区为零；t > t_s + t_r 时在途液面用完，σ_e = 0；于是 (P) 是齐次 Neumann 问题，φ = const，u ≡ 0，c 逐点不变。离散上面心速度由同一个 φ 差分得到，严格为零；不需要 β 型阻尼。原型：t_s + t_r 起 max|u| = 0、筏面积变化 0。V2 与"停倒即停"因此是**构造**，物理上取决于 L4 的判据（未验证）。

### 3.5 边界与初始条件

- **杯壁**：∂_nφ = w_∂Ω·n（锥形杯液位上升的新面积）；c 零法向通量；核在杯壁截断后重新归一化。
- **杯倾**：在参考圆盘 ξ 上求解，x = A(t)ξ，A = s(t)·R_θ diag(1/cosθ, 1)R_θᵀ；Laplace 带度量 G = A⁻¹A⁻ᵀ det A，Ȧ_cup = A_cup·d ln det A/dt 进入 ė（v3.1 §3.13）。因为 L3 下筏面积不可压、ė 让画布吸收全部 Ȧ_cup，回正时**只有画布**沿倾轴收缩，筏块保持面积，图案不是仿射缩短（v3.1 的筏厚可变，结论不同）。起笔时筏少，影响小。
- **初始**：c = 0，在途包为空，t_k = 第一次起倒；片子从倒奶中途开始时（郁金香）缓冲装入外推输入，该段首白不进拟合。

### 3.6 账本（逐步检查，机器精度）

1. **可解性与筏面积**：离散 Σ RHS = 0、(∇·u − RHS)Δt ≤ 10⁻¹¹；筏面积 dA_r/dt = GwQ/Γ − Ṙ_core,tot（压入—重浮、吞—浮成对，净零）。v3-min-1 的"∫c + ∫(1 − c) ≡ A_cup"是恒等式，不检查任何东西，已删。
2. **能成白的奶泡体积**（取代 v3.1 的奶泡体积）：∫₀ᵗ GwQ dt′ = Γ[A_r(t) − A_r(0)] + Γ∫₀ᵗ Ṙ_core,tot dt′。第二项是已打散的部分，其气体进入体相，按 L6 不再成白。
3. **液面（表面涡）**：∫F_tr dt = 已在画布重生 + 筏下回流 ∫Ṡ_ur dt + 在途。筏下回流是真实的画布净汇，由全杯 ė 补偿（等压极限下一致的非局部响应）。
4. **液体与液位**：V_cup(z_l) = V₀ + ∫(1 − φ_j)Q dt（筏不改变液位，v3.1 §3.13）。**未原型化**（原型是圆柱、无倾斜），连同锥杯 Ȧ_cup 与杯倾度量。
5. **数值**：有界性修正改变 ∫c 的净量验收为 0（≤ 10⁻¹² 相对）；搬动量单列（§6.1）。

**学长接口**：U = [ℓ, q, m] 取 ℓ ≡ 1、q = u（面心到格心）、m = c、cell_area = det A·h²。学长的"褐量守恒 d/dt∫(ℓ − m) = 0"在这里不成立也不该成立：画布是表面，被吞、在筏下丢失、由 ė 吸收（L1），不是守恒物质；守恒的是账本 2。

## 6. 数值格式与回归测试

### 6.1 离散

- **网格**：N × N 方域内接参考圆盘，阶梯掩模，格心存 c、φ；128² 时杯内 12 892 格，Δx = 0.625 mm。拟合用 128²（全程），复核用 192²/256²，终检加 512²。
- **(P)**：5 点格式 + Neumann（壁面面通量 0）+ 度量 G(θ)。稀疏 LU（`splu`）每个 θ 档（0–25°，1° 一档）分解一次（每档 < 0.1 s），全部评估共用；锥杯外扩只改标量 s(t)。右端按 ė 配平后钉住一格，每步一次回代。面心速度 u_f = G∇_fφ（MAC），离散散度精确等于右端（实测残差 × Δt ≤ 6×10⁻¹³（128²）、5×10⁻¹²（256²））。
- **内区压入（L11′）**：每步开始，排除区与格子的相交份额 χ_E 用 4×4 子样求，c ← min(c, 1 − χ_E)（假定格内的筏先占排除区外的部分），压入面积 ΔA_in 在同一步作为 K_f 上的源（§3.4）。
- **VOF (C)**：方向分裂（x–y、y–x 交替）；PLIC（Youngs 法向，杯外取最近杯内值）给精确条带面积；中间扫掠的散度项用 Weymouth–Yue 指示函数 c_c = 𝟙[c > 0.5]；最终守恒更新 c* = cⁿ − ΣF_PLIC + Δt(σ_f + cⁿσ_c)，之后做有界性修正与打散核相变。
- **有界性：保守重分配（已实现，`bounded_redistribute`）**。越界 (c* − 1)₊ 与欠量 (−c*)₊ 先截去，二者的带号净量放回有空余（或有筏）的格：先在越界格周围 3 格的带内，按空余 (1 − c) 或存量 c 比例分配；带内容量不足时改为全杯。每格得到的量不超过自己的空余，所以 0 ≤ c ≤ 1 严格成立（到舍入），∫c 不变。实测（`log_T5.txt`）：净改变 ∫c 的量在双精度下为 0（T1–T4，96–256²）；搬动量 0.3–1.4×10⁻⁴ cm²/次（约为生成筏面积的 10⁻⁵）；修正前 c* ∈ [−8×10⁻⁶, 1.0027]。账本 2 不受影响（PH 的源项指数积分会破坏它，因为筏厚钉扎要求逐步生成 GwQΔt/Γ）。v3-min-1 写的"守恒重分配"在原型中并不存在（实际是硬裁剪，净 0.6–1.1×10⁻⁴ cm²/次），本版改正。
- **核与扫过沉积**：核只在其支撑的外接方窗内以 4×4 子样计算；移动射流（摆动 8.8 cm/s、细切 2.4–4.8 cm/s）在一步内按 ≤ Δx/2 细分路径沉积，Δt 不受 Δx/|ẋ_j| 限制；打散核对扫过的胶囊与 PLIC 多边形做 8×8 子样相交（不重复扣除）。
- **"储层"的替代**：没有储层场，记忆只有两样。(i) 在途液面包：每个子步把 F_trΔt 存为一个包（释放窗 [t + t_r, t + Δt + t_r)、延迟落点、r_0、r_e），按窗重叠精确释放，变步长下账本 3 仍精确。(ii) t_k：闸门按子区间的精确开启份额计算，τ_w 光滑地进入目标函数。
- **时间步**：Δt = min(20 ms, 0.5Δx/|u|_max, 0.2/max|σ|)，试步越界则重算；128² 上 Δt ≈ 11–20 ms。无重力波 CFL、无 ALG2、无迭代。
- **每步顺序**：(1) 输入与缓冲 → 射流导出量、G(t)；(2) 内区压入；(3) 源与核（记 c̄_s、F_tr、Ṡ_ur）；(4) ė 与 (P) 回代；(5) VOF 守恒更新；(6) 有界性重分配；(7) 打散核相变；(8) 账本、z_l(t)、A(t)，按 15 fps 输出 c。

## 7. 联合拟合方案（六段一起）

### 7.1 输入提取（动作是输入，不是参数）

- **配准**：手持拍摄，杯在画面中移动可达 0.3 幅宽。段首帧杯沿椭圆（5 点手工拟合）定**形状与尺度**，之后逐帧跟踪位姿（受杯沿椭圆约束的单应），不逐帧重定尺度（v3.1 §8.3）。每组观测量报告静止白边的帧间抖动（实测配准误差）。
- **θ(t)**：杯沿纵横比只在起笔 1–2.5 s 非零；它与手持相机俯仰在单目中耦合，取相对于该段回正后杯沿的变化，误差进 σ_eff。heart 首白（1.47 s）落在回正过程中。
- **x_j(t)**：手工关键帧，常速段每 0.2 s，摆动段 ≤ 0.05 s（2.5–3 Hz），样条插值；关键帧精度 1–5% D 进 g3 的 σ。
- **ê(t)、z_sp(t)**：壶嘴朝向、低位与抬缸两个工作区的关键帧。**α_j 单目不可测**，作扰动量（§4.2）。
- **Q(t)**：逐阶段常数（低位、细流各一档；`pitcher.py` 堰流律只在壶倾角可测时给阶段间比值）× 全局标度（扰动量 ×0.5–2）。t_k 由阶段边界给出，人工核对一次后冻结。
- 输入在主拟合中取参照值；逐观测的输入误差（z_s ±0.5/±1 cm、x_j、切段 ±1 帧）进 σ_eff（§7.3）；共享的扰动量（Q 标度、D、α_j、δ_c、α_F）在剖面似然与 T11 中带先验地优化或边缘化。

### 7.3 目标函数

```
\chi^2(\theta)=\sum_{i}\Big(\frac{O_i^{sim}(\theta)-O_i^{vid}}{\sigma_{eff,i}}\Big)^2,\qquad
\sigma_{eff,i}^2=\sigma_{meas,i}^2+\sum_k\Big(\frac{\partial O_i}{\partial u_k}\Big)^2\sigma_{u_k}^2+\sigma_{model,g(i)}^2 .
```

不加组权：组权 1/n_g 使 J 不是 −2 ln L，区间按 √n_g 失真（Γ、τ_w 的 sd 0.03 → 0.10 / 0.08）。u_k 是逐观测的输入（z_s、x_j、θ、切段），偏导由 §4.3 的有限差分给出；σ_model,g 由首轮拟合后该组的 Birge 比定（首白：σ = 0.12 s 而各段离散 0.33 s，χ²/dof ≈ 7，必须吸收），只迭代一次并报告。组的主导问题用逐组残差表与逐组剖面来看，不改似然。任何模拟失败（越界、账本 > 10⁻¹²）令 χ² = +∞ 并单独记录。

### 7.4 先做合成回收（T11，学长 E3）

在六段真实输入上，用宽界内对数均匀抽取的 3 组参数生成合成过程帧，加 §7.2 的噪声与扰动量的随机抽样（Q 标度 ×0.5–2、D 7–10 cm、α_j 5–12°、δ_c、α_F 全先验、z_s ±0.5/±1 cm、切段 ±1 帧），再以参照值输入回收。报告回收偏差（扰动量引起的系统偏差单列）、χ² 协方差的相关矩阵与条件数，并按 r_{e,ref} 三分位分开报告；出现 |相关| > 0.9 的参数对时合并或固定其一，并升版本号。剖面似然的 Δχ² 阈值用这里的参数自助法标定。

### 7.5 联合 CMA-ES

4 维、对数参数化，λ = 8，40–60 代；**全程 128²**（切线亏量 96² 比 256² 高 14%，128² 高 4%；中途换网格等于换目标函数）。**≥ 3 组确定性初值**（闭式初值与两个对角点），相同预算：共 960–1440 次评估。一次评估（六图约 85 s 倒奶，4 核按图并行）128² 约 18 s 墙钟，合计 5–7 h。最优点及 ±1σ 点在 256² 复核（T10 的 5% 线）。

### 7.6 补偿检查

1. **分段拟合交叉检查**：S1 g1 → τ_w（近似闭式：中位数(t_首白 − t_k) 减可见延迟 0.02–0.03 s）；S2 τ_w 固定，g2 → Γ；S3 g3 → r_{e,ref}；S4 Γ 固定，g4 → Π_coh。联合值与分段值相差 > 2σ_剖面即判为补偿，并报告是哪一组残差在推它。
2. **剖面似然**：每个参数在宽界内 ≥ 9 点（Δχ² < 4 处自适应加密），其余 3 个与共享扰动量（带先验）热启动 CMA（λ = 6，10 代），128² 约 2200 次评估，4 核约 11 h。阈值取 Δχ² < χ²_min/dof 或 T11 自助法标定值；全界内低于阈值的参数判为"未被视频钉住"，其值不作物理结论，依赖它的预测给成带。另给 r_{e,ref}、Π_coh 随 Q 标度的条件曲线。
3. **L8 残差检验**：首白残差与 Q、z_s、液位、段序的 Spearman |ρ| > 0.6 即判 L8 受质疑。
4. **留一段交叉验证（必做）**：六次各少一段，报告参数漂移与被留段的预测误差。
5. **学长协议并列**：用郁金香 + 树叶校准、冻结，预测其余四段，与六段联合拟合并列报告。
6. **PX 与 PX-R 并列**：两者都完整拟合，比较 χ²、检验量与 §4.5 的一致性。

### 7.7 产出

拟合参数（条件于 Q_ref、D_ref）与剖面区间；§4.5 一致性表；全部检验观测量（含带）；六段 V0.5 风格视频（图案演化 + 轨迹面板 + 参考帧）；每段残差表与已知失败（§5 的 ✗ 项）的并列图。

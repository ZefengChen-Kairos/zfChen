## 0. 一句话、适用范围、与 v3.1 的关系

**一句话。** 杯面是一张等压漂浮层，白（奶泡筏，相占据率 c）与褐（画布）共用一个只由面积源驱动、停源即精确静止的势流 u = ∇φ；白只来自附在当前射流上、每次加流后延迟 τ_w 才建立、以 wQ/Γ 在射流脚外环上生成的成团奶泡，射流脚外一个时间闭合的表面涡让落点保持褐洞，高位细流的驻点压力超过内聚压 Π_coh 时就地把筏打散成画布，这就是切线。

**适用范围。** 只模拟绘制阶段（注满之后、≤ 30 s）：低位倒奶、移动、摆动、前推后退、多段推挤、抬缸细流画线与切、杯倾回正、液位上升。输入是从视频提取的动作，参数取自六段联合拟合。

**与 v3.1 的关系。** v3-min 是 v3.1 在 13 个命名极限 L1–L13 下的约化（推导、判据与失效症状见 §2）。v3.1 的储层 ψ、Kynch 层 B、膜应变 ε、压实 φ_r、体相柱 G_B,k、团块库存 𝒞、ALG2 都不进入 v3-min；任何扩展都只能一次放开一个极限（§8）。

与学长 H0 门的关系（裁判嫁接 G-H1）：H0 的 c_p、β 只以膜压扩散率 D_Π = c_p²/β 出现，物理上 D_Π = E/ζ = 5×10⁻³–0.18 m²/s；旧拟合值 1.8–1.9×10⁻⁴ m²/s 落在 v3.1 的"可动画布"极限里，该极限预言的白前推挤 0.06–0.08 D 已被重测否定（≤ 0.01–0.03 D）。取 D_Π → ∞ 正好得到 (P)，所以 v3-min 就是 H0"单层单速度"的刚性极限加上射流附着的出白律，不是另起一个状态。

**定稿时做的四个决定**（相对 judge.md 第 8–9 节；依据 `spec_work/` 的 128² 实测）：

1. **射流脚排除（新增，零参数）。** 供给核在 |x − x_j| < r_c 内的部分被重新卷入，按 L11 的极限在其余部分重新浮出（核在脚外重新归一化）。它修好了 PX 的两处实测缺陷：C 形从闭合（0°）变为朝壶开口；白内褐斑从 8.6–12.5 mm² 降到 0–1.4 mm²（96–256²）。落点褐洞保持，dA/dt 精确不变。（"供给按回流套层掩模、涡与汇同心"的变体也会开口，但 3 s 时落点被白填满，否决。）
2. **新液面只在画布份额上重生（裁判 F-1(i) 的后半）。** 回流落在筏下时不生成液面，记为液面面积净汇；切线在 t_r 后的加宽从 62% 降到 16%。
3. **否决 F-1(i) 的前半与 κ。** 重生环外移到供给环外侧（变体 pxo）：3 s 时落点褐洞被白填满，与 V1 相反。净新液面 κ = 1：定点缝只从 0.014 D 变为 0.016 D。两者都没过裁判的验收线，不进模型；V7 的缝如实标 ✗。
4. **κ 腾出的名额给 α_F。** α_F 改为拟合，不固定在先验中心（硬约束：不得把文献值当答案），并用剖面似然检查它是否被数据钉住（§7.6）。r_e 用参考倒奶的褐洞半径 r_{e,ref} 参数化（裁判建议）。

拟合参数共 5 个：Γ、τ_w、r_{e,ref}、Π_coh、α_F。

## 1. 物理图像

1. **漂浮层**：白是奶泡筏，褐是画布（液面 + 吸附膜）。画布等压，发散型液体表面流推不动它，漂浮层只随面积源运动；被推挤的筏年龄 0–7 s，新生、薄、屈服应力小，与画布共用势流 u = ∇φ。
2. **出白**：成团奶泡在射流脚外的环上 ≲ 0.1 s 内浮出，生成筏面积 wQ/Γ；环随奶柱倾角向下游偏 Δ_e，落进射流脚 r < r_c 的部分被卷回、在环的其余部分重浮，所以上游空缺：C 形开口朝壶，远侧更亮。
3. **延迟**：每次加流（起倒，或抬缸后压低加大流量）后的 τ_w 内没有成团奶泡（壶内屈服的奶泡层要滑到嘴才出来，或近场需要重建，对杯面等价）；减流不重新计时，所以紧接抬缸的细流仍能画茎、画天鹅颈。
4. **表面涡**：吞汇两相都吞；被吞的画布 t_r 后在褐洞内的环上重生为新液面（落点褐洞），环被筏覆盖处不生成液面；被吞的筏在低位立即在供给环重浮（移到白上时落点被填回）。
5. **切**：细流驻点压力超过 Π_coh，核 r_d 内的筏就地变成画布（切线宽 2r_d）；慢走时供给沿路径画出宽 (1 − f_d)Q/(ΓV) 的白线（茎、天鹅颈）。
6. **停倒**：供给与吞汇立即消失，在途液面 t_r 内重生完，之后精确静止（引理 F）。

## 2. 推导：每一项都是 v3.1 的命名极限

### 2.1 运动学：从 (V) 到 (P)

v3.1 §3.6 的漂浮层速度是凸泛函 (V) 的唯一极小。依次取 L1（画布合并为一区，π̄ 对筏厚的反馈可略，W 项与筏缘线积分退出运动学）、L2（筏的偏应力阻力，即屈服项 2hτ_y|D|_e 与塑性粘度项 2hη_p|D|_e²，相对拖曳可略）、L3（筏厚钉扎在 h_eff，N(h)∇·u 由体积约束 c(∇·u − σ_raft) = 0 取代）、L4（U_l^σ = 0，ζ_R = ζ_C）、L5（f_J = 0），剩下

```
\min_u \int_\Omega \tfrac12\zeta|u|^2 dA \quad s.t.\quad \nabla\cdot u = \sigma - \dot e\,(1-c),\qquad u\cdot n = w_{\partial\Omega}\cdot n .
```

Euler–Lagrange 方程为 ζu + ∇λ = 0，所以 u = ∇φ（乘子 λ = −ζφ 就是画布表面压的扰动部分）。ζ、E、ΔΠ_c、τ_d、τ_y、η_p 全部从运动学中消失：**运动学零参数**。

L2 的两个判据（PX §2.1）：

```
Bn_d = \zeta\,\Delta U\,L/(2\tau_y h) \gtrsim 1,\qquad Bq = 4\eta_p h/(\zeta L^2) \lesssim 1\quad(\ell_v=\sqrt{4\eta_p h/\zeta}) .
```

本杯数值（源强 3.8 cm²/s，距源 1.5 cm，推心旧块 L = 2.6 cm，ζ = 1 Pa·s/m）：h = 0.3 mm 时 Bn_d = 3.0 / 0.61 / 0.15（τ_y = 0.1 / 0.5 / 2 Pa），Bq = 0.05 / 0.53（η_p = 0.03 / 0.3 Pa·s）；成熟筏 h = 3.35 mm 时 Bn_d ≤ 0.27、Bq ≥ 0.6，L2 不成立。所以 L2 只对年轻、薄、尺度 ≳ ℓ_v（0.6–3.3 cm）的筏成立。取它的理由：视频里被推元素一律变形而不是平移（月牙、回包、远侧更密），而刚体极限让缝闭合（v3.1 F3）；拟合后复核（§4.5）。

### 2.2 白源：L6–L9

v3.1 的出白链（回涌 t_r → 储层浮选 → 画布下 Kynch 层累积到 b_* 成核，或并入筏底）把空间记忆放在液面上。三条视频证据否定了这种"液面附着剂量"（PX §2.2，裁判 §3 复核）：推心第 2 段 B 在 5.73–6.93 s 被倒 1.27 s 不出白，射流移入凹口后 7.13–7.20 s 在当前落点出白（剂量阈预言 B 在 7.20 s 出白、凹口不早于 8.54 s）；推心第 1 段停倒后补白 ≈ 0（在途剂量律给约 2 cm²）；推心第 3 段压低加流 1.1–1.3 s 后在落点出白。由此取四个极限，全部是 v3.1 已列出的分支：
- **L6**（§3.8a H-B2 强极限 k_s b_* > r_K 处处成立）：单泡不在画布成核；v3.1 的 F1（体相气使全杯变白）与 F2（三难）在结构上消失，因为缝、线、杯壁处没有剂量。
- **L7**（§3.9 t_cl → 0）：成团奶泡在射流脚外就近浮出。
- **L8**（§6-7 PB-D1，φ_j(t) 本是输入）：能成白的流量 G(t)wQ，G = 𝟙[t − t_k ≥ τ_w]。t_k 是最近一次加流事件：Q 自下而上穿过 Q_* = 8 mL/s，或从 Q = 0 恢复。减流不重新计时。
- **L9**（§3.9 高斯足迹律）：打散份额 f_d = (r_d/r_sub)² = ln(p_0/Π_coh)/ln(p_0/p_sub)，截断到 [0, 1]，w = 1 − f_d。数值：低位 p_0 = 120–194 Pa < Π_coh 时 f_d = 0；细流 p_0 = 416–712 Pa、Π_coh = 300 Pa 时 f_d = 0.09–0.20。

Q_* 只用来切段：它落在细流 2–5 mL/s 与大流量 10–20 mL/s 之间，5–10 mL/s 内取值不改变切段（T8）。

### 2.3 近场：L10–L13

- **L10 时间闭合表面涡**（v3.1 M1–M2 中 F_up,0 ≈ F_c 取精确，加 C5"画布被覆盖处不回涌"）：吞汇在 r_0 < |x − x_j| < r_c 以 F = α_F·2πr_0v 吞掉液面（两相）；进入在途的液面 F_tr = F(1 − c̄_s) + f_dF c̄_s；t_r = c_tT_f 后在延迟落点的重生环 K_e 上按当地画布份额 (1 − c) 重生，落在筏上的份额不生成液面，记"筏下回流"（液面面积净汇）。
- **L11 瞬时吞—浮**（v3.1 §3.9 回浮取 t_cl → 0，判据 V_j t_cl ≪ r_sub：低位 0.8 mm ≪ 3.7 mm）：被吞而未打散的筏 (1 − f_d)F c̄_s 立即在供给环重新浮出。推论（**射流脚排除**）：落在射流脚 |x − x_j| < r_c 内的供给被同一规则立即卷回、再浮出，几何级数的不动点就是"供给核限制在脚外并重新归一化"；上游扇区因此被排除，这就是 C 形开口。
- **L12 打散核**：p_J = p_0e^{−r²/r_0²} > Π_coh 的核心 r < r_d 扫过的筏就地变为画布（面积守恒相变）。
- **L13 点状内区几何**（v3.1 §3.7，d/D = 0.02–0.07）：r_c = r_0 + δ_c，r_e = r_0 + (r_{e,ref} − r_{0,ref})；回涌偏移 Δ_e = ½min(z_m, H) tan α_j 由输入导出（G-K1），截在 0.95(r_e + r_c) 以下，否则环与射流脚脱开，与 heart 起笔帧"白紧贴奶柱脚"相反；核宽比例固定：重生环 [0.5, 1] r_e、供给环 [1, 1.5] r_e，都以偏移点为心。

### 3.3 核（紧支撑，在杯内重新归一化，∫K dA = 1；q(s) = (1 − s²)₊²）

```
K_c \propto \mathbb 1[r_0<|x-x_j(t)|<r_c]                                                   （吞汇环）
K_f \propto q\big((|x-x_f|-1.25r_e)/(0.25r_e)\big)\cdot \mathbb 1[|x-x_j(t)|\ge r_c],\quad x_f=x_j(t)+\Delta_e\hat e(t)   （供给环，脚外）
K_e \propto q\big((|x-x_e|-0.75r_e)/(0.25r_e)\big),\quad x_e=x_j(t-t_r)+\Delta_e\hat e(t-t_r)                          （新液面重生环）
```

圆与网格单元的相交用 q16（每格 4×4）固定求积，不设核宽下限（v3.1 T11）；核在杯壁截断后重新归一化。

### 3.4 方程

```
\bar c_s=\int c\,K_c\,dA,\qquad \sigma_c=-F\,K_c,
\sigma_f=\big[G\,w\,Q/\Gamma+(1-f_d)\,F\,\bar c_s\big]\,K_f,
F_{tr}(t)=F(1-\bar c_s)+f_d F\bar c_s,
\sigma_e=F_{tr}(t-t_r)\,K_e\,(1-c),\qquad \dot S_{ur}=F_{tr}(t-t_r)\int K_e\,c\,dA\quad(\text{筏下回流，记账}),
\dot R_{core}:\ c\to 0\ \text{在本步扫过的胶囊}\ \{\mathrm{dist}(x,\text{射流路径})<r_d\}\ \text{内（面积守恒相变）};

(P)\quad u=\nabla\phi,\quad \nabla^2\phi=\sigma_c+\sigma_f+\sigma_e-\dot e\,(1-c),\quad \partial_n\phi=w_{\partial\Omega}\cdot n,
\qquad \dot e=\Big[\int(\sigma_c+\sigma_f+\sigma_e)\,dA-\dot A_{cup}\Big]\Big/\int(1-c)\,dA ;
(C)\quad \partial_t c+\nabla\cdot(c\,u)=\sigma_f+c\,\sigma_c-\dot R_{core}.
```

画布方程 ∂_t(1 − c) + ∇·((1 − c)u) = σ_e + (1 − c)σ_c − ė(1 − c) + Ṙ_core 与 (C) 相加正好是 (P)。

量纲：σ、ė、Ṙ 为 1/s；GwQ/Γ 与 F 为 m²/s，乘 K [1/m²] 后为 1/s；φ 为 m²/s。

**引理 F（精确冻结）。** 设最后一次 Q > 0 的时刻为 t_s，杯倾与液位静止（Ȧ_cup = 0）：
- t > t_s 时供给与吞汇为零；
- t > t_s + t_r 时在途液面用完，σ_e = 0；
- 于是 (P) 是齐次 Neumann 问题，φ = const，u ≡ 0，c 逐点不变。

离散上，面心速度由同一个 φ 差分得到，严格为零；不需要 β 型阻尼。原型实测：停倒后筏面积变化 −1.2×10⁻⁷ cm²，自 t_s + t_r 起 max|u| = 0。

### 3.5 边界与初始条件

- **杯壁**：∂_nφ = w_∂Ω·n（锥形杯液位上升的新面积）；c 零法向通量；核在杯壁截断后重新归一化。
- **杯倾**：在参考圆盘 ξ 上求解，x = A(t)ξ，A = s(t)·R_θ diag(1/cosθ, 1)R_θᵀ；Laplace 带度量 G = A⁻¹A⁻ᵀ det A，Ȧ_cup = A_cup·d ln det A/dt 进入 ė（v3.1 §3.13）。
- **初始**：c = 0，在途包为空，t_k = 第一次起倒；片子从倒奶中途开始时（郁金香）缓冲装入外推输入，该段首白不进拟合。

### 3.6 账本（逐步检查，机器精度）

1. **面积**：∫c dA + ∫(1 − c) dA ≡ A_cup(t)。筏面积满足 dA_r/dt = GwQ/Γ − f_dF c̄_s − Ṙ_core,tot。
2. **能成白的奶泡体积**（取代 v3.1 的奶泡体积）：∫₀ᵗ GwQ dt′ = Γ[A_r(t) − A_r(0)] + Γ∫₀ᵗ(f_dF c̄_s + Ṙ_core,tot)dt′。第二项是已打散的部分，其气体进入体相，按 L6 不再成白。
3. **液面（表面涡）**：∫F_tr dt = 已在画布重生 + 筏下回流 ∫Ṡ_ur dt + 在途。
4. **液体与液位**：V_cup(ζ) = V₀ + ∫(1 − φ_j)Q dt（筏不改变液位，v3.1 §3.13）。
5. **数值**：净裁剪（改变 ∫c 的修正）验收为 0（≤ 10⁻¹² 相对）；守恒重分配量单列报告（§6.1）。

## 6. 数值格式与回归测试

### 6.1 离散

- **网格**：N × N 方域内接参考圆盘，阶梯掩模，格心存 c、φ；128² 时杯内 12 892 格，Δx = 0.625 mm。拟合用 96²/128²，复核用 192²/256²。
- **(P)**：5 点格式 + Neumann（壁面面通量 0）+ 度量 G(θ)。稀疏 LU（`splu`）每个 θ 档（0–25°，1° 一档）分解一次（每档 < 0.1 s），全部评估共用；锥杯外扩只改标量 s(t)。右端按 ė 配平后钉住一格，每步一次回代。面心速度 u_f = G∇_fφ（MAC），离散散度精确等于右端（实测残差 × Δt ≤ 8×10⁻¹³），面积账本闭合到舍入误差。
- **VOF (C)**：方向分裂（x–y、y–x 交替）；PLIC（Youngs 法向，杯外取最近杯内值）给精确条带面积；中间扫掠的散度项用 Weymouth–Yue 指示函数 c_c = 𝟙[c > 0.5]；最终守恒更新 c* = cⁿ − ΣF_PLIC + Δt(σ_f + cⁿσ_c)，之后做打散核相变与有界性修正。
- **有界性：守恒重分配**（代替裁剪，裁判 G-H2 的目标）。越界 e_i = (c*_i − 1)₊ 分给面邻格的空余 (1 − c*_j)₊，欠量 (−c*_i)₊ 从面邻格按 c*_j 扣除，至多 3 遍；剩余记"净裁剪"（验收 ≤ 10⁻¹² 相对），搬动量记"重分配"（验收 ≤ 10⁻³ × 本步生成的筏面积）。含义是满格新生筏面积向邻格的亚格位移，∫c 精确守恒，账本 2 不受影响（PH 的源项指数积分会破坏它，因为筏厚钉扎要求逐步生成 GwQΔt/Γ）。定稿几何实测 max c = 1.0002（128²）/ 1.0049（256²）。
- **核与扫过沉积**：核只在其支撑的外接方窗内以 4×4 子样计算；移动射流（摆动 8.8 cm/s、细切 2.4–4.8 cm/s）在一步内按 ≤ Δx/2 细分路径沉积，Δt 不受 Δx/|ẋ_j| 限制；打散核对扫过的胶囊与 PLIC 多边形做 8×8 子样相交（不重复扣除）。
- **"储层"的替代**：没有储层场，记忆只有两样。(i) 在途液面包：每个子步把 F_trΔt 存为一个包（释放窗 [t + t_r, t + Δt + t_r)、延迟中心 x_e），按窗重叠精确释放，变步长下账本 3 仍精确。(ii) t_k：闸门按子区间的精确开启份额计算，τ_w 光滑地进入目标函数。
- **时间步**：Δt = min(20 ms, 0.5Δx/|u|_max, 0.2/max|σ|)，试步越界则重算；|u|_max ≈ 2 cm/s，max|σ| ≈ 7–11 /s，128² 上 Δt ≈ 11–20 ms。无重力波 CFL、无 ALG2、无迭代。
- **每步顺序**：(1) 输入与缓冲 → 射流导出量、G(t)；(2) 源与核（记 c̄_s、F_tr、Ṡ_ur）；(3) ė 与 (P) 回代；(4) VOF 守恒更新；(5) 打散核相变；(6) 有界性重分配；(7) 账本、ζ(t)、A(t)，按 15 fps 输出 c。

## 7. 联合拟合方案（六段一起）

### 7.1 输入提取（动作是输入，不是参数）

每段先用段首帧杯沿椭圆（5 点手工拟合）定一个固定的杯内沿参照，不逐帧归一化（v3.1 §8.3）。然后提取：θ(t)（杯沿纵横比，只在起笔 1–2.5 s 非零）；x_j(t)（落点，每 0.2 s 一个手工关键帧，样条插值）；ê(t)、α_j(t)（壶嘴朝向与出流角）；z_sp(t)（低位与抬缸两个工作区的关键帧）；Q(t)（`pitcher.py` 堰流律由壶倾角关键帧算出，全局标度是规范）；t_k（Q(t) 穿过 Q_* 自动切段，人工核对一次后冻结）。输入在拟合中冻结；其不确定度（z_s ±0.5 cm、切段 ±1 帧）只在 T11 与剖面似然中传播。

### 7.2 过程帧观测量与提取

同一个提取算子 P 作用于视频与渲染：杯内沿仿射到参考盘 → 亮度 L* 按每段画布峰与白峰归一化为 w ∈ [0, 1] → 阈值 0.5 得白掩模 W；积分量直接用 w。渲染端按 v3.1 §3.12 的线性材质由 c 着色后再经 P。

|---|---|---|---|---|
| g1 | 首白时刻 − t_k（9 个阶段；郁金香第 1 段无起倒，除外） | 各段起笔 | x_j 周围 0.15 D 内白面积首次 ≥ 0.05 cm²，帧间插值 | 0.07 s ⊕ 0.1 s |
| g2 | 白面积斜率 dA/dt | 各低位出白段 [t_首白 + 0.5 s, 段末 − 0.2 s]，剔除壶嘴遮挡帧 | W 面积（cm²，D = 8 cm 规范）线性拟合 | 10% |

只作检验的量（§4.4）用同一算子提取，拟合后报告，不进目标函数。末帧量（IoU、白占比、边界距离）一律只作检验：A17 表明末帧面积会奖励光滑圆盘。

### 7.3 目标函数

```
J(\theta)=\sum_{g=1}^{5}\frac{1}{n_g}\sum_{i\in g}\Big(\frac{O_i^{sim}(\theta)-O_i^{vid}}{\sigma_i}\Big)^2 .
```

按组等权，防止某组因个数多而主导（例如 9 个首白）；同时报告未加组权的 χ² 与每组残差表。任何模拟失败（越界、账本 > 10⁻¹²）令 J = +∞ 并单独记录。

### 7.4 先做合成回收（T11，学长 E3）

在六段真实输入上，用宽界内对数均匀抽取的 3 组参数生成合成过程帧，加 §7.2 的 σ 噪声与输入扰动（Q 规范 ±20%、z_s ±0.5 cm、切段 ±1 帧），从 3 组确定性初值回收。报告回收误差、CMA/Fisher 协方差的相关矩阵与条件数；出现 |相关| > 0.9 的参数对时合并或固定其一，并升版本号。

### 7.5 联合 CMA-ES

5 维、对数参数化，λ = 10，60–100 代（含一次重启），共 600–1000 次评估；前 2/3 代用 96²，后 1/3 用 128²。一次评估（六图约 85 s 倒奶，4 核按图并行）在 96² 约 10 s、128² 约 18 s 墙钟，合计 2–3.5 h。最优点及 ±1σ 点在 256² 复核（T10 的 5% 线）。

### 7.6 补偿检查

1. **分段拟合交叉检查**：S1 g1 → τ_w（近似闭式：中位数(t_首白 − t_k) 减可见延迟 0.02–0.03 s）；S2 τ_w 固定，g2 → Γ；S3 g3 → r_{e,ref}；S4 Γ 固定，g4 → Π_coh；S5 g5 → α_F。某参数的联合值与分段值相差 > 2σ_剖面即判为补偿，并报告是哪一组残差在推它。
2. **剖面似然**：每个参数在宽界内（或联合最优 ±3σ 内）取 5 点，其余 4 个热启动 CMA（λ = 6，10 代，约 60 次评估，96²），共 1500 次评估，4 核约 4 h。全界内 Δχ² < 1 的参数判为"未被视频钉住"（α_F 可能如此），其值不作物理结论，依赖它的预测给成带；剖面最小点与联合最优不一致说明 CMA 未收敛。
3. **L8 残差检验**：首白残差与 Q、z_s、液位、段序的 Spearman |ρ| > 0.6 即判 L8 受质疑。
4. **留一段交叉验证**（可选，约 3 h）：六次各少一段，报告参数漂移与被留段的预测误差。

### 7.7 产出

拟合参数与剖面区间；§4.5 一致性表；全部检验观测量；六段 V0.5 风格视频（图案演化 + 轨迹面板 + 参考帧）；每段残差表与已知失败（§5 的 ✗ 项）的并列图。

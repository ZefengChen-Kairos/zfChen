# 第 0 层壶模型：牛奶壶 → 倾斜出流 → 自由射流 → 2D 表层模型的输入

实现：`latte_imex/pitcher.py`；演示：`python -m latte_imex.run --control pitcher --N 256`，`python -m latte_imex.pitcher_demo`；
网页交互版：`web/pitcher_playground.html`。

## 0. 为什么不用三维流体

壶里的牛奶在倾斜过程中自由面近似保持水平（重力主导；壶的运动周期 ≳ 1 s，远慢于壶内第一阶晃荡周期 ≈ 0.3 s 的倒数，
所以液面来得及跟上）。壶嘴是一个尖顶 V 形堰口，出流只由"液面高出堰口多少"决定，这是 Francis/Kindsvater 以来的堰流
公式。出壶后的奶柱是抛体运动，直径按连续性收缩，10 cm 以内不会破碎。所以整条链是几个代数式加一个常微分方程，
不是偏微分方程，每帧微秒级，浏览器里就能跑。三维 CFD（VOF/FLIP）只用来离线标定两三个系数（§6）。

## 1. 坐标与姿态

- 世界系：z 向上，咖啡液面 z = 0，杯面中心为原点。杯坐标（2D 求解器用）= 世界 (x, y)/D_L，D_L = 杯径 8 cm。
- 壶体系：Z 沿壶轴向上，X 指向壶嘴。姿态 R = R_z(yaw)·R_y(tilt)·R_x(roll)，tilt > 0 使壶嘴向下。
- 姿态的参考点取壶嘴 V 口的顶点 **tip**（奶离开壶的地方），因为用户拖的是壶嘴而不是壶底：
  世界点 = tip_world + R·(P_body − tip_body)。

## 2. 壶的几何（参数化，7 个数）

旋转体轮廓 r(z) 分段线性过 (0, r_bottom)、(z_belly, r_belly)、(H, r_top)，默认 350 mL 壶：
H 9.5 cm，r 3.4 / 4.0 / 3.0 cm，容量 378 mL。壶嘴：壶沿在方位角 |φ| < φ_w 处下切成 V 形，
z_rim(φ) = H − s·max(0, 1 − |φ|/φ_w)，s = 1.5 cm，φ_w = 25°（对应 V 口张角约 82°）；壶沿在壶嘴处径向外凸 12%（鸟嘴）。
V 口以上没有壁，所以内部采样点排除 z > z_rim(φ) 的区域。

内部体积用 34 200 个带权采样点表示（z、φ 均匀，r² 均匀），权重 dv = π r_body(z)²·dz/(n_r n_φ)。
任何姿态下"平面以下的体积"= 把采样点转到世界系后对 z 做加权分位数，O(N log N)，2.5 ms。
网页版同样做法（JS 里 2 万点排序约 1 ms），或者预先按倾角做成 V(tilt, c) 查找表。

## 3. 准静态液面

给定姿态和剩余体积 V，液面高度 c 由 Σ_{z_i < c} dv_i = V 决定（加权分位数，线性插值）。若 V 超过该姿态下壶能
容纳的体积，多出的部分当作溢出，本帧直接流走。

液面高出壶沿的 **水头** h(l) = c − z_rim,world(l)，沿壶沿曲线 l 取值；h_max 是它的最大值。

## 4. 堰流出流

尖顶堰（sharp-crested weir）积分形式，对壶沿上所有 h > 0 的弧元：

    Q_ss = C_d · (2/3) · √(2g) · ∮ h_eff(l)^{3/2} dl_h,     h_eff = max(h − h_k, 0)

dl_h 是弧元在水平面上的投影长度。对纯 V 口它退化成教科书的 V 形堰公式
Q = (8/15) C_d √(2g) tan(θ/2) h^{5/2}；代入 θ = 82°、C_d = 0.6：h = 9 mm → 9.5 mL/s，h = 13 mm → 25 mL/s，
正好落在学长估计的 6–24 mL/s。积分形式的好处是倾斜过头、侧滚、从整圈壶沿溢出都自动包含。

系数：C_d = 0.60（V 形堰 0.58–0.60），Kindsvater–Shen 水头修正 h_k = 0.8 mm（表面张力、粘性）。

瞬态修正（第 1 层的最小版本）：
- 起流/停流滞回：未流动时需 h_max > h_on = 2.5 mm 才起流（表面张力把奶扣在壶沿）；流动中 h_max < h_off = 0.5 mm 才停。
- 壶嘴通道的充放：dQ/dt = (Q_target − Q)/τ，起流 τ = 0.08 s，停流 τ = 0.15 s（停倒的拖尾）。
- 体积守恒：dV/dt = −Q。

**倾角不能单独决定流量**：同样 60° 倾角，壶里 250 mL 时 Q ≈ 105 mL/s，200 mL 时 31，150 mL 时 3。曲线很陡
（8 → 22 mL/s 只差 2°），这正是咖啡师靠手腕微调流量的原因，也说明从视频里读倾角估流量必须同时知道壶里剩多少
（学长 V1.2 的 T12 + M12）。见 `results/pitcher_demo/tilt_flow.png`。

## 5. 自由射流与冲击量

- 出口速度：Torricelli 在流量加权水头上，u₀ = √(2g h̄)，h̄ = ∮h^{5/2}dl / ∮h^{3/2}dl（V 口解析值 5h/7）。
- 出口截面：A₀ = Q/u₀，等效直径 d₀ = 2√(A₀/π)。
- 出口方向：沿壶嘴方向，在壶体系里比水平低 lip_slope = 10°，再转到世界系：v₀ = u₀·R·(cos α, 0, −sin α)。
- 射流起点：堰口上的流量加权点（V 口顶点附近）。
- 抛体：z(t) = z₀ + v₀z t − ½ g t²，落到 z = 0 的时间 t* = (v₀z + √(v₀z² + 2g z₀))/g；
  落点 x_hit = x₀ + v₀h t*；冲击速度 v = (v₀h, v₀z − g t*)。
- 2D 模型要的量：U⊥ = −v_z，u_h = v₀h（水平分量不变），d_jet = d₀·√(u₀/|v|)（连续性收缩）。
- 是否成束：Weber 数 We = ρu₀²d₀/σ，层流射流破碎长度 L_b ≈ 19.5 d₀ We^{0.325}（Grant & Middleman）。
  典型 d₀ 5 mm、u₀ 0.4 m/s：We ≈ 18，L_b ≈ 25 cm，远大于拉花的 2–8 cm 落差，所以"连续奶柱"假设成立。

典型数值（200 mL、tilt 56°、壶嘴离液面 1.5 cm）：Q 15 mL/s，h̄ 7 mm，u₀ 0.37 m/s，d₀ 7 mm，落差 1.7 cm，
U⊥ 0.68 m/s，u_h 0.14 m/s，d_jet 5.3 mm；抬到 7 cm 后 U⊥ 1.2 m/s，d_jet 2.2 mm。

## 6. 接到 2D 表层模型（Coupling）

位置量按几何直接换算（除以 D_L，精确）。三个速率量各带一个尺度常数，因为 V0.5 的控制量是"有效单位"而非 SI：

| 2D 输入 | 来源 | 换算 |
|---|---|---|
| x_hit | 抛体落点 | /D_L |
| S_eff | Q | c_S·Q，c_S 使 15 mL/s ↦ 0.05（V0.5 心形圆盘段的值） |
| U⊥ | 冲击法向速度 | c_U·U⊥，c_U 使低位 0.70 m/s ↦ 0.263 D_L/s |
| u_in | 射流水平速度 | c_u·u_h，c_u 使 0.15 m/s ↦ 0.5 D_L/s，再按 V0.5 的 60° 限幅 |
| d_jet, r₁, r₂, φ | V0.5 的连续性椭圆规则 | 由 (S_eff/κ_Q, U⊥, u_in) 算出 |

三个常数是"要从视频学的物理参数"的一部分；现在的取值只是把物理量级对到 V0.5 的量级上。
因为 U⊥ 现在只在低位/高位之间变 2 倍（物理值），而 V0.5 靠把足迹半径缩到 0.0015 让 U⊥ 变 34 倍来关掉沉积，
沉积开关尺度要相应改：B_dep = 4（低位 χ ≈ 0.85，高位切割 χ ≈ 0.1），其余参数同 θ05。见 `PHYSICAL_PARAMS`。

## 7. 虚拟咖啡师（动作的"意图层"）

输入不再是入口记录，而是咖啡师的意图：奶柱落点路径（杯坐标）、壶嘴高度、想要的流量 Q_want。
- 瞄准：壶嘴位置 = 目标落点 − 上一帧的射流水平偏移（咖啡师看着奶柱落点而不是壶嘴）。
- 手腕：倾角速率 = K_p (Q_want − Q) + K_i ∫(Q_want − Q)，限幅 60°/s；奶还没到壶沿时按 60°/s 甩到起流；
  停倒按 60°/s 回正。这样"倒得越久要越倾斜"（V 掉、h 掉）会自动出现，倾角从 56° 爬到 63°。
- 心形脚本 `heart_moves()` 按 V0.5 的心形写成意图：远侧低位圆盘 15 mL/s 4 s → 9 mL/s 回到中心 → 抬到 7 cm 从中心
  向近侧切 0.8 s，流量 4 → 1 mL/s → 停。

结果：`results/pitcher_demo/`（inputs.png 八个时间序列；side_view.png 四个时刻的侧视；final.png / movie.mp4 是
IMEX 求解器在 N = 256 下用这些输入跑出的心形，共倒出 61 mL）。

## 8. 第 0 层没管的事（第 1、2 层）

- 壶与杯的碰撞：已做（`Cup`、`Pitcher.required_lift`）：杯子向壶身一侧倾斜（默认 20°），每帧求壶壁不碰杯沿、杯壁、咖啡面、桌面的
  最小抬高量并抬高；低位铺盘时参数化壶要抬 0.8 cm，NX 壶不用抬。
- 晃荡：画叶子时 5–8 Hz 的横向抖壶接近壶内第一阶晃荡模态（7 cm 口径约 3.6 Hz），会调制流量；可加一个阻尼振子
  描述液面倾斜。
- 奶泡分层：壶内上层是微泡沫，出壶的泡沫比例随时间变；先按常数。
- 出口方向与收缩系数、C_d、h_k、h_on：要用"水 + 色素 + 秤 + 尺"的自拍实验或离线 VOF 标定。

## 9. 第 1 层：壶的加速度、晃荡、带出速度（已实现，`OutflowLaw.slosh`）

第 0 层假设液面水平，只在壶匀速运动时成立。咖啡师抖壶时壶在加速：横向抖动 3.6 mm、2.5 Hz 的加速度约 0.9 m/s²，
8 mm、4 Hz 约 5 m/s²，与 g 同量级。在壶的参考系里有效重力是 g − a，液面要垂直于它。

- 运动学：壶嘴位置按帧差分得速度 v 和加速度 a，加速度经 τ = 0.02 s 低通（`acc_tau`）。
- 准静态斜率：s_qs = −a_h/(g + a_z)，a_h 为水平加速度。
- 第一阶晃荡模态当受迫阻尼振子：s'' + 2ζω s' + ω² s = ω² s_qs，ω² = g·k·tanh(kH)，k = 1.841/R，
  R 取壶腹半径，H 取当前液深 V/(πR²)；默认 ζ = 0.3（奶泡阻尼大，待标定；ζ = 0.08 时 2.5 Hz 的抖壶在 NX 壶里正好共振，
  液面倾到 45°，奶柱在壶沿两侧来回跳，落点横跨大半个杯子，显然不对），斜率上限 tan 20°。200 mL 的参数化壶 ω/2π ≈ 3.1 Hz，
  抖壶频率（2.5–6 Hz）就在共振附近，所以不能只用准静态，也不能把阻尼取得太小。
- 液面法向 n = (−s_x, −s_y, 1)/‖·‖；液面高度、壶沿水头、湿周弧元都改为沿 n 度量；堰流和出口速度里的 g 换成 |g − a|。
- 带出速度：奶柱离开壶嘴时带着壶的速度，v₀ = u₀·e_spout + v_pitcher，之后仍只受重力。横向抖壶 3.6 mm、2.5 Hz 的
  壶速幅值 0.06 m/s，与出口速度 0.37 m/s 相比不小，落点摆幅因此从 0.045 增大到 0.059 杯径并带相位差。
- 虚拟咖啡师相应改成"看平均流量"（Q 经 0.25 s 低通再进 PI）和"瞄平均落点"（偏移经 0.3 s 低通），抖动起止各有 0.25 s 的包络。

结果（`results/pitcher_level1/wiggle_pulsation.png`，ζ = 0.3）：横向抖壶使壶嘴处水头在 V 口两侧反向涨落，净流量几乎不变
（3.6 mm，2.5 Hz 看不出脉动；8 mm，4 Hz 约 10%）；前后抖壶 3.6 mm、2.5 Hz 就能让流量在 3 到 27 mL/s 之间脉动，更大幅度时每个周期
断流。V0.5 千层心靠猜的 flow_modulation = 0.85 在物理上对应"抖动里有前后分量"。
但把这条物理链接到 2D 模型后，千层心（横向、前后、大幅三种抖法，N = 128）都只得到一个圆盘或带缺口的盘，没有同心弧纹
（`results/pitcher_level1/*_final.png`）。原因是 V0.5 的叠层来自 ±1.4 杯径/s 的射流横向速度，而物理壶速只有它的 1/7；
也就是说奶柱横向动量传给表层的效率（c_u）或 2D 模型里奶柱推开表层的机制，是下一步要从视频学的东西，壶模型本身给不出。

## 10. 用你的 NX 壶（STEP）替换参数化壶（`pitcher_cad.py`，`GridPitcherGeometry`）

`python -m latte_imex.pitcher_cad latte_imex/pitcher_geom/pitcher_nx.stp` 把 STEP 实体细分、按水平面切片，取壁环的
内孔为内腔，用柱坐标描述：内壁半径 r_in(z, φ)、外壁半径 r_out(z, φ)、每个方位角的壶沿高度 z_rim(φ) 与半径 r_rim(φ)，
壶嘴（壶沿半径最大处）转到 +x，单位换成米。内部采样点按 (z, φ, r²) 均匀生成，权重 ½ r_in² dφ dz / n_r。
JSON 不依赖 CAD 库；网页用同一份 JSON（`web/pitcher_nx.json`）。

这只壶：内腔 519 mL，高 100.7 mm，内径 81 mm 的直筒，壁厚 2.1 mm，壶沿是平的（没有 V 口），壶嘴是约 ±10° 宽、
外伸 7 mm 的鸟嘴。倾斜时鸟嘴尖是最低点，堰流积分自动把它当堰顶，湿周约 17 mm。
装 275 mL 时 15 mL/s 需要倾角 55°，8 到 22 mL/s 只差 3°（`results/pitcher_nx/tilt_flow.png`）。
直筒加鸟嘴的几何比参数化壶更不容易撞杯：低位铺盘时壶壁最低点在咖啡面上方 0.6 到 1.0 cm（`results/pitcher_nx/side_view.png`）。

V0.5 入口回放 · 末帧对照

五张图同一朝向：物理俯视，x 向右，+y 在上（壶把和咖啡师在 +y 一侧，拉花从上往下切）。蓝框是当前选的这一组。动作是 Codex 猜的，不是视频里咖啡师的动作，所以只能比末帧图案，不能比时间。

这一组是什么

入口回放，不是壶链脚本：把 Python 求解器（latte_imex，单层 IMEX，闭合 'chi'，回流律 v05）实际收到的入口按 1/120 s 一帧导出（落点 x_hit、S_eff、u_in、U⊥、d_jet、足迹椭圆 r₁ r₂ φ、扫描速度；全物理组另有壶嘴高 z、接收流量 Q、χ），在这里直接喂给同一个 2D 求解器。帧内线性插值，帧长规则与 run.run 相同。128² 上与 Python 用同一张表复放的末帧几乎逐位一致（|Δc| ≤ 3e-8）；与原始 Python 运行相比 IoU(c > 0.4) ≥ 0.996（量化表和帧内插值带来的小差别）。虚拟咖啡师、壶模型和耦合都绕过；闭合参数用该组自己的一套（见下表）。3D 壶只是摆姿势：奶柱落在 x_hit、壶嘴在高度 z，壶里没有流动物理。

闭合参数

重新猜的（不是测量）

  • 每一笔的壶嘴高度：P2 反设计。在共享闭合 B_dep = 1550 D/s²、p_dep = 8、κ_r = 0.0373 下，逐笔解出高度，让该笔流量加权的 χ 逼近 V0.5 同一笔的 χ（差 ≤ 0.02）；全部落在物理范围内。本图案的逐笔数值见下表。
  • 流量脉动的相位事后再猜：两种相位都是看过结果之后才改的动作，不是先验设定。郁金香、树叶、天鹅把峰从摆到两端（Codex，π）挪到过中线（0），沿用报告 P4f 的修补，是 P4 用 π 在中轴扫出褐色空洞之后才改的；千层心挪到回摆途中（π/2，strictfp90），是看过 π 和 0 都不成形之后才改的。
  • 路径、时序、摆幅、摆频都沿用 Codex 的猜测；大白心、推推乐没有脉动。

注意

  • p_dep = 8：这一组的沉积开关很陡，几毫米高度就从全沉积切到不沉积；反设计顶到了上界，不是拟合值。后来的补跑（最终组 FS 的 p_dep = 2 变体，即 V0.5 自己的指数）六个图案也都成形，只是摆动铺底多沉积、白区大 1.15–1.33 倍，所以陡开关不是必需的。
  • 这里回放的是复核时的严格组 strictB3。最终组 FS 在它上面又把出口水平速度的下限只加在出口部分、加了 0.08 s 的壶嘴滞后、让笔与笔之间的高度连续变化，256² 上同样六个都成形，图和这里很接近（见 latte_imex/V05_ALLPHYS_RESULT.md）。
  • 大白心：心形和尖都在，但上半有一条从凹口往下劈到心中部的褐缝（strictB3：沿轴 c < 0.6 计 32 mm，c < 0.4 计约 19 mm；c < 0.6 的缝宽约 4 mm）。V0.5 只有 4 mm 的凹口。
  • 线条更宽：足迹大 3–5 倍；郁金香、树叶的白底变成两根细条，树叶叶脉偏淡（对比约为 V0.5 的 0.8）。
  • 天鹅：头、颈和最后补白要压到 0.3–0.55 cm，近乎贴面倒；喙变短或卷成钩。
  • 比的是 V0.5 自己的图：IoU(c > 0.4) 大白心 0.71、推推乐 0.82、千层心 0.68、郁金香 0.61、树叶 0.76、天鹅 0.75（256²）。IoU 不能当成形的证据，判断看结构（千层心 0.68 也成形）。
  • V0.5 原版按原样回放，这些数倒不出来；3D 壶的高度只是示意（低位 1.0 cm、切 2.5 cm）。
  • 网页默认 96²，比 256² 粗，细线、叶脉、天鹅颈会更糊；看细节请选 256²（约 1/8 实时），或看上面 Python 预算的 256² 图。

和真实视频比

全物理和 V0.5 离真实视频一样远。两者与真实末帧的 IoU（模拟 c > 0.4 对真实 w > 0.5）原样只有 0.29–0.68，最佳刚体对齐（±25°、±0.06 D）后 0.39–0.74；全物理减 V0.5 在 −0.04 到 +0.11 之间，六个图案平均 +0.01。两者共同离真实的差距比彼此之间的差大得多（多数图案大一个量级，大白心大 3–4 倍）：图案偏小（大白心、千层心、树叶的真实白区 0.34–0.39，模拟 0.17–0.27）；细褐线少而宽（树叶 66 道对 24–28 道，天鹅 74 对 12–13，千层心每瓣 8–10 道弧对 3–4 道）；元件布局不同（推推乐的独立小心和单侧外弧、郁金香叠起的几颗心、天鹅没有单独的身体，Codex 的动作里都没有）。这些差距不是入口物理化造成的；它们来自猜的动作还是模型本身（单层闭合、足迹、扩散），这次比较分不开，要用从视频读出的真实动作（stage_scripts）去跑才能分开。
